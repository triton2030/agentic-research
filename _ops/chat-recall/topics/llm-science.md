# Научное исследование поведения и управления LLM

В этой теме владелец определяет научный статус работы по изучению LLM и критерий оценки исследований на пользу скилам и базе знаний agentic-research.

## Статус работы

- Владелец решил считать текущую работу новым важным научным проектом по изучению LLM, а не только набором скиллов или экспериментов, и выделить для неё новую папку в корне с полным научным документом по изучению LLM. [2026-08-04-140649-claude-d8fcf6fd.md#L15]

## Критерий оценки исследований

- Владелец задал критерий полностью прочитать исследование arXiv 2605.06717 при оценке его пользы для скилов и базы знаний agentic-research. [2026-08-19-034014-codex-01a01707.md#L15]
- Владелец уточнил критерий свежести: дата публикации за последние полгода недостаточна, если исследование проведено на уже старых моделях; поколение экспериментальных моделей оценивается отдельно. [2026-08-25-115044-codex-01a037ac.md#L18]
