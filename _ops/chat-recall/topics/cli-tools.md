# Маршрутизация к установленным CLI по версии и ситуации

`1cli-tools` нужен для сообщения агенту о новых возможностях терминальных инструментов, которых нет в памяти агента. При предположении о наличии на его устройстве уже установленных инструментов агент должен проверять и релевантно переиспользовать их, чтобы ускорить работу и не разрабатывать уже доступное заново.

## Назначение

- Владелец определил цель `1cli-tools`: при предположении о наличии на его устройстве уже установленных инструментов агент должен проверять и релевантно переиспользовать их, чтобы ускорить работу и не разрабатывать уже доступное заново. [2026-08-09-165811-codex-019fe662.md#L20]
- Владелец уточнил, что `1cli-tools` нужен для сообщения агенту о новых возможностях терминальных инструментов, которых нет в памяти агента. [2026-08-19-160259-codex-01a019a8.md#L20]

## Форма

- Владелец решил, что `1cli-tools` должен иметь маленькое компактное вызывающее тело, а подробности новых возможностей — в разделённых по разделам reference-файлах. [2026-08-09-165811-codex-019fe662.md#L21, 2026-08-19-160259-codex-01a019a8.md#L22]

## Критерии основного текста

- Владелец задал критерием, чтобы основной текст `1cli-tools` описывал ситуации применения — работу с Markdown, дизайном, кодом и проверками. [2026-08-09-165811-codex-019fe662.md#L22]
- Владелец задал критерием рефактора `1cli-tools` минимальное число строк, содержащих только самое главное. [2026-08-09-165811-codex-019fe662.md#L19]

## Разрешение конфликтов версий

- Владелец предпочитает решать конфликты терминальных инструментов обновлением обеих конфликтующих вещей до новых версий, поскольку последние версии могут не конфликтовать между собой. [2026-08-19-160259-codex-01a019a8.md#L19]

## Режим выполнения

- В рамках переработки `1cli-tools` владелец предпочитает автономное выполнение всего цикла без дополнительных вопросов. [2026-08-19-160259-codex-01a019a8.md#L21]
