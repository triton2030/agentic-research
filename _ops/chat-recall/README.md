# chat-recall

Руда source-bound выдержек слов владельца: файл на разговор
`<дата>-<время первой записи>-<агент>-<session8>.md`, строка на реплику со
временем до секунды и классификацией `type: … | topic: …`. Шапка файла — его
инвентарь: `types`/`topics` для сканирования без чтения тела, `session` — ключ
к полному транскрипту разговора, пока его не удалил retention.

Статус: датированное сырьё, не текущая правда. Сказанное могло быть позже молча
отменено — агенты не читают эту папку перед решениями по своей инициативе;
только явная команда владельца или его harvest-задача (повторяющиеся коррекции
→ правка инструкций, автоматизмы).

Пишет `1chat-recall` сам в момент, когда прозвучало: решение, коррекция,
red line, предпочтение, критерий, важное число, сырая идея на будущее,
durable-хвост императива. Выдержка строится преимущественно удалением речевого
шума, повторов, разовой команды и вставленного чужого материала; сохраняет
лексику, смысл, условия и числа владельца без интерпретации агента. Чужой
вставленный текст не попадает; сохраняется только явно выраженное отношение
владельца к нему. Каждый разговор пишет только свой файл и только про то, что
в нём прозвучало; без session id скрипт отказывает — общий файл смешал бы
разговоры.

Ограничения метаданных: `model`, если присутствует, — точно известная resolved
модель, создавшая файл (разговор мог продолжиться другой моделью); `date` —
день первой записи (разговор через полночь остаётся в файле своей даты).

Записи не редактировать. Превращение выдержки в правило `AGENTS.md` /
`CLAUDE.md` или decision `GOAL.md` — отдельный manual проход.

Предшественник — `../user-said/`, заморожен (записи по 2026-05-28).
