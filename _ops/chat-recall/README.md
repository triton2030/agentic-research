# chat-recall

Руда source-bound выдержек слов владельца: файл на разговор
`<дата>-<время самой ранней сохранённой цитаты>-<агент>-<session8>.md`, строка
на реплику с полным timezone-aware source timestamp и классификацией
`type: … | topic: …`. Шапка файла — его инвентарь: `types`/`topics` для
сканирования без чтения тела, `session` — ключ к полному транскрипту разговора,
пока его не удалил retention.

Статус: датированное сырьё, не текущая правда. Сказанное могло быть позже молча
отменено — агенты не читают эту папку перед решениями по своей инициативе;
только явная команда владельца или его harvest-задача (повторяющиеся коррекции
→ правка инструкций, автоматизмы).

Свежую реплику `1chat-recall` пишет в том же ходе. Цитату, восстановленную из
старого хода этого же разговора, он пишет с timestamp исходной transcript
record, никогда с часами запуска helper-а. Timestamp отсутствует, не содержит
timezone, transcript удалён retention-ом или schema неизвестна — запись
отклоняется, дата не угадывается. Legacy session-файл со строками только
`HH:MM[:SS]` сначала требует отдельного source-bound восстановления из своего
transcript; helper не дописывает к нему новые цитаты.

Сохраняются решение, коррекция, red line, предпочтение, критерий, важное число,
сырая идея на будущее и durable-хвост императива. Выдержка строится
преимущественно удалением речевого шума, повторов, разовой команды и
вставленного чужого материала; сохраняет лексику, смысл, условия и числа
владельца без интерпретации агента. Чужой вставленный текст не попадает;
сохраняется только явно выраженное отношение владельца к нему. Каждый разговор
пишет только свой файл и только про то, что в нём прозвучало; без session id
скрипт отказывает — общий файл смешал бы разговоры.

Ограничения метаданных: `model`, если присутствует, — точно известная resolved
модель, создавшая файл (разговор мог продолжиться другой моделью); `date` —
локальный день самой ранней сохранённой source-цитаты. Если позже добавлена
более старая цитата, helper переименовывает этот же session-файл и обновляет
`date`/заголовок; текст уже сохранённых цитат не меняет.

Текст записей не редактировать. Превращение выдержки в правило `AGENTS.md` /
`CLAUDE.md` или decision `GOAL.md` — отдельный manual проход.
