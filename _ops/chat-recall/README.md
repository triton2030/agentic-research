# chat-recall

Дневной лог слов владельца: `YYYY-MM-DD.md`, строка на реплику, со временем.

Пишет `1chat-recall` сам, в момент, когда прозвучало устойчивое — решение,
коррекция, red line, предпочтение, критерий, важное число. Цитата дословная,
слегка очищенная от речевого шума; интерпретация агента сюда не попадает.

Записи не редактировать. Превращение цитаты в правило `AGENTS.md` / `CLAUDE.md`
или в decision `GOAL.md` — отдельный manual проход.

Предшественник — `../user-said/`, заморожен (записи по 2026-05-28).
