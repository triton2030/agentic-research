# Карта тем

Словарь тем корпуса `_ops/chat-recall/`: чем помечается запись в поле `topic`.
Это единственный владелец словаря — файлов-пересказов по темам больше нет, и
тема ничего не утверждает о позиции владельца. Её работа одна: собрать записи
одного предмета так, чтобы поиск находил их вместе.

Перед записью цитаты агент читает этот список и выбирает тему по смыслу
предмета, а не по совпадению слов. Подходящей темы нет — заводит новую строкой
здесь же, в том же ходе: короткое латинское имя долгоживущего предмета и одна
строка границы. Близкая тема есть — берётся она, новая не плодится.

записях не использовать; в старых остаются как есть.

- `thinking-methods` — поглощена `mental-model-checks`
