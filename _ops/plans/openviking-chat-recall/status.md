# Статус — библиотека знаний из chat-recall

## Next

Волна переразметки топиков в `raw/`. Решение владельца 2026-08-24
(`raw/2026-08-24-125426-claude-832fc1f8.md`): система своя, не OpenViking;
тема цитаты при записи выбирается из существующих, новая создаётся осознанно
(`--new-topic` уже в скиле и скриптах); поле `topic` у всех старых записей
переписывается субагентами на словарь слоя — имена файлов `topics/`, чтобы оба
маршрута поиска (сырой архив и дистиллированные темы) сходились в одной точке.
Механика по слову владельца: много Codex-субагентов, по 4–5 файлов цитат на
каждого, меняют только поле `topic`; полный транскрипт сессии доступен по
`session` из шапки файла. Текст цитат неприкосновенен.

Вторым номером — схлопывание повторов слоя: две волны обновления извлекли одни
и те же факты в разное время, и слой копит по два пункта на факт с разными
якорями; стадии слияния, обещанной docstring-ом `apply_update.py`, не
существует. Без неё растёт не знание, а объём, и разбор дрейфа якорей
предлагает каскадные сдвиги (2026-08-24: 4 висячих якоря из 1336 оставлены
как есть).
