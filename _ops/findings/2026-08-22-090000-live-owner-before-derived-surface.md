# Производная поверхность не заменяет live owner

Повторившийся класс сбоя: агент принимал roster, ожидаемый baseline,
canonicalized path или знакомую форму CLI за полный действующий контракт.

Перед мутацией проверять owner тем же интерфейсом, который будет исполнен:
`--help`/targeted probe для CLI, отдельные lexical и canonical identities для
filesystem boundary, exact address для task state. Summary и нормализованное
представление остаются маршрутом, не доказательством интерфейса.
