# Autonomous Capture Skip

## Observation

Модель замечает дешёвый append-only сигнал, но оставляет его только в ответе
пользователю вместо автономной записи через owner-skill. Причина: основной
аудитовый фрейм держит внимание на выводе, а не на in-flight capture.

## Counter

- 2026-05-20 [GPT-5.5]: при аудите `1md-navigator` нашёл проектную находку:
  навигатор не индексирует `~/.codex/skills` / `~/.claude/skills`, потому что
  `.codex` / `.claude` default-excluded. Написал это в ответе, но не вызвал
  `1findings` сразу. User поправил: «проверь почему ты не вызываешь сам
  1findings».

## Possible upgrade

Когда в ответе появляется формулировка «нашёл странность / конфликт /
не сходится / это уже не стилистика», сразу применить тест: проектная находка
с источником -> `1findings`; AI-поведение -> `1self-learning`.
