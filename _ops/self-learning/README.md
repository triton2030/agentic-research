# Self-Learning

Legacy/read-only поверхность.

Живой маршрут новых записей: `1findings` → `_ops/findings/**` с префиксом
`self-learning:`.

Папка хранит старый сжатый список уроков о поведении ИИ: промахи с намерением,
скилами, инструментами, лишним ритуалом или преждевременным действием.

Новые записи сюда не добавлять без явной отдельной миграции. Агент может читать
`lessons.md` как исторический контекст, но новые self-learning факты пишет в
`_ops/findings/**`.

Форма файла осталась Obsidian-friendly Markdown. Это слой чтения, не второй
источник правды.

Не сюда: проектные баги, фичи, архитектура и новые self-learning факты
(`1findings`); буквальные устойчивые цитаты пользователя (`user-said`, только
manual/legacy).
