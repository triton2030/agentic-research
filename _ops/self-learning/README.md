# Self-Learning

Владелец: `1self-learning`.

Живой файл: `lessons.md`.

Папка хранит один сжатый список уроков о поведении ИИ: промахи с намерением,
скилами, инструментами, лишним ритуалом или преждевременным действием.

Новые записи не создают тематические файлы. Агент читает `lessons.md`,
обновляет секцию своего агента (`GPT-5.5`, `Claude Opus 4.7`, `Other agent`),
сливает повторы и переписывает файл целиком до 4000 символов.

Форма файла — Obsidian-friendly Markdown: несколько уровней заголовков,
короткие bullets, выборочные callouts и полезные wikilinks к локальным
owner-файлам. Callouts не должны заменять всю структуру файла. Это слой чтения,
не второй источник правды.

Не сюда: проектные баги, фичи и архитектура (`1findings`); буквальные
устойчивые цитаты пользователя (`1user-said`).
