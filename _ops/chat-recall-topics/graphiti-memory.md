# Эксперимент Graphiti для преобразования цитат в память

Владелец решает, как адаптировать штатный Graphiti для преобразования полного корпуса цитат в связанную базу знаний с заново сформулированным смыслом, а не для хранения самих цитат. Тема также задаёт архитектуру ingest и критерии сравнения полезности Graphiti с 1chat-recall.

## Цель и границы результата

- Владелец уточнил, что целью Graphiti/Codex является связанная база знаний с заново сформулированным смыслом его цитат, а не хранение самих цитат. [2026-08-18-151822-codex-01a0145e.md#L31, 2026-08-18-151822-codex-01a0145e.md#L37, 2026-08-18-151822-codex-01a0145e.md#L38]
- Владелец поправил границу пользовательской поверхности Graphiti: она не должна давать ссылки на существующие цитаты. [2026-08-18-151822-codex-01a0145e.md#L39]

## Архитектура и интеграция

- Владелец предложил как правило не изобретать новую систему и не ломать штатную реализацию Graphiti, которая уже доказала работоспособность; он уточнил, что задача Graphiti/Codex состоит в замене штатной обработки языковыми моделями на нашу. [2026-08-18-151822-codex-01a0145e.md#L40, 2026-08-18-151822-codex-01a0145e.md#L49]
- Владелец решил попробовать установить Graphiti в experiments/agentic-research и слегка адаптировать его для анализа данных через Codex вместо Graphiti API, одновременно проверив возможные готовые решения. [2026-08-18-151822-codex-01a0145e.md#L30]
- Владелец уточнил, что полезный контекст можно записывать вместе с цитатой в Graphiti, если это не меняет архитектуру и не уводит от философии Graphiti. [2026-08-18-151822-codex-01a0145e.md#L47, 2026-08-18-151822-codex-01a0145e.md#L48]
- Владелец предложил проверить, может ли Graphiti писать в один чат, представляя запросы как сообщения пользователя. [2026-08-18-151822-codex-01a0145e.md#L61]
- Владелец уточнил, что для записей Graphiti без точного времени нужно восстанавливать время по часовому окну между соседними файлами, используя дату сессии и порядок цитат внутри целевого файла; для двухнедельного корпуса порядок важнее точности минут и секунд. [2026-08-18-151822-codex-01a0145e.md#L50, 2026-08-18-151822-codex-01a0145e.md#L51, 2026-08-18-151822-codex-01a0145e.md#L52, 2026-08-18-151822-codex-01a0145e.md#L53]

## Ingest и выполнение

- Владелец уточнил, что целью является обработать всю папку чата и записать её в Graphiti. [2026-08-19-023138-codex-01a016c7.md#L17]
- Владелец уточнил, что Graphiti нужно существенно заполнить файлами цитат за пару недель по полной методике, а затем гонять запросы с помощью 1codex-bg-threads. [2026-08-18-151822-codex-01a0145e.md#L33]
- Владелец решил использовать фоновые треды с Luna Max, которая будет следить, чтобы полный ingest не останавливался до конца. [2026-08-19-023138-codex-01a016c7.md#L18]
- Владелец предложил ускорить Graphiti-ingest правильной параллельностью, если это возможно. [2026-08-18-151822-codex-01a0145e.md#L41, 2026-08-18-151822-codex-01a0145e.md#L42]
- Владелец решил оставить episodes последовательными, сохранить четыре параллельных Luna-turn внутри одного episode и перейти на один тёплый Codex app-server с новым Ephemeral thread для каждого Graphiti-вызова. [2026-08-18-151822-codex-01a0145e.md#L64, 2026-08-18-151822-codex-01a0145e.md#L67]
- Владелец предпочитает короткие наблюдаемые запуски Graphiti-ingest вместо одного долгого запуска, который приходится долго ждать. [2026-08-18-151822-codex-01a0145e.md#L54, 2026-08-18-151822-codex-01a0145e.md#L55]
- Владелец предложил проверить, может ли один правильно составленный промпт позволить агенту сразу создавать множество записей со связями в Graphiti. [2026-08-18-151822-codex-01a0145e.md#L56]

## Модели и retrieval

- Владелец решил использовать для LLM-вызовов Graphiti модель Luna Max: Terra не дала существенного выигрыша по скорости, а Luna дешевле. [2026-08-18-151822-codex-01a0145e.md#L32, 2026-08-18-151822-codex-01a0145e.md#L62, 2026-08-18-151822-codex-01a0145e.md#L63]
- Владелец сообщил, что в 1chat-recall есть локальная модель эмбедингов. [2026-08-18-151822-codex-01a0145e.md#L34]
- Владелец предложил выяснить, используют ли модели Graphiti языковые модели без скилов, памяти и, возможно, без reasoning, чтобы определить, нужен ли Luna на минимальном уровне мышления. [2026-08-18-151822-codex-01a0145e.md#L44]
- Владелец предположил, что модели Graphiti могут только получать переданные им данные и выдавать один ответ, не имея права читать и писать. [2026-08-18-151822-codex-01a0145e.md#L45]
- Владелец предположил, что Sol/medium или даже Luna Max справится с записью целого файла цитат в Graphiti в требуемом Graphiti-формате. [2026-08-18-151822-codex-01a0145e.md#L57, 2026-08-18-151822-codex-01a0145e.md#L58]

## Исследование и оценка

- Владелец решил собрать с официального сайта Graphiti документацию о его философии и о том, как должны вести себя агенты или Luna, чтобы субагентам было легче искать дальше. [2026-08-18-151822-codex-01a0145e.md#L35]
- Владелец задал критерий для этого Graphiti guide: будущий агент должен иметь возможность диагностировать и исправлять интеграцию без повторного поиска с нуля. [2026-08-18-151822-codex-01a0145e.md#L36]
- Владелец предположил, что официальная документация Graphiti должна содержать рекомендации по параллельности. [2026-08-18-151822-codex-01a0145e.md#L43]
- Владелец уточнил, что при изучении Graphiti предпочитает ориентироваться на официальную документацию, GitHub или код на GitHub и оценивать саму систему, а не её скорость. [2026-08-18-151822-codex-01a0145e.md#L59, 2026-08-18-151822-codex-01a0145e.md#L60]
- Владелец задал для A/B-проверки shared и Ephemeral критерий: память должна улучшать качество ответа, а ответы нужно вручную сравнивать на разных сериях вопросов, а не только на одной; для каждого запроса нужно сопоставить выданные ответы и отдельно сравнить один и тот же запрос в Graphiti и 1chat-recall по полезности. [2026-08-18-151822-codex-01a0145e.md#L65, 2026-08-18-151822-codex-01a0145e.md#L66, 2026-08-19-122330-claude-01a016c7.md#L15]
