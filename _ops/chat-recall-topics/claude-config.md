# claude-config

Обе реплики решают состав глобального окружения Claude Code — отключаемые ключи settings.json, снос MCP-сервера и стартовый контекстный след агентов, — а существующие темы покрывают только инструкции, routing skills или внешние provider-мосты, не сам runtime-конфиг.
