# Final Check

## Knowledge check

- Did you name the real failure mode or control lever?
- Did you separate stable knowledge from local inference?
- Did you avoid answering with generic prompt-writing slogans?

## Portability check

- Would this still help in another repo or on another machine?
- If something is local, did you label it as local instead of pretending it is universal?
- Did hidden chat context stay out of the final advice?

## Artifact check

- If you built a prompt, agent, or skill, did you inject only the relevant subset of the library?
- Did you avoid turning the artifact into a dump of all known rules?
- Is the main file still readable and durable?

## Honesty check

- If the stronger fix is outside prompting, did you say so?
- If the evidence is weak, did you mark uncertainty or escalation instead of acting sure?
