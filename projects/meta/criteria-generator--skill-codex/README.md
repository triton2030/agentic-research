# Criteria Generator — Codex

Кодекс-версия скилла `criteria-generator`. Рядом лежит клодовская версия: `projects/meta/criteria-generator--skill-claude-code/`.

## Что Это

Тот же скилл: берёт пользовательскую задачу, читает контекст проекта, возвращает исходный промпт с добавленными LLM-устойчивыми критериями приёмки. Перед глубокой генерацией критериев он теперь опирается на `ops/` как на свой операционный слой: ищет `ops/NORTH-STAR.md`, а если `ops/` или `NORTH-STAR.md` отсутствуют, создаёт их в минимальном виде и уже потом продолжает.

## Отличия От Клодовской Версии

- `TodoWrite` → `update_plan`.
- Нет отдельного `AskUserQuestion` — уточняющие вопросы задаются обычным текстом, пользователь отвечает в чат.
- `Skill` tool не требуется — Codex подгружает скиллы нативно, достаточно активации по имени.
- `Read`/`Write`/`Bash` — нативные файловые и шелл-инструменты Codex.
- Операционные артефакты скилла живут в `ops/`: там же лежит и минимальный `ops/NORTH-STAR.md`, если проект его ещё не завёл.

Остальное (discovery, EVPI, adversarial pass, quality gate, формат output, Red Flags) — без изменений по сути, но discovery теперь поднимает `ops/NORTH-STAR.md` в приоритет и допускает создание минимального north-star note до дальнейшей работы.

## Файлы

- `SKILL.md` — ядро, адаптированное под Codex.
- `references/discovery-map.md` — карта источников контекста.
- `references/failure-modes.md` — каталог типовых LLM-халтур с пробами и контрмерами.
- `references/format-examples.md` — три рабочих примера output на разных типах задач.

Во время исполнения сам скилл может создавать только свои служебные файлы в `ops/`.

## Куда Деплоить

В пользовательский каталог скиллов Codex (ориентировочно `~/.codex/skills/criteria-generator/`). Путь подтвердить по текущей конфигурации Codex перед деплоем.

## Открытые Вопросы

- Как Codex реагирует на frontmatter-описание в SKILL.md. В Claude Code сильный императивный description критичен для срабатывания; в Codex это стоит проверить отдельно.
- Нужна ли дополнительная регистрация скилла через `plugin.json` или `config.toml`. Клодовская версия работает сразу после размещения файлов в `~/.claude/skills/`.
