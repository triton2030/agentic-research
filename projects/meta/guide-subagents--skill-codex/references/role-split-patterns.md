# Role Split Patterns

- `Explorer` — один узкий вопрос по кодовой базе, контексту или фактам. Не владеет write scope.
- `Worker` — ограниченная продуктивная работа с disjoint write scope.
- `Validator` — проверка, критика или независимый второй проход без утечки ожидаемого ответа.
- `Default` — только если работа реальна, но не попадает в более узкую роль.

## Правила

- Сначала назови локальный следующий шаг главного агента. Его не делегируют только потому, что есть субагенты.
- Один субагент = один owned scope.
- Если два субагента тронут одни и те же файлы, split слабый.
- Лучше меньше субагентов с чёткими границами, чем “команда на всё”.
