# Ops — Claude Code

Рабочая папка по Claude Code-версии скилла `ops`.

Скилл заставляет агента не верить постановке на слово: сначала pressure-test framing, собрать траекторию задачи как рабочую гипотезу, пройтись от first principles и выбрать одну лучшую профессиональную роль, только потом действовать.

Если по всей переписке видно, что проблема не только в задаче, но и в самих агентных инструкциях проекта, `ops` может предложить короткую правку в `AGENTS.md` или другой project-local instruction layer. Не правит молча — только поднимает предложение.

Широкая работа с `ops/` вынесена в отдельный режим, но один маленький default-артефакт у `ops` теперь есть всегда: `ops/learnings.md`. Скилл должен при необходимости создать `ops/`, завести или подтянуть `learnings.md`, держать его короче 100 строк, переписывать его как компактную текущую выжимку вместо механического append и следить, чтобы project instructions требовали читать этот файл перед нетривиальной работой.

## Отличия От Codex Версии

Логика и этапы совпадают полностью. Главное отличие — шаг "вопросы":

- Claude Code использует `AskUserQuestion`
- варианты ответа можно дать через структурированный UI, а не обычным списком в чате

Смысл тот же: каждый вопрос имеет право на существование, только если ответ на него меняет выбор подхода или может доказать, что пользователь целится не туда.

Если пользователь явно просит создать или заполнить `ops/` шире, `ops` может перейти в отдельный `ops-folder mode` и уже там отдельно сформулировать главную цель проекта, записать `NORTH-STAR.md` или обновить другие явно запрошенные operational files. Это отдельный слой поверх обязательного `ops/learnings.md`, а не его замена.

Прочие соглашения переносятся один в один: гипотеза задачи, жёсткий pressure test рамки, first-principles проход, одна главная профессиональная роль, право прямо возражать пользователю, варианты с явной ценой выбора, анти-сикофантный блок и маленький meta-check на случай, если узкое мышление рождается из project instructions, а не только из самой задачи.

## Файлы

- `SKILL.md` — текущая Claude Code-версия скилла в репо.

## Ограничения

- Триггер размыт. Фактически скилл часто активируется через явное упоминание `ops`.
- Коллизия с `superpowers:brainstorming` — оба скилла перехватывают шаг до исполнения.
- После-выполнение завязано на наличии task/issue tracker файлов. Если их нет, часть хвоста не используется.
