# Discovery Map

For major execution tasks, start with:
- `_ops/PROJECT-ROADMAP.md` for Goal, relevant Stage, Approach, and Anti-goals.
- `_ops/INTERVIEW.md` for user-owned preferences and boundaries.
- Existing task files in the matching `_ops/plans/phase-NN-*` folder.
- Local owner docs/code only after the upstream anchor is clear.

If `_ops/PROJECT-ROADMAP.md` is missing or no Stage fits the task, stop task-file creation and route to `project-roadmap`. Do not substitute a `local-only` contract for missing strategy.

Use local sources only when they materially change criteria for this task.
