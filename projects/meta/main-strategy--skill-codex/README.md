# Main Strategy — Codex

Рабочая папка по Codex-скиллу `main-strategy`. Зеркало Claude Code-версии `projects/meta/main-strategy--skill-claude-code/` с codex-специфичными адаптациями.

## Что Это

Универсальный эксперт-стратег-консьерж. Принимает цель в любом домене (лендинг, книга, аналитика, маркетинг, дизайн, продукт, кампания, ресёрч) и адаптивно надевает нужную экспертную роль.

Скилл включается автоматически на:

- любой нетривиальной task-level работе;
- любом упоминании предпочтения пользователя (чтобы копить профиль);
- любом противоречии уже зафиксированному (жёсткий блок + диалог о мотивации).

Пользователь общается с скилом так, будто пришёл к эксперту-консьержу: говорит цель, отвечает на 3-4 интервью-вопроса про предпочтения и интент, получает opinionated план крупными мазками.

## Три Файла

- **`_ops/INTERVIEW.md`** — живой профиль предпочтений пользователя с адаптивными секциями под тип работы. Используется также как shared user profile для других агентов в новых чатах.
- **`_ops/PROJECT-PLAN.md`** — живой план: чёткий Goal, короткий Approach+Why, этапы со статусами `[ ] / [~] / [x]`. Крупные мазки, не 200-шаговый Gantt.
- **`_ops/learnings.md`** — дельты "реальность vs план/интервью". Не changelog, не retro.

## Внутренние Инструменты Мышления

Pressure-test, inversion, premortem, adversarial self-play, fresh-session check — скилл прогоняет в голове, **не** оформляет как видимые секции в файлах. Результат прогона превращается в opinionated рекомендацию пользователю или в шаг плана.

## Hard Block

Если пользователь просит что-то, что противоречит его же предпочтениям в INTERVIEW или шагу в PROJECT-PLAN — скилл **не** соглашается молча. Он входит в диалог, держит позицию и разбирается с мотивацией, пока она не станет понятной.

## Отличия От Claude Code Версии

Функционально и структурно идентичны. Различия платформенные:

- **Вопросы пользователю.** В Claude Code — через native `AskUserQuestion` tool с дискретными опциями. В Codex — текстом в чате в дисциплинированной форме (2-4 опции + "Своими словами", tradeoff в описании каждой, явный `Рекомендую:` когда есть позиция).
- **Progressive disclosure references.** В Claude Code `references/` открываются через Skill tool. В Codex скил загружается нативно, `references/` открываются через обычный file read по необходимости.
- **Активация.** В Claude Code — через `Skill` tool с именем. В Codex — нативно.

Core discipline одинаков: адаптивная экспертная роль, gate на task-level + preferences, hard block на противоречиях, внутренние мыслительные инструменты, три файла с жёсткими контрактами.
