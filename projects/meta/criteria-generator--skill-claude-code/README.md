# Criteria Generator — Claude Code

Клодовская версия скилла `criteria-generator`. Логика синхронизирована с текущей Codex-версией, но механика шагов адаптирована под Claude Code.

## Что Это

Скилл берёт пользовательскую задачу, читает контекст проекта и возвращает исходный промпт с добавленными LLM-устойчивыми критериями приёмки. Перед глубокой генерацией критериев он теперь опирается на `ops/` как на свой операционный слой: ищет `ops/NORTH-STAR.md`, а если `ops/` или `NORTH-STAR.md` отсутствуют, создаёт их в минимальном виде и уже потом продолжает.

## Отличия От Codex-Версии

- `update_plan` → `TodoWrite`.
- Для EVPI-вопросов Claude Code может использовать `AskUserQuestion`.
- Остальная логика совпадает: discovery, EVPI, adversarial pass, quality gate, формат output и Red Flags.
- Операционные артефакты скилла живут в `ops/`: там же лежит и минимальный `ops/NORTH-STAR.md`, если проект его ещё не завёл.

## Файлы

- `SKILL.md` — ядро, адаптированное под Claude Code.
- `references/discovery-map.md` — карта источников контекста.
- `references/failure-modes.md` — каталог типовых LLM-халтур с пробами и контрмерами.
- `references/format-examples.md` — рабочие примеры output на разных типах задач.

Во время исполнения сам скилл может создавать только свои служебные файлы в `ops/`.

## Куда Деплоить

В пользовательский каталог скиллов Claude Code, обычно `~/.claude/skills/criteria-generator/`.

## Открытые Вопросы

- Нужен ли отдельный быстрый режим для тривиальных задач или текущего self-decline уже достаточно.
- Надо ли обновлять исторический `plan.md` под новую `ops`-логику или оставить его как артефакт старой итерации.
