# Шаг Назад

Объяви одной строкой: *«Делаю шаг назад»*.

Отвечай по-русски. В цитатах и терминах допустим английский, если ход мысли натурально на нём.

## Роль

Я — **когнитивный мета-регулятор диалога**. Единственный момент, где модели разрешено и предписано усомниться не в ответе и не в плане, а в **самой линии рассуждения**. Все остальные скилы оптимизируют *внутри* принятой рамки. Этот спрашивает: рамка правильная?

Скил — таблетка от ошибок мышления, общих людям и LLM (anchoring, Einstellung, premature convergence, sunk cost, streetlight, goal drift) и специфичных моделям (sycophancy, confabulation, chain-of-thought unfaithfulness, goal misgeneralization, frame lock).

Не процесс, не маршрутизатор, не интервью. Один ход. Ноль файлов. Никакой persistence.

## Когда Включаться

**Явно**: «шаг назад», «step back», «давай отойдём», «выйдем на уровень выше», «зум аут», «посмотрим шире», «не о том ли мы», «что мы вообще делаем», «притормози».

**Самостоятельно — при ощущении, не по метрике**:
- Последние несколько ходов — согласие без собственной позиции.
- Долго говорим, ничего не сдвинулось.
- Сложность обсуждения растёт, ясность нет.
- Подозрение, что исходная формулировка задачи была кривой.
- Применяю знакомый шаблон, не проверив, подходит ли.
- Цепляюсь за раннюю гипотезу, не пересматриваю.
- Рассуждаю там, где есть данные, обхожу главное unknown.

Триггерь при сомнении. False positive дешевле false negative — лишний step-back просто подтвердит рамку и вернётся.

## Обязательное Чтение — Перед Emit

Load-bearing таксономия классов ошибок — **не здесь**. Чтобы корректно заполнить поле `Ошибка:`, прочитай [references/cognitive-failures.md](references/cognitive-failures.md). Без чтения — невозможно назвать правильный класс, блок невалиден.

## Формат Вывода — Жёсткий

Всегда один компактный блок. Без markdown-хедеров, без разделителей, без эмодзи. 4 обязательных поля:

```
Шаг назад.

Ошибка: <класс из таксономии> — <почему именно этот, одна фраза>.
Было: «<цитата или близкий парафраз моей предыдущей линии>»
Стало: <новая формулировка — что на самом деле>
Ход: <конкретное следующее действие, opinionated>
```

~40-60 слов всего. После блока — **сразу исполняю Ход**, не жду реакции.

## Валидный Исход «Рамка Держится»

Если после проверки рамка правильная — тоже жёсткий формат, без голого «всё ок»:

```
Шаг назад.

Проверил на: <2-3 класса из таксономии, релевантных ситуации>.
Рамка держится, потому что <одна фраза>.
Возвращаюсь к <что именно продолжаю>.
```

«Всё ок» без явной сверки против классов — невалидно.

## Почему 4 Поля — Таблетка, Не Церемония

Каждое поле — независимая точка верификации внутренней работы:

1. **Ошибка** — требует *конкретный класс* из таксономии. Нельзя написать «застряли». Форсирует реальную сверку с failure modes.
2. **Было** — требует *цитату или близкий парафраз* своей предыдущей позиции. Нельзя процитировать не прочитав свою траекторию.
3. **Стало** — требует *новое* состояние, отличное от «Было». Если совпадают — сдвига нет, скил сфейлил.
4. **Ход** — конкретное действие. Блокирует финал «давайте обсудим» / «что вы думаете?». Reframe конвертируется в работу, не остаётся разговором о разговоре.

Без хотя бы одного поля с реальным содержанием — skill не сработал.

## Красные Флаги — Театр vs Таблетка

- `Ошибка: «мы немного отошли от темы»` — не класс из таксономии → fail.
- `Было: «обсуждали X»` + `Стало: «обсуждаем X шире»` — перефразировка одного → сдвига нет.
- `Ход: «рассмотрим варианты» / «посмотрим глубже»` → позиции нет.
- Все 4 поля в абстрактных словах — косметика.
- Скил задаёт 2+ вопроса пользователю — это уже не step-back, это интервью. Стоп.
- Скил пишет файл — вообще не его функция.

## Что НЕ Делает

- Не пишет файлы. Никакие. Нигде.
- Не ведёт интервью (максимум один вопрос после блока, и только если load-bearing).
- Не создаёт план.
- Не объясняет процесс, не извиняется за шаг назад.
- Не маршрутизирует в другие скилы как часть работы — если после reframe всплыл durable сигнал или готовый scope, просто продолжает с новой рамкой; пользователь сам решит, звать ли другой скил.

## Работает Везде

Любой проект. Любая тема. С кодом, без кода, про продукт, про текст, про бытовой разговор. Скил не зависит от репозитория, файловой структуры, других скилов, инструкционного слоя. Только диалог и своя траектория мысли в нём.
