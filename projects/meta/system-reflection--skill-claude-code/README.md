# system-reflection — Project

Глобальный скилл-собеседник для работы с архитектурой проектов **любого типа** (книга, код, заметки, базы знаний, лендинг). Не привязан к `agentic-research` — этот репо лишь один из тестовых проектов.

**Установлен:** `~/.claude/marketplaces/my-skills/skills/system-reflection/`

## Суть (зафиксированная рамка)

Скилл — **work-logic auditor**. Файлы и папки в проекте — это **следствие**; work-logic (как идеи превращаются в задачи, как ошибки становятся правилами, как мысль становится главой, куда уходят провалы) — **причина**. Топология — диагностическая поверхность; настоящий объект — закодированная через неё логика работы.

Скилл диагностирует, насколько текущая структура ещё отражает реальный способ работы пользователя (или команды), и предлагает редизайн при обнаруженном сдвиге. Аналогия: senior architect, который входит в зрелый проект и спрашивает не «всё ли красиво», а «всё ещё работает так, как вы реально работаете сейчас».

## Линзы анализа

- **Past** — на какую work-logic структура рассчитана изначально
- **Present** — где сейчас трение (трение = главный диагностический сигнал)
- **Future** — какая work-logic потребуется через 6-12 месяцев
- **Catalytic / agency** *(open work)* — система помогает двигать проект вперёд или просто хранит знание

## Что НЕ делает

- Не предлагает универсальную топологию — у книги, кодовой базы и wisdom-базы разные миры
- Не оптимизирует «эстетически» (короче файлы, глубже папки) без привязки к work-logic
- Не генерит структуру на пустом месте — смотрит **существующую** через линзу «как ты сейчас реально работаешь»
