# design-auditor — Финальное решение 2026-04-17

После прохода 2.0.0 → 3.0.0 провели повторный аудит: почищенная структура не решает главную проблему — **design-auditor есть теневая копия уже установленных скиллов**.

Решение: **выпилить плагин, заменить на `knowledge/guides/design-review-playbook.md`**.

## Ландшафт скиллов на момент решения

- `my-skills:screenshot-design` — rigid, Visual Evidence Ledger, мандатен при screenshot-визуальных задачах (глобальный CLAUDE.md).
- `my-skills:playwright-skill` — flexible, mode 1 (flows), mode 2 (алгоритмический дизайн-аудит: APCA, spacing, weight, typography, reading order).
- `impeccable:critique` — двухагентный UX-ревью с AI Slop Detection и persona testing, каталог anti-patterns в `impeccable` base.
- `impeccable:audit` — технический pass (a11y, perf, responsive).
- `impeccable:arrange / typeset / colorize / polish / distill / clarify / …` — узкие подходы.
- `taste-skill:minimalist / brutalist / stitch / output` — эстетические mood-фреймы.

## Overlap-матрица

| Линза design-auditor 3.0.0 | Существующий сильнее |
|----------------------------|----------------------|
| `identity` (AI slop, distinctiveness) | `impeccable:critique` + `impeccable` base catalogue |
| `structure` (hierarchy + layout) | `screenshot-design` оси 1–3 + `impeccable:arrange` |
| `craft` (color, typography, contrast) | `screenshot-design` ось 4 + `impeccable:typeset`/`colorize` + `playwright-skill` APCA numbers |
| Dispatch 3 независимых агентов | `impeccable:critique` уже dispatch'ит 2 независимых sub-agents с grounded каталогом |

В каждой строке альтернатива имеет якорь (ledger / числа / каталог), которого у 3 prose-агентов нет.

## Failure-mode симуляции (10 сценариев)

1. **«Дизайн аудит» + скриншот** — CLAUDE.md → мандатен `screenshot-design`. design-auditor либо не триггерится, либо повторяет пиксельный разбор без ledger. Избыточно.
2. **«Дизайн аудит https://…»** — CLAUDE.md прописывает связку `playwright-skill + screenshot-design`. design-auditor не участвует в уже задокументированном паттерне.
3. **«Это AI slop?»** — `impeccable:critique` имеет grounded AI Slop Detection. `identity` — проза без каталога. Дубликат слабее.
4. **«Second opinion»** — после мандатного `screenshot-design` 3 агента повторяют анализ тех же пикселей без передачи ledger.
5. **Мелкая CSS-правка** — 3 opus агента на косметику. Cost/scale mismatch.
6. **Оркестратор забыл context** — SKILL.md предупреждает прозой, но не форсит. Агенты уходят в generic «best practice».
7. **Противоречия агентов** — нет протокола разрешения, опоры на ledger-якоря тоже нет.
8. **Дизайн-мок как файл** — SKILL.md прописывает playwright MCP для live URLs; для файла путь покрыт слабо.
9. **В сессии уже есть числа от `playwright-skill` mode 2** — design-auditor не умеет консумить, агенты игнорируют.
10. **Запрос про стиль (minimalist / brutalist)** — `taste-skill:*` покрывает явно. `identity` отдаст generic personality-проверку.

В 9 из 10 сценариев альтернатива из другого скилла даёт лучший результат. Уникальная ниша — только сценарий «adversarial слепой взгляд без якорей», и он редкий.

## Три направления, которые рассматривались

- **A. Router/composer** — рерайт design-auditor как композера `screenshot-design` + `playwright-skill` + каталог anti-patterns. Сильное, но требует рерайта.
- **B. Deprecate + playbook** — удалить плагин, написать `knowledge/guides/design-review-playbook.md` с явной картой композиций. **Выбрано.**
- **C. Узкий adversarial скилл** — оставить как «слепой взгляд без якорей». Ниша узкая, триггер неочевиден.
