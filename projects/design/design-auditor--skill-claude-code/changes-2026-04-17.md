# design-auditor 2.0.0 → 3.0.0

Дата: 2026-04-17. Изменения применены к `~/.claude/marketplaces/design-auditor/` и синхронизированы в `~/.claude/plugins/cache/design-auditor/design-auditor/3.0.0/`.

## Сжатие поверхности

Агенты: 5 → 3.

- Удалены: `render-integrity`, `hierarchy-scannability`, `layout-flow`, `visual-craft`, `distinctiveness`.
- Созданы: `structure` (merge hierarchy + layout), `craft` (=visual-craft упрощён), `identity` (=distinctiveness упрощён).
- `render-integrity` выпилен: его роль — проверить качество скриншота перед раздачей — перекладывается на оркестратора через явный пункт «Verify first» в SKILL.md. Отдельный агент для self-check избыточен.

## Модели

Все три агента: `model: opus` вместо `model: sonnet`. Меньше агентов — можно позволить более сильную модель без раздувания стоимости.

## Имена субагентов

Был баг: SKILL.md звал агентов по filename (`render-integrity`), а dispatcher использует frontmatter-поле `name:` (которое было в human-readable форме `"Render Integrity"`). Теперь `name:` в агентах = kebab-case filename (`structure`, `craft`, `identity`) — SKILL.md и dispatch совпадают.

## SKILL.md

Переписан по `perfect-skills.md` и `claude-code-skills.md`:

- Декларирован тип — **flexible**.
- Добавлены «When to use», «When not to use», «Context they need», «Done when».
- description стал «настойчивым»: перечисляет триггеры (ru/en), контексты, сценарии, и явно разводит поверхность с `screenshot-design` («breadth across lenses» vs «depth of evidence ledger»).
- Убраны: «Capture Strategies» таблица, «Re-use During a Session» — это шум.
- Workflow сжат до 4 шагов с явным требованием self-verify перед dispatch.
- Output contract: «ваш синтез, не dump агентских текстов».

## Capture

`scripts/capture_page.mjs` удалён. Причины:

1. Нарушал глобальный `~/.claude/CLAUDE.md`: «не поднимать отдельный Chromium — MCP уже работает».
2. Зависел от `playwright` в CWD пользователя через `createRequire` — хрупко для глобально установленного скилла.
3. Делал скилл «тяжёлым» — лишний инструмент, который можно заменить одной строкой в workflow.

SKILL.md теперь просто говорит: «capture whatever way you have — playwright MCP для live URLs».
