# Screenshot Design (Claude Code)

Рабочая папка по Claude Code-скиллу `screenshot-design`.

Скилл нужен для одной узкой задачи: разбирать интерфейс по скриншоту так, чтобы модель не отделывалась общими словами вместо настоящего визуального чтения.

## Что Это За Скилл

`screenshot-design` — скилл для визуального дизайн-аудита по одному или нескольким скриншотам.

Его фокус не на коде, не на Figma и не на браузерной проверке. Он нужен именно там, где важно понять, что видно на экране:

- как читается иерархия;
- где ломается логика блоков;
- где отступы собирают или разваливают структуру;
- насколько аккуратно работают выравнивание, плотность, ритм и контраст;
- выглядит ли экран собранным и намеренным.

## Чем Он Отличается От Обычного Design Review

Скилл не верит самоотчёту модели. Он требует сначала показать видимый след рассуждения, а уже потом делать выводы. Внутри это оформлено как обязательный `Visual Evidence Ledger`: набор наблюдений, привязанных к конкретным зонам экрана.

Фразы вроде «иерархия слабая», «spacing feels off», «выглядит чище», «дизайн стал премиальнее» скилл считает слабыми, если не показано, из чего они следуют.

## Структура

- `SKILL.md` — основной файл скилла
- `references/output-contract.md` — формат ledger, рекомендаций, comparison mode, uncertainty
- `references/failure-modes.md` — red flags и anti-bypass правила

Версия без `agents/openai.yaml` — это Claude Code, а не Codex.

## Установка

Скилл ставится в плагин `my-skills` и подхватывается Claude Code глобально.
