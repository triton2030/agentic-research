# pitch-coherence-audit

Claude Code skill.

Итеративный аудит инвесторских питч-материалов — deck, memo, script.
Вызывается часто во время работы над контентом: после правок текста,
смены структуры слайдов, правок дизайна. Цель — ловить моменты, когда
последние изменения повредили инвесторский посыл.

## Зачем он есть

Питч-контент нестабилен. Одна правка в wedge рушит coverage проблемы.
Уточнение metrics на слайде tractions может обессмыслить ask. Редактура
языка ради "понятнее" часто снимает уникальный insight. Такой дрейф
виден инвестору мгновенно и убивает интерес — его трудно поймать
глазом из-за привыкания к собственному тексту.

Скилл — это не генератор презентаций. Это стабильная рамка проверки:
6 осей того, что делает питч инвестиционно привлекательным, плюс
cross-cutting проверка coherence drift между ними.

## Тип

Rigid review skill. 6 осей и ledger не сокращаются и не адаптируются
в ходе одного прогона. Адаптация к стадии инвестора (pre-seed / seed /
Series A / growth) идёт через `references/stage-criteria.md` — меняется
планка proof и критерии "живой боли", но не структура аудита.

## Где соседи

- **impeccable:** — визуал слайдов, не текст.
- **simplify / impeccable:clarify** — общее качество прозы.
- **screenshot-design** — визуальный аудит рендера.
- **step-back / brainstorming** — выработка первичного нарратива, если его ещё нет.

`pitch-coherence-audit` срабатывает только на уже существующий текст
инвесторского питча. Если текста нет — сначала brainstorming, не этот скилл.

## Установка

Локально: `<repo>/.claude/skills/pitch-coherence-audit/` — копируются
`SKILL.md` и `references/`.

Глобально: пакуется в `my-skills` плагин, путь
`~/.claude/marketplaces/my-skills/skills/pitch-coherence-audit/`.

В установленную версию попадают только `SKILL.md` и `references/`.
`README.md` остаётся в проектной папке репо.

## Файлы

- `SKILL.md` — тонкое ядро: триггеры, рабочий ход, done when.
- `references/stage-criteria.md` — планка proof, живой боли и wedge
  по четырём стадиям.
