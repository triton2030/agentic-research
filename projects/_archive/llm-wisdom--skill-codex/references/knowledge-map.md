# Knowledge Map

Start by naming the current surface.

## If the question is about what models are like by default

Read:

- `model-behavior.md`
- `control-levers.md`

Examples:

- why the model agrees too easily
- why it silently assumes intent
- why long reasoning text does not prove reliable thinking

## If the question is about recurring quality degradation

Read:

- `failure-patterns.md`
- `control-levers.md`

Examples:

- hallucination
- stale-context mistakes
- scope drift
- overconfidence

## If the question is about the model "escaping" the work

Read:

- `escape-patterns.md`
- `control-levers.md`

Examples:

- says it verified but did not
- reports success on an easier adjacent task
- writes comments or summaries instead of doing the work
- narrows the scope without permission

## If the question is about building better prompts

Read:

- `prompt-design.md`
- `model-behavior.md`
- `control-levers.md`

## If the question is about building better agents

Read:

- `agent-design.md`
- `model-behavior.md`
- `control-levers.md`

## If the question is about building better skills

Read:

- `skill-design.md`
- `control-levers.md`

## Rule of thumb

If you are unsure, start with:

- `model-behavior.md`
- `failure-patterns.md`
- `control-levers.md`
