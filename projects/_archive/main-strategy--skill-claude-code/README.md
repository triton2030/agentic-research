# Main Strategy — Claude Code

Рабочая папка по Claude Code-скиллу `project-strategy`.

## Что Это

Универсальный эксперт-стратег-консьерж. Принимает цель в любом домене (лендинг, книга, аналитика, маркетинг, дизайн, продукт, кампания, ресёрч) и адаптивно надевает нужную экспертную роль.

Скилл включается автоматически на:

- любой нетривиальной task-level работе;
- любом упоминании предпочтения пользователя (чтобы копить профиль);
- любом противоречии уже зафиксированному (жёсткий блок + диалог о мотивации).

Пользователь общается с скилом так, будто пришёл к эксперту-консьержу: говорит цель, отвечает на 3-4 интервью-вопроса про предпочтения и интент, получает opinionated план крупными мазками.

## Три Файла

- **`_ops/INTERVIEW.md`** — живой профиль предпочтений пользователя с адаптивными секциями под тип работы (для лендинга одни секции, для книги другие). Используется также как shared user profile для других агентов в новых чатах.
- **`_ops/PROJECT-PLAN.md`** — живой план: чёткий Goal, короткий Approach+Why, этапы со статусами `[ ] / [~] / [x]`. Крупные мазки, не 200-шаговый Gantt.
- **`_ops/learnings.md`** — дельты "реальность vs план/интервью". Не changelog, не retro — только наблюдения, которые могут повлиять на будущие решения.

## Внутренние Инструменты Мышления

Pressure-test, inversion, premortem, adversarial self-play, fresh-session check — скилл прогоняет в голове, **не** оформляет как видимые секции в файлах. Результат прогона превращается в opinionated рекомендацию пользователю или в шаг плана, не в артефакт.

## Hard Block

Если пользователь просит что-то, что противоречит его же предпочтениям в INTERVIEW или шагу в PROJECT-PLAN — скилл **не** соглашается молча. Он входит в диалог, держит позицию и разбирается с мотивацией, пока она не станет понятной. Это не магическая фраза-override; это профессиональный диалог эксперта.

## Файлы

- `SKILL.md` — ядро скилла: роль, gate, interview/plan/learnings protocols, hard block, красные флаги.
- `references/file-contracts.md` — жёсткие контракты трёх `_ops/` файлов с negative list'ами. Открывается из SKILL.md перед write-шагами.

## Связь С Другими Скиллами

- `task-contract` — читает `INTERVIEW.md` + `PROJECT-PLAN.md` как upstream. `Anchored in:` в критериях ссылается на секции этих файлов.
- `instruction-layer` — читает `PROJECT-PLAN.md` (Goal + активный Stage) + `learnings.md` (реальные failure modes).
- `step-back` — dialog-time fallback для короткой pressure-test / reframe сессии, включается явно пользователем.
