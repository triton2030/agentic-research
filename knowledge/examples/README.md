# Examples

Постоянный корпус эталонов агентных инструкций, системных промптов и скиллов из дикой природы. Используется как pull-источник при написании новых: канон живёт в `knowledge/guides/perfect-*.md` и `knowledge/wisdom-*.md`, примеры — здесь.

## Структура папки эталона

```
{slug}/
  takeaways.md        — одна страница: что ценного + где цитируется
  {original files}    — только инструктивные/эталонные артефакты
```

`slug` — по источнику, `kebab-case`. Не проектная папка по `AGENTS.md` — это корпус, не скилл/агент/плагин.

## Что сюда кладём

- Системные промпты, CLAUDE.md, AGENTS.md, README других репозиториев.
- Скилл-манифесты и их `references/`.
- Инструкции агентов/плагинов официальных и сильных сторонних.

## Что сюда НЕ кладём

- Сгенерированные артефакты (HTML, CSS, картинки), если они не иллюстрируют сам приём.
- Всё, из чего невозможно вытащить повторимый урок.
- Собственные наработки — для них проектные папки в категориях.
