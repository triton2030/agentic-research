# Anthropic Design Generator — Takeaways

Эталон агентных инструкций из официального генератора дизайна (Anthropic). Разбирается связка `CLAUDE.md` (корневой) + `ds/README.md` (доменный) + `design-system.html` (живой визуальный канон).

## Что ценного

- **Двухуровневая иерархия инструкций.** Корневой `CLAUDE.md` — операционный: файлы, правила, рецепты, verify. `ds/README.md` — доменный и самодостаточный, читается без корня. Повтор главного правила здесь ценен как локальная страховка, но не default для новых GPT-5.6/Opus 4.7 инструкций.
- **Живой визуальный канон рядом с текстом.** `design-system.html` — runtime-источник правды. Текст работает как индекс, HTML — как реальность. Текстовые каталоги (таблицы примитивов/паттернов) обязательно синхронизируются с ним через шаг 4 рецепта добавления секции.
- **Порядок блоков в корневом `CLAUDE.md`:** одна строка идентичности + бренд-константы → карта файлов → *архитектурное правило (слоение)* → конкретный полный пример паттерна → где живут данные → операционные детали (cache-bust) → пошаговый рецепт → verify-чеклист → `Deliberate non-goals`. Инварианты в топе, рецепты ниже, запреты в конце.
- **Порядок в доменном `ds/README.md`:** одна строка + указатель на живой канон → диаграмма слоёв → *две плотные таблицы-каталога* → повтор правила с WRONG/RIGHT парой → полный повторный сниппет expandable → мини-рецепты добавления. Каталоги закрывают галлюцинации «предложить несуществующий класс».
- **Негативное пространство явное.** `Deliberate non-goals` + `Wrong/Right` блоки закрывают самые частые LLM-ошибки (добавить Tailwind, сделать dark mode, переопределить примитив в паттерне).
- **Конкретика > принципы.** Там, где можно написать «используйте expandable utility», дан полный copy-paste HTML + JS-хук регидрации. Паттерн — артефакт, не абстракция.
- **Verify встроен в workflow.** Обновление `design-system.html` — обязательный шаг рецепта добавления секции, иначе каталог рассинхронизируется. Дыра закрыта заранее.
- **Операционные мелочи, ломающие агента, проговорены:** `?v=N` cache-bust, `window.DSExpandable.hydrate()` после innerHTML, когда допустим inline `style=""` (только одноразовые значения).
- **Минимальная поверхность.** Ни «why we chose this», ни «philosophy», ни «roadmap». Только то, что нужно не испортить систему.

## Главный приём

**Архитектурное правило (слоение `tokens → primitives → patterns → HTML`) повторено трижды:** в корневом `CLAUDE.md`, в диаграмме `ds/README.md`, в WRONG/RIGHT паре. Каждый раз — с другой стороны. Это полезная страховка в этом артефакте, а не универсальное разрешение дублировать правила в каждом subtree.
