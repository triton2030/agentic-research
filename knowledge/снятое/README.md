# снятое

Документы, переставшие быть правдой. Живая база их не содержит, и за маршрутом
сюда не ходят.

- `design-review-playbook.md` — маршрут дизайн-аудита строится через
  `1impeccable`, которого нет ни в одной установке. Принцип разделения на
  поверхности пережил маршрут и живёт в понятиях базы.
- `structural-critique-playbook.md` — раскладывает работу по восьми скилам,
  снятым к сентябрю 2026: `1skill-architect`, `instruction-layer`, `1ia-audit`,
  `project-roadmap`, `task-contract`, `plan-drift-watch`, `strategy-trace`,
  `pulse-check`. Словарь поломок и дисциплина находки их пережили и живут в
  понятиях базы.
- `инвентарь meta — снимок 2026-05.md`, `инвентарь dev — снимок 2026-05.md`,
  `инвентарь design — снимок 2026-05.md`, `инвентарь business — снимок 2026-07.md`
  — перечисляют, какие ручки существовали на дату снимка. Живой реестр скилов —
  `skills/shared/README.md`, живые маршруты — `INDEX.md`.
- `источники meta — снимок 2026-05.md` — список статей по памяти, оценке и
  модельным дельтам. Опоры действующих утверждений живут в самих документах.
