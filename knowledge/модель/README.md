# модель

Языковая машина как вещь. Общее — как она устроена и что верно про весь рабочий
набор; частное — чем отличается конкретная модель, когда это меняет работу с
ней.

- [`как мыслит машина.md`](<как мыслит машина.md>) — физика: вероятностное
  продолжение, перекосы, поведение контекста, удержание траектории. Общий
  корень, на который опираются остальные стороны.
- [`свойства рабочего набора.md`](<свойства рабочего набора.md>) — измеренные
  свойства текущего набора моделей и их режимы сбоя.
- [`gpt-5.6.md`](<gpt-5.6.md>), [`claude opus 5.md`](<claude opus 5.md>),
  [`claude fable 5.md`](<claude fable 5.md>) — правила, меняющие работу именно с
  этой моделью: brief, усилие, scope, делегирование.

Точный рабочий набор моделей задаёт `_ops/GOAL.md`. Среда исполнения — не здесь,
а у рантайма.
