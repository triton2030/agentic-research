# снятое из базы

Документы, переставшие быть правдой. Живая база их не содержит, и за маршрутом
сюда не ходят. Каждый назван тем, чем он перестал быть верным; когда это
случилось, видно в истории файла.

## Маршруты, ведущие в несуществующее

- `design-review-playbook.md` — весь маршрут дизайн-аудита строится через
  `1impeccable`, которого нет ни в одной установке. Слой вкуса и `AI slop`
  живой замены не имеет.
- `structural-critique-playbook.md` — раскладка работы по восьми снятым скилам:
  `1skill-architect`, `instruction-layer`, `1ia-audit`, `project-roadmap`,
  `task-contract`, `plan-drift-watch`, `strategy-trace`, `pulse-check`. Словарь
  структурной критики в теле документа их пережил и годится к переносу.

## Снимки состояния, а не знание

Инвентарь перечисляет, какие ручки существуют в данный момент, — это состояние
проекта, и оно устаревает. Живой реестр скилов — `skills/shared/README.md`, живые
маршруты — `INDEX.md`.

- `инвентарь meta — снимок 2026-05.md` — четыре из перечисленных ручек сняты.
- `инвентарь design — снимок 2026-05.md` — две из перечисленных ручек сняты.
- `инвентарь dev — снимок 2026-05.md`, `инвентарь business — снимок 2026-07.md`
  — перечень ручек на дату снимка.
- `источники meta — снимок 2026-05.md` — список статей по памяти, оценке и
  модельным дельтам. Опоры действующих утверждений живут в самих документах.
