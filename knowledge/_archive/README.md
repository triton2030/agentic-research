# Снятое из базы

Документы, которые перестали быть правдой, но выбрасывать которые рано: их
знание может пригодиться при пересборке. Живая база их не содержит, и агент
сюда не ходит за маршрутом.

Причина снятия у каждого — здесь, одной строкой. Дата снятия видна в git.

- `design-review-playbook.md` — снят 2026-09-10. Маршрут дизайн-аудита строился
  через `1impeccable`, которого не существует ни в одной установке; шесть
  вызовов из девяноста трёх строк вели в пустоту. Живая замена слою вкуса и
  `AI slop` не найдена — при пересборке начинать с этого вопроса.
- `structural-critique-playbook.md` — снят 2026-09-10. Карта «Skill Map»
  раскладывала работу по восьми снятым скилам: `1skill-architect`,
  `instruction-layer`, `1ia-audit`, `project-roadmap`, `task-contract`,
  `plan-drift-watch`, `strategy-trace`, `pulse-check`. Словарь структурной
  критики в теле документа пережил их и годится к переносу; сама раскладка — нет.
