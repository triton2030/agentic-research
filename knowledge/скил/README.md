# скил

Скил как вещь: повторяемое профессиональное вмешательство с отдельным триггером
и проверяемым результатом. Здесь всё, что нужно, чтобы его написать и принять.

## Как писать и чем принимать

- [`как писать.md`](<как писать.md>) — канон: когда скил вообще нужен, как
  держать scope, `description`, тело и доказательство по риску. Начинать
  отсюда.
- [`условия приёмки.md`](<условия приёмки.md>) — ворота для уже выбранного
  решения: go/no-go, routing, форма, платформа, доказательство. Не следующий
  обязательный шаг после канона, а проверка перед сдачей.
- [`почему скил не поднимается.md`](<почему скил не поднимается.md>) — узкий
  профиль коротких описаний для вызова в середине длинной работы.
- [`где расходятся платформы.md`](<где расходятся платформы.md>) — различия
  Agent Skills standard, Codex, Claude Code, MCP и API при упаковке.
- [`упаковка знания.md`](<упаковка знания.md>) — скил и плагин как форма
  упаковки знания: что во что складывается и чем это отличается от инструкции.

## Датированные срезы внешнего поля

Снимки, а не вечная истина: перед аудитом решений «как принято сейчас» сверяй
свежие официальные документы. Канон держит только выводы, которые такую сверку
переживают.

- [`что нашли снаружи — срез 2026.md`](<что нашли снаружи — срез 2026.md>) —
  выводы из официальных документов и исследований.
- [`скилы matt pocock — срез 2026-08.md`](<скилы matt pocock — срез 2026-08.md>)
  — форензика 25 промотированных скилов: формулировки, порядок, размеры,
  отрицательное пространство.
- [`формулировка и соблюдение — срез 2026-08.md`](<формулировка и соблюдение — срез 2026-08.md>)
  — неоднозначность, число активных правил, порядок, проверяемый результат и
  граница соблюдения одним текстом.
- [`имя метода вместо процедуры — срез 2026-08.md`](<имя метода вместо процедуры — срез 2026-08.md>)
  — когда имя известного метода заменяет полную процедуру.
- [`триггеры в середине траектории — срез 2026-08.md`](<триггеры в середине траектории — срез 2026-08.md>)
  — короткие описания и поздний автоматический вызов по состоянию работы.
- [`авторинг инструкций — срез 2026.md`](<авторинг инструкций — срез 2026.md>) —
  польза, вред, состав, routing и live-оценка Agent Skills.
