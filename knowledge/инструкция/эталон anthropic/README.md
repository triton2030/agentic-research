# эталон anthropic

Захваченный целиком чужой артефакт: проектная инструкция Anthropic вместе с
дизайн-системой, на которую она опирается. Ценность — в связке инструкции,
доменного гайда и живого визуального канона: правило не описывает результат
словами, а показывает его.

Оригинал сохранён дословно, включая имена файлов: форма исходника здесь и есть
предмет изучения, и правка её уничтожает.

- [`разбор.md`](<разбор.md>) — наш разбор: что ценного и где это цитируется.
- `CLAUDE.md`, `ds-README.md`, `design-system.html` — оригинал.
