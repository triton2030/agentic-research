# как писать

Стороны одного дела: сделать так, чтобы текст управлял поведением, а не просто
сообщал требования.

- [`системный промпт.md`](<системный промпт.md>) — устойчивая роль, приоритеты,
  границы и форма сильного системного промпта.
- [`сборка контекста.md`](<сборка контекста.md>) — владельцы, интерфейсы,
  ссылки, progressive disclosure и проверка. Внутренний слой одного файла.
- [`форма проекта.md`](<форма проекта.md>) — как инструкция проекта роутит новое
  по смыслу и по каким наблюдаемым сигналам видно, что форма распадается.
  Внешний слой топологии, в которой живёт такой файл.
- [`план.md`](<план.md>) — планировать следующий проверяемый фронтир, а не всю
  цепочку заранее.
- [`корневые инструкции — срез 2026-08.md`](<корневые инструкции — срез 2026-08.md>)
  — датированный срез внешних публикаций о корневых `AGENTS.md` и `CLAUDE.md`.
  Срез, не канон.

Модельные различия — у модели; поверхности рантайма — у рантайма.
