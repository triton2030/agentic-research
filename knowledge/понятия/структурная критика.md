# Структурная критика

Разбор формы целого — кода, скила, промпта, инструкции, дерева папок,
конфигурации. Не про стиль и не про имена: про то, держит ли артефакт свою
главную идею.

## Дисциплина

1. Диагностируй, не чини. Исполнение остаётся у владельца артефакта.
2. Если находка не ясна — молчи. Пустой разбор валиден.
3. Сначала структура, потом стиль, имена и локальная эстетика.
4. Находка должна улучшать ясность через месяцы, а не выигрывать спор сейчас.
5. Если не можешь назвать главную идею артефакта, его поверхность срабатывания
   или цель плана — это и есть первая находка. Назови её и остановись.

## Две поломки, из которых растут остальные

**Нарушение главной идеи** — локальные правки разъедают принцип, ради которого
вещь построена. **Мелкая абстракция** — интерфейс не экономит чтение
реализации: чтобы им пользоваться, надо всё равно открыть внутренности.

Находка называет не только поломку, но и лучшую форму: какой контур сохранит
главную идею и глубокие модули.

## Словарь симптомов

| Симптом | Что видно |
| --- | --- |
| Метод-пробрасыватель | вызов ничего не добавляет, только передаёт дальше |
| Интерфейс равен реализации | сигнатура повторяет внутреннее устройство |
| Взрыв конфигурации | поведение задаётся флагами, которых больше, чем случаев |
| Деление по времени вместо ответственности | шаги процесса стали модулями |
| Утечка знания | одна деталь известна нескольким несвязанным местам |
| Свалка-утилита | папка или модуль «разное», куда кладут не подошедшее |
| Разбитое окно | одно нарушение узаконило следующие |
| Карго-культ | форма скопирована без причины, по которой она работала |
| Внезапная зависимость | связь, которой не видно из имени и пути |
| Слепота к новому в легаси | новый код написан так, будто старого рядом нет |
| Выдуманный API | вызов того, чего не существует |
| Правдоподобно неверное поведение | работает, но не то, что обещано |

## Опоры

- Ousterhout: глубокие модули, мелкие абстракции, когнитивная нагрузка.
- Brooks: целостность замысла, существенная и привнесённая сложность.
- Feathers: швы легаси, характеризационные тесты, риск нового в старом.
