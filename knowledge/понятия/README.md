# понятия

Понятия, которые встречаются во многих вещах, но своей папки среди них пока не
получили. Как только понятие обрастает сторонами, оно переезжает туда, где стоит
по принадлежности, а здесь остаётся определение.

- [`системное мышление.md`](<системное мышление.md>) — как думать о системе
  прежде, чем её строить.
- [`структурная критика.md`](<структурная критика.md>) — как разбирать форму
  целого и когда критике правильнее промолчать.
- [`дизайн-аудит.md`](<дизайн-аудит.md>) — почему дизайн-работу не собирают в
  один общий инструмент.
