# понятия

Понятия, о которых сказать пока нечего сверх одной стороны. Как только у понятия
появляется вторая сторона, оно получает свою папку там, где стоит по
принадлежности, а здесь остаётся определение.

- [`системное мышление.md`](<системное мышление.md>) — зум-аут, idealized design
  и язык паттернов: как думать о системе до того, как её строить.
- [`визуальное качество.md`](<визуальное качество.md>) — что проверено про
  визуальное качество, композицию, motion и проверку интерфейсов.
