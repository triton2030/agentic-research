# Dev — Инвентарь Codex

Снимок на 16 апреля 2026.

## Что Есть

### subagents
- Тип: agent
- Источник: OpenAI
- Что делает: позволяют распределять независимые dev-задачи между отдельными агентами внутри Codex

### skills
- Тип: skill
- Источник: OpenAI
- Что делает: позволяют закреплять повторяемые инженерные workflow поверх базового поведения агента

### plugins
- Тип: plugin
- Источник: OpenAI
- Что делает: дают пакетный слой для skills, integrations и MCP в инженерных сценариях

- Тестирование (unit, integration, e2e)
- CI/CD диагностика
- Рефакторинг с проверкой регрессий
