# Литературная сверка 2026 — проверяемая реконструкция

Эта сводка восстановлена 2026-08-04 после четырёх параллельных проходов по
литературе. Их raw outputs не были сохранены. Поэтому файл **не доказывает
независимость четырёх обзоров и не реконструирует их дословно**: он сохраняет
claim → primary source → граница поддержки для находок, перенесённых в главный
научный документ.

Live evidence-статусами владеет
[`../../how-to-steer-llm-thinking.md`](../../how-to-steer-llm-thinking.md).
Здесь лежит только source-ledger; изменение статуса делается в owner-е вместе
с новым evidence.

## Прямо перепроверенные числовые claims

- [2605.20382 v2](https://arxiv.org/abs/2605.20382), full-text table 1:
  исследование охватывает 13 моделей и 16 инструкций. Для task-based условий
  порог `N_50` равен 43 демонстрациям у GPT-5.2 и 31 у Claude Opus 4.6. Для
  fixed-output условий в той же таблице пороги равны 1 и 16 соответственно;
  числа 43/31 нельзя представлять как универсальную стойкость моделей.
- [2606.22953](https://arxiv.org/abs/2606.22953), abstract: на
  Llama-3.1-70B сигнал плана после пика падает в 4,1 раза за один
  action-observation шаг; на HotpotQA падение составляет 12,4 раза. Источник не
  поддерживает формулу «4–12× за 1–2 шага».

Оба claims перепроверены по первичным страницам 2026-08-04. Остальные строки
ниже — адресуемая реконструкция перенесённых находок; raw review-level
provenance для них утрачен.

## Открытый provenance gap

Нельзя восстановить, какой из четырёх проходов нашёл конкретную работу, какие
контраргументы он отбросил и были ли outputs действительно независимы. Этот
gap закрывается только найденными raw transcripts/outputs; до этого главный
документ не должен использовать число обзоров как усилитель evidence.
