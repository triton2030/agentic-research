# Дистилляция

Не про длину: перенеси нормы на дешёвые носители — механизм → структура →
имя → сфакторованный текст; удаление последнее. Предел: любой
файл пакета ≤2000 символов; не влезает — вынос в reference-файл (сколько
угодно, каждый ≤2000), а не резка смысла. Плоскости (скил, слой инструкций,
промпт) — `references/planes.md`.

## До разреза

Назови приёмника письменно; партитура показа — видимый выход, на котором
учится владелец, — выносится из объёма, без его разрешения не режется
(`references/receiver.md`). Батарея: 10–15 ситуаций «дано X — какой первый
ход», из веток текста, в файл (`references/battery-build.md`); сверь покрытие с
инвентарём отрицаний. Порог — до прогона. Ядро батареи после первого
разреза не правится. Порядок шагов и конфликтные пары —
`references/procedure.md`.

## Разрез

Партиями сверху вниз; батарея на каждой партии (`references/battery-run.md`).
Несущая строка = единственный заполнитель ячейки проводки; без прогона абляции
строка несущая (`references/wiring.md`). Модели нельзя обобщать, сливать
правила, вводить дефолты, пересказывать своими словами
(`references/operations.md`); запрещённое — владельцу пакетом эскалации.
Кратное сжатие, недостижимое удалением, открывает пересборку —
`references/rebuild.md`; пересборщик батарею не видит.

## Приёмка

Слепой агент на рабочей модели, заданной явно; три прогона на ситуацию,
меньше — «не измерено». Батарея ловит пропажу слов, не веса: норма выживает дословно
и перестаёт держать под нагрузкой — приёмка включает реальную задачу
(`references/acceptance.md`). Сдача: символы + доля совпавшего первого хода +
поведение на задаче.
