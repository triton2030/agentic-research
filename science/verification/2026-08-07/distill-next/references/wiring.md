# Проводка и несущая строка

Инвентарь одних «правил» — неполная модель текста. **Проводка** — адресат
нормы, её триггер, ветка решения, слот в выходе и путь отказа. Она не выглядит содержанием: строка про проводку почти
всегда формально пересказывает соседнюю. Удаляют её первой.

Размечай каждую строку ячейками: `адресат · триггер · ветка · действие · слот
выхода · путь отказа`. Разметка — единственное место, где остаётся суждение;
делай её дважды независимо, расхождение разметок — сигнал дефекта строки.

> Строка несущая ⟺ она **единственный заполнитель хотя бы одной ячейки**.
> Содержание в критерии не участвует.

Пересказ — строка, все ячейки которой заполнены другими строками. Пересказ по
содержанию — только кандидат на дедупликацию; решает проводка.

**Тест затемнения:** зачеркни строку, прогони покрытие ячеек. Потеряла ячейка
последнего заполнителя — строка несущая, удаление блокируется. Удалять пересказ
можно только с переносом ячеек в выжившую строку; не вмещает синтаксис —
удаление блокируется, а не принимается с оговоркой.

**Ветки отказа несущие по определению.** Содержание проверки обычно есть и в
другом месте; уникальна ветка «не пройдена». Каждая проверка обязана иметь слот
для обеих веток.

Дешёвый прокси: строка-дубль, несущая токены ветвления,
отрицания, адресации или времени, которых нет в её дубле — «если… не», «иначе»,
«сам», «до/после», «в том же ответе», имена слотов.

**«Выводимо» — замер, а не суждение.** Тест затемнения судит по ячейкам, но
заполненность оценивает тот же, кто решил резать; строку-«пересказ» проверяет
абляция прогоном (`battery-run.md`). Без прогона строка
**несущая**: цена ошибочного удаления асимметрична цене лишней строки.

Рычаг «знание модели» скользок: «не пиши то, что модель знает» опровергнут —
декларативная память не предсказывает поведение (снятие инструмента: 0% →
74.7% при неизменном тексте). Рабочая формулировка одна: **не пиши то, что
модель уже делает без этой строки** — проверяется абляцией, не опросом.
