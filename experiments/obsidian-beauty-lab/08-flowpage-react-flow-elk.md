# FlowPage

> [!summary]+ Что проверяем
> **Цель:** вместо статичного SVG попробовать отдельную страницу с zoom/pan,
> крупными HTML-узлами и первичной раскладкой через ELK.
>
> React Flow здесь отвечает за интерактивную поверхность: drag, zoom, pan,
> controls и minimap. ELK, `d3-force` и WebCola не встроены в React Flow: они
> только считают позиции узлов, а сама поверхность остаётся интерактивной.

## Открыть

```bash
cd experiments/obsidian-beauty-lab
npm run dev:flowpage
```

[Открыть FlowPage](http://127.0.0.1:5173/flowpage.html)

## Что Смотреть

> [!example]+ Поведение
> - колесо мыши приближает и отдаляет карту;
> - canvas можно таскать;
> - узлы можно двигать руками, и они остаются там до следующей ELK-раскладки;
> - карточки обнимают контент по высоте, а не держат один фиксированный размер;
> - связи рисуются кривыми React Flow edges, а не квадратными `smoothstep`;
> - связи сами выбирают ближайшую сторону карточек после раскладки и ручного
>   перетаскивания;
> - стартовый вид открывается в читаемом масштабе, а не пытается вместить всю
>   карту сразу;
> - кнопка `ELK` заново собирает строгую слоистую карту;
> - кнопка `d3-force` собирает свободную force-карту,
>   затем снижает пересечения связей и разводит пересекающиеся карточки;
> - кнопка `Cola` собирает карту через WebCola: `flowLayout` тянет связи вниз,
>   `avoidOverlaps` не даёт карточкам налезать друг на друга;
> - раскладки анимируются: `ELK` плавно переезжает в финальные позиции,
>   `d3-force` и `Cola` показывают промежуточное схождение;
> - кадры анимации пишутся прямо во внутренний React Flow store через
>   `useStoreApi()`, без controlled `nodes={...}` слоя и без очереди `setNodes`;
> - ползунки `Отталкивание`, `Длина связей` и `Зазор нод` позволяют руками
>   менять характер force/Cola раскладки;
> - `Обзор` возвращает всю карту в экран.

> [!warning]- Граница React Flow
> Бесплатный React Flow даёт viewport и интерактивные узлы. Автоматическая
> раскладка в обычных примерах подключается отдельной библиотекой вроде ELK,
> Dagre, d3-hierarchy, `d3-force` или WebCola.
