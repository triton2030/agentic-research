# Graph Authoring Contract

Этот файл для агента, который пишет новые графы в `src/pages/<slug>.js`.
`TECHNICAL.md` объясняет механику приложения; здесь — как сделать граф
понятным человеку.

## Язык

Весь видимый текст графа пиши по-русски: `title`, `description`, `kicker`,
`body`, `bullets`, `label`, `tooltip`, подписи рёбер и заметки.

Не смешивай русский и английский ради стиля. Английский оставляй только когда
это точное название файла, API, команды, скилла, компонента, значения `kind`,
имя Material Symbol или другой технический идентификатор. Если английское имя
видимо пользователю, рядом дай русскую роль через `kicker`, `note`, `body` или
подпись.

## Минимальный Скелет Страницы

```js
import { card, note, header, materialIcon, decision, quote, file, edge } from "./_helpers";

export default {
  id: "project-map",
  title: "Карта проекта",
  description: "Главные владельцы смысла и связи между ними",
  nodes: [
    header({ id: "h", title: "Основной путь" }),
    card({
      id: "readme",
      kind: "doc",
      weight: 2,
      title: "README.md",
      kicker: "вход",
      body: "Объясняет, зачем существует проект и куда смотреть сначала."
    }),
    materialIcon({ id: "gate", icon: "rule", label: "правило" })
  ],
  edges: [
    edge("h", "readme", { kind: "dimmed" }),
    edge("readme", "gate", { label: "проверяется", kind: "dashed" })
  ]
};
```

## Типы Узлов

- `card(...)` — основной смысловой блок. Используй для процессов, файлов,
  скиллов, правил, результатов и важных сущностей.
- `note(...)` — короткая аннотация без рамки. Не делай из неё второй main
  card.
- `header(...)` — раздел canvas: фаза, область, группа.
- `icon(...)` — emoji или короткий символ, когда нужен маленький маркер.
- `materialIcon(...)` — Material Symbols Rounded, когда нужна узнаваемая
  системная пиктограмма.
- `decision(...)` — развилка, условие, проверка.
- `quote(...)` — точная формулировка, красная линия, важный принцип.
- `file(...)` — документ или конфиг с заметкой.

## Цвета `kind`

- `origin` — источник, запрос, стартовая точка.
- `skill` — рабочий механизм, скилл, процедура.
- `gate` — проверка, условие, runtime guard.
- `memory` — память, сохранённый контекст, долговременное знание.
- `review` — аудит, проверка, обратная связь.
- `truth` — пользовательская правда, критерий, решение владельца.
- `branch` — альтернатива, развилка, вариант пути.
- `doc` — файл, документ, инструкция.
- `output` — результат, артефакт, готовый выход.

Не выбирай цвет по красоте. Цвет должен отвечать на вопрос: какую роль играет
этот узел в системе?

## Material Icons

Используй helper `materialIcon({ icon, label?, tooltip? })`.

`icon` — это точное имя Material Symbol, например:

- `account_tree` — граф связей, структура, зависимости.
- `rule` — правило, проверка, критерий.
- `hub` — центральный узел, маршрутизатор.
- `route` — путь, переход, поток.
- `schema` — структура данных или форма.
- `psychology` — reasoning, мышление, выбор.
- `fact_check` — аудит, проверка фактов.
- `memory` — память, сохранённый контекст.
- `terminal` — команда, CLI, локальный инструмент.
- `folder_open` — папка или область файлов.
- `description` — документ.
- `task_alt` — завершённый результат.

Видимый `label` у Material Icon пиши по-русски: `правило`, `память`, `команда`.
Само значение `icon: "account_tree"` остаётся английским, потому что это
техническое имя glyph'а.

## Рёбра

- `solid` — обычная сильная связь.
- `dashed` — опциональный путь, условная связь, переход по ситуации.
- `dotted` — слабая связь, комментарий, аннотация.
- `bold` — главный путь.
- `dimmed` — фоновая или второстепенная связь.
- `accent` — важный риск или место, которое надо заметить.

Подписи рёбер должны быть короткими: глагол или отношение, не целое
предложение.

## Масштаб

Делай граф сканируемым:

- 1-3 больших смысловых блока на область;
- много средних карточек лучше, чем одна огромная простыня;
- большие ноды допустимы, когда они действительно работают как мини-страницы;
- не смешивай на одном уровне мелкие маркеры и огромные панели без причины.

## Анти-Паттерны

- одинаковые `kind` у всех карточек;
- английские подписи ради “технического вайба”;
- Material Icon без русской подписи, если значение не очевидно;
- рёбра с длинными объяснениями;
- попытка вручную кодом решить layout, который должен решать ELK;
- скрытые страницы или состояние вне `src/pages/*.js` и `data/layouts/*.json`.
