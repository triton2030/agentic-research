# skill-gallery

Мод Claude Code: скиллы, встроенные команды и агенты по разделам-папкам.
Клик по пункту вставляет `/имя ` (скилл, команда) или `@agent-имя `
(агент) в поле ввода. Разделы плагинов меньше пяти пунктов сливаются
в «Остальное».

Главный вид — строка над полем ввода: в ней кнопки папок с числом пунктов.
Клик по папке раскрывает под строкой её список, по восемь пунктов за раз;
колесо над строкой и кнопки ▲▼ листают список, строка папок остаётся
на месте. Выбор пункта закрывает папку, второй клик по папке — тоже.

Боковая панель сама больше не открывается, её зовёт команда
`/skill-gallery`. Звёздочка в панели ведёт избранное; в строке над полем
избранного нет. Разделы панели свёрнуты по умолчанию.

Агентов мод узнаёт из события `agent.offer`, когда Claude Code показывает
их модели, и запоминает список, чтобы новая сессия видела его сразу.
Агент, которого убрали, остаётся в списке.

## Установка

Папка — локальный магазин `skill-gallery-mods`, плагин стоит на уровне
пользователя: `skill-gallery@skill-gallery-mods`. Сессии читают его прямо
из `skill-gallery/` (проверено `claude plugin update` на 2.1.312), копия
в `~/.claude/plugins/cache/` не используется.

Правка доходит до сессии при её старте или после `/reload-plugins`.
Новая версия в `plugin.json` для этого не нужна.

## Хранилище

Избранное, развёрнутые разделы и агенты лежат в
`~/.claude/plugins/store/skill-gallery_skill-gallery-mods-<hash>.json`.
Хранилище привязано к источнику плагина: копия мода из
`~/.claude/dev-mods/` пишет в отдельный файл `skill-gallery_inline-*`.
Поэтому не держи копию в `dev-mods` рядом с установленным плагином:
после перезапуска сессии грузятся оба, и избранное расходится.
Правь эту папку и делай `/reload-plugins`.

## Проверка правки

```bash
claude plugin test experiments/skill-gallery/skill-gallery
```

```bash
claude plugin validate experiments/skill-gallery
```

API модов — встроенный скилл `plugin-authoring`, его `types/claude-code.d.ts`.
