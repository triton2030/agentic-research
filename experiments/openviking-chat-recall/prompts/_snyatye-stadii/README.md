# Контракты снятых стадий

Это **история, не живые контракты**. Стадии письма страниц и указателя сняты из
протокола 2026-08-24 по результату слепой приёмки: слой тем выиграл у собранной
из него библиотеки и по точности, и по цене чтения.

Файлы оставлены, потому что в них записана оплаченная цена — три правила,
найденные аудитом и переживающие снятие стадии:

- модальность берётся из поля `type` записи, а не угадывается;
- страница не дописывает, чем предмет **не** является;
- решение владельца не подаётся настоящим временем, как уже сделанное.

Живые контракты — на уровень выше: `flatten-file.v1.md`, `merge-topic.v1.md`,
`backfill-missed.v1.md`.
