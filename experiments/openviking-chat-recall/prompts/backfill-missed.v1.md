# Backfill v1 — записи, не дошедшие до библиотеки

## Outcome

Сборка библиотеки уронила часть записей корпуса: сжатие файлов и написание
страниц потеряли их молча. Проверка нашла точные адреса. Твоя работа — решить
судьбу каждой такой записи и **назвать её вслух**.

Ты не строишь структуру заново. Страницы этой темы уже написаны и перечислены
ниже. Ты решаешь по каждой записи одно из трёх и ничего больше.

## Три судьбы и только они

- **`add`** — запись несёт знание, и на него уже есть страница. Назови её путь.
- **`new`** — запись несёт знание, но ни одна существующая страница на этот
  вопрос не отвечает. Предложи новую страницу.
- **`skip`** — запись не несёт знания, которое переживёт разговор: служебное
  согласие («да, делай»), реплика о ходе текущей работы, повтор уже стоящего
  на странице факта. Назови причину.

`skip` — полноправный ответ, а не поражение. Насильно внесённый пустой факт
хуже честно названного отсутствия: он занимает место и лжёт о наличии позиции.
Но `skip` по лени — прямой провал: если сомневаешься, запись несёт знание.

## Модальность берётся из поля `type`, а не угадывается

| `type` записи | как называешь в факте |
| --- | --- |
| `решение` | Владелец решил … |
| `критерий` | Владелец задал критерий … |
| `правило-кандидат` | Владелец предложил как правило … |
| `коррекция` | Владелец поправил … |
| `предпочтение` | Владелец предпочитает … |
| `идея` | Владелец высказал идею … |
| `факт` | нейтральное утверждение без «владелец» |
| `обо-мне` | Владелец рассказал о себе … |

Не расширяй область и время: сказанное об одном скиле не становится правилом
обо всех. Не добавляй участника, границу или причинную связь, которых нет в
цитате. Не советуй от себя.

## Формат ответа

Верни **только** строки TSV, по одной на каждую полученную запись, без шапки,
без пояснений вокруг, без markdown-разметки. Пять колонок через табуляцию:

```
<якорь>	add	<путь существующей страницы>	<сухой факт одной строкой>	<краткая метка ссылки>
<якорь>	new	<тип>/<слаг>.md|<заголовок-вопрос>|<описание одной строкой>	<сухой факт одной строкой>	<краткая метка ссылки>
<якорь>	skip	—	<причина одной строкой>	—
```

Якорь копируй посимвольно из полученного списка. Он твой ключ: строка с чужим
или переписанным якорем будет отвергнута целиком. Ссылки и пути к страницам не
собирай сам — их проставит скрипт.

Тип новой страницы — один из `entity | concept | method | comparison |
analysis`. `entity` — названная вещь; `concept` — переиспользуемая идея;
`method` — процедура владельца; `comparison` — его взвешивание альтернатив;
`analysis` — его рассуждение о причине.

## Стоп

Файлы не правь: ни страницы, ни что-либо ещё. Твой ответ — только TSV. Число
строк обязано совпасть с числом полученных записей.
