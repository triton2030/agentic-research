# Как устроено извлечение текста из оцифрованных VHS?

Владелец решил завести в workspace отдельную папку под проект извлечения текста из видеофайлов и последующего осмысления; статьи на основе извлечённого из фильмов пока пишутся в этой же папке. Материалы разделяются на два файла — чистую транскрипцию и отдельный смысловой файл; для полного фильма «тогыз фильм.mpg» транскрипция генерируется сразу вся, а файл смысла делается один. В настройках Handy для распознавания оцифрованных VHS решено задать автоматическое определение языка, потому что в подобных фильмах смешиваются русский и казахский.

## Папка и файлы

- Владелец решил завести в workspace отдельную папку под проект извлечения текста из видеофайлов и последующего осмысления.
- Статьи на основе извлечённого из фильмов пока пишутся в этой же workspace-папке: настоящие статьи ещё только предстоит делать.
- Материалы разделяются на два файла: чистая транскрипция и отдельный смысловой файл — владелец решил так устроить структуру.
- Для полного фильма «тогыз фильм.mpg» транскрипция генерируется сразу вся, а файл смысла делается один.

## Настройки распознавания

- В настройках Handy для распознавания оцифрованных VHS владелец решил задать автоматическое определение языка, потому что в подобных фильмах смешиваются русский и казахский.
