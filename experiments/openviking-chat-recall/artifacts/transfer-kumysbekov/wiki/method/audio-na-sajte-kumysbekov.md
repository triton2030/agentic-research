# Как добавить музыку на сайт kumysbekov?

Нужная музыка есть на древнем сайте владельца. Плеер добавляется прямо на главную страницу: каждый трек вытаскивается с правильным названием, и при прослушивании показывается карточка с информацией про этот трек. Готовое решение для установки владелец предпочитает найти в интернете, а не писать аудиоплеер с нуля.

- Владелец сообщил, что на его древнем сайте есть нужная музыка.
- Владелец решил добавить плеер прямо на главную страницу: вытащить каждый трек с правильным названием и при прослушивании показывать карточку с информацией про этот трек.
- Владелец предпочитает найти в интернете готовое решение для установки, а не писать аудиоплеер с нуля.
