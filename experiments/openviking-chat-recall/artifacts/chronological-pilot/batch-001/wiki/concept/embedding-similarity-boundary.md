# Похожесть текстов — это доказательство смыслового дубля?

Нет. Результат embedding показывает математическую похожесть, а не доказательство смыслового дубля. Для общего skill это красная линия: инструмент может вводить в заблуждение о своих границах.

## Action

Называй результат похожестью; не объявляй тексты копиями без отдельного evidence.

## Boundary

Правило запрещает использовать embedding search для поиска смысловых дублей, но не выбирает заменяющий алгоритм.
