# Насколько единообразной должна быть глобальная Ops-структура?

В одной owner correction сказано, что все skills создают папку Ops и глобальная структура должна быть одинаковой. Это expectation, не установленная схема.

## Implication

Inference from that correction: при добавлении global skill сохраняй cross-project uniformity как constraint, но не выводи из записи конкретные subfolders или paths.

## Unknown

Source не устанавливает точные имена папок, owner, implementation status или migration route; эти сведения остаются неизвестными на batch boundary.
