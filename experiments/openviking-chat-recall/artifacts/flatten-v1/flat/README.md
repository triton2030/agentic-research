- Корпус `_ops/chat-recall` хранит source-bound выдержки слов владельца по одному файлу на разговор; имя файла кодирует дату, время первой цитаты, агента и session. [L3-L5]
- Каждая реплика в файле имеет полный timezone-aware source timestamp и классификацию `type`/`topic`, а шапка содержит инвентарь `types`/`topics` и `session` для доступа к полному транскрипту, пока действует retention. [L5-L8]
- Записи являются датированным сырьём, а не текущей правдой; их нельзя применять без проверки scope и более свежего owner-а. [L10-L12]
- По замеру 79 сессий от 2026-08-12 агент по своей инициативе выполняет 56% чтений корпуса для закрытия пробелов текущей задачи, а 16 из 19 таких находок отсутствуют в нормативных файлах. [L14-L17]
- Типичный читатель корпуса — read-only субагент из свежего окна, включая goal-lens, premortem и критика; без истории чата корпус служит ему единственным каналом к намерению владельца. [L18-L19]
- Второй канал использования корпуса — harvest, при котором повторяющиеся коррекции переходят в правку инструкций; явной команды владельца найти его слова в 79 сессиях не было. [L20-L21]
- Если корпус расходится с нормативными файлами, расхождение не разрешают молча: его фиксируют строкой в `_ops/findings` с адресами обоих источников. [L23-L25]
- `1chat-recall` записывает свежую реплику в том же ходе, а цитата, восстановленная из старого хода, получает timestamp исходной transcript record, а не время запуска helper-а. [L27-L29]
- `source-timestamp` использует самый точный доступный момент: точный ISO с таймзоной, минуту из транскрипта или день; `unknown` допустим только для repair `--kind note`, и дата не угадывается. [L29-L31]
- В session-файле legacy approximate-строки остаются как есть, а новая запись пишется чисто. [L32-L33]
- В корпусе сохраняются решения, коррекции, red line, предпочтения, критерии, важные числа, сырые идеи на будущее и durable-хвосты императивов. [L35-L36]
- Выдержка строится удалением речевого шума, повторов, разовых команд и вставленного чужого материала, сохраняя лексику, смысл, условия и числа владельца без интерпретации агента. [L36-L39]
- Чужой вставленный текст не сохраняется; остаётся только явно выраженное отношение владельца к нему. [L39-L40]
- Каждый разговор записывается в отдельный файл и содержит только сказанное в нём; без session id скрипт отказывает, чтобы не смешивать разговоры. [L40-L42]
- Если поле `model` есть, в нём указывается точно известная resolved модель, создавшая файл, даже если разговор продолжала другая модель; `date` — локальный день самой ранней сохранённой source-цитаты. [L44-L46]
- Если позже добавлена более старая цитата, helper переименовывает тот же session-файл и обновляет `date`/заголовок, не меняя уже сохранённый текст. [L46-L48]
- Текст записей не редактируется; превращение выдержки в правило `AGENTS.md`/`CLAUDE.md` или decision `GOAL.md` является отдельным ручным проходом. [L50-L51]
- Предшественник `../user-said/` заморожен и содержит записи по 2026-05-28. [L53]
