# Проектирование читаемого кода и устойчивых программных границ

Владелец определяет содержание 1readable-code через внешние исследования о коде, который предпочитают LLM-агенты, и через общие системные промпты, помогающие им успешно писать код. Для этого заданы критерии исследований, принципы Брукса и deep modules, а также равенство версий Codex и Claude.

## Основание содержания и критерии исследований

- Владелец поправил направление 1readable-code: содержание должно опираться на внешние исследования о коде, который предпочитают LLM-агенты, а не на читаемость кода для владельца. [2026-08-11-050000-claude-ad4c0fa8.md#L19]
- Владелец задал критерий использовать для 1readable-code только исследования за последние полгода. [2026-08-11-050000-claude-ad4c0fa8.md#L21]

## Принципы кода

- Владелец решил, что весь код должен следовать концептуальной целостности Брукса и принципам deep modules Ousterhout, поскольку исследования связывают их с улучшением работы агентов. [2026-08-11-050000-claude-ad4c0fa8.md#L20]

## Границы входа и совместимость

- Владелец решил расширить вход 1readable-code: учитывать не только предпочтения coding-агентов к коду, но и общие системные промпты, помогающие им успешно писать код. [2026-08-11-050000-claude-ad4c0fa8.md#L22]
- Владелец решил, что версия 1readable-code для Codex должна быть такой же, как версия для Claude. [2026-08-11-050000-claude-ad4c0fa8.md#L23]
