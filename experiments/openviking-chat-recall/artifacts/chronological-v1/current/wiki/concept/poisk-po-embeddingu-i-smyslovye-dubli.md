# Как владелец различает поиск по эмбеддингам и смысловые дубли?

Владелец описал поиск по эмбеддингам как математический поиск похожестей, а не смысловой поиск. Он сформулировал правило-кандидат: не использовать этот механизм для поиска смысловых дублей и красной линией закрепить это ограничение в скилах.
