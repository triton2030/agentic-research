# Какой охват владелец задаёт для глобальных скилов?

Владелец считает скилы глобальными: они должны запускаться во всех проектах, а не быть привязаны к одному проекту. Он задал работу в Claude и Codex критерием, назвал Fable и Opus 4.8 средами использования и связывает скилы с передачей агенту особенностей инструментов.
