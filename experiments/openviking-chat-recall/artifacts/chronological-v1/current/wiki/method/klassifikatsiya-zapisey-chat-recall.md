# Как владелец хочет классифицировать записи chat-recall?

Владелец хочет различать в записях возможные инструкции и сведения о собственном поведении, а не оставлять лог просто набором цитат. Для каждой записи нужна тема, причём темы он хочет делать гранулярными и близкими к предмету разговора; поля type и topic должны писаться по-английски, чтобы агенту было легче искать.
