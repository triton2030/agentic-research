# Chat recall owner statement canon

This page consolidates recurring owner positions that appear across the supplied chat-recall pilot records rather than retelling each source separately. It covers only positions that recur in the provided files and states uncertainty where the evidence is thin.

In this repair pass, semantically equivalent statements are merged into one canonical page with exact record counts, earliest and latest dated occurrences, a current formulation, and any visible change or contradiction.
