# Chat recall pilot wiki

This wiki captures the wave-1 pilot knowledge preserved in six immutable chat-recall holders from July to August 2026. It focuses on how the recall system was scoped, corrected, and shaped around chronology, process, preferences, and explicit boundaries.

## Concepts

- [Chat recall capture policy](concept/Chat%20recall%20capture%20policy.md) — What a valid captured quote should preserve, how literal it should be, and which metadata or transformations are out of bounds.
- [Session-context retrieval model](concept/Session-context%20retrieval%20model.md) — How file-level session cards were introduced to improve retrieval without treating them as proof of the owner's position.
- [Autonomy boundary in agent execution](concept/Autonomy%20boundary%20in%20agent%20execution.md) — Where autonomous action is encouraged, where literal confirmation is still required, and how later corrections narrowed overreach.

## Methods

- [Improving chat-recall retrieval experimentally](method/Improving%20chat-recall%20retrieval%20experimentally.md) — The evidenced process for testing retrieval changes, defining acceptance criteria, and keeping evaluation tied to real evidence.
