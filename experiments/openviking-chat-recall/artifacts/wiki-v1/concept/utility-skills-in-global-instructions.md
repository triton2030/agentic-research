# Какие рабочие скилы подключает глобальная инструкция?

Владелец предложил как правило: добавить в глобальную инструкцию строчку про чтение маркдаунов через скилл 1md-read, но позднее отменил это правило.

- Владелец предложил как правило: добавить в глобальную инструкцию строчку, чтобы агент всегда читал маркдаун-файлы через скилл 1md-read. [правило: маркдауны через 1md-read](../../../../../_ops/chat-recall/2026-07-29-000000-claude-a9f0f34a.md#L17)
- Владелец предложил добавить в глобальную инструкцию ультракороткое упоминание скилла находок: по ходу работы быстро записывать замеченные проблемы, чтобы не забыть, и продолжать работать не отвлекаясь. [правило: находки по ходу без отвлечения](../../../../../_ops/chat-recall/2026-07-29-201927-codex-019fadc9.md#L16)
