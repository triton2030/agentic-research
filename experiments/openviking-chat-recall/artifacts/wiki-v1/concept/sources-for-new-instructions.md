# Что владелец считает правильным источником для новых инструкций?

Поправлен дефолт для чистого нового проекта: инструкции следует создавать на основе официальных рекомендаций по агентным инструкциям, а не только на основе известных провалов языковых моделей. Знания исследований владелец предпочитает использовать за последние полгода, когда модели уже сильные.

- Владелец поправил дефолт для чистого нового проекта: инструкции следует создавать на основе официальных рекомендаций по агентным инструкциям, а не только на основе известных провалов языковых моделей.
- Владелец предпочитает использовать знания исследований за последние полгода, когда модели уже сильные.
