# По каким признакам владелец судит о качестве агентной инструкции?

Хорошая инструкция, по критерию владельца, ускоряет работу агента, снижает вероятность ошибки и быстро загружает в чистую сессию файлы, релевантные задаче; она создаёт направление движения и ограничители, чтобы владельцу не приходилось бесконечно работать вместо агента. Проектирование Agent Skills не должно ухудшать поведение по сравнению с вариантом без скила и опирается на общие принципы, а не на тесты и прогоны — нужен общий, не гарантированный способ проектирования. Действительную эффективность скилла владелец мерит качеством инструкций, которые агент пишет с его помощью; исходная боль этой работы — агенты не получают достаточно контекста или неправильно понимают его задачи.

- Владелец задал критерием для рассматриваемого скилла действительную эффективность инструкций, которые агент пишет с его помощью.
- Владелец задал критерий агентных инструкций: они должны ускорять работу агента, снижать вероятность ошибки и быстро загружать в чистую сессию файлы, релевантные задаче.
- Владелец задал критерий хорошей инструкции: она создаёт направление движения и ограничители, чтобы владельцу не приходилось бесконечно работать вместо агента, исправляя его.
- Владелец задал критерий: проектирование Agent Skills должно не ухудшать поведение по сравнению с вариантом без скила и должно опираться на общие принципы, а не на тесты и прогоны.
- Владелец поправил направление работы: нужен общий, не гарантированный способ проектирования, а не план, основанный на тестировании.
- Владелец рассказал о своей основной боли: агенты не получают достаточно контекста или неправильно понимают его задачи.
