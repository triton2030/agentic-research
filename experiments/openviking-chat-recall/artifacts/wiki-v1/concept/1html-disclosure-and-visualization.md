# Как артефакт должен раскрывать и иллюстрировать информацию вместо стены текста?

Артефакт раскрывает информацию прогрессивно и связанно — средствами табов, компонентов, кнопок, скрытия и якорей, а страницу прототипа интерфейса можно листать по состояниям. Стену текста заменяют иллюстративные HTML-артефакты — вложенность, графики, карты потоков, таймлайны, аккордеоны, попапы. Свобода дизайна не ограничивается обязательными шаблонами, а для разнообразной визуализации данных планируется подключить мощные библиотеки с примерами.

- Владелец решил, что скилл 1html должен обучать прогрессивному связанному раскрытию информации с учётом возможностей табов, компонентов, кнопок, скрытия и якорей. [прогрессивное связанное раскрытие](../../../../../_ops/chat-recall/2026-07-29-201852-codex-019fada0.md#L35)
- Владелец предпочитает, чтобы страница интерфейсного прототипа позволяла просматривать разные состояния через выпадающий список и комментарии. [просмотр состояний прототипа](../../../../../_ops/chat-recall/2026-07-29-201852-codex-019fada0.md#L30)
- Владелец поправил, что `1html` не должен ограничивать свободу дизайна обязательными шаблонами, а содержимое каждой React Flow node должно легко меняться под задачу. [свобода дизайна и гибкость нод](../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L33), [свобода дизайна и гибкость нод](../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L40)
- Владелец решил, что `1html` должен заменять стену текста иллюстративными HTML-артефактами: показывать вложенность, использовать разные графики, flow maps, bar charts и pie charts, анимации, timelines, accordions, popups и текст на hover, а также учитывать последние возможности CSS и HTML. [стена текста заменяется визуализацией](../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L37)
- Владелец решил включить в планы переработки `1html` мощные библиотеки с примерами разнообразной визуализации данных. [библиотеки визуализации данных](../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L41)
