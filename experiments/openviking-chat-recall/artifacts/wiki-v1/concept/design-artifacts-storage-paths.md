# Где хранить артефакты дизайн-скиллов?

В любом проекте артефакты `recraft-images` хранятся в `Workspace/Design/Recraft` — этот путь заменил `Workspace/Recraft`. Для design skills, создающих project artifacts, владелец предложил общий namespace `Workspace/Design`; под него подпадают и скриншоты глобального `1design-review`, которые решено хранить в `Workspace/Design`.

- Владелец уточнил, что в любом проекте артефакты `recraft-images` должны храниться в `Workspace/Design/Recraft`, заменяя путь `Workspace/Recraft`. [правило пути: Workspace/Design/Recraft вместо Workspace/Recraft](../../../../../../../_ops/chat-recall/2026-08-13-165535-codex-019ffaf7.md#L20)
- Владелец предложил применять общий namespace `Workspace/Design` к design skills, создающим project artifacts. [предложение: общий namespace Workspace/Design](../../../../../../../_ops/chat-recall/2026-08-13-165535-codex-019ffaf7.md#L21)
- Владелец решил хранить скриншоты глобального `1design-review` в `Workspace/Design`. [решение: скриншоты 1design-review в Workspace/Design](../../../../../../../_ops/chat-recall/2026-08-13-165535-codex-019ffaf7.md#L22)
