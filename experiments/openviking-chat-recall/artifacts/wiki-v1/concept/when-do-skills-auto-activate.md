# Когда skill должен активироваться автоматически?

Для глобальных agent skills владелец задал критерий максимально точного автоматического вызова нужного скилла в нужный момент. Короткие trigger-описания должны обеспечивать такой вызов во время длительной работы — когда агент входит в соответствующую релевантную часть работы, определяемую типом выполняемой задачи; так следует писать скиллы по умолчанию. Отдельно владелец решил вызывать `1use-principles` активнее, чаще и агрессивнее.
