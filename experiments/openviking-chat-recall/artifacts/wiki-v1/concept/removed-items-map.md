# Куда деваются удалённые из скила вещи?

Удалённое из скила не исчезает молча: составляется карта удалённых вещей, их сортируют по пользе, дают мнение о возврате или удалении, а самые полезные пункты подкрепляются цитатами владельца — вопрос рассматривается с точки зрения эффективного управления языковыми моделями. Отдельно фиксируется scope правки: уточняется только та версия скила, которая существует в конкретном рантайме.
