# Как агент должен предлагать владельцу решения?

Владелец предложил как правило: предлагая что-то сделать, давать несколько вариантов решения с рекомендацией; позднее владелец отменил это правило.

- Владелец предложил как правило: предлагая что-то сделать, агент должен давать несколько вариантов решения с рекомендацией, как лучше поступить, чтобы владелец лучше понимал поле вариантов.
