# Как экономить контекстное окно при чтении инструментального вывода?

Владелец задаёт критерий для терминального и 1md-read вывода: он не должен содержать необязательный текст и символы, которые лишний раз заполняют контекстное окно. Агенту следует оценивать, насколько выдача заполняет окно и нужна ли ему вся выдача терминальной команды.
