# Как устроен запуск множества агентов и кто ими управляет?

Один workflow одной командой запускает множество `Luna Max`-агентов, организуя их работу по порядку и параллельно. Root-agent выступает оркестратором фоновых тредов для этого проекта, а планирование ведётся в отдельной локальной папке планирования.

## Workflow и порядок запуска

- Владелец решил после аудита запускать множество Codex-агентов, именно `Luna Max`, для создания этой библиотеки.
- Владелец решил организовать один workflow, который одной командой запускает множество `Luna Max`-агентов, организуя их работу по порядку и параллельно.

## Оркестрация и планирование

- Владелец решил вести отдельную локальную папку планирования и поручить root-agent быть оркестратором фоновых тредов для этого проекта.

## Режим выполнения

- Владелец решил не использовать worktree для этого запуска и выполнять Luna Max в видимых фоновых тредах, чтобы видеть работу агента в Codex.
