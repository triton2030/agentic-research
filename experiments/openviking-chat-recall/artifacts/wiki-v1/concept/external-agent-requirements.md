# Каким должен быть внешний агент по требованиям владельца?

Требования к внешнему агенту сводятся к тому, что он читает все необходимые инструкции, качественно погружается в проект и по возможности использует скилы основного агента. Для `1hermes` владелец задал два проверяемых критерия: health должен показывать, работает ли инструмент, а cold-start должен давать новому агенту понимание, как пользоваться инструментом при первом знакомстве.

## Погружение и инструкции

- Владелец поправил требование к внешнему агенту: он должен читать все необходимые инструкции, качественно погружаться в проект и по возможности использовать скилы основного агента. ## Health

- Владелец задал для `1hermes` критерий: состояние health должно показывать, работает ли инструмент. [критерий: health показывает, работает ли инструмент](../../../../../../../_ops/chat-recall/2026-08-04-234007-codex-019fce09.md#L18)

## Cold-start

- Владелец задал для `1hermes` cold-start-критерий: новый агент при первом знакомстве с инструментом должен понимать, как им пользоваться. [критерий: cold-start понятен новому агенту](../../../../../../../_ops/chat-recall/2026-08-04-234007-codex-019fce09.md#L19)
