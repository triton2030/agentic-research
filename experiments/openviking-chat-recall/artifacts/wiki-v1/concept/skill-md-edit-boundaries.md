# Что можно менять в тексте `SKILL.md` пакета `123-explain`?

Владелец задал критерий для текста `SKILL.md`: когнитивные шаги должны быть описаны явно и без неоднозначности, причём это требование относится к самому скилу, а не к стилю ответа вызвавшего агента.
