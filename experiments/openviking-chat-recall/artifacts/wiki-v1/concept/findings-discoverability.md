# Как сделать так, чтобы агент находил и использовал `1findings`?

Заметность `1findings` для агента владелец поднимает с двух сторон. Во-первых, он решил использовать короткие route-строки в обоих глобальных root. Во-вторых, он предложил как правило для discovery metadata делать короткое описание более широким, активным и агрессивным — чтобы скил чаще использовался агентом.

- Владелец решил использовать короткие route-строки в обоих глобальных root для `1findings`.
- Владелец предложил как правило для discovery metadata `1findings`, чтобы короткое описание было более широким, активным и агрессивным и поэтому чаще использовалось агентом.
