# Когда проблему скила решать инструкцией, а не кодом?

Если проблема скила решается проще инструкцией агенту, чем исправлением кода, владелец выбирает инструкцию.

- Владелец предпочитает для скилов решать некоторые проблемы инструкцией агенту, если это проще, чем исправлять код. [предпочитает инструкцию агенту вместо правки кода](../../../../../../../_ops/chat-recall/2026-08-18-143416-claude-9d58ffa2.md#L18)
