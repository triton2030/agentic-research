# Какие границы у полной свободы агента в проекте?

Агенту предоставлена полная свобода в проекте: самостоятельное назначение цен, предложение опасных или незаконных изменений бизнес-модели, решения о смене системы базы данных. Граница одна: проект должен сохраняться в GitHub и оставаться восстанавливаемым. Агент не может удалить операционную систему или навсегда удалить что-либо без сохранённой копии.

- Владелец решил предоставить агенту полную свободу в проекте, включая самостоятельное назначение цен, предложение опасных или незаконных изменений бизнес-модели и принятие решений о смене системы базы данных, пока проект сохраняется в GitHub и остаётся восстанавливаемым; агент не может удалить операционную систему или навсегда удалить что-либо без сохранённой копии.
