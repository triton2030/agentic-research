# Где лежат записи 1chat-recall и как устроены имена файлов и метаданные?

Записи скила находятся в `_ops/chat-recall`, и сам скил сделан глобальным для всех проектов. Единица записи — один файл на один сеанс: одно окно чата и один разговор содержат только происходившее в этом окне, а одно окно записывает только этот один файл. В имя файла входит имя записывающего агента, чтобы параллельные агенты не пересекались; в метаданных — точность времени до секунды, session ID и максимально возможная точность даты.

## Расположение и охват

- Владелец решил, что записи скила должны находиться в `_ops/chat-recall`. [решение хранить записи в `_ops/chat-recall`](../../../../../_ops/chat-recall/2026-07-22-105500-claude-d8a832a4.md#L23)
- Владелец решил сделать скил глобальным для всех проектов. [решение сделать скил глобальным](../../../../../_ops/chat-recall/2026-07-22-105500-claude-d8a832a4.md#L24)

## Единица файла

- Владелец решил, что одно окно чата и один разговор образуют один файл, который содержит только происходившее в этом окне, и что одно окно может записывать только этот один файл. [решение один разговор — один файл](../../../../../_ops/chat-recall/2026-07-22-111300-claude-37219ddd.md#L31)
- Владелец сообщил, что в одной сессии работает только один агент, а субагенты получают не его прямые цитаты, а сообщения вызвавшего их агента. [рассказ об одном агенте в сессии и субагентах](../../../../../_ops/chat-recall/2026-07-22-111300-claude-37219ddd.md#L32)

## Имя файла, время и метаданные

- Владелец решил включать имя записывающего агента в имя файла, чтобы параллельные агенты не пересекались, а в метаданные — точность времени до секунды и session ID для возможного чтения переписки. [решение об имени агента в файле и точности времени](../../../../../_ops/chat-recall/2026-07-22-111300-claude-37219ddd.md#L28)
- Владелец решил, что скил должен сохранять даты его высказываний. [решение сохранять даты высказываний](../../../../../_ops/chat-recall/2026-07-22-105500-claude-d8a832a4.md#L20)
- Владелец задал для записи в `1chat-recall` критерий: агент сам указывает дату настолько точно, насколько это возможно. [критерий максимально точной даты](../../../../../_ops/chat-recall/2026-08-12-000000-claude-2649459a.md#L20)
