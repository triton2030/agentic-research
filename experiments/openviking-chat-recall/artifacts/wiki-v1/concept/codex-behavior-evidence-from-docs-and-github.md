# Чем подтверждать поведение Codex при расследовании?

Расследование поведения Codex опирается на документацию или GitHub, а не только на эмпирический опыт. Для анализа используется интернет — в первую очередь официальная документация Codex.

- Владелец уточнил, что при расследовании поведения Codex нужно обращаться к документации или GitHub, а не полагаться только на эмпирический опыт. [уточнил: расследовать по документации или GitHub](../../../../../_ops/chat-recall/2026-08-14-122215-claude-2e4e5183.md#L37)
- Владелец предпочитает использовать интернет для анализа официальной документации Codex. [предпочитает анализ официальной документации Codex через интернет](../../../../../_ops/chat-recall/2026-08-18-143416-claude-9d58ffa2.md#L20)
