# Через что формулировать скил?

Скил формулируется через желаемый результат, а не через внутренние действия агента: описание отвечает тем, что должно получиться, а не перечислением шагов внутри агента.

- Владелец поправил работу скила: формулировать его через желаемый результат, а не через внутренние действия агента.
