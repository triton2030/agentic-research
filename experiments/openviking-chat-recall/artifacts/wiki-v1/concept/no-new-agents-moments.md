# Когда владелец останавливал запуск новых агентов?

Наряду с правилами о веере субагентов есть два точечных останова: в одном разговоре было сказано, что сейчас новые агенты запускать не нужно, а в другом — прекратить использовать субагентов в процессе текущей правки глобального `1chat-recall`.

## Точечные остановы

- Владелец указал, что сейчас не нужно запускать новых агентов.
- Владелец поправил процесс текущей правки глобального `1chat-recall`: прекратить использовать субагентов.
