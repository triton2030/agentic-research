# Как формулировать строки глобальной инструкции, чтобы агент понял их однозначно?

Правила формулируются через желаемый результат, а не через большое количество ограничений: по наблюдению владельца, Codex сейчас крайне плохо работает и выглядит так, будто его сломал избыток инструкций. Критерий для английской глобальной инструкции Codex — предельно однозначные, понятные агенту формулировки с проверяемым результатом при минимально достаточной подробности; глобальную корневую инструкцию Claude владелец перевёл на английский и переформулировал предельно однозначно, чтобы исключить неправильное понимание агентом.

## Избыток инструкций и желаемый результат

- Владелец сообщил, что Codex сейчас крайне плохо работает и выглядит так, будто его сломал избыток инструкций, хотя в глобальной корневой инструкции их не так уж много.
- Владелец предложил формулировать инструкции Codex через желаемый результат, а не через большое количество ограничений.

## Однозначность и язык

- Владелец задал критерий для английской глобальной инструкции Codex: формулировки должны быть предельно однозначными, понятными агенту и обеспечивать проверяемый результат при минимально достаточной подробности.
- Владелец решил перевести глобальную корневую инструкцию Claude на английский язык и переформулировать её предельно однозначно, чтобы исключить неправильное понимание агентом.
