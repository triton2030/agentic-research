# Каким критериям должен отвечать скил, чтобы его использовали?

Скил должен доказать ИИ, зачем он нужен: без такого обоснования ИИ не будет качественно его использовать. Это критерий владельца, заданный для `1product-shaping`, и вопрос возникает всякий раз, когда пишется или ревьюится любой скил.

- Владелец задал критерий для скила: он должен доказать ИИ, зачем нужен, иначе ИИ не будет качественно его использовать.
