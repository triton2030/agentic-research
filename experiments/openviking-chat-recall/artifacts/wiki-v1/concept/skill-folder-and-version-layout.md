# Что владелец считает правильным устройством папок и версий скила?

У каждого скила должна быть отдельная папка, сохраняющая историю изменений и правила, не вошедшие в текущую версию. Скилл хранится в одной папке с версиями внутри при необходимости, без отдельного деления на Claude и Codex, хотя скиллы обычно зеркалятся.
