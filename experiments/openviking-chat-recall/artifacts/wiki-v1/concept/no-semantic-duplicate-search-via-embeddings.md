# Почему нельзя искать смысловые дубли через эмбеддинги?

Владелец предложил как правило никогда не использовать поиск дублей через эмбеддинги для поиска смысловых дублей и зафиксировать эту границу красной линией в скиллах, особенно при поиске по эмбеддингам. В том же правиле предлагается писать только дельту и описывать поиск по эмбеддингам как математический поиск похожестей, а не как смысловой поиск.
