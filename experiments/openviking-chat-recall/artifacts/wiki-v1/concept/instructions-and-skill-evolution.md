# Как владелец развивает и поддерживает инструкции 1chat-recall?

Инструкции обновляются по лучшим рекомендациям с учётом используемых моделей и сортируются по важности, не меняя цель и пользу скилла. В reference-файле указывается самый быстрый путь на основе экспериментов, проведённых в проекте. Краткое описание скилла должно явно сообщать, что цитаты владельца записываются, сохраняются и их можно сокращать, — иначе агенты читают только заголовок и фиксируют не-буквальные цитаты как буквальные.

## Обновление и порядок инструкций

- Владелец решил обновить репозиторий и промпты для Claude, особенно для Fable, по лучшим рекомендациям с учётом использования Fable и Opus 4.8. [решение обновить промпты по лучшим рекомендациям](../../../../../_ops/chat-recall/2026-07-22-105500-claude-d8a832a4.md#L25)
- Владелец задал критерий сортировать инструкции по важности, не меняя цель и пользу скила. [критерий сортировки инструкций по важности](../../../../../_ops/chat-recall/2026-08-09-132538-codex-019fe572.md#L23)
- Владелец предпочитает указывать в reference-файле самый быстрый путь на основе экспериментов, которые будут проведены здесь. [предпочтение самого быстрого пути в reference-файле](../../../../../_ops/chat-recall/2026-07-26-163521-claude-bddf1411.md#L16)

## Референты при рефакторах

- Владелец поправил референт текущего рефактора: обновлён `1skill-shaping`, а не `1chat-recall`. [поправка о референте рефактора](../../../../../_ops/chat-recall/2026-08-09-132538-codex-019fe572.md#L24)
