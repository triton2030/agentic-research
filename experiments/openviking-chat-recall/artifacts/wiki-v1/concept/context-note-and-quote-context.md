# Каким должен быть контекст, сопровождающий цитату владельца?

Вырванная из разговора цитата иногда непонятна, поэтому к записи добавляется контекст. По умолчанию это дельта-сюрприз — то, что нельзя вывести из самой цитаты; очевидное не повторяется, а факт выносится выше, чтобы агент его не пропустил.

`context-note` при этом служит поиску: он называет предметы своими именами, даже если сам владелец сформулировал цитату неточно.

## Правило для context-note

- Владелец предложил добавить в запись ещё одно поле `контекст`.
- Владелец задал критерий, что цитата, вырванная из контекста, иногда может быть непонятной.
- Владелец уточнил правило для `context-note`: контекст должен существовать по умолчанию как дельта-сюрприз, которую нельзя вывести из цитаты, не повторять очевидное и быть вынесенным выше, чтобы агент не пропускал этот факт.
- Владелец поправил назначение `context-note`: он должен улучшать поиск, называя предметы своими именами, даже если сам владелец формулирует цитату неточно.
