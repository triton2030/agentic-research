# Чем когнитивный скил отличается от справочного?

Сложная когнитивная работа должна быть целым протоколом или методологией, а не одним когнитивным прыжком. Справочный скилл вроде design system — второй жанр: он опирается на поведение модели, а не на личные пожелания владельца. Для когнитивного скила провал определяет сам владелец (см. страницу о разговоре с владельцем).

- Владелец поправил модель авторинга skills: сложная когнитивная работа должна быть целым протоколом или методологией, а не одним когнитивным прыжком.
- Владелец выделил второй жанр скилов: справочный скилл вроде design system должен опираться на поведение модели, а не на личные пожелания владельца.
