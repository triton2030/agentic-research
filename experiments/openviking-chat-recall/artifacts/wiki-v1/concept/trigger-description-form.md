# Как писать trigger description скила?

Description скила готовится по референсу о коротких trigger descriptions в `1skill-shaping`: его нужно переосмыслить так, чтобы оно оставалось коротким и при этом выполняло свои цели. Форма — прямая императивная команда, сформулированная по лучшим практикам. При балансе точный вызов важнее проблемы излишнего триггера.

## Подготовка

- Владелец поправил способ подготовки description 1product-shaping: нужно прочитать референс о коротких trigger descriptions в 1skill-shaping и переосмыслить описание так, чтобы оно оставалось коротким и выполняло свои цели. [поправка: короткий description через референс в 1skill-shaping](../../../../../_ops/chat-recall/2026-08-12-163448-claude-1d2d9841.md#L20)
