# Как цель превращается в планы через продуктовые рамки?

Высокоуровневые вопросы задаются на этапе 1product-shaping — там формируется продуктовая форма. Планирование (1planning) затем строится на этих продуктовых рамках через `1use-principles`. Отдельный скил протокола вопросов для этого не создаётся.

## Распределение между скилами

- Владелец решил, что высокоуровневые вопросы должны задаваться на этапе 1product-shaping, а 1planning должен строиться на продуктовых рамках через 1use-principles; отдельный скил протокола вопросов не создаётся.
