# На чём строится содержание 1readable-code?

Содержание 1readable-code по решению владельца опирается на внешние исследования о коде, который предпочитают LLM-агенты, а не на читаемость кода для самого владельца. Исследования отбираются по критерию свежести — только работы за последние полгода.

- Владелец поправил направление 1readable-code: содержание должно опираться на внешние исследования о коде, который предпочитают LLM-агенты, а не на читаемость кода для владельца.
- Владелец задал критерий использовать для 1readable-code только исследования за последние полгода.
