# На чём строится содержание 1readable-code?

Содержание 1readable-code по решению владельца опирается на внешние исследования о коде, который предпочитают LLM-агенты, а не на читаемость кода для самого владельца. Исследования отбираются по критерию свежести — только работы за последние полгода. Во вход 1readable-code входят не только предпочтения coding-агентов к коду, но и общие системные промпты, помогающие им успешно писать код.
