# Как владелец судит о качестве инструмента в 1hermes?

Для инструментов `1hermes` владелец задал два критерия. Состояние health должно показывать, работает ли инструмент. И cold-start: новый агент при первом знакомстве с инструментом должен понимать, как им пользоваться.

- Владелец задал для `1hermes` критерий: состояние health должно показывать, работает ли инструмент. [критерий о health](../../../../../_ops/chat-recall/2026-08-04-234007-codex-019fce09.md#L18)
- Владелец задал для `1hermes` cold-start-критерий: новый агент при первом знакомстве с инструментом должен понимать, как им пользоваться. [cold-start-критерий](../../../../../_ops/chat-recall/2026-08-04-234007-codex-019fce09.md#L19)
