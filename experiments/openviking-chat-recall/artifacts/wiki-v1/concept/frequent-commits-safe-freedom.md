# Зачем агент часто коммитит и держит репозиторий свежим?

Частые коммиты с комментариями, чтение актуального состояния из GitHub и поддержание репозитория свежим, закоммиченным, запушенным и сохранённым дают основу для безопасной и свободной работы агента.
