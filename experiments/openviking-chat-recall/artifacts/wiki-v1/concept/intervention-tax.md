# Что такое налог вмешательства?

Налог вмешательства означает, что каждая инструкция, процедура или скил усложняет работу агента, поэтому их нужно оставлять только в объёме, необходимом для нужного эффекта без общего ухудшения работы. С этим связан критерий необходимости для каждой инструкции: нужно уметь назвать наблюдаемое ухудшение, которое появится после её удаления.

- Владелец задал критерий необходимости: нужно уметь назвать наблюдаемое ухудшение, которое появится после удаления инструкции.
- Владелец решил учитывать налог вмешательства: каждая инструкция, процедура или скил усложняет работу агента, поэтому их нужно оставлять только в объёме, необходимом для нужного эффекта без общего ухудшения работы.
