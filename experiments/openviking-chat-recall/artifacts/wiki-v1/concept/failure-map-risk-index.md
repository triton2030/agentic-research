# Что такое Failure Map / Risk Index?

INDEX должен отвечать на вопрос, что модель особенно склонна забывать, и иметь формат Failure Map / Risk Index: When → Failure → Cost → Source. Ручной вызов скилла индекса и его обновление владелец рассматривает как вероятную модель обслуживания, а сам скилл — как часть handoff-протокола для будущих агентов; самостоятельное обновление он считает ненадёжным. За INDEX.md сохранена отдельная роль с допущением менее важных, но всё же полезных ссылок.
