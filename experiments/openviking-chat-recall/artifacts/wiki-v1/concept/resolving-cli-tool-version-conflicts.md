# Как решать конфликты терминальных инструментов?

При конфликте терминальных инструментов владелец предпочитает обновить обе конфликтующие вещи до новых версий. Основание: последние версии могут не конфликтовать между собой.

## Разрешение конфликтов версий

- Владелец предпочитает решать конфликты терминальных инструментов обновлением обеих конфликтующих вещей до новых версий, поскольку последние версии могут не конфликтовать между собой.
