# Должны ли глобальные инструкции Claude и Codex совпадать?

Нет. Владелец поправил, что описание для Claude должно соответствовать практикам Claude, которые отличаются от практик для ChatGPT. Точно так же одобренный блок `Мне тоже не доверяй` и сокращение `Читай воздух` применяются только к `/Users/triton/.codex/AGENTS.md`, а `/Users/triton/.claude/CLAUDE.md` менять не следует.
- Владелец поправил, что ту же переделку корневой инструкции требовалось сделать и в корневом промпте Codex — агент забыл его обновить. [коррекция: ту же переделку в codex root](../../../../../_ops/chat-recall/2026-08-08-135137-claude-457be55d.md#L31)
