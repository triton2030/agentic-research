# Как устроена панель экспертов 1fresh-eyes?

`1fresh-eyes` по умолчанию запускает панель нескольких экспертов с разными линзами, чтобы отчёты различались. Панель — это три субагента (`ladder`, `solvent`, `prospector`) плюс четвёртый участник `premortem`, который зеркально распределён между моделями: premortem для Claude выполняет Codex, а для Codex — Claude.

## Субагенты по экспертным ролям

- Владелец решил, что `1fresh-eyes` вызывает субагентов по экспертным ролям. [решил: вызов субагентов по экспертным ролям](../../../../../_ops/chat-recall/2026-08-05-153153-claude-1087a584.md#L15), [решил: вызов субагентов по экспертным ролям](../../../../../_ops/chat-recall/2026-08-10-200839-codex-019fec35.md#L20)
- Владелец решил, что `1fresh-eyes` должен ставить каждой роли отдельную задачу с собственной зоной чтения и мышления, чтобы она применяла свою экспертную линзу, а не методологию соседнего скила. [решил: каждой роли отдельная задача со своей зоной чтения и мышления](../../../../../_ops/chat-recall/2026-08-05-153153-claude-1087a584.md#L16)
- Владелец поправил `1fresh-eyes`: скилл должен позволять вызывать субагентов и не должен содержать церемонии, описывающие невозможность их вызова. [поправил: разрешить вызов субагентов, убрать церемонии о невозможности](../../../../../_ops/chat-recall/2026-08-11-234650-codex-019ff225.md#L15)
