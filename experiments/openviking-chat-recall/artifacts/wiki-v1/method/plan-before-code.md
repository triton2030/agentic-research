# Какая когнитивная работа должна предшествовать коду артефакта?

Ни один артефакт не создаётся до протокола когнитивной работы и планирования, жёстко встроенного в `1html`: план обеспечивает использование нужных компонентов и стабильный дизайн без ошибок CSS и HTML. Правило-кандидат «План До Кода» требует переиспользовать классы дизайн-системы, ограничить типографику примерно десятью видами текста и доказать responsive-поведение. Проверка правила — сравнить создание артефакта после плана субагента с созданием без плана.

- Владелец предложил правило-кандидат для `1html`: перед созданием любого артефакта агент должен выполнить и описать в скрытом toggle наверху артефакта требуемую когнитивную процедуру, а затем перейти к коду. [когнитивная процедура в скрытом toggle](../../../../../_ops/chat-recall/2026-08-20-212455-claude-0407e6d0.md#L19)
- Владелец поправил требование к работе с `1html`: нужно следовать скилу и не игнорировать его инструкции. [следовать скилу](../../../../../_ops/chat-recall/2026-08-20-212455-claude-0407e6d0.md#L22)
- Владелец решил жёстко встроить в `1html` протокол когнитивной работы и планирования, чтобы ни один артефакт не создавался до этой работы, а план обеспечивал использование нужных компонентов и стабильный дизайн без ошибок CSS и HTML. [протокол до любого артефакта](../../../../../_ops/chat-recall/2026-08-20-224022-claude-1bc0a881.md#L21)
- Владелец задал критерий проверки `1html`: сравнить создание артефакта после плана субагента с созданием артефакта без плана и по результату определить, сработало ли правило. [критерий проверки правила](../../../../../_ops/chat-recall/2026-08-20-224022-claude-1bc0a881.md#L22)
- Владелец предложил правило-кандидат для `План До Кода`: переиспользовать классы дизайн-системы, ограничить набор типографики примерно десятью видами текста и доказывать responsive-поведение. [правила План До Кода](../../../../../_ops/chat-recall/2026-08-20-224022-claude-1bc0a881.md#L23)
