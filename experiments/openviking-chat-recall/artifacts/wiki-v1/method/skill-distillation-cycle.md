# Как проводить цикл дистилляции скила?

Нужная мудрость записывается в скилл, затем субагент сокращает его с помощью 1distill, и результат оценивается. Для экспериментов используются только скилы экспертной линзы, переписывание поручается Claude Opus, а сделанный выбор объясняется Kimi с просьбой проверить план. Сам 1distill допустимо сокращать, выполняя его функцию и излагая желаемый результат в иной форме, если при этом сохраняется функционал.

## Маршрут

- Владелец решил использовать 1distill как маршрут: записывать нужную мудрость в скилл, затем запускать субагента для его сокращения с помощью 1distill и оценивать результат.
- Владелец предложил сокращать 1distill также через выполнение его функции и изложение желаемого результата в иной форме, если при этом сохраняется функционал.

## Подопытные, модель и проверка

- Владелец предложил для экспериментов 1distill всегда использовать скилы экспертной линзы как подопытные, чтобы не переписывать хорошие скилы.
- Владелец предпочитает поручать переписывание 1expert-lens модели Claude Opus и не использовать модели ниже Opus.
- Владелец предпочитает после написания 1distill объяснять Kimi сделанный выбор и просить проверить план.
