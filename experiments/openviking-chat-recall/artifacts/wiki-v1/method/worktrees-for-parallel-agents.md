# Когда создавать Git-worktree для параллельных агентов и когда удалять?

Worktree нужен только тогда, когда есть уверенность, что параллельные агенты будут писать в одни и те же файлы: при раздельных файлах конфликта не будет, и агенты могут писать непосредственно в основную ветку. Устаревшие окружения убираются: Codex-managed Git worktrees старше трёх дней — правило-кандидат на удаление.
