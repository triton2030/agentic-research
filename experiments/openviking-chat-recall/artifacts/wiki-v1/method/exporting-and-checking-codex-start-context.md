# Как экспортировать и проверить стартовый контекст Codex?

Критерий владельца: экспорт стартового контекста Codex должен одним текстом показывать всё, что попадает в контекст при любой работе и при её запуске, причём проверка касается только нулевого стартового input в начале разговора, до первого ответа Codex, без накопленной истории и результатов инструментов. Для получения экспорта владелец решил создать скрипт повторяемой сборки вместо ручной и смотреть результат в черновом HTML-артефакте. Особый предмет проверки — попадание в стартовый контекст коротких описаний отключённых скилов, а не загрузка полного `SKILL.md`.

- Владелец решил получить текстовый файл только с разрешённой к экспорту частью полученного контекста, включая короткие описания скилов и память, чтобы понять его состав; он рассматривает эти описания как возможный дополнительный системный промпт. [решил получить файл разрешённой части контекста](../../../../../_ops/chat-recall/2026-08-22-144408-codex-01a028da.md#L20)
- Владелец считает, что короткие описания скилов даже без вызова полного скила являются дополнительным контекстом, могут сообщать агенту сведения о владельце и проекте и способны менять поведение агента.
