# Когда wave 1codex считается закрытой?

Wave 1codex закрывается только при наличии в fleet.md квитанции с полями `wave.cleanup_done`, `wave.kept_branches` и `wave.threads_archived`. `SKILL.md` содержит указатель на эту квитанцию, а не её копию.
