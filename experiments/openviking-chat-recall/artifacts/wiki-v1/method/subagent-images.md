# Какие картинки получают субагенты 1design-review?

Большую картинку субагентам не передают: каждый subagent получает одну узкую производную картинку, вырезанную из большой, а при общей оценке дизайна — отдельные смысловые блоки и кнопки. Для оценки количества текста относительно воздуха и отступов готовятся специальные изображения, а коллаж видимых кнопок вмещает не более четырёх кнопок.

## Раздача субагентам

- Владелец уточнил, что каждый subagent `1design-review` получает одну узкую производную картинку, вырезанную из большой, а большую картинку субагентам не передают.
- Владелец задал критерий: при общей оценке дизайна субагентам нужно передавать отдельные смысловые блоки и кнопки, а не всю картинку целиком.

## Специальные изображения

- Владелец задал критерий: оценка количества текста относительно воздуха использует изображение с белым фоном и красными квадратами вместо букв, а оценка отступов — отдельное изображение без контента, где перекрашены только отступы.
- Владелец задал критерий: коллаж видимых кнопок может содержать не более четырёх кнопок.
