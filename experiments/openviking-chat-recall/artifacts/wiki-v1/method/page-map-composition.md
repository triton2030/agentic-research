# Как составлять карту страницы?

Карту страницы агент описывает в максимально коротком, почти телеграфном техническом стиле; порядок элементов и их размер имеют существенное значение. Содержание текстового блока не передаётся — описываются назначение блока и то, как его видит пользователь. По умолчанию берётся десктопная PC-версия, мобильная и другие размеры — только по запросу.

## Стиль и существенное

- Владелец решил, что агент должен описывать всю страницу в максимально коротком, почти телеграфном техническом стиле.
- Владелец задал критерий: в карте страницы порядок элементов и их размер имеют существенное значение.

## Вместо текста блока

- Владелец решил не передавать в карте содержание текстового блока, а описывать назначение блока и то, как его видит пользователь.

## Viewport по умолчанию

- Владелец решил использовать десктопную PC-версию как viewport по умолчанию, а мобильную версию и другие размеры — только по запросу.
