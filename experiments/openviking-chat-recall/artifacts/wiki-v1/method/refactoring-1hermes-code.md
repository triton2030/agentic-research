# Как менять код 1hermes?

Код Hermes нужно сверить с документацией Hermes, чтобы проверить, не изобретает ли он уже описанные в ней решения. Решён рефакторинг из-за чрезмерного количества строк в одном файле: код упрощается переносом части работы запускаемого скилом агента в его когнитивные способности — это сохраняет гибкость, не ограничивает агента программированием и уменьшает объём кода. Все методики обучения убираются из кода и переносятся в скил, а не наоборот.
