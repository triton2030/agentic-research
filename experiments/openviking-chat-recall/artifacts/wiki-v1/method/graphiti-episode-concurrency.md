# Как устроена параллельность и форма запусков внутри одного episode?

Решение по структуре выполнения: episodes остаются последовательными, внутри одного episode сохраняются четыре параллельных Luna-turn, а исполнение идёт через один тёплый Codex app-server с новым Ephemeral thread для каждого Graphiti-вызова. Отдельно предложено ускорить Graphiti-ingest правильной параллельностью, если это возможно, и проверить, сможет ли один правильно составленный промпт позволить агенту сразу создавать множество записей со связями в Graphiti.

## Структура episodes и тредов

- Владелец решил оставить episodes последовательными, сохранить четыре параллельных Luna-turn внутри одного episode и перейти на один тёплый Codex app-server с новым Ephemeral thread для каждого Graphiti-вызова.

## Ускорение

- Владелец предложил ускорить Graphiti-ingest правильной параллельностью, если это возможно.
- Владелец предположил, что официальная документация Graphiti должна содержать рекомендации по параллельности.

## Записи одним промптом

- Владелец предложил проверить, может ли один правильно составленный промпт позволить агенту сразу создавать множество записей со связями в Graphiti.
