# Насколько автономно выполняется эксперимент — нужен ли approval gate?

Владелец решил следовать цели автономно, без отдельного approval gate со стороны владельца, и до конца придерживаться рекомендованной схемы: без `changeset`-слоя заявок с манифестами и хешами, с батчами, процедурой OpenViking в промпте, смысловым аудитом и git как откатом. Дополнительные согласования не запрашиваются.
