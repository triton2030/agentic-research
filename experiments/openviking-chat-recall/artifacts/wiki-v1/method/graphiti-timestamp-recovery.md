# Как восстановить время для записей Graphiti без точного времени?

Для записей Graphiti без точного времени нужно восстанавливать время по часовому окну между соседними файлами, используя дату сессии и порядок цитат внутри целевого файла. Для двухнедельного корпуса порядок важнее точности минут и секунд.

## Правило восстановления

- Владелец уточнил, что для записей Graphiti без точного времени нужно восстанавливать время по часовому окну между соседними файлами, используя дату сессии и порядок цитат внутри целевого файла; для двухнедельного корпуса порядок важнее точности минут и секунд.
