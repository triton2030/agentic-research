# Как сжимать инструкции скилла?

Инструкции в скиле нужно раскладывать по правильным разделам, а повторяющиеся объединять в зонтичные инструкции верхнего уровня — большое количество инструкций ослабляет их; набор инструкций сокращается через зонтичные инструкции, чтобы их стало меньше и каждая стала сильнее. Новая версия может быть примерно вдвое короче без потери смысла.
