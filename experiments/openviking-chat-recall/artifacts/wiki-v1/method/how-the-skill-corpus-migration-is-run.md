# Как владелец предписывает переписывать корпус skills и инструкций?

Порядок работы зафиксирован поправкой владельца: в текущей работе редактируются именно `1skill-shaping` и `1instruction-shaping`, а цель — с помощью обновлённой пары переработать остальные глобальные skills и instructions по методу Matt Pocock, а не переделывать прежде всего сами skills формы. Пересмотр должен включать многоагентный анализ переусложнения числа инструкций, возможного объединения под более широкими именами на верхнем уровне и удаления текущих инструкций, противоречащих планируемым изменениям, с привлечением субагентов, включая Claude. Владелец решил вместе с Claude Opus продумать редактирование пары, а по остальным развилкам принять рекомендации, написать скилл и затем проверить субагентами, что потеряно и что ещё можно сократить.
