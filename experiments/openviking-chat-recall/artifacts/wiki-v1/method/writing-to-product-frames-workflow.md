# Как агент записывает новое знание в продуктовые рамки?

Запись идёт через скилл продуктовых рамок: он помогает агенту настроиться и корректирует его траекторию, поэтому вызывается перед любой записью. Сам workflow разграничивает чтение и запись: скрипт нужен только для чтения. Ручная запись начинается с поиска дубликата — при повторе новая рамка не создаётся, при дополнении существующая слегка улучшается; вместо нового `Product Frame` в метаданные существующего добавляется ещё одна ссылка на цитату, причём ссылки бывают только цитатными.

## Вызов скилла перед записью

- Владелец предложил как правило перед любой записью вызывать скилл продуктовых рамок, чтобы он помогал агенту настроиться и корректировал его траекторию.

## Скрипт и ручная запись

- Владелец поправил workflow Product Frames: скрипт нужен только для чтения, а перед ручной записью агент должен искать дубликат и при повторе не создавать новую рамку, а при дополнении слегка улучшать существующую; новый `Product Frame` не создаётся, а в метаданные существующего добавляется ещё одна ссылка на цитату; ссылки бывают только цитатными.
