# Как прогнать полный ingest корпуса цитат через Graphiti?

Цель — обработать всю папку чата и записать её в Graphiti: существенно заполнить базу файлами цитат за пару недель по полной методике, а затем гонять запросы с помощью 1codex-bg-threads. Исполнение держится на фоновых тредах с Luna Max, которые следят, чтобы полный ingest не останавливался до конца; сам владелец предпочитает короткие наблюдаемые запуски одному долгому запуску, который приходится долго ждать.

## Объём ingest

- Владелец уточнил, что целью является обработать всю папку чата и записать её в Graphiti.
- Владелец уточнил, что Graphiti нужно существенно заполнить файлами цитат за пару недель по полной методике, а затем гонять запросы с помощью 1codex-bg-threads.

## Надзор за завершением

- Владелец решил использовать фоновые треды с Luna Max, которая будет следить, чтобы полный ingest не останавливался до конца.

## Форма запусков

- Владелец предпочитает короткие наблюдаемые запуски Graphiti-ingest вместо одного долгого запуска, который приходится долго ждать.
