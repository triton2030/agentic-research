# Эксперимент Graphiti: превращение цитат в память

Как прогнать полный ingest корпуса цитат, какие модели выбрать для LLM-вызовов, как встроить Graphiti в проект и как проверяется, что память улучшает ответы

- [Как владелец проверяет, что память улучшает ответы, — внутри Graphiti и против 1chat-recall?](../comparison/memory-usefulness-comparison.md) — Память должна улучшать качество ответа; ручное сравнение на разных сериях вопросов, включая A/B shared и Ephemeral и тот же запрос в Graphiti и 1chat-recall.
- [Как восстановить время для записей Graphiti без точного времени?](../method/graphiti-timestamp-recovery.md) — Восстанавливать время по часовому окну между соседними файлами из даты сессии и порядка цитат внутри файла; для двухнедельного корпуса порядок важнее минут и секунд.
- [Как встроить Graphiti в проект и что можно менять?](../concept/graphiti-integration-approach.md) — Опираться на штатную реализацию Graphiti, меняя обработку языковыми моделями на свою; установка в experiments/agentic-research и лёгкая адаптация под Codex.
- [Как прогнать полный ingest корпуса цитат через Graphiti?](../method/graphiti-full-ingest-run.md) — Полный ingest всей папки чата по полной методике под надзором фоновых тредов с Luna Max, короткими наблюдаемыми запусками; затем запросы через 1codex-bg-threads.
- [Как устроена параллельность и форма запусков внутри одного episode?](../method/graphiti-episode-concurrency.md) — Episodes последовательные, четыре параллельных Luna-turn внутри одного episode, один тёплый Codex app-server с новым Ephemeral thread на каждый вызов; параллельность ingest ускорять, если возможно.
- [Какие модели выбрать для LLM-вызовов Graphiti?](../comparison/graphiti-model-choice.md) — Luna Max выбрана для LLM-вызовов (Terra не дала выигрыша по скорости, Luna дешевле); Sol/medium или даже Luna Max предположительно справятся с записью целого файла цитат.
- [Кто советник по стратегии кода?](../method/opus-code-strategy-advisor.md) — При работе над кодом владелец предпочитает чаще вызывать Opus как советника по стратегии кода.
- [По каким источникам изучать Graphiti и каким критерием проверять guide?](../method/graphiti-study-guide.md) — Официальная документация, GitHub и код на GitHub, оценка самой системы, а не скорости; guide принимается, только если агент чинит интеграцию без повторного поиска с нуля.
- [Что владелец хочет получить от Graphiti в этом эксперименте?](../concept/graphiti-goal-and-surface.md) — Цель — связанная база знаний с заново сформулированным смыслом цитат; пользовательская поверхность не должна давать ссылки на существующие цитаты.
