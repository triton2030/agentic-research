# Принципы читаемого кода (1readable-code)

Каким принципам должен следовать код, каковы границы входа 1readable-code, на чём строится содержание и отличается ли версия для Codex

- [Должна ли версия 1readable-code для Codex отличаться от версии для Claude?](../entity/readable-code-codex-claude-parity.md) — Позиция владельца: версия 1readable-code для Codex должна быть такой же, как версия для Claude.
- [Каким принципам должен следовать код?](../concept/readable-code-brooks-deep-modules.md) — Позиция владельца: весь код должен следовать концептуальной целостности Брукса и принципам deep modules Ousterhout.
- [Каковы границы входа 1readable-code?](../concept/readable-code-entry-boundaries.md) — Границы входа 1readable-code — не только предпочтения coding-агентов к коду, но и общие системные промпты, помогающие им успешно писать код.
- [На чём строится содержание 1readable-code?](../concept/readable-code-content-basis.md) — Основание содержания 1readable-code — свежие внешние исследования о коде, который предпочитают LLM-агенты, а не читаемость для владельца.
