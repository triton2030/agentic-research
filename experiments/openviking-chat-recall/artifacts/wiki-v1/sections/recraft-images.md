# Генерация изображений через Recraft

Как оформлен пакет recraft-images, где хранить артефакты дизайн-скиллов, можно ли менять storage paths без shaping-аудита и что решено о будущем Recraft MCP

- [Где хранить артефакты дизайн-скиллов?](../concept/design-artifacts-storage-paths.md) — Артефакты recraft-images хранятся в Workspace/Design/Recraft; для design skills с project artifacts владелец предложил общий namespace Workspace/Design, включая скриншоты 1design-review.
- [Как владелец оформил пакет recraft-images?](../entity/recraft-images-tracked-owner.md) — У recraft-images будет tracked owner в agentic-research, синхронизируемый с установленной projection.
- [Можно ли менять storage paths в дизайн-скиллах без shaping-аудита?](../concept/storage-path-change-without-shaping-audit.md) — Текущую смену storage paths в recraft-images и 1design-review владелец разрешил вносить сразу, без полного shaping-аудита.
- [Что владелец решил о будущем Recraft MCP?](../entity/recraft-mcp-future-plans.md) — Recraft понадобится в будущем; код Recraft MCP планируется отредактировать, чтобы массовые попытки открыть Recraft не повторялись.
- [Что известно о массовом открытии Recraft в браузере?](../analysis/recraft-browser-opening-incident.md) — Владелец наблюдал массовые попытки открыть Recraft, остановил обращавшийся к нему неизвестный повторяющийся процесс и предположил вирусную причину.
