# Запуск Ox Alpha и внешних агентов через Hermes

Как запускать Ox Alpha через Hermes, какая модель там по умолчанию, какие права даны внешним агентам, можно ли строить связки из нескольких агентов, как менять код 1hermes

- [В каких ролях владелец использует Codex-субагентов?](../concept/codex-subagent-roles.md) — Позиция: Codex-субагентов предпочитают чаще использовать как советников и аудиторов; вариант «только после основной работы и только аудиторы» не принят.
- [Где живёт код 1hermes и как его упрощают?](../entity/1hermes-code-home-and-simplification.md) — Позиция: код 1hermes хранится под git рядом с product-frame как owner, ~/.claude — проекция; код сверяют с документацией, рефакторят и переносят обучение из кода в скил.
- [Как агент должен понимать запросы владельца и исправлять ошибки?](../concept/goal-over-literal-instructions.md) — Позиция: агент работает по цели владельца, а не по буквальному исполнению команд, и сразу исправляет выявленные проблемы по своему усмотрению без дополнительных вопросов.
- [Как владелец делегирует работу субагентам?](../concept/delegation-to-subagents.md) — Позиция: субагентам отдают внимательное чтение слов владельца и токеносберегающие задачи; связки агентов строятся последовательно, контекст основного агента не заполняется чужими ответами.
- [Как владелец запускает Ox Alpha через Hermes?](../entity/ox-alpha-through-hermes.md) — Позиция: Ox Alpha живёт в 1hermes через Hermes harness без отдельного скила, провайдер — Nous, гейт zero-pricing без fallback, использование только пока модель бесплатна.
- [Как владелец судит о качестве инструмента в 1hermes?](../concept/tool-health-and-cold-start.md) — Инструмент в 1hermes хорош, когда health показывает работу и новый агент понимает его с первого раза
- [Как делегировать работу субагентам и внешним агентам?](../method/delegating-to-subagents.md) — Субагентам отдают исследование слов владельца и экономию токенов основного агента; внешний агент обязан погружаться и читать инструкции
- [Как запускать Ox Alpha через Hermes?](../entity/how-to-run-ox-alpha.md) — Провайдер Nous, provider-specific zero-pricing gate без fallback, strict resume identity и лимиты подписки не сдерживают вызовы
- [Как менять код 1hermes?](../method/refactoring-1hermes-code.md) — Сверка с документацией Hermes, рефакторинг перегруженного файла, перенос методик обучения в скил
- [Какая модель по умолчанию работает в 1hermes?](../entity/default-model-kimi-k3.md) — Дефолт 1hermes — Kimi K3 с высоким reasoning effort плюс привычка перепроверять конкретные значения настроек
- [Какая модель по умолчанию стоит у 1hermes?](../entity/hermes-default-model.md) — Позиция: дефолт 1hermes — Kimi K3 с высоким reasoning effort; конкретные значения настроек владелец просит проверять, а не брать на веру.
- [Какие права владелец даёт внешним агентам и Ox Alpha?](../concept/external-agent-rights.md) — Внешним агентам и Ox Alpha — полные права; приватность и гейт бесплатности их не ограничивают
- [Каким должен быть внешний агент по требованиям владельца?](../concept/external-agent-requirements.md) — Позиция: внешний агент читает все инструкции, глубоко погружается в проект и использует скилы основного агента; health показывает работоспособность инструмента, cold-start понятен новичку.
- [Можно ли строить связки из нескольких внешних агентов?](../method/chains-of-external-agents.md) — Владелец предложил научить скилл вызова внешних моделей строить последовательные связки агентов
- [По чему агент выбирает способ работы?](../concept/agent-by-goal-not-literal-orders.md) — Агент работает по цели владельца, а не исполняет его команды буквально
- [Спрашивать ли владельца перед исправлением выявленных проблем?](../concept/fix-problems-without-asking.md) — Выявленные проблемы исправляются сразу и по своему усмотрению, без дополнительных вопросов
