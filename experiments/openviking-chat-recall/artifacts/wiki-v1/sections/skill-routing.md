# Имена, описания и автоактивация скилов

Когда скил должен активироваться автоматически, как отображать имена, какие скилы отключить, и что короткие описания делают с поведением агента

- [Как отображать имена skills?](../concept/how-skill-names-are-displayed.md) — Названия скиллов с префиксом 1 показываются в Codex русскими именами, по звучанию близкими к оригиналу.
- [Как экспортировать и проверить стартовый контекст Codex?](../method/exporting-and-checking-codex-start-context.md) — Повторяемым скриптом одним текстом экспортировать нулевой стартовый input и проверить, попадают ли туда короткие описания даже отключённых скилов.
- [Какие скиллы отключить, а каким разрешить автоматический вызов?](../entity/skill-audit-disable-and-auto-invoke-list.md) — Аудит всех установленных скилов в таблице описаний и поимённый вердикт владельца об удалении, отключении автозова и включении автозова.
- [Когда skill должен активироваться автоматически?](../concept/when-do-skills-auto-activate.md) — Точные trigger-описания должны звать нужный скилл в момент входа агента в релевантную часть работы — так писать скиллы по умолчанию.
- [Что короткие описания скилов делают с поведением агента?](../analysis/what-skill-descriptions-do-to-behavior.md) — Даже без вызова полного скила описания — дополнительный контекст, способный менять поведение; поэтому инструкции поведению из них вычищаются.
