# Ревью UI-дизайна по скриншотам (1design-review)

Из чего собран 1design-review, как вызывающий агент готовит скриншотный evidence, как составлять карту страницы, какие картинки получают субагенты-рецензенты и как устроен 1ui-reading-audit

- [Где хранить артефакты design skills?](../concept/design-artifacts-placement.md) — Запуск 1design-review — проектно-локально в _workspace/design/1design-review/MM-DD; общее правило — cross-project namespace Workspace/Design; для 1ui-reading-audit — с папками по дням.
- [Как 1design-review управляет работой субагентов?](../method/subagent-orchestration.md) — Главный агент сам отбирает выводы субагентов, заслуживающие внимания; скил обрабатывает 50–60 субагентов последовательно при максимуме трёх одновременно работающих.
- [Как вызывающий агент готовит скриншотный evidence?](../method/screenshot-evidence-preparation.md) — Критерий владельца — полный протокол подготовки evidence требует от вызывающего главного агента множества разных скриншотов.
- [Как называть display_name скилов с техническим именем на «1»?](../concept/leading-1-in-display-name.md) — Глобальные Codex skills с техническими именами на «1» сохраняют эту начальную «1» в русскоязычном display_name из agents/openai.yaml.
- [Как составлять карту страницы?](../method/page-map-composition.md) — Почти телеграфный технический стиль, существенные порядок и размеры, назначение блока вместо его текста, десктопная PC-версия как viewport по умолчанию.
- [Как устроен 1ui-reading-audit?](../entity/1ui-reading-audit.md) — Code-only аудит — карта страницы восстанавливается из кода без анализа скриншотов, проверка построена на паре «один пишет документ — другой читает и рекомендует».
- [Какие картинки получают субагенты 1design-review?](../method/subagent-images.md) — Каждому субагенту — одна узкая производная картинка, вырезанная из большой; большую не передают, а для текста, отступов и кнопок готовятся специальные изображения.
- [Что делает субагент-рецензент после карты страницы?](../method/map-review-subagent.md) — После создания карты вызывается субагент — анализирует документ и выдаёт рекомендации под цель страницы, как эксперт, с доказательствами и логикой в subagent-review.md.
- [Что такое 1design-review и из чего он собран?](../entity/1design-review.md) — Единый скил дизайн-ревью — объединение 1screenshot-design, 1design-subagents и 1design-review, улучшение по референсам и 1skill-shaping, проверка скриптов на реальном проекте.
