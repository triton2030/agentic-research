# Как устроена общая папка артефактов HTML_artifacts?

Архитектура зоны — одна папка `HTML_artifacts`: в ней лежат общие components, styles и libraries, которые переиспользует множество HTML-файлов, без отдельных копий под каждый артефакт. Showcase-артефакт с React Flow, ECharts, Mermaid и nested structures живёт в репозитории `agentic-research`, а не внутри Mavo. Для галереи файлов есть два правила-кандидата: редактировать существующий артефакт вместо создания лишних файлов и держать header со ссылками на все файлы.

## Архитектура папки

- Владелец задал архитектуру `1html`: одна папка `HTML_artifacts` должна содержать общие components, styles и libraries, переиспользуемые множеством HTML-файлов, без отдельных копий для каждого артефакта. [одна папка общих ресурсов](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L46), [одна папка общих ресурсов](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L47)
- Владелец уточнил, что showcase-артефакт с React Flow, ECharts, Mermaid и nested structures должен находиться в текущем репозитории `agentic-research`, а не внутри Mavo. [showcase в agentic-research](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L50)

## Правила галереи файлов

- Владелец предложил правило-кандидат: в галерее файлов нужно редактировать существующий артефакт вместо создания лишних файлов. [редактировать, а не плодить файлы](../../../../../../../_ops/chat-recall/2026-08-20-212455-claude-0407e6d0.md#L20)
- Владелец предложил правило-кандидат: артефакт `1html` должен иметь header со ссылками на все файлы. [header со ссылками на все файлы](../../../../../../../_ops/chat-recall/2026-08-20-212455-claude-0407e6d0.md#L21)
