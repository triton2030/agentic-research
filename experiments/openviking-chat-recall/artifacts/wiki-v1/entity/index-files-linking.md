# Как файлы 1index должны ссылаться друг на друга?

Несколько файлов `1index` не должны дублировать друг друга. Каждый индекс ссылается вниз в пределах своей папки; корневой индекс — единственный, кто может вдобавок ссылаться на другие индексы.

## Топология ссылок

- Владелец решил, что несколько файлов `1index` не должны дублировать друг друга, каждый индекс должен ссылаться вниз в пределах своей папки, а корневой индекс может ссылаться на другие индексы.
