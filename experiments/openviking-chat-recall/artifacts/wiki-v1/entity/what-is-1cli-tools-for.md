# Зачем нужен 1cli-tools?

`1cli-tools` нужен, чтобы сообщать агенту о новых возможностях терминальных инструментов, которых нет в памяти агента. Его цель — при предположении о наличии на устройстве уже установленных инструментов заставить агента проверить их и релевантно переиспользовать: так работа ускоряется и не разрабатывается заново уже доступное.
