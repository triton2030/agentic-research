# Что такое 1codex и зачем владелец его вызывает?

1codex — оркестраторский слой, который владелец использует для разведки при чтении большого объёма материалов, для запроса мнения умной модели и для запуска флота пишущих агентов либо одного агента с проверяемой работой: Codex иногда надолго застревает без понятного прогресса. Слой поддерживает поиск, чисто читающий review и другие роли Codex наряду с пишущими воркерами, и зовёт Codex не только как работника, но и как советника.

## Зачем вызывают

- Владелец решил использовать 1codex для разведки при чтении большого объёма материалов, для запроса мнения умной модели и для запуска флота пишущих агентов либо одного агента с проверяемой работой, поскольку Codex иногда надолго застревает без понятного прогресса. [решил использовать 1codex для разведки и флота](../../../../../../../_ops/chat-recall/2026-07-27-211730-claude-8e802437.md#L18)
- Владелец решил, что краткое описание 1codex должно говорить о наличии супермозга и напарника по мышлению, а не побуждать угадывать его буквальные просьбы, и что 1codex нужно использовать при сомнении и неуверенности в полноте поиска. [решил, каким быть описанию 1codex и когда его звать](../../../../../../../_ops/chat-recall/2026-07-27-211730-claude-8e802437.md#L21)

## Какие роли Codex поддерживает слой

- Владелец решил, что оркестраторский слой `1codex` должен поддерживать поиск, чисто читающий review и другие роли Codex наряду с пишущими воркерами. [решил поддерживать роли сверх пишущих воркеров](../../../../../../../_ops/chat-recall/2026-08-14-122215-claude-2e4e5183.md#L23)
- Владелец поправил расхождение в роли Codex: 1codex должен вызывать его как советника, а не только как работника. [поправил: Codex зовут и как советника](../../../../../../../_ops/chat-recall/2026-08-18-143951-claude-524d8920.md#L17)

## Фокус интереса к плагину

- Владелец поправил, что в плагине Codex его интересуют код и работа с инструментом, а не предпочтения. [поправил: в плагине важны код и работа инструмента](../../../../../../../_ops/chat-recall/2026-07-27-211730-claude-8e802437.md#L22)
