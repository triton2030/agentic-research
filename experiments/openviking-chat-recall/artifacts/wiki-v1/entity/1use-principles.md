# Что такое 1use-principles?

1use-principles создан, чтобы выбирать из множества возможных и длинных файлов принципов нужные для текущей работы следствия, и входит в состав планирования. Триггер расширен: проверять принципы нужно перед любой работой, где есть риск применить неподходящий дефолт, включая чистовую запись кода и документации спецификаций. Читает скилл только файлы принципов и файл цели — из них можно вывести направляющий контекст текущей работы. Поправка к автономии: решение нельзя выводить из одного принципа без проверки возможных контрпринципов (например, принципа выбора страны запуска по прибыльности при решении о добавлении индийского языка).

- Владелец решил создать 1use-principles, который выбирает из множества возможных и длинных файлов принципов нужные для текущей работы следствия и входит в состав планирования.
- Владелец решил расширить триггер 1use-principles: проверять принципы нужно перед любой работой, где есть риск применить неподходящий дефолт, включая чистовую запись кода и документации спецификаций.
- Владелец решил, что 1use-principles читает только файлы принципов и файл цели, поскольку из них можно вывести направляющий контекст текущей работы.
- Владелец поправил 1use-principles: автономное решение нельзя выводить из одного принципа без проверки возможных контрпринципов, например принципа выбора страны запуска по прибыльности при решении о добавлении индийского языка.
