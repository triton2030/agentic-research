# Когда вызывать 1md-read и какую задачу он решает?

`1md-read` вызывается, когда нужно читать много Markdown-файлов или сразу несколько файлов. Его цель, по поправке владельца, — ознакомиться с существующим слоем инструкций и инструментов, чтобы быстро читать множество файлов по заголовкам и коротким описаниям, не открывая сами файлы. Утверждён минимальный runtime-текст `1md-read` без отдельного reference и списка команд; live md-каталог остаётся владельцем возможностей.

- Владелец поправил цель `1md-read`: агент должен ознакомиться с существующим слоем инструкций и инструментов, чтобы быстро читать множество файлов по заголовкам и коротким описаниям, не открывая сами файлы. [поправка: цель — читать по заголовкам и описаниям](../../../../../_ops/chat-recall/2026-08-09-153733-codex-019fe619.md#L22)
