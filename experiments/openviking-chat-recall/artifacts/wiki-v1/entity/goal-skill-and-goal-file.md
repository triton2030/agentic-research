# Что такое 1goal и как связан файл GOAL?

`1goal` — скил, который проводит стратегическое интервью для формулирования глобальной цели всего репозитория; сама цель живёт в файле GOAL. Владелец задал критерий: агенты должны всегда читать этот файл, а знания о том, как его писать, должны помогать агентам стремиться к цели. Цель может уточняться по мере формирования продуктовой формы.

## Интервью и критерий файла

- Владелец решил, что `1goal` должен проводить стратегическое интервью для формулирования глобальной цели всего репозитория. [решение: 1goal ведёт стратегическое интервью](../../../../../_ops/chat-recall/2026-08-04-162452-codex-019fcbb1.md#L18)
- Владелец ограничил текущую работу скиллом `1goal`: `1product-shaping`, посвящённый более детальной форме продукта, не затрагивается. [ограничение: работа идёт в 1goal, 1product-shaping не затронут](../../../../../_ops/chat-recall/2026-08-04-162452-codex-019fcbb1.md#L18)
- Владелец задал критерий для файла цели: агенты должны всегда читать этот файл, а знания о том, как его писать, должны помогать агентам стремиться к цели. [критерий: GOAL читается агентами всегда](../../../../../_ops/chat-recall/2026-08-04-162452-codex-019fcbb1.md#L19)

## Эволюция цели

- Владелец решил, что цель может уточняться по мере формирования продуктовой формы. [решение: цель уточняется по мере продуктовой формы](../../../../../_ops/chat-recall/2026-08-04-162452-codex-019fcbb1.md#L20)
- Владелец решил, что связь Product Frame с GOAL должна быть строгой, но несовершенную цель следует редактировать через `1goal`; цель и принципы могут эволюционировать при отсутствии противоречий. [решение: строгая связь Product Frame и GOAL, правка через 1goal](../../../../../_ops/chat-recall/2026-08-08-190948-claude-60e39467.md#L21)
