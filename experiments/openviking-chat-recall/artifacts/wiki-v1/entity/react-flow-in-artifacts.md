# Как владелец требует использовать React Flow в артефактах?

Для больших нод с интерактивными toggles и accordions владелец добавил отдельный React Flow workflow с анимированными линиями течения данных — но только если он работает без dev server. Визуально React Flow не вводит собственный язык, а следует шрифтам и цветам палитры.

- Владелец решил добавить в `1html` отдельный React Flow workflow для больших нод с интерактивными toggles и accordions внутри и анимированными линиями, показывающими течение данных; workflow не нужен, если он не работает без dev server. [workflow для больших нод](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L35), [workflow для больших нод](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L38)
- Владелец задал, что React Flow должен следовать шрифтам и цветам палитры, а не вводить собственный визуальный язык. [React Flow по палитре](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L36)
