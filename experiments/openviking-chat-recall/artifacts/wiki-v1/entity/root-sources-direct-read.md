# Какие root-источники читает оркестратор?

Root-источники оркестратор должен читать напрямую, без посредников. Это одна из двух критичных правок, которые владелец решил внести в общий 1orchestration; второй стала поддержка durable manifest восстановления.

- Владелец решил внести в общий 1orchestration две критичные правки: прямое чтение root-источников оркестратором и durable manifest восстановления. [решение: прямое чтение root-источников как критичная правка](../../../../../_ops/chat-recall/2026-08-10-134812-codex-019feadb.md#L19)
