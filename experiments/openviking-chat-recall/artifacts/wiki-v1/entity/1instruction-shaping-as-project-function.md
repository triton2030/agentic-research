# Что такое 1instruction-shaping как функция от проекта?

1instruction-shaping владелец определил как функцию от проекта: сначала понять, что в проекте нужно делать, затем предугадать поведение агента и его возможные проблемы по целям проекта, после чего сформировать инструкции, которые облегчают работу, ускоряют её и повышают качество. Важность ориентировки определяется тем, к чему агент будет часто обращаться. При обнаружении проблемы скилл вызывает скилл формирования скилов; в споре об Agent Harness владелец уточнил, что отказ касается только второго дублирующего скила — сам 1instruction-shaping и есть этот harness.
