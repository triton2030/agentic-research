# Как 1html развивается и устанавливается в рантаймы?

Скилл правится одновременно в Claude и Codex и должен быть установлен в обоих; при просьбе создать черновой артефакт глобальный `1html` вызывается автоматически, для чего одобрена точная строка description. При изучении документации Alpine фиксируются особенно свежие сведения, которых нет в знаниях. Для текущей правки trigger-description граница — не использовать субагентов.

## Знания о библиотеках

- Владелец задал критерием внимательно изучать документацию Alpine, выявлять особенно свежие сведения, которых не хватает в знаниях об Alpine, и записывать их. [изучение документации Alpine](../../../../../../../_ops/chat-recall/2026-07-29-201852-codex-019fada0.md#L33)
- Владелец задал для 1document-system критерий формулировки, которая будет интересно и понятно читаться, а все проекции — легко читаться и проверяться агентами. [критерий читаемости проекций](../../../../../../../_ops/chat-recall/2026-08-01-122602-claude-5db612ad.md#L22)

## Правки и установка

- Владелец решил исправлять `1html` одновременно в Claude и Codex. [одновременно Claude и Codex](../../../../../../../_ops/chat-recall/2026-08-19-212344-codex-01a01ad4.md#L48)
- Владелец решил обновить корневую инструкцию репозитория `agentic-research` ссылками на расположение скилов и добавить `INDEX.md`. [корневая инструкция и INDEX.md](../../../../../../../_ops/chat-recall/2026-08-20-212455-claude-0407e6d0.md#L18)
- Владелец поправил требование установки `1html`: скил должен быть установлен и в Codex, и в Claude. [установка в Codex и Claude](../../../../../../../_ops/chat-recall/2026-08-21-010201-codex-01a020be.md#L17)
- Владелец решил включить автоматический вызов глобального `1html` в Codex и Claude при просьбе создать черновой артефакт. [авто-вызов на черновой артефакт](../../../../../../../_ops/chat-recall/2026-08-21-010201-codex-01a020be.md#L18)
- Владелец установил для текущей правки trigger-description границу: не использовать субагентов. [граница без субагентов](../../../../../../../_ops/chat-recall/2026-08-21-010201-codex-01a020be.md#L19)
- Владелец одобрил показанную точную строку description для глобального `1html`. [одобренная строка description](../../../../../../../_ops/chat-recall/2026-08-21-010201-codex-01a020be.md#L20)
