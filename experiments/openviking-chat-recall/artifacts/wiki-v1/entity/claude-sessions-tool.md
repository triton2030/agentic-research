# Что умеет MCP tool `claude_sessions`?

Владелец решил добавить read-only MCP tool `claude_sessions` для списка активных локальных Claude-сессий и чтения видимой переписки. Позже он поправил scope `claude_sessions`: чтение сессий является необязательной дополнительной возможностью, поскольку сессии нельзя создавать или редактировать.
