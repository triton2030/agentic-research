- Владелец задал условие завершения для двух активных планов работы MAVO — выполнять запланированное по порядку (сначала дизайн-трек, затем launch-build) и не останавливаться, пока всё возможное не сделано [L18]
- По ходу этой работы при возникновении конфликтов или пустот владелец решил принимать решения автономно через скилы [L18]
- Founder-only и внешние gates остаются границей полномочий в этой работе [L18]
- Владелец решил вести эту многофайловую работу через скилл оркестрации веток: агент выступает оркестратором веток, root сохраняет интеграцию и траекторию, пишущие задачи изолируются [L19]
- Для веток текущей MAVO-работы владелец предпочитает модельную маршрутизацию: Luna Max по умолчанию для дешёвой реализации и чтения, Sol xhigh для сложных развилок и synthesis [L20]
