# Distilled knowledge probe

This default surface contains only claims explicitly marked `current` or `contested` in the evidence manifest. Exact wording, chronology and unresolved claims stay outside this surface.

## Knowledge

- [The Wiki stores distilled facts, not source chronology](concept/distilled-facts-not-history.md) — The Wiki keeps distilled knowledge and facts while the original quotes keep the chronology of how those facts were reached. (current)
- [Subagents scout; the main agent reads the holder](concept/retrieval-scout-boundary.md) — Retrieval subagents locate useful holder files, while the main agent reads selected holders fully and owns the recovered position. (current)
- [The Wiki is a static derived library](concept/static-derived-library.md) — The distilled Wiki is a rebuildable knowledge library compiled from a static snapshot; the source holders remain the evidence layer. (current)
