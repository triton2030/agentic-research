Активные hooks из settings.json

PreToolUse 10s

Markdown graph pre-edit

Matcher
Edit|Write|MultiEdit|NotebookEdit
Делает
Для Markdown-файлов читает graph frontmatter, разворачивает read-before-edit и edit-after-edit.
Вывод
hookSpecificOutput.additionalContext
PreToolUse 10s

Markdown search pre-grep

Matcher
Grep
Делает
Если Grep идёт по индексированному Markdown-корпусу (.md-navigator/) и паттерн похож на понятие, советует md search-read вместо строкового grep.
Вывод
hookSpecificOutput.additionalContext
