# Обзор Хуков

## Роль

Эта папка держит snapshot-карты hook surfaces для Codex и Claude: что сейчас
подключено, когда срабатывает, что делает и что видит агент после срабатывания.

## Граница

Это view, не runtime truth. Live truth остаётся в глобальных config/settings,
hook scripts и plugin bundles. Перед обновлением карты сначала читай live
поверхности, а не старый HTML.

## Правила Документа

- Один runtime — один самодостаточный HTML-файл.
- В карточке hook-а показывай: событие, matcher, что делает, какой state
  читает/пишет, что агент видит как результат.
- Обязательно добавляй короткие examples agent-visible output: injected
  context, status block, reminder text или явное `silent/continue`, если агент
  ничего не видит.
- Не вставляй тела hook-ов, shell-команды запуска, длинный код, stack traces,
  общий учебник “зачем нужны hooks” или историю миграций.
- Неподключённые/legacy файлы показывай отдельно и только если они помогают не
  спутать их с active wiring.
- Если hook prompt меняется, обновляй пример того, что видит агент, в том же
  проходе.

## Проверка

Перед финалом проверь desktop и mobile viewport. Карта не должна иметь
горизонтальный overflow, а текст не должен содержать hook body или command
listing.
