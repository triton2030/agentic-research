Короткие examples результата hook-а, не код.

SessionStart

1start-here

[session-start] Ниже автоматически загружена ориентационная часть `1start-here/SKILL.md`.

UserPromptSubmit

Owner anchor

Якорь: в проектной работе проверь локальные owner-файлы, если они меняют маршрут, риск или проверку.

PreToolUse

Markdown graph

1md-graph: `md preflight` нашёл Markdown-контекст. До правки учти must-read; после — must-update/cascade.

PreToolUse

First-touch

Есть более точный способ чтения: используй `1md-reader`, если Markdown-target уже выбран.

Stop

Graph rollup

md-graph: за turn изменено N MD. Есть файлы с graph-связями/риском; проверь связанный контекст.

UserPromptSubmit

Supermemory

[SUPERMEMORY CONTEXT] User Profile + Relevant Memories, если recall нашёл релевантный контекст.
