# Срез портфеля MAVO для Obsidian Base Board

Это отдельный **read-only эксперимент**: локальная визуальная копия текущих
проектов и задач из ClickUp. Единственный operational source of truth остаётся
в ClickUp. Не переносите управление статусами или новые задачи сюда.

## Что внутри

- `Задачи/` — одна заметка на каждый проект и задачу из трёх списков MAVO;
- `Бизнес.base`, `Дизайн.base`, `Разработка.base` — три независимые табличные
  Base-страницы с проектом, типом, стадией и статусом;
- `scripts/sync-from-clickup.mjs` — намеренное обновление среза через
  установленный read-only launcher ClickUp.

Строка хранит ссылку на исходную задачу, статус, стадию, родительский проект,
описание, зависимости и заполненные поля ClickUp. Изменения в этой таблице
остаются только в локальном срезе и не записываются обратно в ClickUp.

## Открыть

Откройте одну из трёх `.base`-страниц внутри vault `agentic-research` — это
обычный путь для этого эксперимента. Фильтры также работают, если открыть саму
папку отдельным vault; в нём подключён Base Board 2.3.1, разделяемый с
установленным плагином MAVO.

## Обновить срез

```bash
node scripts/sync-from-clickup.mjs
```

Скрипт читает только рабочие списки `01 · Бизнес`, `02 · Дизайн` и
`03 · Разработка`, затем целиком пересоздаёт `Задачи/`. Не запускайте его после
ручных локальных правок карточек, если хотите их сохранить.
