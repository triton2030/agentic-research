# Результаты и ограничения

Эти сведения нужны при интерпретации ответа, ожидании или восстановлении
после сбоя. Они описывают сигналы инструмента, а не отдельный review-процесс.

## Когда вызов вернулся

One-shot success содержит `structuredContent.text`, native `session_id`,
`resolved_model`, requested fields, duration и warnings. У него нет отдельного
поля `terminal`. В managed session завершение turn обозначает
`terminal.kind: success`; принятые `open`/`send`/`steer` говорят лишь о приёме
операции. `terminal: null` означает отсутствие terminal result.

Мост проверяет subscription route и модель. Fresh результат соответствует
выбранному семейству; resume сохраняет исходное семейство Opus 5/Fable 5.
Подмена другим primary model возвращает `unsupported_model`, а не успешный
ответ от якобы выбранной модели. Requested effort — отправленная настройка;
он не доказывает применённый effort при ограничениях аккаунта или runtime.

Технический success обозначает завершённый turn. Файлы, выводы и выполненная
работа остаются результатом конкретной задачи и оцениваются по её условиям.

## Когда ответ обрезан

One-shot text ограничен 12 000 символами; managed observation хранит последние
четыре сообщения, не более 4 000 символов каждое. Маркер обрезки или warning
`result_truncated_at:*` сообщает потерю текста. Больший `max_chars` не вернёт
то, что уже отсечено при сохранении.

Доступные варианты — продолжить тот же разговор с конкретным вопросом,
попросить компактный полный вывод, разбить ответ по частям либо поручить Claude
сохранить большой результат в файл и читать этот файл. При `claude_ask` resume
передаётся прежний ID и profile; новый effort не меняет native session.

## Когда возникла ошибка

| Сигнал | Что он означает для следующего решения |
| --- | --- |
| Старая/missing callable schema | Новые модели или параметры появятся после переподключения MCP либо в свежей задаче хоста |
| Auth, billing, unsupported model/profile | Точная граница подключения; замена модели или способа оплаты — отдельное изменение запроса |
| Timeout/cancellation | Работа могла уже выполнить изменения; перед повтором важны фактическое состояние и безопасность повторного действия |
| Missing lease | MCP потерял процесс-local запись; native ID может оставаться пригодным для `open_resume` |
| `max_turns` с `resumable` и ID | Достигнут лимит одного turn; разговор допускает содержательное продолжение |
| Invalid path/permission | Ошибка доступа к указанному месту; другой путь или права меняют контекст операции |

Мост ограничивает один turn 48 шагами модели и 29 минутами. Native interrupt
получает время завершить отмену, затем процесс принудительно закрывается.
Warnings сохраняют компактные сведения о лимитах подписки, fallback и именах
отклонённых tools; hidden reasoning и raw tool I/O не возвращаются.
