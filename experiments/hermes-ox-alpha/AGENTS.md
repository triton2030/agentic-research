# Эксперимент: Ox Alpha как рабочая модель

Задача владельца 2026-08-22: скил `1hermes` должен уметь использовать Ox Alpha
для долгой сложной работы — читать долго, потом писать, и запускать несколько
агентов. Root оркестрирует, работает Ox.

## Владельцы правды

| Смысл | Адрес |
| --- | --- |
| Runtime-скил Claude | `skills/claude/1hermes/` — живой пакет `~/.claude/skills/1hermes` является симлинком сюда |
| Продуктовая рамка скила | `skills/shared/1hermes/product-frame.md` |
| Аудит дефектов wrapper-а | `_ops/findings/2026-08-22-ox-alpha-hermes-wrapper-audit.md` |
| Этот эксперимент | эта папка |

Правка `1hermes` — глобальный артефакт: cross-project, veto-class. Пиши
project-independent, без путей и допущений этого проекта. Откат — git, пакет
установлен симлинком и отдельной синхронизации не требует.

## Что уже есть в скиле

Route `stealth/ox-alpha` через `nous`, reasoning `max`, бюджет 2000 итераций и
три часа, fail-closed гейт бесплатности по живому каталогу, session-backed
приёмка runtime. Одиночный read-only прогон работает: этим маршрутом сделан сам
аудит wrapper-а.

## Чего не хватает

- **запись.** `--allow-write` и `--worktree` документированы, но на Ox не
  проверялись ни разу;
- **несколько агентов.** Wrapper намеренно не программирует декомпозицию;
  параллельность — работа оркестратора, и её носителя пока нет;
- **починка дефектов** из аудита: C1 тело ответа не доказано session store, C2
  нет верхнего обработчика, C3 гейт цены одноразовый, E1 непиннутый провайдер,
  E2 session_id регексом по всему stderr, E4 дубль парсинга toolsets.

## Границы

Не менять глобальный конфиг Hermes. Не печатать сырой `sessions export`. Ox
получает те же права, что любая роль; гейт бесплатности — единственное, что
относится к ней отдельно, и он про деньги, а не про права.
