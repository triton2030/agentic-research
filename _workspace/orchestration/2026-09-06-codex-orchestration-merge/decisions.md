# Самостоятельные решения

- Разделить runtime owners вместо изменения общего sync-скрипта: существующий механизм уже устанавливает раздельные Claude/Codex пакеты.
- Сохранить прежние изменённые файлы и diff в before/, чтобы рефактор не потерял работу предыдущей сессии.
- В этой среде обязательные внутренние проверки идут через субагентов: create_thread ограничен старшими инструкциями. Это ограничение явно сохраняется в новом скилле.
