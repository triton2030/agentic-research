# Самостоятельные решения

- Разделить runtime owners вместо изменения общего sync-скрипта: существующий механизм уже устанавливает раздельные Claude/Codex пакеты.
- Сохранить прежние изменённые файлы и diff в before/, чтобы рефактор не потерял работу предыдущей сессии.
- В этой среде обязательные внутренние проверки идут через субагентов: create_thread ограничен старшими инструкциями. Это ограничение явно сохраняется в новом скилле.
- Исходное состояние сохранено в GitHub коммитом bbe71d62.
- Условные стадии «выбор / исполнение / приёмка» заменили фиксированный конвейер: лёгкий запуск не ждёт отсутствующего результата.
- Замечания двух проверяющих закрыты локально; счёт поручений сохранён для каждого агента, но разрешена одна таблица волны.
- Код установки не менялся: два runtime owners установлены существующим sync; Claude побайтно сохранён.
- После нового решения владельца Claude также получает новую версию: отдельный 1codex сохранён; прежнее решение оставить Claude побайтно отменено именно для orchestration.
