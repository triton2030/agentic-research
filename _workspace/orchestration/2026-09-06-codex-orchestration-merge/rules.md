# Условия этой оркестрации

- Цель скилла: быстро, дёшево и качественно через эффективное сочетание Luna Max, Opus и собственных субагентов.
- Codex получает отдельную версию; байты Claude-версии сохраняются.
- Общая рабочая папка; каждый исполнитель пишет только назначенный файл. Интеграцией и Git владеет root.
- Старые изменения не откатываются; исходное состояние сохранено в before/.
- Владелец сказал «Да, отлично делай» после обсуждения намерения: выполнить рефактор, проверку и установку без повторного общего согласования.
- Текущие старшие инструкции Codex запрещают использовать create_thread для внутренних подзадач. Для обязательных clean-room/review применяются доступные субагенты; Opus — через Claude MCP. Ограничение не обходится.
