Hub-вариант

лучше для owner-системы

Показывает главное: почти все решения проходят через право слоя. Хорошо объясняет, почему 1folder-contract не делает всю работу сам, а раздаёт handoff.

Как выбирать

быстрый verdict

  • Hub — для разговора “кто главный owner и почему”.
  • Router table — для практики “куда идти с конкретной задачей”.
  • Если нужен один финальный вид, я бы оставил table как основную, а hub как обзор сверху.
