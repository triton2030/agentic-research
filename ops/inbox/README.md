# Inbox

Временный лоток для входящих артефактов (чужие `CLAUDE.md`, системные промпты, скиллы, агентные инструкции), которые мы хотим разобрать.

Правило жизни: **inbox не живёт дольше одного ops-триажа.** При ближайшей ops-сессии каждый артефакт проходит триаж по правилу из `AGENTS.md` → «Входящие Артефакты» и либо поднимается в `knowledge/examples/{slug}/` с `takeaways.md`, либо удаляется.
