# Доказательство

Вход: стадия 4 — полный пакет candidate-текстов из Сборки.

1. До запроса «да» прогони пробник минимум по самой рисковой зоне — той, где
   цена неучтённого ребра выше всего.
2. Пробник — свежий субагент: из инструкций ему даётся только файл входа,
   рабочие файлы зоны доступны; до зонного файла он доходит сам по связке.
3. Задачу пробнику дай такую, что правильно она решается только через рёбра,
   а известный дефолт без инструкций расходится с требуемым.
4. Суди по diff и порядку действий пробника, не по его самоотчёту.
5. Всё, что пробник не покрыл, — candidate-claim, уходит в сдачу.

Выход: evidence по прогнанным зонам · candidate-claims по остальным.
