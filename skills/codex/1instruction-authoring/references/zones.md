# Зонная разведка

Вход: стадия 2 — карта зон с целями из Замысла.

Главный агент:

1. Запусти по субагенту на зону, параллельно; в задание каждому — цель
   проекта, цель его зоны, карта зон и форма файла из тела скила.
2. Рёбра не подсказывай: субагент с чистым окном сам чувствует, чего ему не
   сказали, — его слепота и есть искомое.

Протокол зонного субагента:

1. Прочитай свою зону целиком.
2. Выпиши исходящие рёбра: от каких внешних правд зависит работа здесь и в
   какой момент каждая нужна — прежде чем начать · когда меняешь конкретное ·
   перед сдачей.
3. Выпиши входящие рёбра: кто за пределами зоны сломается от изменений здесь.
4. Если у зоны нет собственных рёбер — она склад: файла не собирай, верни её
   адрес; иначе собери черновик файла зоны: «Цель», «Контекст», рёбра шагами
   по моментам, закрывающая строка «больше ничего не читай».
5. Ремесло зоны — как писать её код — не пиши: агент прочитает папку сам.
6. Кандидатов в корень — кросс-зонные правила — и вопросы владельцу отдай
   отдельным списком; сам их не решай.

Выход: черновики зонных файлов · кандидаты в корень · вопросы владельцу.
