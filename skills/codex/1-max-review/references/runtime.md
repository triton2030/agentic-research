# Codex

Передай сбор и приёмку одному отдельному свежему координатору с сильной
доступной моделью. Native subagent подходит для этой роли; листовые проверки
он запускает общим CLI `max-review` с фиксированной Luna Max.

В передаче нужны область, режим, существенные решения, путь скилла и сессии.
Вызывающий не читает все источники и отчёты повторно; координатор возвращает
короткий итог. Если отдельное окно недоступно, явно назови ограничение:
текущий агент выполняет координацию сам, изоляция его контекста не достигнута.

CLI работает через установленный Codex и его ChatGPT-вход. Число CLI-процессов
отдельно от лимита native subagents. Готовые пакеты уменьшают самостоятельное
чтение leaf, но не гарантируют пустой системный контекст и не отменяют лимиты
сервиса. Запрошенная модель не выдаётся за наблюдённую resolved model.
