# Когда выбираешь локальное освобождение места

Свежая проверка содержимого даёт основание рассмотреть действие, но не
определяет его безопасность. Перед показом плана установи реальный путь и
состояние синхронизации по текущим настройкам приложения, включая локальные
папки Desktop/Documents/Computers вне обычного каталога Drive. Имя пути само
по себе не доказывает, что он не синхронизируется. Пауза или выход из клиента
не делают удаление безопасным: оно может распространиться после возобновления.

## Выбор действия

| Состояние | Допустимый следующий план |
| --- | --- |
| Streaming / File Provider | Поддерживаемое действие удаления локальной загрузки / offline pin, сохраняющее облачный объект; точное название проверь в текущем UI |
| Mirroring или синхронизируемая локальная папка | Сначала согласованная смена режима или прекращение синхронизации с независимой проверкой сохранности облачного оригинала; обычное удаление пока исключено |
| Самостоятельная локальная копия вне синхронизации | Удаление только конкретных подтверждённых локальных файлов после разрешения |
| Связь с синхронизацией не установлена | Файлы остаются на месте; блокер — неизвестное распространение операции |

В macOS File Provider перемещение из Drive может отправить облачный файл в
корзину. Не используй перенос «в безопасную локальную папку» как универсальную
страховку. Изменение настройки синхронизации также отдельное действие с
объяснёнными последствиями, не молчаливая часть удаления.

## Перед разрешением владельца

Предъяви точный список путей, облачные ссылки, метод/время совпадения,
основание отсутствия распространения в облако, ожидаемый объём и конкретный
способ. Сохрани целостность выбранного набора и доступ владельца к оригиналам.
Общий вопрос «почистить диск?» и совпадение только имени/размера не подходят.
Список может включать только MATCH_SHA256 или MATCH_BYTES со свежей повторной
проверкой удалённого оригинала и возможности его получить. Старое подтверждение
права доступа, чужая shared-копия с отзываемым доступом или trashed-файл не
подменяют устойчивый архив владельца; такую зависимость надо разрешить явно.

## После разрешения и непосредственно перед действием

Сопоставь разрешённый список с текущими файлами, сверкой и состоянием sync.
Изменившийся файл исключи и перепроверь; не распространяй старое разрешение
на новые объекты или более разрушительный способ. Между проверкой и действием
сохраняй малое окно и остановись при признаках активной записи/синхронизации.
Команды удаления по wildcard или рекурсивному родителю не заменяют список.
Не удаляй ничего из Google Drive ради освобождения диска MacBook.

Для самостоятельных локальных файлов предпочтительна обратимая корзина,
если она подходит задаче. Корзина обычно не освобождает занимаемые байты;
её очистка или прямое безвозвратное удаление — явно названный способ,
требующий соответствующего подтверждения. Восстановление из облака требует
интернета и времени; это не мгновенный откат.

После действия проверь сохранность удалённых ID/сумм в реальном Drive,
результат локального удаления либо освобождения загрузки и свободное место
на том же томе. Logical size, hardlinks, APFS snapshots и purgeable space
могут расходиться с реально полученным местом. При неожиданной потере
облачного объекта останови оставшийся набор и разберись с восстановлением.
