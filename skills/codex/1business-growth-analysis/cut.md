# Cut

- Смена мышления root снята: владелец требует отдельного субагента с чистым
  окном.
- Атака уже выбранного маршрута снята: это зона `business-critic`.
- Техническое проектирование и оценка реализации сняты: аналитик возвращает
  первичный бизнес-ответ, технические ограничения интегрирует root.
- Подготовленный root пакет документов снят: агент сам читает без allowlist.
- Обязательный дешёвый эксперимент снят: он появляется только при условном
  вердикте.
- Полная приёмка отчёта внутри скила снята: она уже принадлежит глобальному
  контракту root и не дублируется.
- Ритуальный запуск всех методик снят: каждый применённый метод обязан изменить
  вывод.
