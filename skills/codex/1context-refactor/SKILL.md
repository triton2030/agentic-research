# Рефактор контекста

## Цель

Превратить повторившийся сбой в причинный разбор и сохранить независимо
доказанные результаты у их владельцев.

## Уникальный контекст

Повтор может поддерживать любой контекст, доступный до ошибки. Симптом и
последний открытый источник не доказывают причину. Скилл работает только
постфактум.

## Работа

Перечитай всю доступную сессию и докажи связь контекста, доступного до ошибки,
с повторившимся выбором по наблюдаемому следу активации, проверив сильнейшую
альтернативу различающим контрфактом; недоказанное оставь гипотезой или
неизвестным.

Даже при неизвестной причине независимо вызови `1index` для доказанно дорогого
маршрута и `1findings` для наблюдаемой системной проблемы вне текущего
результата.

Автономность этого вызова охватывает только конкретный существующий `INDEX.md`
и находку; новый INDEX требует отдельного разрешения.

При доказанном влиянии конкретных слов дай пользователю совет. Ремонт источника
требует доказанного влияния, разрешения его владельца и повтора исходного
эпизода.
