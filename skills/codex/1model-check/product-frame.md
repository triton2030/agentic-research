# Product Frame · 1model-check

## Проблема

После нескольких несовпадений ожидания с реальностью агент может продолжать
локально чинить симптомы, сохраняя ошибочную рабочую модель ситуации.

## Продукт

После явного вызова агент разбирает до пяти последних ещё не разобранных
собственных `⚡ UNEXPECTED` и:

1. делает ошибки прогноза явно адресуемыми;
2. ищет наиболее компактное предположение, способное их объяснить;
3. получает новое различающее наблюдение либо честно называет blocker;
4. связывает результат со следующим рабочим действием.

Допустимые выводы: одна причина объясняет все случаи; объясняет только часть;
причины независимы; evidence пока недостаточно.

Видимые ответы доказывают исполнение протокола, но не качество вывода.
Качество подтверждается только различающим наблюдением и результатом
следующего действия.

## Границы

Skill не объясняет владельцу общую картину, не проводит независимую проверку
траектории и не пересобирает цель всей задачи. Он не создаёт отдельную задачу,
советчика или hook и не использует словесную уверенность как evidence.

Skill не вызывается моделью автоматически. Пользователь вручную решает, когда
стоимость накопленных расхождений оправдывает проверку рабочей модели.

## Acceptance

До признания skill рабочим:

- проверить явный вызов на ограниченном корпусе до пяти прошлых подходящих
  эпизодов, включая хотя бы один случай частичного или отсутствующего общего
  объяснения;
- проверить, что без явного вызова skill не активируется;
- сравнить anonymized baseline без skill и результат с skill;
- проверить, появилось ли новое evidence и обоснованно ли изменилось либо
  сохранилось следующее действие;
- провести один живой случай.

Прошлые replay являются проверкой кандидата, а не доказательством работы
runtime-trigger. Видимый блок без изменённого control action доказывает только
protocol compliance.
