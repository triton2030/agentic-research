# Дом смешан или перерос

**Вход:** документ, в который встаёт ответ, несёт две разные работы либо заметно
крупнее обычного документа своего типа в этом проекте.

**Выход:** ответ записан; работа по разделению названа как отдельная и не
начата.

## Задача

Записать ответ, не чиня документ письмом.

## Цель

Ответ лежит в доме, а разделение осталось работой, которой никто не начинал
попутно: документ, переросший один файл, письмом не чинится ни при каком
качестве отдельной записи.

Ни одна часть не заведена без собственного читателя, владельца и проверки.

## Критерии принятия

- Разделение не произошло этим ходом. Документ, разделённый попутно с записью, —
  не успех, каким бы очевидным ни был шов: этот выбор переживёт твой ход, а
  проверить его в этом ходе нечем.
- Строка перечня называет, какие именно две работы документ несёт и по какому
  шву они расходятся. «Файл слишком большой» — не успех: по такой строке
  следующий ход не начнётся.
- Часть, для которой ты не смог назвать собственного читателя, собственного
  владельца и собственную проверку, в предложении о разделении не появляется:
  дробление по заголовкам даёт много слабых поверхностей правды вместо одной
  сильной.
