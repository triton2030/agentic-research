# Cut

- Отдельная папка на каждое изображение — отменена владельцем как излишняя.
- Год в имени дневной папки — явно исключён владельцем.
- Платные 3–6-word exploratory prompts — отменены; оставлен один structured path.
- Generic image trigger — исключён; skill срабатывает только на прямой Recraft.
- README, prompt templates на каждый жанр и постоянный price table — не нужны
  горячему пути и быстро устаревают.
- Текущий баланс не записывается в skill: только live `get_user` после output.
- Utility/Vector model ids не выведены из названий официального семейства:
  текущая live enum их не допускает.
- Автоматический raster→vector fallback не включён: это скрытый второй платный
  шаг; требуется отдельное разрешение.
- Буквальный пример `80%` не сохраняется как шаблон prompt: он закрепил бы
  именно сбой. Сохранён общий переход `служебное число → видимый признак`.
- Старые Recraft outputs не переносятся в новую storage topology: правило
  действует на новые сохранения.
