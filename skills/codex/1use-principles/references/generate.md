# Порождение из пустоты

Развилка выбирает из готовых вариантов; пустота требует их создать. Дефолт
модели — жанровый шаблон: admin dashboard, лендинг, карточка. Шаблон выглядит
профессионально и не содержит продукта. Три хода порождения — в шаге 2 тела;
здесь эталон и приёмка.

## Эталон — админ-панель платформы

Задача: придумать админ-панель, строки в SPEC нет.

Шаблонный ход: sidebar, карточки метрик, таблицы, графики — и цитаты
принципов постфактум. Принципы применены фильтром: «ничего не нарушаю»,
след идеален, продукта на экране нет.

Сценовый ход: кто сюда приходит? Не «менеджер метрик», а Founder, вручную
разбирающий заявки студий; боль — очередь необработанного. Принцип «труд
против красоты» генератором: построй очередь с действием в один клик, убери
витринность. Принцип «честность против гладкости»: покажи возраст заявки
честным числом, не светофором. Состав экрана вышел из сцены и принципов —
шаблон не понадобился.

## Проверка переноса

Перед следом каждый блок концепта называет источник: сцена · принцип · жанр.
Жанровый блок без работы в сцене вычёркивается или получает пометку
допущения. Экран, у которого все блоки жанровые, — признак пропущенной сцены:
вернись к ней.

## Граница

Микропустоты (название кнопки, порядок полей) закрываются обычными шагами
тела, без концептов. Порождение — для состава: экран, документ, структура.
