# Связность

Возьми только пары смыслов, способные одновременно повлиять на одну реальную
задачу, включая пары между root, folder, skill, hook и task prompt.

Для пары выбери один вердикт:

- дополняют;
- конфликтуют — кто побеждает и при каком условии;
- дублируют — оставить одного owner-а;
- одно поглощает другое — снять частное;
- влияет — один смысл меняет силу другого, даже без прямого конфликта.

Явное разрешение нужно только там, где без него чистая сессия может честно
выбрать разные действия. Пара, которую агент надёжно выводит из hierarchy и
scope, не требует нового правила.

Hook или validator побеждает prose в покрытом событии, но не притворяется
покрытием остальных событий. User task обычно конкретнее resident guidance;
если resident boundary обязана победить, ей нужна authority или другая
поверхность.

Готово, когда у каждого материального пересечения один owner и одно
операционное разрешение.
