# Cut

- Screenshot и rendered visual review — не входят: другой evidence class.
- Click QA, accessibility conformance, user testing и multi-page flows — не
  входят: соседние аудиты.
- Исправление кода — не входит: skill только аудирует.
- Пересказ prose-контента снят: карта несёт только его роль для
  пользователя.
- Mobile/tablet по умолчанию сняты: владелец выбрал desktop PC.
- Обязательный общий verdict снят: нужны адресные
  `Оставить / Изменить`.
