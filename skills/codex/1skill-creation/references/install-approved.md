# Установка утверждённой версии

Вход: пользователь безусловно утвердил точную проверенную версию, и после его
ответа она не менялась.

## Порядок

1. Найди владельца пакета по реестру владельцев пакетов проекта; в
   `agentic-research` это `skills/shared/README.md`.
2. Если tracked owner существует, сначала запиши утверждённую версию туда.
3. Синхронизируй проекции существующего tracked owner.
4. Установи ту же неизменённую версию в живые пакеты сред, для которых она
   предназначена.
5. Проверь совпадение состава и содержимого установленных пакетов с утверждённой
   версией.
6. Проверь существование всех внутренних ссылок установленных пакетов.
7. Покажи в чате прямые ссылки на установленный скил и каждый его
   reference-файл.
8. В сдаче назови функцию словами пользователя, находки двух проверяющих, свои
   решения по ним, снятое с причиной и остаточные риски.

## Границы

- Если tracked owner отсутствует, не создавай второй source tree.

Выход: одинаковая утверждённая версия в owner-пакете и его проекциях, либо явно
названная среда, в которую она не установлена.
