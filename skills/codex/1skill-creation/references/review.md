# Три проверяющих

Нужно для полной переработки или нового скила. Каждый проверяющий — свежее
окно другой семьи моделей. Он получает черновик, слова пользователя
и принципы, границу заказа, карту потерь и результаты проб, а из ролей —
только свою. Выводов соседей до своего ответа не видит, файлы не меняет,
агентов не запускает.

| Роль | Предмет |
| --- | --- |
| Смысл | какое понимание добавляет каждая часть намерения; есть ли у Контекста дельта к сильному агенту и последствия; что меняет Задача против ответа без скила; какую лазейку закрывает каждый Критерий |
| Необходимость | что сильный агент сделает иначе без каждого требования; повторы; потерянные условия пользователя |
| Применение | путь реалистичного случая каждой двери вызова: контекст → первое решение → действия → завершение; доступно ли требование до выбора; сходятся ли результаты проб с заявленным |

Находка — адрес с цитатой, неверное прочтение или потеря, свидетельство
или пометка «прогноз», минимальная правка. «Это подразумевается целью»
безопасного снятия не доказывает. Пустой список допустим; отклонённая
находка без нового основания не возвращается.
