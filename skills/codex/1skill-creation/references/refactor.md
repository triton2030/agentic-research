# Рефактор

Вход: пользователь просит рефактор скила, или живой скил раздут либо
ритуален.

- Локальная формулировочная правка внутри прежнего смысла — короткий путь:
  точный diff вместо шагов 1–4, дальше сразу «Проверка и утверждение».

1. Прочитай папку-историю скила: функцию, `cut.md`, буквальные цитаты
   пользователя; истории нет — пройди раздел «Цель и контекст» и вернись
   сюда.
2. Абстрагируй по шагам: выпиши все несущие указания тела и references
   плоским списком → сгруппируй по цели → каждой группе выведи инструкцию
   высшего порядка.
   - Частность снимай, только если агент с чистым окном выведет её из общего;
     невыводимое оставь явной строкой.
3. Сверь новый набор с прежним смыслом и функцией: потерянного нет.
4. Новый набор не помещается в тело — прочитай `reference-files.md`.

- Модель умеет весь скил целиком — предложи пользователю снять скил: снятие —
  лучший исход.
- Наблюдаемый сбой скила совпал с известным — прочитай
  `refactor-failures.md`; перед собственной сдачей — `refactor-check.md`.

- Выход: перекроенный черновик в папке-истории + таблица объединений (какая
  высшая инструкция что поглотила, что осталось явным) — с ними иди в
  «Проверку и утверждение».
