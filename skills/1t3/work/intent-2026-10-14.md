# Намерение и допуск содержания, 2026-10-14

## Функция и момент вызова

Агент Claude Code поручает работу чужой модели — Muse или Gemini — тредом
T3 Code либо отдаёт аудио и видео скрипту над `agy`, и закрывает ответ. Момент:
владелец назвал T3 Code, Muse, Gemini или Antigravity; нужно услышать или
увидеть; чтение пачки можно отдать быстрому читателю; тред уже идёт.

Поддержание, а не разовое достижение: каждый прогон закрывается названным
эффектом.

## Что допущено сверх намерения и почему

| Элемент | Какой выбор меняет | Основание |
| --- | --- | --- |
| общие правила в «Границы» брифа | агент коммитит, трогает чужие правки, запускает сценарий по чужому скилу, записывает бриф как слова владельца | решение владельца о приписке общих правил; запуск сценария замерен под `muse exec`, запись брифа цитатой — прогноз: в треде Muse получает личные правила владельца |
| Muse только по просьбе | агент сам запускает платный тред Muse | вопрос владельца не решён: `skills/1gemini/work/roster-2026-10-13.md` |
| строка брифа Gemini «обходов не ищи» | Flash вместо отказа ищет обход | замерено: распознаватель на Swift, `find` по домашней папке, `killall` |
| медиа — скрипту | агент шлёт аудио в тред Gemini | замерено на одном файле обоими путями |
| `runtimeMode` всегда | тред встаёт на подтверждении | по документации T3 Code; не мерилось |
| ожидание не дольше 55 секунд | вызов обрывается ошибкой клиента | замерено: 58 с проходит, 180 с нет |
| форма `modelSelection` с массивом `options` | агент шлёт усилие объектом | схема инструмента форму не показывает; взята из конфигурации живого треда |
| заголовок треда по образцу | владелец не видит, куда ушёл лимит | перенос подписи вызова из обёрток |
| раздел «Что ещё даёт T3 Code» | агент не знает, что приложение умеет сверх тредов и что из этого ему недоступно снаружи | заказ владельца; схемы сотни отложенных инструментов дорого грузить ради обзора |
| таблица исходов аудита | вывод принят голосом | перенос из `1codex` по решению владельца `#recall-cf7b89b083f54065941ef4f60764631e` |

Отдельного раздела критериев нет: неверные результаты, которые ещё допускают
Контекст, Задача и Цель, закрыты строками в моментах, где они возникают.

## Утверждения для пробы, записаны до запуска

Свежий агент получает пакет по нейтральному пути и просьбу владельца:
проверить аудитором чужую работу и сказать, что говорится в записи.

1. Аудит уходит тредом Muse, запись — скрипту, а не треду Gemini.
2. Тред запущен в проекте, найденном по `workspaceRoot`; `runtimeMode` —
   `full-access`; модель — `muse-wonder-full-1.0`, усилие `xhigh` массивом
   `options`; заголовок по образцу.
3. В брифе четыре раздела, «файлы не меняй», обе строки для Muse, вывода
   самого агента о работе нет.
4. Ожидание — вызовами не дольше 55 секунд.
5. Ответ аудитора разложен на выводы с исходами; владельцу дана ссылка на
   тред.
6. Расшифровка сверена со строкой `viewed:`.
