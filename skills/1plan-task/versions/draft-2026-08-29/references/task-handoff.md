# Стадия передачи

## Цель

Один новый ответственный писатель восстанавливает контракт задачи как автономный
промпт до передачи полномочий; одновременных писателей нет.

1. Новый писатель полностью перечитывает файл задачи и актуальный эпик. Без
   записи он называет следующий ход, условие остановки и двусмысленности.
2. Прежний писатель явно передаёт полномочия. Только после этого новый писатель
   становится единственным владельцем, исправляет файл и запускает прибор;
   роль не пожизненная, но передача последовательна.
