# Стадия подзадач

## Цель

Подзадачи дают ближайший проверяемый путь одной цели, не превращаются во второй
план и не забирают работу другой задачи или эпика.

1. Каждая подзадача — один результат или разрешимый вопрос с одним
   доказательством. `[x]` требует адрес `доказательство:`.
2. `3–7` — сигнал проверить упаковку; новый файл появляется только при
   самостоятельной цели, а не ради числа.
3. Execution ведёт к принятому результату; Wayfinding ставит следующий ход
   перед ранним дорогим расхождением. Туман остаётся в «Зачем», а доступный
   только владельцу вопрос — адресом `1interview-tool`.
