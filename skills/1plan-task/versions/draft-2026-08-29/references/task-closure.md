# Стадия закрытия

## Цель

Задача закрывается только доказательством целого результата и приёмкой
потребителя; её писатель не присваивает себе правду эпика.

1. Завершённые подзадачи сами по себе задачу не закрывают.
2. Ответственный писатель ставит статус и `evidence` задачи. `1plan-map`
   отдельным событием меняет только эпик.
3. После обеих записей проектный прибор сверяет производные поля и общий
   словарь.
