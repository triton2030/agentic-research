# Стадия жизненного цикла

## Цель

Новое доказательство продолжает только ту же автономную цель внутри принятого
эпика, границы и полномочий; иначе задача возвращается владельцу изменившегося
смысла.

1. Если смысловая граница держится, пересобери только затронутые подзадачи и
   сохрани принятое решение. Если цель, эпик, граница, полномочия или
   материальный приоритет изменились, запиши `разрыв: <смысл · доказательство>`,
   остановись; смена слов сама по себе не разрыв.
