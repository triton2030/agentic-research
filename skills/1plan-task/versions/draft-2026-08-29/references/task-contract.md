# Стадия контракта задачи

## Цель

Один самоописывающий файл в одном актуальном эпике раскрывает «Зачем», а ход и
доказательства сворачивает под подзадачами; статус и доказательство целого
остаются в верхних метаданных. Токены схемы литеральны, содержимое — на языке
проекта.

Разрешены ровно три верхнеуровневых раздела.

```markdown
---
тип: задача
эпик: "[[<Имя эпика>]]"
эпик-снимок: "<снимок по форме карты или прибору>"
траектория: "<принятое движение эпика и приоритет>"
режим: execution | wayfinding
статус: <литерал общего словаря>
порядок: <принятый номер в очереди задач эпика>
подзадач: 0
подзадач-готово: 0
обновлено: <дата>
evidence: "<обязательно при ✅ — доказательство всей задачи>"
---

# <Самоописывающее имя — проверяемый результат>

## Зачем

<заполняется на стадии цели и контекста>

## Принципы

<заполняется на стадии цели и контекста>

## Подзадачи

<заполняется на стадии подзадач>
```

Контракт задачи зеркалит общий словарь `1plan-map`: `✅ готово · 🔨 в работе ·
◽ в очереди · 🔒 заблокировано · 🛑 затык · ⏳ отложено`. Прибор проверяет
равенство. Производные счётчики пишет только прибор.
