# Стадия отчёта

## Цель

Готовый файл показывает доказуемый ход по подзадачам; помощник может принести
ограниченное доказательство, но не получает задачу или право менять контракт.

```markdown
## Подзадачи

- [x] <результат Execution или разрешимый агентом вопрос Wayfinding>

> [!note]- Отчёт
> статус <дата>: <где мы находимся>
> доказательство: <запуск, файл `_evidence/` или приёмка потребителя>
> решение: <решение через `1use-principles`, если было>
> <свободный результат и находки>

- [ ] <следующая подзадача>

> [!note]- Отчёт
> статус <дата>: <где мы находимся>
```

1. Блок отчёта стоит без отступа сразу после флажка: иначе Obsidian показывает
   код вместо свёрнутого блока.
2. Результат помощника возвращается в `_evidence/**`.
3. Для новой задачи запиши весь собранный пакет одним готовым файлом; для
   существующей измени только затронутый отчёт.
