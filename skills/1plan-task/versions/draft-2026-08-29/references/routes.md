# Маршруты стадий

Закрой этот файл с названием одной следующей стадии.

- Новая утверждённая задача:
  `размещение → контракт → контекст → бюджет → работа → отчёт`.
- Новое доказательство: `допуск исполнения → жизненный цикл`, затем только
  затронутая стадия;
  изменение подзадач завершается `отчётом`.
- Закрытие: `допуск исполнения → жизненный цикл → закрытие`.
- Смена писателя: `передача`.
- Отсрочка, архивная история или внешнее состояние: `хранение`.
- Изменение смысла маршрутизируй в `1planning`; изменение эпика — в `1plan-map`.

Файлы стадий: [размещение](task-placement.md),
[контракт](task-contract.md), [контекст](task-context.md),
[бюджет](task-budget.md), [работа](task-work.md),
[отчёт](task-report.md), [допуск исполнения](task-state.md),
[жизненный цикл](task-lifecycle.md),
[закрытие](task-closure.md), [передача](task-handoff.md),
[хранение](task-retention.md).

Стадии новой задачи обновляют один пакет задачи в памяти; стадия отчёта пишет
готовый файл целиком. Для существующей задачи выбранная стадия пишет только
свою дельту. Новая версия пакета заменяет прежнюю, поэтому результаты прошлых
стадий не остаются отдельными обязательствами.
