# Стадия хранения

## Цель

История задачи сохраняется без ложного текущего состояния и без отдельного
архива вне папки эпика.

1. `⏳` хранит причину владельца, а возврат снова проходит допуск и сверку.
2. Внешнее состояние выполнения — датированный снимок
   `handle · observed_at · source`; недоступный источник означает `unknown`.
