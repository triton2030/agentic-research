# Стадия допуска исполнения

## Цель

Задача продолжается только в исполняемом сейчас эпике и фронтире; иначе она
останавливается с доказанной причиной или возвращает невалидную карту её
владельцу.

1. Перечитай актуальный статус эпика и вычисленный фронтир до работы с задачей.
2. Открытая зависимость даёт задаче `🔒`, отсрочка владельца — `⏳`, нерешённый
   шлюз — `🛑`.
3. Здоровый эпик с живой задачей вне фронтира означает невалидную карту: не
   пиши ложный статус, верни её в `1plan-map`.
4. Возобновление после ремонта снова проходит допуск `1planning`.
