# Стадия размещения

## Цель

Одна утверждённая, не дублирующая существующие цели задача получает ровно один
актуальный эпик и снимок его композиции; фронтир сам по себе файл не разрешает.

1. Полностью перечитай эпик и перечисли существующие файлы задач; дубликат по
   имени или автономной цели отвергни до записи.
2. Расхождение вычисленного снимка останови и маршрутизируй владельцу
   изменившегося смысла.
3. Если прибор не задал нормализацию, снимок включает только `описание`,
   `область`, `порядок`, `запуск`, `критерий`, `ранний-индикатор`, `зависит-от`
   и тело вне «Апдейтов»; поля состояния и производные поля исключаются.
