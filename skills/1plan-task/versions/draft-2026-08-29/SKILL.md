# План задачи — изолированный контракт исполнения

## Уникальный контекст

Файл задачи — промп текущего ответственного агента в чистом окне. Его
ментальная модель — довести одну принятую цель, не забрав чужую работу и не
потеряв условие остановки.

## Цели владельца

- Чистое окно понимает цель, границу, полномочия, критичные сюрпризы,
  доказательство и следующий ход без чата планирования.
- Обычное доказательство меняет работу внутри контракта; смысловой разрыв возвращает
  её в `1planning`.

## Механика

1. По [маршрутам](references/routes.md) выбери одну стадию; файл маршрутов и
   файл стадии не держи открытыми одновременно.
2. Сохрани результат стадии до перехода. После любой записи файла задачи
   запусти проектный прибор.

## Границы

Допуск принадлежит `1planning`, правда эпика — `1plan-map`; вопрос владельцу
остаётся адресом `1interview-tool`.
