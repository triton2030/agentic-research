# План задачи — изолированный контракт исполнения

## Уникальный контекст

Файл задачи — промп текущего ответственного агента в чистом окне. Его ментальная
модель — довести одну принятую цель, не забрав чужую работу и не потеряв stop.

## Цели владельца

- Чистое окно понимает цель, границу, полномочия, критичные сюрпризы,
  доказательство и следующий ход без чата планирования.
- Обычное evidence меняет работу внутри контракта; смысловой разрыв возвращает
  её в `1planning`.

## Поведенческий протокол

> «скилл задач — это скилл изолированности задач»
>
> «надо рассматривать каждую задачу как промп для агента»

1. Сначала открой только [маршруты](references/routes.md), выбери стадию и
   закрой reference.
2. Выполни выбранную стадию по одному reference; запиши результат до перехода.
3. После записи файла задачи запусти проектный прибор.

## Границы

Допуск принадлежит `1planning`, правда эпика — `1plan-map`; вопрос владельцу
остаётся адресом `1interview-tool`.
