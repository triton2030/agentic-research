# Стадия цели и контекста

Результат стадии — самостоятельный раздел «Зачем», который служит ядром промпта
чистого окна без пересказа всей документации.

```markdown
## Зачем

**Цель:** <что получить; какой эффект это даёт; какого главного провала
избежать; каким доказательством подтвердить целое>

- граница: <что входит и что намеренно не входит>
- полномочия: <что ответственный агент вправе решать сам>
- происхождение:
  - `<R01 · краткое несущее требование → точный владелец/принцип/документ/посылка>`
- ось: <ось декомпозиции и ближайший проверяемый рубеж>
- аппетит: <предел времени или усилий до пересмотра>
- верно, пока: <существенная посылка; рухнула → остановка>
- критично помнить:
  - `<точный адрес>` — <что способный агент иначе упустит и что это меняет>
  - «<дословная несущая строка>» (`<точный адрес>`) — <почему она нужна>
- контекст-бюджет: <только близко/выше ориентира: N [· неделимо — причина]>
- отпавшие ходы: <отклонённый маршрут + причина>

## Принципы

- [[<принцип или пара>]] — <что он здесь решает>
- <ничего не подходит: нет принципа — <причина>>
```

1. Каждое неочевидное несущее требование сопоставь точному происхождению.
   Адрес без самостоятельного смысла не считается единицей активного ядра.
2. Обычно достаточно адреса. Несколько несущих строк разрешены вместе с точным
   адресом, когда их пропуск ломает результат; самостоятельное утверждение,
   уже принадлежащее источнику, не дублируй.
