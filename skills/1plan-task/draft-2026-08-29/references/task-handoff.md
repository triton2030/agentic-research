# Стадия передачи

Результат стадии — один новый ответственный писатель, который восстановил
контракт задачи; одновременных писателей нет.

1. Новый писатель полностью перечитывает файл задачи и актуальный эпик.
2. Как чистый читатель он восстанавливает цель, границу, полномочия, ось,
   критичный контекст, доказательство, следующий ход и условие остановки и
   сообщает двусмысленности без записи.
3. Прежний писатель явно передаёт полномочия. Только после этого новый писатель
   становится единственным владельцем и исправляет файл, а не чат; роль не
   пожизненная, но передача последовательна.
