# Стадия хранения

Результат стадии — сохранённая история задачи без ложного текущего состояния.

1. Активные и закрытые задачи остаются в папке эпика; история живёт в git.
2. `⏳` хранит причину владельца, а возврат снова проходит допуск и сверку.
3. Внешнее состояние выполнения — датированный снимок
   `handle · observed_at · source`; недоступный источник означает `unknown`.
