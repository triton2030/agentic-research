# Маршруты стадий

Закрой этот reference с названием одной следующей стадии.

- Новая утверждённая задача: `размещение → контракт → контекст → бюджет → работа`.
- Новое evidence: `жизненный цикл`, затем только затронутая стадия.
- Смена писателя: `передача`.
- Отсрочка, архивная история или внешнее состояние: `хранение`.
- Изменение смысла маршрутизируй в `1planning`; изменение эпика — в `1plan-map`.
