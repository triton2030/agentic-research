# Стадия размещения

Результат — разрешение записать одну задачу в один актуальный эпик.

1. Для новой задачи потребуй материальные решения `1planning`; форма не решает
   заново, нужна ли задача.
2. Полностью перечитай эпик, вычисли `эпик-снимок` и проверь принадлежность
   ровно одному эпику.
3. До создания отвергни дубликат по имени и автономной цели. Фронтир или
   JIT-потребность не разрешают файл без допуска.
4. Расхождение снимка останови и маршрутизируй владельцу изменившегося смысла.
5. Если прибор не задал нормализацию, снимок включает только `описание`,
   `область`, `порядок`, `запуск`, `критерий`, `ранний-индикатор`, `зависит-от`
   и тело вне «Апдейтов»; поля состояния и производные поля исключаются.
