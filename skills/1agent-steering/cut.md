вторая реплика, type: коррекция. Пользователь меняет роль скилла: прочитать,
понять науку, затем применять и объяснять её применение в чате.

| Было | Стало | Основание и проверка |
| --- | --- | --- |
| Задача непосредственно собрать/пересмотреть текст | Прочитать полный пакет и освоить знание | Прямое уточнение владельца; новый текст Задачи |
| Цель описывала только поведение читателя создаваемого файла | Последующие файлы соответствуют изученным практикам; в чате видна их связь с решениями | Прямое уточнение владельца; Цель и критерий |
| Зачем объясняло важность мира владельца в создаваемом тексте | Зачем объясняет нужду в обучении автора и проверяемом применении | Причина новой функции из текущей реплики; исходное знание о мире сохранено в reference |
| Два критерия качества управляющего текста в теле | Те же два пункта дословно в reference; в теле один критерий применения знания | Общая наука не потеряна; у новой функции другая ложная победа |
| Шесть тем знания в теле | Дословно в references/steering-science.md | Сравнение извлечённых блоков со снимком первой версии |
| Самодостаточность одного SKILL.md | Самодостаточность пакета из тела и обязательного reference | Владелец прямо требует полного чтения материалов; внешний репозиторий не нужен |
| Trigger создания/редактирования | Тот же момент, функция уточнена как обучение и объяснение | Description меньше 200 символов; ни один носитель не исключён |
| Две волны и четыре практических выхода | Сохранены как evidence первой версии | Новое объяснение в чате ими не проверено; прошлый успех не перенесён на новую обязанность |

Научных условий и пользовательского протокола не снято. Полное чтение стало
прямым действием при вызове, а объяснение применения — наблюдаемым состоянием
по ходу последующего авторинга. Разбиение материала по случаям остаётся
возможностью, названной владельцем, а не основанием размножать общий материал.

Третья реплика уточняет абзац Контекст: дельту читателя, принципы из мира,
происхождение и важность цели, последствия и рабочую модель внимания.
Прежнее утверждение о дословном переносе относится к состоянию до этого
уточнения; остальные темы reference и оба прежних критерия сохранены.
