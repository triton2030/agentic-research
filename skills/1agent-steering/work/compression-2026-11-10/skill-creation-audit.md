# Разбор 1skill-creation против науки и гайдов (2026-11-10)

Источники: Skill authoring best practices (platform.claude.com), Claude Code
skills docs (code.claude.com/docs/en/skills), skill-creator из официального
магазина (установлен, `~/.claude/plugins/cache/claude-plugins-official/skill-creator/`),
наука после правки 2026-11-10.

| # | Место | Чем вредит | Основание | Правка |
|---|---|---|---|---|
| H1 | «Когда начинаешь»: прочитать `user-said.md` в истории | Отправляет в архив: там без пометок лежат снятые правила («меньше 20 инструкций», «цель — максимум три пункта», «один этап — один reference», нумерация каждой инструкции) | AGENTS.md репо: `skills/1<name>/` — история, не контракт; Fable 5.2: старые правила исполняются буквально | Убрать; действующее — принципы у владельца |
| H2 | Контекст, Задача, «Когда добавляешь»: читатель — «сильный агент» | Скилы исполняют и Sonnet/Haiku-субагенты, и Codex: под сильного читателя снимается нужное слабому | Best practices «Test with all models you plan to use»; наука «Достаточная проверка» | Читатель — самая слабая модель, которая будет исполнять скил |
| H3 | Задача: «Сравни с поведением сильного агента без скила» | Мысленное сравнение выдаёт прогноз за свидетельство | Best practices «Build evaluations first»; Claude Code «baseline comparison»; P-004/P-005 проекта | Конфликт с P-009 `1agent-steering` — вопрос владельцу |
| H4 | «Когда проверяешь»: проба по нейтральному пути; `description.md`: проверка фразами в уме | Проба не проверяет вызов; проверка описания мысленная | Claude Code: вызов и результат меряются отдельно; skill-creator меряет частоту вызова | Вызов — замером skill-creator; исполнение — прогон со скилом против прежней версии |
| H5 | — | После сжатия контекста остаются первые 5000 токенов скила | Claude Code skills «Skill content lifecycle» | Важное — в начало; неизменное правило — хуком (S1) |
| H6 | `description.md`: «Фразу, которая не меняет решение…, удали» | Режет слова, которыми пользователь зовёт скил: недовызов | Best practices: key terms; skill-creator: Claude склонен недовызывать | Сохранять естественные слова вызова, ключевой случай первым |
| H7 | «Форма: Контекст → Задача → Критерии → Цель → Когда…» | Каждый скил получает каркас разделов, даже когда хватит абзаца; новые модели следуют форме буквально | Best practices «Concise is key»; слова владельца «идеальный скил — одно предложение» | Порядок сохранить, раздел — только если есть содержание |
