## Заказ и граница

Владелец сравнил наш авторинг со скилом Matt Pocock `writing-for-agents`
и выбрал вариант А: два скила с чёткими ролями.[^idea][^choice]

- `1agent-steering` — общий справочник рычагов: скелет Покока, у каждого
  рычага проба; наша наука — основания и сноски; наши собственные рычаги
  сохраняются.
- `1instruction-authoring` — механика слоя: что найти, куда положить,
  как проверить доставку; общая наука из него убирается, а не повторяется;
  проверка соразмерна цене ошибки — пункт 2 принятого предложения.

Вне границы: механика скилов Покока (способ вызова, router-скилы) —
отдельная задача для `1skill-creation`.

## Карта потерь `1instruction-authoring`

Все снятые строки — общая наука, которую тело велит применять до авторских
решений (`1agent-steering`). Снятие дешёвое: смысл остаётся в обязательно
читаемом материале.

| Снятое | Где смысл теперь |
| --- | --- |
| `SKILL.md`: абзац о ролях Контекста, Задачи, Цели, Критерия и квоте разделов | Контекст; Дельта и кеш; Критерий завершения; Момент применения |
| `writing.md`: «Контекст передаёт неизвестную систему…» | Контекст; Контекст тела `1instruction-authoring` |
| `writing.md`: критерий по Контексту, Задаче и Цели вместе; «перечень критериев не создаётся» | Критерий завершения |
| `writing.md`: группировка по решениям, короткий случай, «разводи моменты, убирай повторы» | Момент применения |
| `writing.md`: причина в единице или рядом; один Контекст на несколько требований | Соседство |

Сохранено вопреки направлению сокращения: поиск неочевидного с читателями
папок (P-002, P-007 истории), три проверяющих (P-003), «склейка строк не
доказывает уменьшения нагрузки», особая граница пользователя, объединение
частных правил в принцип (P-005 истории), защита через контракт другого файла.

Добавлено: кеш при допуске строки, ссылка в слое как указатель, роль скила

## Находки трёх проверяющих

Одна волна, все три роли ответили. Принято:

| Находка | Правка |
| --- | --- |
| Вступление «агент идёт одним способом» спорит с «способ остаётся исполнителю» (смысл, необходимость) | Вступление через нужное состояние и существенные выборы; в `SKILL.md` «рычаги управляющего текста» |
| Кеш без условия «агент пойдёт искать до выбора» (смысл) | Условие добавлено в науку и в `writing.md` через пробу |
| «Спор о no-op решается запуском» возвращает прогоны (все три) | Запуск — только у дорогого снятия |
| Слабое ведущее слово лечится «не другим приёмом», а проба показала критерий (необходимость) | «более сильное слово или наблюдаемый критерий завершения» |
| У четырёх рычагов нет пробы (необходимость, применение) | Пробы добавлены: 16 разделов — 16 проб |
| Повтор про границу контекста; «Так ставится…» сдвинута (необходимость) | Повтор снят, фраза о слиянии — в критерий, «Так ставится…» на прежнем месте |
| «Две нагрузки» почти не меняет выбор, половина — о способе вызова вне границы (необходимость) | Свёрнуто в одно предложение «Указателя» |
| «Только целевым поведением» делает неизмеренное предпочтение обязательным (необходимость) | «только» снято |
| «Разбросанность» повторяет «Соседство» (необходимость) | Снято |
| Проверка соразмерно цене выпала из границы (смысл) | `1instruction-authoring`: «Когда правка названа заранее»; тройная проверка — для нового или переписанного слоя, нового обязательства, новой зоны, дорогого снятия |
| В `writing.md` пропал глагол распределения по моментам (применение) | Глагол возвращён ссылкой на рычаг |
| Отчёт о пробе завышал разницу по дефекту 2; версия пробы не совпадает (применение) | `probe-results.md` исправлен, границы названы |
