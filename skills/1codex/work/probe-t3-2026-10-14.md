# Проба: 1codex с путём через T3 Code, 2026-10-14

Свежий агент получает черновики по нейтральным путям: `1codex` —
`/tmp/t3s/c1/`, `1t3` — `/tmp/t3s/s5/`. Реплика владельца: Codex проверяет
аудитором работу в зоне `codex/` пробного проекта; отдельно — нативное ревью
незакоммиченного диффа той же папки.

Утверждения, записаны до запуска:

1. Аудит по заданию ушёл тредом T3 Code, нативное ревью — мостом с `--mode diff`.
2. В треде `modelSelection` Codex с явным усилием; заголовок
   `Codex <модель>/<усилие> · аудитор · <суть>`.
3. Бриф аудитора — по `1codex`: работа и исходные критерии без своего вывода,
   «файлы не меняй», команда и код возврата по каждой проверке, право сказать
   «работа держится»; плюс общие правила `1t3` с репликами агента.
4. Ожидание треда — вызовами до 55 секунд или фоновым ожидателем; мост —
   фоновой командой.
5. Выводы аудитора и ревью закрыты исходами; владельцу даны ссылка на тред
   и `RUN_DIR` моста.

## Итог

Агент оборвался под конец ошибкой API: фильтр безопасности модели счёл
сообщение подозрительным (`reasoning_extraction`), к задаче это отношения не
имеет. Отчёт оборван на разделе о нативном ревью; итоги сверены по первичке:
по T3 Code и по каталогу прогона моста.

| Утверждение | Итог | Свидетельство |
| --- | --- | --- |
| аудит — тредом T3 Code, нативное ревью — мостом | да | тред `mcp:c7d65a4e-73c1-4a3f-a611-1b2f4682e973`; прогон `/private/tmp/codex-runs/2026-10-14-t3-probe-codex/20261014-ревью-дифа/`, `result.json`: `mode: diff`, `status: completed`, `ok: true` |
| `modelSelection` с явным усилием, заголовок по образцу | да | `t3_thread_configuration`: `gpt-6.1-sol`, `reasoningEffort: medium`; заголовок «Codex gpt-6.1-sol/medium · аудитор · готовность зоны codex» |
| бриф аудитора по `1codex` плюс общие правила `1t3` | да | исходные критерии дословно, своего вывода нет, «файлы не меняй», право сказать «работа держится», команда и код возврата по каждой проверке; правило о репликах агента в новой формулировке |
| способ ожидания | не установлено | отчёт оборван |
| выводы закрыты исходами | да, для аудита | иконка — принято с замером; `TypeError` на списке списков — воспроизведено, отклонено как вне задачи модуля; тесты — принято с перезапуском |

Сверх утверждений: два пути проверки нашли разное. Аудит по критериям нашёл
брак иконки (кольцо с полупрозрачной дырой в центре), нативное ревью диффа —
«No actionable regressions»: оно смотрит код и картинку не оценивает.

Прогон моста лёг в `/private/tmp`, а не в рабочую папку работы, как велит
`references/bridge.md`: агенту запрещено было менять файлы проекта.
