полного черновика»: старый пакет прочитан целиком повторно, каждый смысл из

## Потерь результата или конечного состояния — нет

**Поправка после круга проверок.** Первая редакция карты объявляла инвариант
треда сохранённым и одновременно считала `advise.md` поглощением без потери —
хотя мой собственный текст в `advise.md` противоречил сам себе: раздел «Тред
советника» заводил `--dialog`, а абзац ниже утверждал, что тред есть только у
пишущего воркера. Обе независимые проверки нашли это. Восстановлена точная
формулировка старого пакета: рабочее дерево — только у пишущего воркера, а
разговор с советником — названное владельцем исключение через явный `--dialog`.

Пять смыслов были потеряны первой сборкой черновика и **восстановлены до
закрытия проверки**, а не оставлены:

|---|---|---|
| низкий порог вызова: сомнение — уже повод, асимметрия цены | владелец `2026-08-14…:41` | тело, первое правило |

## Смена оси: предмет → момент роли

Старая ось приложений — «предмет старше фазы» (2026-08-19): `fleet.md` владел
волной на любой фазе, `orchestration.md` — прогоном любого вида, `threads.md` —
тем, что переживает прогон. Ось решала свою задачу, но нарушала правило
протокола «референс-файл не требует чтения другого»: `fleet.md` отправлял за
надзором в `orchestration.md`, тот за составом ремонтной задачи — обратно в
`fleet.md`, оба — в `threads.md`. Момент «волна идёт, воркер молчит» требовал
двух файлов.

Новая ось — **роль и момент**, в порядке приоритета владельца: `audit.md`,
`advise.md`, `delegate.md`, затем `watch.md`, `threads.md`, `arbitrate.md`. Один
наблюдаемый момент открывает ровно один файл.

## Снято с причиной

| Снято | Причина |
|---|---|
| ось «предмет старше фазы» как организующий принцип | производила момент, требующий двух файлов; протокол требует самодостаточной стадии |
| дублирование яруса, фона и запрета `claude-mcp` по приложениям | подняты в тело один раз; в приложениях их больше нет |
| формулировка «Глубина — в приложениях, по одному на момент» | заменена таблицей моментов, которая называет момент наблюдаемо |
| `--mode diff` в общем роутере | ушёл в `audit.md`: ревью дифа — аудит, а не отдельный класс входа |

## Обоснование инструкций, не выводимых из commander's intent

Из Уникального контекста и трёх целей компетентный агент выводит низкий порог
вызова, аудит до слова «готово», задание от результата и уборку волны. Не
выводит и потому остаётся инструкцией:

| Инструкция | Почему не выводится |
|---|---|
| ярус `sol`+`xhigh`, `luna` на тупое и большое, `max`/`ultra` сняты | решение владельца 2026-08-14, а не следствие цели; модель по умолчанию экономила бы |
| «кредиты не жалей» | стоячее решение владельца против реального дефолта модели экономить |
| любой оплаченный turn — фоном | свойство runtime: форграунд вешает сессию, из целей это не следует |
| запрет обратного вызова `claude-mcp` в задании | измеренный дефект 2026-07-28 (9 часов тишины); intent его не предотвращает |
| «Codex не виден в списке агентов» | факт среды; агент без него ищет прогон в `ListAgents` — так и было в замере 2026-08-16 |
| успех = `status=completed` и `ok=true` | без него partial response синтезируется как результат |
| порядок разделов задания Контекст → Цель → Границы → Готово | слова владельца 2026-08-30 о том, как читают инструкции языковые модели |
| `steer_accepted` ≠ «послушался» | схема SDK; событие `applied` отсутствует намеренно |
| одна реплика, не серия | слова владельца; порог ожидания не измерен и мерится событием |
| инвариант «дерево ⟺ пишущий воркер ⟺ тред» | инвариант владельца 2026-08-14 |
| single-writer lock на тред | заявленный инвариант движка, отобрать writer нечем |
| `read-only` — профиль моста, а не неподвижность диска | внешние MCP живут вне sandbox; постфлайта у ревьюера нет вовсе |
| контракт волны: file-disjoint, `prompt` ⊆ `files`, HEAD только вперёд | нарушение стоит потерянных правок, из целей не выводится |
| квитанция волны `cleanup_done` / `kept_branches` / `threads_archived` | решение владельца 2026-08-18 |
| измеренные факты cross-model bias | провенанс арбитража; без них слепой протокол становится произволом |
