# Слепая перекрёстная проверка

**Вход:** решение труднообратимое — внешний эффект, миграция, правка
глобального скила, выбор, на котором строится остальное, — и тебе нужен
независимый от твоего вывод Codex. **Выход:** решение, опёртое на первичные
файлы.

Вторая модельная семья полезна тем, что её ошибки не совпадают с твоими, а не
«характером». Судья завышает знакомый себе текст, а голосование похожих
моделей усиливает их общую правдоподобную ошибку. Поэтому первый проход слепой,
артефакт передаётся без следа авторства, а решает сверка с первичкой, не
консенсус.

1. **Одинаковый вход обоим:** критерии, пути к evidence, форма выхода.
2. **Слепо:** ни одна сторона не видит вывод, рассуждение или авторство другой
   до первого вердикта. Свой вердикт пиши в файл — диф будет воспроизводим; у
   Codex вердикт уже в `run_dir`.
3. **Диф делаешь ты:** совпадения — подтверждено предварительно; уникальные
   находки каждого; прямые противоречия и разошедшиеся допущения — отдельные
   находки, не шум.
4. **Арбитраж по первичным файлам.** Показывать модели ответ другой можно только
   после того, как оба независимых ответа зафиксированы.
5. **Совпадение не доказательство:** обе стороны могли унаследовать твою рамку из
   задания. Для решений с большим радиусом совпавшие ключевые утверждения сверь
   сам.

`1fresh-eyes` — проверка внутри твоей семьи и слепую перекрёстную не заменяет.
