# Reference-файл

Кому: агенту, пишущему `references/` создаваемого скила, обоих классов.
Reference — не приложение и не склад: открытый файл попадает в тот же
контекст, что и тело, его правила тратят тот же бюджет внимания.

## Бюджет — правила, не строки

Замер 2026: одно активное правило соблюдается в ~96%, двадцать — в 20–60%,
ломают попарные конфликты; корреляции «длина → балл» нет. Следствие: длинный
справочник фактов на один момент законен, длинный список правил — перегруз
при любом объёме текста. Каждое правило в reference платит из бюджета всего
скила и глушит в том числе правила тела.

## Один файл — один момент

Под один конкретный ход открывается ровно один файл. Не влезло — в файле два
момента: режь по моменту, не по языку и не по объёму. Первые строки файла
называют момент и что файл даёт; дальше — операции и точные факты этого
момента. Философия, вторая теория и «на всякий случай» не кладутся: нужный
факт тонет, агент не дочитывает.

## Повтор тела — только помеченной копией

Независимый пересказ правила тела — вторая правда и дрейф. Повтор допустим в
точке действия, помечен как копия формулировки владельца и правится вместе с
ней.

## Признак готовности

Под реальный ход: файл открыт в свой момент, момент закрыт одним этим файлом,
ни одно правило файла не повторяет и не оспаривает тело.
