# Пакет

Вход: якорь решения и выбранный `mode`. Выход: замороженный пакет или пакеты.

## Цель

Заморозить ненаводящий, привязанный к источникам вид одного решения: достаточно конкретный для независимой работы, но без объяснения, диагноза и желаемого вердикта главного агента. Панель получает непересекающиеся главные зоны поиска; именованный специалист — объект доказательства своего родного результата.

1. Для `panel` перечисли `Main уже читал`, дай каждой из четырёх линз другую главную зону исходных материалов и передай `Кругов пройдено` только числом.
2. Для `named` зафиксируй только явно выбранный пользователем доступный `profile`.
3. Заморозь все пакеты до первого отчёта; взаимозаменяемые зоны панели разведи заново.
