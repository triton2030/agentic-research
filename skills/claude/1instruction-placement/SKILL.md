# Место правила

## Контекст

Смысл уже есть — не решено, где он живёт; цель — положить его на самом дешёвом
слое, достигающем первого решения, которое он меняет. Шов, которым владеет этот
скил: корень · папка · скил · хук/validator · план · чат · канонический owner ·
нигде.

Правило допускается, только когда его эффект дороже того, что оно отменяет; цена
— активные обязанности в точках решения траектории, которые правило должно
пережить, не длина текста, а context volume — отдельная цена. Сомнение, что
строка неожиданно уведёт мысль агента, — не пиши её вовсе.

## Обязанности

1. **Класс — до слоя.** Раздели поведение · ориентировку · изменяемое значение.
   Значение живёт у канонического owner-а, ориентировка платит context cost и в
   счёт обязанностей не входит.
   Смешаны значение и поведение → [knowledge-out](references/knowledge-out.md).
2. **Естественный ход — до формулировки.** Назови, что агент сделает без строки
   и какое состояние должно стать истинным. Нет различия — инструкции нет.
3. **Самый дешёвый достигающий слой, один owner.** Смысл не живёт раньше первого
   решения, которое меняет, и достигает каждого следующего материального решения
   в горизонте; resident допускает только cross-task дельту; проза не
   enforcement — hard invariant держит hook, schema, validator, permission или
   test. Уже сказанное чинится у owner-а, второе правило рядом не создаёт вторую
   правду.
   Выбирается поверхность, считается бюджет траектории →
   [placement](references/placement.md).
4. **Цель и границы вместо способа; одно честное прочтение.** По умолчанию дай
   цель, границы и критерий выхода; порядок фиксируй только там, где он несёт
   correctness (границы SOP — владелец
   [behavior-package](../1skill-authoring/references/behavior-package.md)).
   Формулировка выдерживает чистое окно.
   Возможно дешёвое прочтение → [wording](references/wording.md).
5. **Evidence по claim.** Проверяй раздельно достижение текста, изменение
   решения и сохранение обязательства до конца горизонта. Чтение, заполненность
   и самоотчёт evidence не являются; непроверенное остаётся candidate.

## Соседи

- поверхность = skill, скила ещё нет → `1skill-authoring`;
- поверхность = skill, скил есть и правится → `1skill-refactor`;
- смыслов много, перегружен весь свод → `1instruction-refactor`.

## Завершение

Корень, папка, хук, план: точный итоговый текст записывается после «да»
владельца; правка после «да» — новое «да». Поверхность skill — по автономной
границе `1skill-authoring`.

Сдача: выбранный слой и почему более дешёвый не достигает решения · что теперь
меняется · какие законные пути закрыты · чем проверены достижение и behavior ·
какие claims остались candidate. В сдаче цитируй применённые пункты канона; имя
без пункта — не применение →
[canon](../1skill-authoring/references/canon.md).
