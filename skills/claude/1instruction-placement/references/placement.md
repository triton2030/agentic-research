# Выбор поверхности

Выбирай не самый заметный, а самый дешёвый слой, гарантированно достигающий
первого решения, которое меняет смысл.

| Surface | Admission |
| --- | --- |
| root | cross-task Delta, нужная большинству задач scope |
| folder | Delta поддерева |
| skill | опознаваемый момент; допустим риск, что routing не сработает |
| hook/schema/validator/test | hard invariant или детерминированное действие |
| plan | состояние одной длинной работы |
| chat prompt | невыводимая Delta текущей задачи |
| canonical owner | изменяемое значение |
| nowhere | модель быстро выводит смысл сама |

Проза не является enforcement. «Всегда делай» остаётся просьбой, пока
correctness не удерживает механизм.

Resident surface платит на каждой задаче. Допуск требует:

- смысл применяется к большинству задач scope;
- не выводится быстро из repo и task;
- меняет observable action или check;
- none/always-on/selective comparator оправдывает доставку на target model
  соразмерно риску.

**Владелец счёта по траектории — этот файл.** Универсального числового порога
правил, токенов или одновременно активных skills нет: бюджет задаёт владелец
(для скилов — около десяти обязанностей, владелец числа `1skill-authoring`).
Считай по траектории; для representative task отдельно:

- active obligations в каждой точке решения;
- сколько решений, фаз и compaction boundaries должен пережить persistent
  смысл;
- конфликты и уже созданные ассистентом прецеденты;
- loaded context, включая tool output;
- повторную доставку или механизм проверки hard invariant.

Поэтому длинный one-shot список может быть дешевле нескольких правил,
обязательных на протяжении большой работы. Wall-clock duration сама по себе
ничего не измеряет; benchmark другого model set остаётся evidence, не порогом.

Различай authority и conditioning. Инструкция задаёт норму; прежний текст
ассистента и состояние инструментов её владельцами не становятся, но создают
прецедент, который тянет следующее решение. Поэтому формально старшая строка
может оставаться в контексте и всё же проигрывать накопленной траектории.

Ориентировка размещается по частоте обращения и тоже платит context cost.
Нужна позже или уже в узкой зоне — доставляется позже или ниже.

До новой строки прочитай только применимую цепочку: system/root, folder по
пути, пересекающийся skill, покрывающий hook и активный plan. Уже сказанное
чинится у owner-а; второе правило рядом не добавляется.

Если выбран skill, дальнейшее устройство пакета принадлежит 1skill-authoring
(нового) или 1skill-refactor (существующего).
