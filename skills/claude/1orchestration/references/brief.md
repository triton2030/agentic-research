# Поручение

Этот файл задаёт контракт передачи работы; способ написания текста выбирай
по `1agent-steering`, без дополнительного порядка составления разделов.

- Исполнителю доступны причина нужного владельцу результата, цель и способ
  проверить каждый критерий: свобода маршрута требует ясности результата.
  Если результат проверить нечем, назови этот пробел и необходимый способ
  работы, чтобы отсутствие проверки не выдавало произвольный путь за успех.
- Поручение называет зону исполнителя, главное в ней, адреса необходимого
  чтения и применимое старшинство источников: конфликт с самостоятельно
  открытым файлом может возникнуть уже в его окне.
- Дельта учитывает то, что этому исполнителю уже доступно; причина каждой
  оставшейся строки объясняет, какой неверный выбор она предотвращает.
  Двусмысленность исправляется формулировкой поручения, а не страховочным
  ограничением исполнителя.

До отправки предъяви в чате счёт нагрузки по написанному поручению и
действующим зависимостям: перечень коротких ссылок не означает короткого
набора обязательств. Сам счёт не доказывает посильности — её проверяют
возвраты по критериям основного скилла.
