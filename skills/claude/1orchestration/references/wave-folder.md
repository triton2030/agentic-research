# Durable carrier без живого плана

Читай этот файл только без живого плана, когда потеря root-контекста будет
стоить больше одной переиздаваемой волны. При живом плане carrier принадлежит
плану; stalled return принадлежит [repair](repair.md).

## Carrier

Создай `<корень проекта>/_workspace/orchestration/<дата-слаг>/` и добавь этот
маршрут в `.gitignore`, если проект ещё не исключает его. `context.md` хранит
только достаточное для холодного продолжения:

```text
# Волна <дата-слаг>
Зачем · цель · границы · runtime/session handles

## Потоки
<id> · outcome · worker · return/artifact · write ownership ·
status pending|running|returned|accepted|repair|blocked

## Барьер и переход
Какие возвраты обязательны · что разрешено после их принятия · следующий ход

## Закрытие — перечитать при каждом возврате
- результат принят по evidence; требуемую независимую приёмку выполняло не
  писавшее окно
- конфликт, blocker или смена ветки разрешены root по owner-источникам;
  зависимый ход до решения остановлен
- status и переход обновлены в этом ходе
- после обязательного барьера дан синтез и отчёт в чат
```

После каждого принятого возврата обнови status и переход в том же ходе.
Самостоятельное решение root, которое меняет ветку, запиши в `decisions.md`:
`решение · основание · evidence`; переживающая волну правда переносится к её
настоящему owner-у, а не остаётся каноном carrier-а.

Блок `Закрытие` — помеченная pause-point копия acceptance, branch-stop,
transition и report из `SKILL.md`; правится вместе с ними.
