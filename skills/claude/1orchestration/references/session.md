# Папка сессии

Вход: пишущих исполнителей много. Выход: папка сессии, из которой ты
продолжаешь после любого сжатия окна, а владелец читает твои самостоятельные
решения за один присест.

## Уникальный контекст

Такая работа длится дольше одного окна. По измерению сжатие оставляет около
половины правил после одного раза и около десятой части после пяти; в окне
после сжатия есть только его пересказ и то, что ты перечитал. Чат многодневной
работы владелец за один присест не прочтёт. Папка — твоя рабочая память, а не
правда проекта: правда живёт там, где проект её держит, и папку переживает
только перенесённое туда.

## Задача

Заведи на работу одну папку там, где проект держит папки оркестраций, и веди
её файлами и папкой прогонов, названными ниже, до конца работы; окно,
продолжающее ту же работу, ведёт её папку дальше.

## Цель

После любого сжатия ты называешь следующее действие по одному `state.md`, не
перечитывая чат; владелец, вернувшись через день, читает в `decisions.md`
каждое самостоятельное решение, принятое без него, — выбор между вариантами
возвратов, разрешение их конфликта, замену его слова, трату, которой не
вернуть, — и знает, каким словом его отменить; порядок событий за дни читается
по `log.md` без чата; каждый исполнитель пишет только в свою зону записи и
свой файл прогона, где живёт его возврат, а в твоё окно входит лишь
перечитанное тобой для приёмки — либо приёмку ты отдаёшь другому окну.

## Критерии принятия

Не успех:

- `state.md`, по которому после сжатия следующее действие не назвать без чата,
  — считая и разросшийся дописыванием вместо перезаписи;
- самостоятельное решение, записанное позже работы, которая на него оперлась;
- возврат, вошедший в твоё окно текстом ответа исполнителя, а не адресом;
- долговечное — слово владельца, находка, решение проекта, — оставшееся только
  в папке;
- два поручения с правом писать в один файл без зоны записи, названной в
  обоих.

## Файлы

- `state.md` — для тебя после сжатия. Около тысячи знаков, перезаписывается
  целиком при каждой смене положения: цель работы словами владельца, в работе
  — кто, что и где ляжет возврат, — и вопросы, ждущие владельца.
- `decisions.md` — для владельца. Дописывается в момент решения: что решено,
  почему и что заменяет.
- `runs/NN-<суть>.md` — для исполнителя и для тебя. Поручение и ответ
  исполнителя — адрес этого файла: текст поручения лежит сверху, возврат —
  ниже, вердиктом по каждому критерию с адресом доказательства; ты дописываешь
  приём или причину возврата.
- `log.md` — для владельца и для тебя. Дописывается строкой на событие —
  отправлено, вернулось, принято, решено, сжато — со временем и адресом файла
  прогона.

Выход: папка, из которой чистое окно продолжает работу, а владелец читает
решения.

*Пересмотреть при следующем рефакторе этого скила, если после сжатий следующее
действие стабильно называется без `state.md`, либо `decisions.md` автономных
дней стабильно пуст.*
