# Агенточитаемые Сложные Артефакты

Читай эти карточки только для многоэкранного, интерактивного или diagram-heavy
artifact. Это свойства результата, а не новые стадии, manifest или проверки.

## Карточка: DOM Следует Рассказу

**Сигнал:** визуальный порядок создают CSS placement или JS, а source order
перемешан.

**Практика:** располагай main, sections, пояснения и действия в том порядке, в
котором их должен понять читатель. CSS меняет композицию, но не причинную
последовательность.

## Карточка: Заголовки И Anchors

**Сигнал:** раздел можно найти только по позиции или случайному generated ID.

**Практика:** один `h1`; содержательные `h2`/`h3`; стабильный короткий `id` на
каждом смысловом section. Link text называет назначение, а не «подробнее».

## Карточка: Alpine Не Владеет Смыслом

**Сигнал:** initial HTML пуст, а все states и labels появляются только после
запуска JS.

**Практика:** default state и краткий вывод существуют в HTML. Alpine меняет
видимость и derived presentation. Для альтернативных важных states оставь
текстовые labels и объясни результат рядом с control.

## Карточка: Mermaid Имеет Текстовый Вывод

**Сигнал:** решение можно извлечь только из spatial topology SVG.

**Практика:** рядом с diagram оставь краткий вывод, главный путь и критическую
развилку. В definition добавь `accTitle` и `accDescr`; node labels остаются
короткими и содержательными.

## Карточка: Многостраничный Project Имеет Карту

**Сигнал:** внутренние страницы существуют, но их связь или текущий путь
понятны только из dropdown runtime.

**Практика:** project entry объясняет общую работу и содержит обычные links на
экраны. Каждая страница возвращает к project entry; navigation labels стабильны
и совпадают с названиями экранов. Дерево в `ARTIFACT_PROJECT.pages` повторяет
реальную информационную иерархию, а breadcrumbs оставляют ancestor path видимым.

## Карточка: Provenance Рядом С Утверждением

**Сигнал:** artifact опирается на входные материалы, но source relationship
существует только в чате.

**Практика:** существенное внешнее утверждение получает видимую ссылку или
короткий source note. Реальные вложения живут в `sources/`; технические assets
туда не переносятся.

## Карточка: Нет Второго AI-Рассказа

**Сигнал:** предлагается скрытый summary, JSON manifest или параллельная
agent-only версия содержания.

**Практика:** один HTML остаётся общей правдой для человека и агента.
Семантический DOM, headings, links и visible text несут смысл напрямую.

**Не делай:** не создавай обязательный `artifact.json`, скрытую копию prose,
data-атрибуты с дублированным рассказом или отдельную проверочную стадию.
