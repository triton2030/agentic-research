# Классы Раскладки Зоны

Эти классы **уже установлены** в `assets/shared/components.css` каждой зоны —
используй, не копируй скелеты. Открывай на оси «что на узком», когда тянет
написать `@media`: сначала проверь, не переносится ли блок готовым классом.
Порог — всегда минимум блока из плана, не ширина экрана.

| Класс | Отношение | Ручки | Пример |
|---|---|---|---|
| `flow` | поток сверху вниз, один ритм на контейнер | `--space` | `<section class="flow">` |
| `cluster` | ряд меток/чипов, перенос по содержимому | `--gap` | ряд `badge` |
| `switcher` | 2–3 блока: ряд ↔ колонка целиком | `--threshold` = минимум ряда | пары «до/после» |
| `with-sidebar` | панель + текучее тело | `--side` = минимум панели | легенда у канвы |
| `auto-grid` | равноправные карточки | `--min` = минимум карточки | `card` ×N |
| `reel` | горизонтальная лента внутри рамки | `--gap` | полоса миниатюр |

Ручка задаётся инлайн через style: `<div class="auto-grid"
style="--min:17rem">` — число берётся из плана.

## Ловушка Имён

Похожие имена уже заняты DaisyUI с другим смыслом: его `stack` складывает
детей стопкой друг на друга (страница ложится слоями), `join`, `mask`,
`indicator` — тоже его. Своему классу — своё имя, не совпадающее с Daisy;
проверка: имя ищется в `lib/daisyui.css`.

## Когда `@media` Всё Же Нужен

Только когда перелом меняет саму композицию — две разные раскладки, а не
сжатие одной. Такой перелом называется в плане поимённо; число `@media` в CSS
равно числу названных переломов. Ритм, перенос и схлопывание колонок делают
классы выше — без брейкпоинтов.

## Порог От Места, Не От Экрана

Если перенос зависит от ширины места, где стоит блок, а не страницы:

```css
.host { container-type: inline-size; }
@container (min-width: 30rem) { /* композиция шире порога */ }
```

Принцип тот же: порог — минимум блока.
