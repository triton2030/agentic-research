# Примитивы Раскладки

Открывай на оси «что на узком», когда тянет написать `@media`. Сначала проверь,
не переносится ли блок примитивом сам. Примитив владеет одним отношением;
порог — это минимум блока из плана, не ширина экрана. Daisy раскладок не даёт:
композиция — всегда страница.

## Stack — вертикальный ритм потока

```css
.stack > * + * { margin-block-start: var(--space, 1rem); }
```

Поток блоков сверху вниз. Ритм один на стек, не свой отступ у каждого элемента.

## Cluster — ряд, который переносится сам

```css
.cluster { display: flex; flex-wrap: wrap; gap: 0.5rem; align-items: center; }
```

Бейджи, чипы, кнопки, метаданные. Переносится по содержимому, порога нет.

## Switcher — ряд ↔ колонка целиком

```css
.switcher { display: flex; flex-wrap: wrap; gap: 1rem; }
.switcher > * {
  flex-grow: 1;
  flex-basis: calc((var(--threshold, 30rem) - 100%) * 999);
}
```

`--threshold` — минимум всего ряда. Ниже порога все элементы падают в колонку
разом, а не по одному. Ряды сравнения, пары «до/после».

## Sidebar — панель + текучее тело

```css
.with-sidebar { display: flex; flex-wrap: wrap; gap: 1rem; }
.with-sidebar > .sidebar { flex-basis: 15rem; flex-grow: 1; }
.with-sidebar > .body { flex-basis: 0; flex-grow: 999; min-inline-size: 60%; }
```

Панель держит свой минимум, тело забирает остальное; на узком панель падает
вверх или вниз без перелома.

## Grid — карточки auto-fit

```css
.auto-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1rem;
}
```

`16rem` — минимум карточки из плана. `min(100%, …)` спасает экран уже минимума.

## Редкие: Cover · Frame · Reel

- Cover — экран с центрированным главным: `display: grid` +
  `min-block-size: 100svh`, центр через `place-content`;
- Frame — фиксированная пропорция канвы: `aspect-ratio`;
- Reel — горизонтальная лента внутри рамки: `overflow-x: auto` у контейнера,
  прокручивается лента, не страница.

## Когда `@media` Всё Же Нужен

Только когда перелом меняет саму композицию — две разные раскладки, а не сжатие
одной. Такой перелом называется в плане поимённо; число `@media` в CSS равно
числу названных переломов.

## Порог От Места, Не От Экрана

Если перенос зависит от ширины места, где стоит блок, а не страницы:

```css
.host { container-type: inline-size; }
@container (min-width: 30rem) { /* композиция шире порога */ }
```

Принцип тот же: порог — минимум блока.
