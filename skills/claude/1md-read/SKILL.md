# 1md-read

## Цель

Знать доступные способы быстро исследовать множество Markdown-файлов по
описаниям и заголовкам, не открывая их тела.

## Критерии успеха

Агент ознакомился с доступными инструкциями и инструментами чтения и поиска,
после чего продолжил исходную задачу.

## Инварианты

Не превращай скил в справочник и не запускай инструменты ради демонстрации
ознакомления. Живая поверхность возможностей принадлежит их собственным
описаниям и каталогу.

## Дельта

Без этого скила агент может начать открывать Markdown-файлы по одному, не
заметив существующий лёгкий слой навигации.

## Известные сбои

Копирование команд и правил внутрь скила размывает главный сигнал и устаревает
вместе с инструментами.

## Механика

Просмотри описания доступных `1md-*` скилов и выполни:

```bash
md tools --json
```

Обрати особое внимание на чтение множества файлов по descriptions и headings
без их тел. Затем вернись к исходной задаче.

## Завершение

Выведи одной строкой:

```text
С инструментами чтения и поиска ознакомлен, продолжаю работу.
```
