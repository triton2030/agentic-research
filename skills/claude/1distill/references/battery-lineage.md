# Батарея — родословная

Карта на случай усиления процедуры; ни один метод у нас не прогонялся — это не
evidence.

- **Delta debugging / ddmin** (Zeller 1999), потомки **C-Reduce**, **Perses**:
  иерархическая абляция только удалением, каждое удаление сертифицируется
  прогоном оракула, до 1-минимальности. Ближайший родственник процедуры;
  единственный метод в округе с гарантией в терминах поведения, не прокси.
  Отсюда гранулярность сверху вниз и условие остановки. Цена — квадратичное
  число прогонов в худшем случае, поэтому у нас партии, а не полный ddmin.
- **Перевёрнутое mutation testing**: пробы строятся под конкретное внесённое
  изменение. Источник прицельных проб.
- **TOST** (тесты эквивалентности, биостатистика): равенство недоказуемо, но
  разница ограничивается сверху при заранее названной границе. Отсюда порог
  паритета до прогона. Power-анализ не делаем и заявлять не вправе.
- **Контрпример — минимизация тестовых наборов по покрытию**: покрытие
  сохраняется, способность ловить дефекты падает. Причина, по которой матрица
  покрытия — фильтр, а не сертификат.
- **QuestEval / SummaQA / FEQA / QAFactEval**: вопросы порождаются из
  оригинала, задаются модели, видящей только сжатую версию. Наша батарея — этот
  метод, суженный до вопросов с развилкой.
- **FactCC / SummaC** (влечение): каждое утверждение оригинала должно
  выводиться из сжатого. Дешевле батареи, но меряет текст, не поведение —
  быстрый фильтр перед ней.
- **Пирамида, FActScore**: атомарные единицы и счёт покрытия — статическая
  матрица с весами.
- **Knowledge distillation**: ученик совпадает с учителем по выходам на
  распределении задач, не по тексту.
- **LLMLingua, Selective Context**: выводимость токена считается маленькой
  моделью, не суждением. Предок абляции; полная автоматизация требует логитов и
  здесь не реализована.
