# Батарея — прогон и счёт

Слепой агент: своё окно, видит **только одну версию текста**, не знает ни о
второй, ни о том, что здесь что-то резали. Формулировка задачи — голая ситуация
из батареи, без ярлыков вроде «проверь, сохранилось ли правило».

Три прогона на ситуацию при одной модели и настройках. Один совпавший прогон
доказывает возможность, а не сдвиг вероятности; 3/3 и 1/3 — разные события.

Модель слепого агента **задаётся явно** и совпадает с рабочей. Унаследованная
от сессии — молчит и делает прогон невоспроизводимым; модель слабее рабочей
меряет чужую ситуацию и выдаёт потерю, которой нет.

Обязательные плечи, без них числа нечитаемы:

- **Калибровка** — прогон батареи на полной версии до сжатой; единственное
  легальное окно между заморозкой ядра и первым разрезом.
- **Нулевая рука** — прогон без текста вовсе: пол «модель делает сама», ниже
  которого текст не работает.

Форматы наблюдения по убыванию силы: **первый ход** на развилке; **план
работы** (расхождение множеств шагов локализует потерю, когда первый ход
одинаков по построению); **артефакт** — появился ли след, а не сказал ли агент,
что помнит о нём.

Счёт:

- **Совпало** — первый ход тот же в ≥2 из 3 прогонов.
- **Разошлось** — записывается с номером партии разрезов; партия из 5–8
  существует ровно ради локализации.
- **Не измерено** — прогонов меньше трёх. Не «совпало».

Порог годится только асимметрично: обвал опровергает, паритет почти ничего не
доказывает.

**Абляция одной строки** — для строки, которую тест затемнения пропустил как
пересказ: убрать её, дать ситуацию, где она должна была сработать, посмотреть,
породит ли агент операнд сам. Породил — выводима. Нет — несущая. Без прогона
строка считается несущей.

Стоп: батарея меряет поведение агента-исполнителя. Обучающую функцию владельца
она не меряет; если приёмников два, батарея закрывает одного, второй остаётся
под запретом резки.
