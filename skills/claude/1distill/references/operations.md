# Операции: что модели можно и чего нельзя

Граница одна: **операция допустима, если её эквивалентность проверяется
механически, без чтения.**

| Разрешено | Почему безопасно |
|---|---|
| Дедупликация с переносом ячеек | множество обязательств сравнимо как множество строк |
| Канонизация дубля указателем | один экземпляр плюс отсылки, токены те же |
| **Факторинг**: «X перед Y; X перед Z» → «X перед: Y; Z» | нормативные токены — подмножество исходных |
| **Смена представления**: семейство «если C, то A» → таблица | ячейки заполнены исходными формулировками |
| Перенос нормы в среду: артефакт, снятие инструмента | текст не порождается вовсе |

| Запрещено | Почему |
|---|---|
| Подъём уровня абстракции | общая формулировка не содержится в исходнике |
| Слияние правил в более общее | эквивалентность проверяется только суждением |
| Установление дефолта («разрешено всё незапрещённое») | новая норма, не свёртка |
| Переформулировка «своими словами» | замер: skill-файлы, переписанные моделью, уходят ниже базовой линии (−8…−11.5 п.п.); человеческие дают +16.6 |

У разрешённых операций есть механическая обратная процедура: развернуть и
получить исходное множество обязательств токен в токен. Нет обратной процедуры
— операция запрещена, какой бы очевидной ни казалась.

**Но обратимость — свойство текста, а не поведения.** Она доказывает целость
множества обязательств и молчит о порядке и позиции, а те влияют
самостоятельно: перестановка примеров водит результат, середина длинного
контекста используется хуже краёв. Факторинг и смена представления проходят
батарею **наравне с удалением**; обратимость даёт право на попытку, не пропуск
проверки.

Запрещённое не выбрасывается, а **уходит владельцу пакетом эскалации**: модель
локализует свёртку и показывает, что свернётся; формулировку пишет куратор.
