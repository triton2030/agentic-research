# Hermes Model Bench

Открывай, когда дефолтная `moonshotai/kimi-k3` не та семья или нужно назвать
модель точно. Таблица в `SKILL.md` — рабочий минимум; здесь живой каталог и
правила выбора.

## Живой каталог, а не память

Список моделей меняется на стороне Nous Portal. Не называй модель по памяти —
прочитай кэш каталога (бесплатно, без вызова модели):

```bash
python3 -c "import json,pathlib;d=json.loads((pathlib.Path.home()/'.hermes/cache/model_catalog.json').read_text());print(d['updated_at']);print(*[m['id'] for m in d['providers']['nous']['models']],sep='\n')"
```

Кэш обновляет сам Hermes; `hermes model --refresh` перечитает live-списки, но
это интерактивный picker — не запускай его в сессии. Модель вне списка даст
runtime mismatch и `ok=false`, а не тихую подмену: это и есть проверка.

## Как выбирать

Ось выбора одна — **насколько далеко от Claude**. Дальше = информативнее при
несогласии, но и дороже по переносу контекста.

| Семья | Модели | Чем полезна против Claude |
|---|---|---|
| Moonshot | `moonshotai/kimi-k3` | дефолт: длинный контекст, крепкое рассуждение, другой корпус |
| Google | `google/gemini-3.1-pro-preview`, `google/gemini-3.6-flash` | иная деградация внимания на больших документах |
| xAI | `x-ai/grok-4.5` | спор с консенсусом, меньше конформности |
| DeepSeek | `deepseek/deepseek-v4-pro`, `deepseek/deepseek-v4-flash` | RL-линия рассуждения: ломается в других местах |
| Z.AI | `z-ai/glm-5.2`, `z-ai/glm-5.1` | дешёвый широкий second pass |
| Alibaba | `qwen/qwen3.8-max` | китайская экосистема, нестандартные стеки |
| MiniMax, Tencent, StepFun, NVIDIA, Xiaomi, Sakana | `minimax/minimax-m3`, `tencent/hy3`, … | редкий срез; бери осознанно, не «для разнообразия» |
| Anthropic, OpenAI | `anthropic/*`, `openai/*` | **не отсюда**: та же семья, что ты и `1codex` |

Anthropic и OpenAI через Hermes оправданы ровно в одном случае: нужно сравнить
поведение конкретной версии модели на одном и том же промпте (стенд), а не
получить независимое мнение.

## Дешёвый рабочий, а не советник

Вторая работа этого стенда — не мнение, а **пропускная способность**. Механика,
которую жалко считать дорогой моделью: перебрать корпус по одному признаку,
извлечь поля, свести список, переформатировать, вычитать длинный вывод.

Бери `deepseek/deepseek-v4-flash-0731` (закреплённая версия; скользящая
`deepseek/deepseek-v4-flash` меняется под тобой) с `--reasoning low` или
`medium`. Дорогой ярус на такой задаче — сожжённые деньги, а не качество.

Правило приёмки жёстче обычного: **результат дешёвого рабочего принимается
только когда его проверяет артефакт** — файл, команда, тест, точная сверка
цитат. Он не «второе мнение» и не голос при расхождении; его ошибка выглядит
ровно так же уверенно, как ответ. Не отдавай ему развилку, суждение и вердикт:
для этого существует остальная таблица.

Граница с `1codex`: `gpt-5.6-terra` остаётся дефолтным дешёвым исполнителем там,
где нужны правки файлов проекта, флот и глубокая интеграция. Flash берут, когда
работа read-only и её объём важнее интеграции, либо когда нужен исполнитель вне
обеих западных семей.

## Смена модели

Модель, провайдер и reasoning задаются только на **свежем** прогоне:

```bash
python3 "$HOME/.claude/skills/1hermes/scripts/hermes_advisor.py" --cwd "$PWD" \
  --model google/gemini-3.1-pro-preview --provider nous --reasoning high \
  > /tmp/hermes-gemini.json 2> /tmp/hermes-gemini.err <<'HERMES_BRIEF'
<самодостаточный brief>
HERMES_BRIEF
```

Если передан только `--model`, provider выбирается из живого каталога. С
`--resume` менять runtime нельзя — начинай новый прогон.

Reasoning: `none|minimal|low|medium|high|xhigh|max|ultra`. Дефолт скила `medium`.
Не всякая модель поддерживает верхние уровни — несовпадение придёт как
`runtime mismatch` в `warnings` и `ok=false`; это ответ «модель не та», а не
повод принять результат.

## Параллельный стенд

Несколько семей на один вопрос — это несколько фоновых прогонов с **разными
файлами вывода** и одной схемой ответа в brief-е. Синтез твой: расхождение —
находка, согласие двух далёких семей — уже настоящий сигнал. Не сливай их в
один прогон и не считай голоса как выборы.

Дефолтный набор `file,web` не включает память, поэтому независимые advisor-runs
можно запускать параллельно с разными файлами вывода. Если добавлен `memory`,
параллель на одном профиле отменяется: сессии могут влиять друг на друга.
