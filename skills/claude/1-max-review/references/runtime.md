# Claude: запуск

Передай координацию отдельному свежему агенту: абсолютный адрес SKILL.md,
область, режим и адрес сессии. Модели определяет тело SKILL.md. Листовые
проверки запускаются общей командой `max-review`, которая использует
установленный Codex CLI и его сохранённый вход через ChatGPT. Claude
остаётся координатором; Sonnet не подставляется вместо Luna.

Проверь доступность команды, файлов и сохранённой авторизации через doctor.
Не считай установку пакета Claude установкой Codex CLI или готовой авторизацией.
Не создавай новые ключи и не переключай способ оплаты молча.

Если отдельный координатор недоступен, объясни потерю режима «запустил и ждёт»:
предложи вызывающему роль диспетчера или сохранение очереди для другой среды.
До выбора статус incomplete; ранее данное согласие на такой путь сохраняет
силу. Оболочка управляет очередью проверяющих, но не создаёт координатора.

Свежая CLI-сессия сохраняет автоматически доставляемые инструкции. Requested
model и доступную resolved model различай. Отчёт об успешном процессе не
подтверждает смысловой PASS. `max-review run` работает, пока жив его процесс;
скилл не создаёт постоянный сервис после завершения сессии.
