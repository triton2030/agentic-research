# Behavioral Characterization Notes

This is a non-replayable observation log from one interactive session, not an
evidence owner or regression gate. Raw prompts, outputs and acceptance receipts
were not preserved as immutable addressed fixtures. The notes only prevent a
later editor from inflating these runs into stronger claims.

## Setup

- Date: 2026-08-05
- Characterized target: GPT-5.6 Codex subagents; Claude Code passed only a
  skill-loading smoke, not orchestration characterization
- Primary packet: a six-person team deciding whether to split an order
  monolith into microservices
- Unseen transfer packet: a 500-page developer portal deciding whether to
  replace team-owned navigation with a task-based hierarchy
- Compared product: framework declaration, step-addressed public artifacts,
  grounding and gaps, framework-native conclusion and cross-framework synthesis

Workspace-wide hashes changed during the run because unrelated concurrent repo

independent sandbox proof.

## Observation Boundary

The observed runs are consistent with, but do not prove:

- explicit one-framework provenance per returned stream;
- complete, addressable public method artifacts rather than framework labels;
- visible gaps when a framework step requires missing research or evidence;
- linear and iterative operational adapters;
- a completion barrier before root synthesis.

Current evidence does not support:

- access to, or proof of, private chain-of-thought;
- truth of a conclusion merely because every step is present;
- guaranteed no-write enforcement by either runtime's fresh-agent primitive;
- a causal claim that isolated streams reason more deeply than one precisely
  matched single-context agent;
- a stable quality-per-token advantage.

The product is therefore three separately attributable method traces and their
synthesis. Do not market it as demonstrated reasoning superiority.

## Reopen Gate

Repeat matched comparisons on genuinely different decision classes. Hold task
packet, frameworks, operational spines, schema and output budget constant; vary
only one context versus three history-isolated streams. If the cheaper
single-context comparator repeatedly preserves the same distinct operations,
gaps and decision, reconsider the three-stream default rather than defending
it by name.
