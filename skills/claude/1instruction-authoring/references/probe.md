# Доказательство

Вход: стадия 4 — полный пакет candidate-текстов из стадии «Сборка».

1. Материализуй candidate-тексты во временное draft-дерево с рабочими
   связями, не трогая итоговые адреса.
2. До запроса «да» у владельца прогони по этому дереву пробник минимум по
   самой рисковой зоне — той, где цена неучтённого ребра выше всего; пробник
   — свежий субагент: из инструкций ему даётся только файл входа дерева,
   рабочие файлы зоны ему доступны, а до зонного файла он должен дойти сам по
   связке.
3. Задачу пробнику дай такую, что правильно она решается только через рёбра
   пакета, а известное дефолтное поведение агента без инструкций расходится с
   требуемым.
4. Суди по diff и порядку действий пробника, а не по его самоотчёту; проверь
   и набор прочитанного им — чтение за пределами цепочки тоже находка.
5. Всё, что пробник не покрыл, становится candidate-claim и уходит в сдачу.

Выход: evidence по прогнанным зонам · candidate-claims по остальным.
