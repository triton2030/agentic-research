# Доказательство

Вход: стадия 4 — полный пакет candidate-текстов из стадии «Сборка».

1. До запроса «да» у владельца прогони пробник минимум по самой рисковой
   зоне — той, где цена неучтённого ребра выше всего.
2. Пробник — свежий субагент: из инструкций ему даётся только файл входа,
   рабочие файлы зоны ему доступны; до зонного файла он должен дойти сам по
   связке.
3. Задачу пробнику дай такую, что правильно она решается только через рёбра
   пакета, а известное дефолтное поведение агента без инструкций расходится с
   требуемым.
4. Суди по diff и порядку действий пробника, а не по его самоотчёту.
5. Всё, что пробник не покрыл, становится candidate-claim и уходит в сдачу.

Выход: evidence по прогнанным зонам · candidate-claims по остальным.
