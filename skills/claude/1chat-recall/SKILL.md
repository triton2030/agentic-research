# Chat recall

Запусти read-only helper; он возвращает последние 10 записей пользователя из активной ветки текущей session и исключает текущий turn:

```bash
"${CLAUDE_SKILL_DIR}/scripts/chat_recall.py" --session-id "${CLAUDE_SESSION_ID}"
```

Если нужного контекста нет или важна полнота, повтори с `--all`.

Используй только прямые сообщения и подтверждённые ответы `AskUserQuestion` из результата. Формулировка вопроса и option label принадлежат Claude; считай их зафиксированным выбором, а не дословной репликой пользователя. Image content не извлекается и помечается явно.

Если helper завершился ошибкой, сообщи, что recall не подтверждён. Не угадывай по памяти, не открывай другую session и ничего не сохраняй автоматически.
