# Контракт сохранения user-only summary

Этот reference применяется только после явной просьбы пользователя сохранить восстановленный контекст в файл.

## До записи

1. Получи exhaustive JSON через `read --limit all` с нужным scope.
2. Убедись, что `returned == total`, `warnings` пуст и `current_turn_excluded` соответствует запросу.
3. Используй путь, явно названный пользователем. Если место назначения не задано и в проекте нет однозначного owner-файла, спроси его; не создавай новый owner по догадке.
4. Не перезаписывай существующий файл без явного разрешения.

## Что разрешено сохранять

- Точные direct human messages.
- Свободные ответы пользователя на `AskUserQuestion`.
- Факт выбора agent-authored option, сформулированный как `Пользователь выбрал: <label>`.
- Минимальную source metadata, достаточную для проверки происхождения.

Не приписывай пользователю слова вопроса Claude, описания вариантов, выводы модели, tool output или вычисления агента. Если делаешь synthesis, явно отдели его от source evidence.

## Secrets

Не сохраняй токены, пароли, приватные ключи, session cookies и другие credentials, даже если они присутствуют в сообщении. Замени значение на `[REDACTED]` и явно отметь redaction. При сомнении остановись и попроси пользователя указать безопасный scope.

## Минимальная шапка

```yaml
---
capture_kind: claude-user-input
source_session_id: <CLAUDE_SESSION_ID>
captured_at: <ISO-8601 timestamp>
current_turn_included: false
---
```

После записи перечитай файл и проверь, что каждое число, ограничение и цитата имеют source record, а option selections не оформлены как дословные цитаты пользователя.
