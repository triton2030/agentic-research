# Recraft MCP: инструменты

Открой, когда нужна операция кроме `generate_image`, стиль, своя картинка на
входе или Design Agent. Схема коннектора claude.ai снята 2026-10-16; если
сервер отклонил параметр, перечитай схему инструмента: она сильнее этого файла.

## Операции

| Задача | Инструмент | Модели | Вопрос о цене |
| --- | --- | --- | --- |
| картинка из текста | `generate_image` | Recraft V4.1, V3, V2 и внешние | Pro и внешние |
| стилистическая переделка одной картинки | `image_to_image` | Recraft V4.1, V3, V2 | Pro |
| правка словами, несколько картинок сразу | `image_edit` | только внешние, по умолчанию `nano_banana_2` | всегда |
| вариации без промпта | `variate_image` | — | нет |
| заменить фон по описанию | `replace_background` | только V3, V2 | нет |
| дорисовать фон по маске | `generate_background` | только V3, V2 | нет |
| перерисовать область по маске | `inpaint_image` | только V3, V2 | нет |
| стереть область по маске | `erase_region` | — | нет |
| убрать фон | `remove_background` | — | нет |
| растр → SVG | `vectorize_image` | — | нет |
| увеличить без смены содержания | `crisp_upscale` | — | нет |
| увеличить с дорисовкой деталей | `creative_upscale` | — | всегда |

- Число результатов — `n` от 1 до 6, по умолчанию 1.
- `image_size` — соотношение сторон; для `variate_image` обязателен.
- `image_to_image`: `strength` от 0 до 1; 0,3–0,6 — баланс между сохранением
  и переделкой.
- Маска — чёрно-белая; белые области обрабатываются.
- Апскейл: вход до 4 Мп, стороны до 4096 px; для `crisp_upscale` от 32 px,
  для `creative_upscale` от 256 px.
- `crisp_upscale` сохраняет содержание: для товара, текста и лица.
  `creative_upscale` перерисовывает детали.

## Стили

| Параметр | Что делает |
| --- | --- |
| `input_style` | тип изображения: `realistic_image`, `digital_illustration`, `vector_illustration`, `icon` (только V2), `logo_raster` (только V3) |
| `input_style_id` | готовый или свой стиль; тип и модель берутся из стиля |

Параметры взаимоисключающие. Flash и внешние модели стилей не принимают.

- `list_basic_styles` — библиотека встроенных стилей Recraft. Начни с неё,
  если нужен узнаваемый стиль.
- `list_styles`, `get_style` — свои стили владельца.
- `create_style` — новый стиль из 1–5 картинок-образцов, бесплатно. Для V4
  `input_style` не передаётся; стиль V4 применяется и с моделью V4.1 того же
  типа: растровый с `_raster`, векторный с `_vector`. Стиль сохраняется в
  аккаунте Recraft — создавай его только по просьбе владельца.
- `delete_style` удаляет без возврата: только по прямой просьбе и с точным id.

## Своя картинка на входе

Инструменты принимают публичный URL. Для локального файла:

1. `request_upload_url` — без параметров, возвращает `upload_url` и готовую
   команду `curl`.
2. `curl -X PUT -H 'Content-Type: image/png' --data-binary @файл.png '<upload_url>'`
   — тип по формату файла: `image/png`, `image/jpeg`, `image/webp`.
3. `image_url` из ответа PUT — во вход инструмента. Ссылка живёт 15 минут.

Ссылку загрузки в ответ владельцу не выводи. Вход: PNG, JPEG, WEBP или SVG.

## Design Agent

`call_agent` строит из описания продукта целый набор ассетов: логотип, палитру,
шрифты, иконку приложения, картинки для соцсетей — и может сохранить их как
Design Kit. Бери его, когда нужен цельный облик, а не одна картинка. Агент
часто отвечает вопросом или вариантами: передай их владельцу дословно, а его
ответ верни с тем же `chat_id`. Не отвечай за владельца.

## Служебные

| Инструмент | Что даёт |
| --- | --- |
| `get_user` | аккаунт и остаток кредитов |
| `suggest_model` | id модели под описание задачи |
| `subscription_plans` | планы и их кредиты; ничего не покупает |

## Результат

Генерация возвращает URL картинок, превью WEBP в base64 и потраченные кредиты.
Ссылка живёт около 24 часов, потерянную не восстановить: сохраняй сразу.
