# Recraft MCP: инструменты

Открой, когда нужна операция кроме `generate_image`, стиль или своя картинка
на входе. Точные имена, параметры и enum — в живой схеме `mcp__recraft__*`;
этот файл объясняет назначение.

## Операции

| Задача | Инструмент | Цена по Credits |
| --- | --- | --- |
| картинка из текста | `generate_image` | цена модели |
| новая картинка из картинки и текста, с силой сходства | `image_to_image` | цена модели |
| заменить фон по текстовому описанию | `replace_background` | цена модели |
| убрать фон | `remove_background` | 1 |
| растр → редактируемый SVG | `vectorize_image` | 1 |
| увеличить без смены содержания | `crisp_upscale` | 1 |
| увеличить с дорисовкой деталей | `creative_upscale` | с вопросом |
| стиль из 1–10 картинок-образцов | `create_style` | — |
| аккаунт и остаток кредитов | `get_user` | 0 |

`crisp_upscale` сохраняет содержание: для товара, текста и лица.
`creative_upscale` перерисовывает детали и может изменить мелкие формы;
Recraft советует его, когда искажены лица и руки.

Сервер может открыть больше инструментов, чем перечисляет страница MCP:
правку по маске, стирание области, вариации, выбор модели. Используй их по
живой схеме и сверяй назначение со страницей операции в API-документации.

## Стили

Стиль V4 строится из 1–10 картинок-образцов без обучения: модель держит
технику, цвет, фактуру и композицию образцов. Для V4 и V4.1 стиль —
необязательный вход; линия `recraftv4_styles*` без стиля не работает.

- `match`: `flexible` (по умолчанию) держит общее настроение, `precise` —
  каждую деталь. Для V2 и V3 — только `regular`.
- Стиль привязан к модели и базовому типу, с которыми создан: применяй его с
  той же моделью.
- V4.1 Flash стили не принимает.
- Стиль создаётся по просьбе владельца, а не «на всякий случай».

## Своя картинка на входе

Инструменты принимают картинку по ссылке: публичный URL или data URL
(`data:image/png;base64,...`). Если в схеме есть отдельный инструмент
загрузки, используй его для локального файла. Ссылку загрузки в ответ не
выводи.

Ограничения входа: PNG, JPG, WEBP (SVG — где указано), до 20 МБ, до 16 Мп,
длинная сторона до 4096 px, короткая — от 256 px (для чёткого апскейла — от
32 px). Маска — в оттенках серого, того же размера, только чистый чёрный и
чистый белый.

## Результат

Ссылка на результат публичная и живёт около 24 часов; потерянную ссылку не
восстановить. Сохраняй сразу.
