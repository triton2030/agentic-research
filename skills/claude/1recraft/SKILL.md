# Recraft

## Контекст

Recraft подключён как коннектор claude.ai «Recraft» — MCP-сервер
`https://mcp.recraft.ai/mcp` со входом через OAuth. Он списывает кредиты
подписки владельца — тот же баланс, что в Recraft Studio. REST API Recraft
оплачивается отдельно и требует `RECRAFT_API_TOKEN`: этот маршрут здесь не
используется, токен не запрашивается.

Каждый вызов, создающий изображение, списывает кредиты. Результат приходит
публичной ссылкой, которая живёт около суток: без сохранения в проект теряются
и картинка, и её промпт.

Скил вызывают слова «Recraft» или «рекрафт». Остальные картинки идут
прежними маршрутами владельца, например в Codex по `1codex`; молча переводить
их в Recraft нельзя.

Recraft часто меняет модели, инструменты и цены. Факты бери из живой схемы
инструментов и документации онлайн: к адресу любой страницы добавь `.md`,
индекс страниц — `https://www.recraft.ai/docs/llms.txt`.

## Задача

Переведи просьбу владельца в продуманный вызов Recraft, сохрани результат
вместе с точным промптом в проекте и назови остаток кредитов.

## Цель

Пригодное изображение при наименьшем расходе кредитов. Если это спорит,
выбирай дешевле и с вопросом, а не дороже и молча.

## Когда инструментов Recraft не видно

Recraft подключён как коннектор claude.ai «Recraft». Его инструменты
называются `mcp__<id коннектора>__generate_image` и видны в сессиях приложения
Claude, но не в `claude -p`.

Инструменты обычно отложены. Загрузи их ToolSearch по именам операций:
`generate_image remove_background vectorize_image get_user`, `max_results` 30.
Запрос по слову `recraft` коннектор не находит: в его именах только id.

Нет ни одного — коннектор не подключён к этой сессии. Коннектор, добавленный
во время сессии, виден только в новой. Включить его может только владелец, в
настройках коннекторов claude.ai. Не подменяй Recraft другим генератором.

## Когда выбираешь операцию и модель

По умолчанию: `generate_image`, `model: recraftv4_1_flash_raster`, `n: 1`.
Модель передавай явно: без неё сервер берёт `recraftv4_1`. Flash делает только
растр и не принимает стиль. Другие операции, стили и входные картинки — в
[tools.md](references/tools.md).

| Нужно | `model` |
| --- | --- |
| обычная картинка, фото, иллюстрация | `recraftv4_1_flash_raster` |
| качества Flash не хватило или нужен стиль | `recraftv4_1_raster` |
| SVG: логотип, иконки, векторная иллюстрация | `recraftv4_1_vector` |
| печать, крупный формат — с вопросом | `recraftv4_1_pro_raster`, `recraftv4_1_pro_vector` |
| готовые стили по имени, `logo_raster` | `recraftv3_raster`, `recraftv3_vector` |
| самый дешёвый вектор, стиль `icon` | `recraftv2_vector` |

Размер — параметр `image_size`, соотношение сторон из списка схемы
(`1:1`, `16:9`, `4:5` и др.); пиксели выбирает модель. Схема на 2026-10-16;
если сервер отклонил id, перечитай схему инструмента. Не выдавай пару
`generate_image` → `vectorize_image` за один шаг: это два списания.

## Когда операция стоит денег

Без вопроса: один результат на недорогой модели и операции за 1 кредит.
В коннекторе все инструменты разрешены без подтверждения: приложение не
спросит перед платной операцией, вопрос задаёт только этот скил.

Спроси и назови цену в кредитах перед:

- любой Pro-моделью;
- Enhance и творческим апскейлом (`creative_upscale`);
- внешней моделью из схемы (Nano Banana, GPT Image, Flux, Seedream и др.):
  их цена в таблице Recraft отдельная. `image_edit` работает только с ними;
- Design Agent (`call_agent`): он делает целый набор ассетов;
- серией, которая в сумме дороже примерно 20 кредитов.

Цены — страница Credits:
`curl -s https://www.recraft.ai/docs/plans-and-billing/credits.md`.
Снимок 2026-10-16: V4.1 Flash — 1, V4.1 — 2, V4.1 Vector — 4, V4.1 Pro — 10,
V4.1 Pro Vector — 12; удаление фона, векторизация, чёткий апскейл — по 1;
Enhance — 10. Страница сильнее снимка. Остаток — только из `get_user`.

## Как писать промпт

Правила — из руководства Recraft
(`https://www.recraft.ai/docs/prompt-engineering-guide/prompting-with-recraft-v4.md`).
Recraft подчёркивает: качество даёт не набор волшебных слов, а ясная
структура — что изображено, как скомпоновано, в какой технике и с какими
свойствами поверхности.

### Длина задаёт режим

- **Короткий промпт, 3–6 слов** — режим интерпретации. Модель сама решает
  кадр, свет и стиль. Годится для поиска формы и настроения на дешёвой модели.
- **Структурный промпт** — режим контроля. Модель исполняет заданную систему.
  Нужен, когда картинка должна попасть в конкретную арт-дирекцию.

Структура не делает картинку «лучше» сама по себе. Она делает результат
предсказуемым и повторимым. Слишком мало контекста — результат случаен,
слишком много — модель зажата: давай столько, сколько требует заказ.

### Каркас

Универсальный шаблон Recraft:

```text
[SUBJECT + ACTION], [COMPOSITION], [CONTEXT], [MEDIUM], [STYLE], [VIBE], [ATTRIBUTES: lighting, color, texture, technical details]
```

| Слой | Что задаёт | Пример формулировки |
| --- | --- | --- |
| Subject | главный объект, с него начинается промпт | `mid-century walnut chair beside a tall window` |
| Composition | ракурс, кадрирование, поза, перспектива, доля кадра | `centered, frontal view, filling one-third of the frame` |
| Context | среда, фон, обстановка — ровно столько, сколько нужно | `plain warm-grey studio background` |
| Medium | техника: фото, акварель, 3D-рендер, плоский вектор | `professional product photograph` |
| Style | традиция или жанр: Bauhaus, editorial, isometric | `minimal Scandinavian editorial style` |
| Vibe | эмоция одним-двумя ясными словами | `calm, contemplative mood` |
| Attributes | свет, палитра, фактура, материалы, типографика | `soft window light from the left, muted earth palette` |

Что раньше в промпте, то сильнее. «Сцена → стиль → детали» ставит содержание
выше эстетики, «стиль → сцена → детали» — наоборот.

Пиши конкретно и проверяемо: `soft diffused window light from the left`
вместо `stunning lighting`. Нагромождение оценок вроде `epic, breathtaking`
точности не добавляет. Точные числа уместны, когда описывают видимое:
`exactly four characters`, `3 × 2 grid`, `filling one-third of the frame`,
`85mm lens at f/2.8`.

Промпт самодостаточен: модель не видела чата. Без «как выше», причин выбора
и инструкций агенту. Пиши по-английски; надпись — в кавычках на том языке,
на котором она должна появиться.

### Порядок слоёв по жанру

| Жанр | Порядок слоёв | Логика Recraft |
| --- | --- | --- |
| фото, портрет, предмет | субъект и сцена → фон → поза и кадр → внешность, материалы → второстепенные объекты и их места → направление и поведение света → камера, глубина, контраст → настроение | свет → материал → кадр → простой фон |
| логотип, иконка, набор | тип графики → логика формы: геометрия, симметрия, силуэт → строгая палитра → дисциплина линии → раскладка: центр, сетка → запреты: `no gradients, no shadows, no texture` | силуэт → ясность формы → единая система; без слов о фактуре и материале |
| постер, обложка | формат → фон, слой A → графика, слой B → иерархия шрифта: что крупнее всего → места текста → контраст слоёв → общая механика | сначала слои, затем их взаимодействие; сетка → поля → соотношение размеров текста |
| иллюстрация | манера рисунка → персонаж и поза → поведение линии → логика цвета → поверхность: flat, зерно, акварель → объём → эмоциональный тон | задаёшь логику рисунка, а не камеры |
| 3D | тип рендера → форма и пропорции → материалы: matte, gloss → среда → свет → ракурс и глубина → цвет | описан только объект — результат случаен; описана физическая система — управляем |
| меню, упаковка, вывеска | формат → главный заголовок: размер и место → вторичная иерархия → цветовые блоки → поверхность печати → раскладка → читаемость → весь текст в кавычках | задаёшь типографскую систему, а не одну фразу |
| брендинг | геометрия → иерархия → интервалы → масштабируемость → ограничения | — |

### Набор и вектор

Для набора пиши `exactly N` и перечисляй каждый элемент. Задай общую систему:
толщину линии, скругления, сетку, палитру, одинаковые детали вроде глаз
персонажей и их места.

Вектор отвечает на структуру и геометрию. Опиши силуэт, ровные заливки и
строгую палитру; слова о фактуре и материале уводят от вектора. Нативный SVG
сохраняй как SVG.

### Текст на картинке

Каждую видимую строку пиши дословно в кавычках: так Recraft точно ставит её
в раскладку. Опиши иерархию: что крупнее всего, где стоит, каким шрифтом
(`oversized heavy condensed sans-serif`). Требуй читаемость:
`large, fully legible typography, no micro text`.

### Правка готового изображения

Сначала назови, что сохранить: форму, позу, композицию, камеру, товар. Затем —
только изменяемое и желаемый итог. Сила изменения — параметр инструмента, не
слова промпта.

### Если результат не тот

Советы Recraft:

- модель не понимает промпт — смени узкий стиль на общий: базовые стили даёт
  `list_basic_styles`;
- лица и руки искажены — творческий апскейл (платно, с вопросом).

### Примеры

Набор векторных иконок:

```text
Set of exactly four flat vector app icons for a crypto wallet: a shield, a lightning bolt, a stacked coin, a padlock. Arranged in a 2 × 2 grid, each icon one bold rounded silhouette centered on its own square tile with even gutters. Shared system: uniform medium stroke weight, identical corner rounding, equal optical size and visual weight. Strict two-color palette: deep navy shapes on warm off-white tiles. Flat fills only, no gradients, no shadows, no texture, no text.
```

Предметное фото:

```text
Ceramic pour-over coffee dripper in matte sand glaze on a pale oak counter, three-quarter view from slightly above, the dripper filling about two-thirds of the frame. Plain warm-grey plaster wall behind, out of focus. Professional product photograph, quiet Scandinavian editorial style, calm tactile mood. Soft diffused morning light from the left, gentle shadow falling to the right, fine glaze texture visible, shallow depth of field with the front rim in sharp focus.
```

### Перед платным вызовом

- Начало промпта — главный субъект; требования не спорят.
- Количество, текст и палитра заданы точно, если они важны.
- Пропорции заданы параметром размера и подходят месту использования.
- Длина промпта в лимите модели: V4.x — 10 000 знаков, V3 и V2 — 1 000.
- Модель и инструмент есть в живой схеме.
- Один результат, если владелец не просил больше.

## Когда результат пришёл

1. Сразу сохрани результат:

   ```bash
   python3 ~/.claude/skills/1recraft/scripts/save_generation.py \
     --dest-dir "<рабочая папка>/images" \
     --name "<смысловое-имя>" \
     --source "<URL или путь>" \
     --prompt "<точный отправленный промпт>"
   ```

   Рабочая папка — папка работы, которой служит картинка; её находит или
   заводит `1work-artifacts`. Несколько результатов — повтори `--source`.
   Скрипт кладёт `<имя>.png` или `.svg` и рядом `<имя>.md` только с промптом.
   Для операции без промпта сохрани точную просьбу владельца.
2. Открой сохранённый PNG через Read и сверь с заказом. Промах назови и
   предложи правку промпта: повтор — новое списание.
3. Один раз вызови `get_user` и закончи строкой `Осталось N кредитов Recraft.`
   Не считай остаток по прайсу.
4. Дай ссылку на файл, инструмент, модель и потраченные кредиты: их число
   приходит в ответе генерации.
