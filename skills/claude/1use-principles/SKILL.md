# Применение принципов

Принципы закрывают развилки без владельца — но только если применены как
матрица, а не как настроение. Экстраполяция — додумка с множеством возможных
решений: самый громкий принцип даёт очевидный вывод, который тихий принцип из
другой темы переворачивает. Эталон владельца — в
[compile](references/compile.md).

## Цель

На руках — решение или чистовая запись под принципами и целью, со следом:
варианты · применённые принципы цитатами · контрпринципная проверка · вывод.

Не входит: создание и правка принципов и цели · развилки, которые они не
покрывают (честная эскалация) · черновая работа.

## Критерии успеха

- Варианты названы **до** первой цитаты принципа.
- Релевантные принципы процитированы, не пересказаны.
- Для каждого названо, что он означает именно для этого решения.
- Контрпринципная проверка имеет след: названный контрпринцип **или** «осей
  против нет» с перечнем просмотренных файлов — голое «противников нет» не
  считается.
- Конфликт разрешён тайбрейкером GOAL или «специальный бьёт общий» — либо
  эскалирован раскладом. Усреднение запрещено как операция.
- След остался в работе или плане.

## Инварианты

- Однопринципный вывод запрещён: следствие проверяется против полного
  релевантного набора — другой принцип может его перевернуть, и прямая
  экстраполяция самого громкого выглядит послушанием, давая противоположное
  воле владельца.
- Релевантность принципа определяется его **последствиями** для вариантов, не
  словарным сходством с задачей: переворачивающий принцип живёт в другой теме.
- Экстраполяция — расклад, не приговор: принципы тянут в разные стороны и
  тайбрейкер молчит → эскалация с раскладом, не уверенный выбор удобного.
- Автономно закрываются обратимые микрорешения; труднообратимое или
  формообразующее — расклад владельцу даже при полном согласии принципов.
- Компиляция временная: канон не переписывается.
- Повторяющийся класс молчания принципов — дыра в принципах: сигнал
  `1product-shaping`, не поток эскалаций.
- Применение без следа неотличимо от неприменения — и не считается.

## Дельта

- Решает из жанрового дефолта **до** чтения принципов, потом цитирует
  поддерживающее: принципы становятся декорацией, след идеален.
- Ищет принципы по словам задачи — и пропускает переворачивающий из другой
  темы.
- Останавливается на первом подходящем; свип не завершён.
- Конфликт принципов сплющивает в компромисс-середину.

## Известные сбои

`когда → сбой → цена → куда`

- решение принято до чтения → принципы цитируются под готовый ответ →
  уверенно-неверное решение с идеальным следом → тело, шаги 1–2
- поиск по словам задачи → контрпринцип из другой темы не найден → «Индия
  отменена» против воли владельца → [compile](references/compile.md)
- громкий короткий принцип → тихий специфичный проигран → mood вместо правила
  → [compile](references/compile.md)
- два принципа тянут в стороны → выбрана середина → воля владельца усреднена в
  кашу → [compile](references/compile.md)
- «противников нет» без перечня просмотренного → театр следа → лазейка
  рационализации → тело, критерии

## Механика

Порядок жёсткий: перестановка ломает результат — варианты до оценки, свип до
вывода, обратный проход до следа.

1. **Назови, что решается** — одной строкой, до открытия принципов.
2. **Перечисли варианты** — минимум два реальных; свой любимый — один из.
3. **Свип осей по последствиям**: заголовки всех файлов принципов +
   тайбрейкеры GOAL; вопрос к каждой оси — «касается ли она любого из
   вариантов?». Ни одна не задета → строка «оси не задеты, смотрел X, Y» — и
   работай дальше без остальных шагов.
4. **Мини-матрица**: каждый релевантный принцип × каждый вариант — «P-X → для
   A значит…, для B…»; абстрактное слово принципа специфицируй под случай.
5. **Обратный проход** по лидирующему варианту: какой принцип мог бы его
   перевернуть? След обязателен.
6. **Разреши конфликт**: тайбрейкер GOAL → специальный бьёт общий → иначе
   расклад владельцу.
7. **След** — решение + 2–3 строки матрицы, в работе или плане.

## Завершение

След есть и содержит контрпринципную проверку · конфликт разрешён или
эскалирован раскладом · молчание принципов оформлено явно (допущение или
вопрос) · канон не переписан.
