# Продуктовая правда

Владелец не видит разрыва между своей головой и твоим пониманием — по
определению. Ты не видишь развилок — правдоподобной выглядит одна трактовка.
Сверка переносит работу туда, где каждый силён: ты читаешь всё,
пересказываешь и признаёшься; владелец коротко правит и подписывает. Его
ответы становятся принципами, по которым развилки решаются без него.

## Цель

На руках — пара `Product Principles` + `Product Frame` своего scope,
привязанная к цели проекта: владелец подписал сцену, его ответы записаны
дословно с областью действия, следующая сессия решает закрытые развилки без
него. Мера — длина автономного участка до первой эскалации или первого дрейфа.

Не входит: применение пары в работе (`1use-principles`) · сама цель (`1goal`)
· планы (`1planning`) · спеки и тесты — отсюда их критерии, сами они живут в
репо · решение за владельца.

## Критерии успеха

- До первого продуктового суждения прочитаны целиком все Frame + Principles
  продукта и `_ops/GOAL.md`; след — в сверке названы применённые и отклонённые
  пары. Заголовки, snippets и память чтением не считаются.
- Владелец узнал замысел в пересказе и подписал сцену; confirmation map
  закрыт: каждый claim — подтверждён · исправлен · unresolved. Молчание не
  подпись.
- Каждый заданный вопрос назвал класс решений, который его ответ схлопывает.
- Каждый дефолт предъявлен до работы; необратимая развилка, не разрешённая
  живыми документами, не задефолчена — запрошено решение или заглушка.
- Привязка Frame к цели несёт запрет: «служит X → из-за цели не делаем Y».
  Без названного запрета привязка не засчитана.
- Конфликт просьбы или пары с целью показан с двумя выходами: править пару
  или звать `1goal` менять цель — цель тоже эволюционирует.
- Прогон: чистая сессия по одной только паре решает уже закрытую развилку —
  выбранную без словарного пересечения с текстом пары — без вопроса владельцу.

## Инварианты

- Ответ владельца — дословно либо deletion-only: пересказ без пометки завтра
  станет «владелец сказал».
- Строка Frame без provenance (ответ владельца или `P-*`) не пишется:
  неполный Frame честнее правдоподобного. Пометка «дефолт агента» authority
  не создаёт.
- Тайбрейкер порождается только commitment `decision` (или разрешённым
  `bounded experiment`) и обязан решать конфликты: назови развилку, которую
  он решает, и развилку, которую нет. Второй нет — это лозунг, не правило.
- Reach («Влияет на», «Снимает») — проверяемый вывод агента, не слова
  владельца; во Frame не переносится.
- Смена ответа — новый `P-*`, прежний помечен «вытеснен»; история не
  переписывается.
- Конфликт двух верных принципов, требующий жертвы (жертва = ход нарушает
  наблюдаемое требование одного из них), — материал минимальной сверки сразу,
  не после «нескольких эскалаций»: такой ответ переиспользуем по определению.
- Пара создаётся только для scope с возвратом в нескольких сессиях; одна
  обратимая развилка пары не заслуживает.
- Ни одной записи в файл до «да» владельца.

## Дельта

Пересказывать и спрашивать модель умеет. Она не умеет:

- породить вторую трактовку: правдоподобной выглядит одна, и развилка не
  рождается вовсе;
- удержаться от статистического разрешения развилки — типовое выглядит как
  ответ владельца;
- показать разумный дефолт заранее: разумность и есть форма, в которой
  приходит дрейф;
- свернуть десять мелких вопросов к одному корню и задать его на языке
  пользователя;
- сохранить добычу сверки: ответ сглаживается в правило без области
  действия, и закрытое эскалируется снова.

## Известные сбои

`когда → сбой → цена → куда`

- пересказ собран → отрицания утверждений не прочитаны → развилку решила
  статистика → [interview](references/interview.md)
- просьба владельца содержит способ → закреплена фича вместо цели → строим
  не тот продукт → [interview](references/interview.md)
- вопросы готовы → дежурная анкета: ответ ничего не схлопывает → внимание
  владельца сожжено → [interview](references/interview.md)
- ответы получены → сглажены в правило без области действия → закрытое
  эскалируется снова → [pair-format](references/pair-format.md)
- Frame собирается → правдоподобная строка без provenance → дрейф с печатью
  владельца → [pair-format](references/pair-format.md)
- привязка к цели → лозунг без запрета → ритуал вместо ограничения →
  [pair-format](references/pair-format.md)
- первая полная сверка → жанр анкеты вместо метода → час владельца впустую →
  [full-walkthrough](references/full-walkthrough.md) — вымышлен: бери
  операции и порядок, не факты
- нужен второй пример механизма → изобретение с нуля →
  [examples](references/examples.md)

## Механика

Жёстких перехода три:

1. **Чтение до суждения.** Все Frame + Principles продукта и `_ops/GOAL.md`
   прочитаны целиком до пересказа, дефолтов и вопросов: принцип соседнего
   scope меняет границу задачи. Существующая пара уже разрешает вопрос —
   форма «только чтение»: применяй и работай, владельца не дёргай.
2. **Дефолты до формы.** Разбор опасных дефолтов и переворот пересказа
   предъявлены вместе со сценой, не припомнены после: припомненный разбор
   защищает уже выбранное.
3. **«Да» до записи.**

Порядок по умолчанию: форма (полная · минимальная — одна сцена-пересказ на
подпись · только чтение) → поиск разрывов; прежние слова владельца по теме
развилки — точечным запросом `1chat-recall` через его скрипт, не общим
поиском: вопрос, уже закрытый его прежними словами, не задаётся, а цитата
идёт в `P-*` как источник → акт 1: сцена с выводимой проверкой · понятно ·
двусмысленно · опасные развилки с дефолтами → акт 2: вопросы с тестом
заслуженности, потолок десять, + аппетит (бюджет · жертвы · событие
пересмотра) → одна форма, один заход → confirmation map → запись: сначала
Principles (блок `P-*`: вопрос · дословный ответ · commitment · влияет-на ·
снимает · источник · пересмотреть-если; шаблон — pair-format), затем
пересборка Frame (цель-сцена · привязка к GOAL · тайбрейкеры ≤10 · аппетит)
→ карта устаревшего: «<артефакт> противоречит <P-*/сцене> → <что сделать>»;
обратимое в разрешённой тебе зоне чини сам → прогон.

## Завершение

Владелец подписал сцену; пара записана и привязана к цели; карта устаревшего
выдана; unresolved-claims названы списком — молчание не подпись.

Сдача: пара + какие развилки теперь закрыты без владельца + чем проверено +
что осталось gap. Не вошедшее — в `cut.md` строкой с причиной.
