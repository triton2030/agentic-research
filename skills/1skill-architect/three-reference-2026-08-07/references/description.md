# Кнопка запуска

Тело недоступно модели до срабатывания: description — единственная поверхность
запуска, и скил с плохим description не существует, каким бы ни было тело. Всё
«когда использовать» живёт только здесь; тело description не дублирует и не
пересказывает — это указатель, не выжимка.

Формула: наблюдаемый момент × ставка.

- Момент — то, что агент видит прямо сейчас: фраза пользователя, действие,
  файл, путь. Абстрактная тема («работа с качеством») слабее наблюдаемого
  момента («просят сократить текст»).
- Ставка — правдоподобный провал без скила: причина потратить контекст на
  открытие тела.

Пиши чуть настойчиво: естественная ошибка моделей — недодёргивать скилы, а не
передёргивать. Перечисли конкретные фразы и случаи, включая «даже если
пользователь не назвал X». Русские разговорные триггеры первичны; английские
хэндлы — для технического жаргона.

Скил поднимается только на нетривиальные задачи: «прочитай этот файл» не
дёрнет его при любом description — не трать бюджет на одношаговые случаи.

Cut test: убери фразу — если выбор скила против живых соседей не изменился,
фраза лишняя.
