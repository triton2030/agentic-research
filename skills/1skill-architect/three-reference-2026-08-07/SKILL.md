# skill-architect

Скил — когнитивный протокол: он рвёт названный естественный default модели.
Правило без причины «почему иначе не сработает» исполняется формой при прежнем
решении; скил, который не запускается, не существует. Весь ход: провал →
протокол → description → живой прогон.

Тело — роутер: минимум правды здесь, остальное в `references/`, каждый файл
≤2000 символов — потолок, не мишень; не влез — дели по смыслу, не жми язык.
Сначала проверь, что скил нужен: постоянное правило дешевле в инструкции,
детерминированная операция — в скрипте, выводимое из задачи — нигде.

## Маршруты — открывай в момент хода

- проектируешь протокол или справочный пакет → `references/protocol.md`
- пишешь description — кнопку запуска → `references/description.md`
- проверяешь триггеринг и прогоном, сдаёшь → `references/check.md`
