# 1skill-architect — невозвратные потери при сжатии

Ранжировка перед прогоном через `1lossy-product-refactor` v2 (сессия
2026-08-07, разбор по живой роутер-форме E10 + сверка с хендофом
`2026-08-07-132240`). Роль файла: контрольный список для таблицы потерь при
сдаче — потеря любого пункта топ-5 означает потерю ядра скила, а не деталь.

## Топ-5 — терять нельзя

1. **Причинная цепочка необходимости (6 звеньев).** Природный default → почему
   привлекателен → trigger-specific вред → невидимость провала → операция,
   рвущая цепочку → перенос на непоказанные случаи. Идея-ядро: правило не
   меняет поведение, пока модель не видит, какой свой default оно рвёт; иначе
   исполняется форма при прежнем решении. Источник: `necessity.md`, `why.md`.

2. **От провала, не от поверхности.** Сначала trace без скила и deficit одной
   фразой; нет показуемого провала — скил строится из вкуса автора.
   Surface-first design — именованный провал: формат диктует объяснение
   проблемы. Задаёт порядок хода: провал → необходимость → механизм → примеры
   → поверхность → description → evidence. Источник: `trace.md`.

3. **Интроспективный императив → наблюдаемая проверка.** «Осознай / не забудь»
   переводится в операцию над текстом или артефактом («процитируй строку»,
   «назови источник»). Полевая статистика владельца: правило без
   предъявляемого следа соблюдается в единицах процентов. Источник:
   `levers.md` (proxy translation), `failures.md`.

4. **Causal cell + form congruence.** Единица когнитивного письма: operator +
   почему default обойдёт голую команду + граница/anti-example. Operator без
   причины — необязательная церемония. Сам текст скила обязан исполнять свой
   метод: latent genre конкурирует с явным правилом дозозависимо. Оплаченная
   переработка владельца 2026-08-04. Источник: `demos.md`, `core-contract.md`.

5. **Proof Gate + Delta-only.** Перед полным механизмом — минимальный
   comparator (одно правило / вопрос / дельта ближайшего owner-а) и точный
   случай trace, который он не закрывает; не назвал — остановись на нём. В
   скил входит только Delta, которую модель не выведет сама; delete-first.
   Тормоз против разрастания в checklist. Источник: `necessity.md`,
   `core-contract.md`.

## Второй эшелон — сжимается в канонические имена

- **Evidence = изменившееся решение, не послушание**: bypass-прогноз до
  прогона (иначе elastic defense), matched resampling, ablation механизма.
- **Discovery = condition × stake**: description — указатель «наблюдаемый
  момент × ставка», не выжимка; hot zone, cut test.
- **Каталог 14 именованных провалов** (`failures.md`) — идеален для
  схлопывания процедур в имена.
- **Два класса** (cognitive shaper / operational package) и запрет гнать оба
  через один шаблон.
- **Пять рычагов** (proxy translation, objective rebasing, phase separation,
  commitment anchor, labor inversion) — брать только против конкретного
  causal failure.
