# Карта провалов

Не checklist. Для сигнала заполни `When → failure → cost → operator/source →
evidence`.

- Нет owner-signal → invented failure → ложный skill. Нужны owner correction,
  повторный trace либо knowledge/tool gap.
- Surface-first → формат оправдывает себя → второй owner. Начни с failure и
  comparator.
- Capability-description → under/over-trigger. Нужны момент, stake, near-miss.
- Access/read → assumed use → прежнее решение. В точке действия потребуй
  task-local source, probe, conflict rule или tool output.
- Vague adjective/MUST → checklist theatre. Дай operator + stop + boundary.
- Outcome-task → универсальный SOP → хрупкость. Оставь критерии; порядок — лишь
  когда его нарушение воспроизводит вред.
- Long horizon → потерян редкий anchor → поздняя ошибка. Верни pointer/generated
  check в точку решения, не второго owner.
- Гладкий финал → proxy = Done → self-stop. Проверь внешний acceptance и каждый
  applicable MUST.
- Compression → исчезла причина/ветка → сломан transfer. Удаляй по одному
  смыслу и повторяй evidence; reference без route не считается.
- Failed run → post-hoc story → elastic defense. До прогона запиши bypass и
  revision criterion; новый диагноз reopen-ит механизм.
- Undated model claim → временный deficit стал вечным. Для GPT-5.6/Opus 5/Fable
  5 фиксируй дату; target-set change требует revalidation.

Form congruence: skill исполняет свой controller; latent genre длинного текста
может перевесить поздний запрет.
