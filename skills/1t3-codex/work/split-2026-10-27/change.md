# Разделение T3 для Codex и Claude

Стадия: проверено и установлено в Codex.

## Заказ

После снятия `1claude-mcp` владелец просит исправить версию T3 для Codex,
сделать её отличной от Claude и назвать `1t3-codex`.
Нужный результат: Codex находит правила вызова Claude через T3,
а обновление его пакета не меняет `1t3` у Claude.

Граница: новый runtime owner, перенос применимого знания о Claude,
четыре зависимых указателя, реестр владельцев и доставка в Codex.
MCP-конфигурация и поведение остальных моделей не меняются.

## Проверка

До правки общий T3 прошёл `sync_simple_projections.py 1t3 --check`, exit 0.
Четыре изменяемых указателя Codex совпадали с установленными файлами.
Свежий агент подготовил действия по шести случаям — [probe.md](probe.md).
Три независимые роли `gpt-6.1-sol`, effort `high`, без истории автора:

- `review_intent`: материальных замечаний по смыслу и сохранению намерения нет.
- `review_instructions`: материальных замечаний по необходимости и потерям нет.
- `review_trajectory`: материальных замечаний по указателям и применению нет;
  самостоятельно сверены каталог, схема T3 и [12 файлов кандидата](candidate-sha256.json).

`quick_validate.py` вернул `Skill is valid!`, exit 0.
Внутренние Markdown-ссылки существуют. Установленный `1t3-codex` и четыре
обновлённых файла потребителей совпали с tracked owner.
`sync_simple_projections.py 1t3 1t3-codex --check` завершился с exit 0:
у `1t3` только Claude owner, у `1t3-codex` только Codex owner.
Установленные `1t3`, `1fresh-eyes`, `1orchestration` у Claude сохранили
состав и SHA-256. Общая рамка `1fresh-eyes` в репо изменена только в строке
о маршруте Codex; установленный пакет Claude не затронут.

Из Codex убран прежний `1t3`; его состав и байты сохранены в
[`versions/live-before-rename-2026-10-27`](../../versions/live-before-rename-2026-10-27/).
Поиск по действующим скилам Codex и корневой инструкции не нашёл ссылок
на `1claude-mcp` или старый путь Codex `1t3`.

Реальный запуск Claude новой редакцией не проверен: подтверждены выбор
параметров, доступность каталога и доставка. Старые ограничения моста
не объявлены возможностями T3; инструкции clean launch сохранены в архиве.
