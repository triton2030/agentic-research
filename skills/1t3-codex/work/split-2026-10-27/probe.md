# Проба выбора маршрута · 2026-10-27

Свежий native-агент `route_probe`, `gpt-6.1-sol`, effort `high`, без истории
автора. Ему даны путь кандидата, шесть независимых ситуаций и запрет запускать
модели, треды или менять файлы. Проверяется подготовленное действие,
а не успешность выполнения Claude. После первоначального capacity error
тот же агент завершил пробу.

## Вход и полученный результат

| Ситуация из поручения | Наблюдаемый ответ агента |
| --- | --- |
| Независимое второе мнение о коротком документе, модель не названа | Новый тред; `claudeAgent`, `claude-opus-5-5`, `effort: high`; исходный вопрос и файл без оценки вызывающего |
| Claude должен проверить diff серверного кода | Новый тред; тот же provider/model, `effort: max`; read-only auditor |
| Явно назван Fable для неоднозначной стратегии | Новый тред; `claudeAgent`, `claude-fable-5-1`, `effort: medium` |
| Новый факт для того же Claude, чей T3 threadId сохранён | Продолжить сохранённый `threadId`; provider/model сначала прочитать, не выдумывать; send/ожидание по T3 |
| Чистый Claude без личных instructions/hooks/skills | До launch назвать несовместимость: T3 грузит setup, выключателя нет; не обещать изоляцию |
| Среда допускает только gpt-6.1-sol, модель второго мнения не названа | `codex`, `gpt-6.1-sol`, `reasoningEffort: medium`; честно отличить отдельное окно от другой модельной семьи |

Для новых тредов агент подготовил `t3_thread_wait` с `timeoutMs: 55000`,
затем чтение с пагинацией; для долгого хода — watcher и `write_stdin`.
Отличил завершённый ход от проверки результата и модель в метаданных от
самоназвания модели в прозе. Запуски не выполнялись.

## Отдельные проверки автора

- Live `orchestrator_capabilities(search="claude")`: нужные модели и `effort`
  доступны в каталоге; сохранено в [capabilities.json](capabilities.json).
- `python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py skills/codex/1t3-codex`:
  `Skill is valid!`, exit 0.
- Внутренние Markdown-ссылки кандидата существуют; exit 0.
- Сборщик видит только Claude owner для `1t3` и только Codex owner для
  `1t3-codex`. Скрипты и справка медиа совпали с исходником побайтно.
- Хеши установленных пакетов Claude и tracked `1t3` совпали с baseline.

Это проверяет доступность маршрута, выбор параметров и отсутствие переноса
bridge-ограничений на T3. Реальный запуск Claude новой редакцией не проверен;
неизменённый T3-путь опирается на датированную пробу 2026-10-19 в справке.
