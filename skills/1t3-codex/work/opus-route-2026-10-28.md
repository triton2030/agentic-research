# Opus из Codex только через T3

Стадия: проверено и установлено в Codex.

Адресная правка к `ad9e65efb59b0f3a77cb504f45f9396baa523133`.
Источник — [слова владельца](../../../_ops/chat-recall/2026-10-27-114447-codex-01a17c18.md#recall-5d429bdc5fd24536877b73ace01e8d51).

Контекст: после снятия `1claude-mcp` его инструменты всё ещё доступны.
В `1t3-codex` оставался пример запуска Opus через Google-скрипт.
В реестре памяти поиск `1claude-mcp|claude.mcp|claude_ask|opus|опус|t3`
совпадений не дал; причина возможного неверного вызова не установлена.

Задача: закрепить единственный маршрут Opus из Codex в существующем
владельце выбора Claude и убрать противоречащий пример.
Цель: запуск Opus остаётся видимым владельцу в T3, в том числе когда
другой доступный транспорт выглядит удобнее.
Критерий: недоступность T3 не разрешает переключиться на прямой мост,
CLI или Google-скрипт. Проверяется выбор маршрута при таком отказе.

Карта потерь: правило добавлено в `references/claude.md` до выбора модели;
Google-пример Opus заменён на сохраняемый Sonnet, из справки wrapper есть
ссылка на правило. Скрипты, параметры моделей, остальные модели и пакет
Claude не меняются. Отказ от прямого запуска Opus задан текущим словом
владельца; отдельный технический запрет в коде не добавляется.

Применимый контракт: `1skill-creation` — адресная правка, проверка смысла,
необходимости и применения; `1agent-steering` — правило рядом с выбором
и доступность инструментов как отдельное от выбора маршрута свойство.

## Проверка и доставка

Три свежих проверяющих `gpt-6.1-sol`: смысл — medium, необходимость — medium,
применение — high. Существенных находок нет. До авторской записки третий
агент прочитал кандидат и подготовил следующие действия:

| Вход офлайн-пробы | Выбранное действие |
| --- | --- |
| Запрос Opus на проверку документа, T3 и `claude_ask` доступны | Найти проект; `t3_thread_launch`, `claudeAgent`, `claude-opus-5-5`, effort `high` |
| T3 connection refused, прямой MCP доступен | Проверить подключение; при сохранении отказа сообщить блокер |
| T3 недоступен, Google Claude quota свободна | Сохранить блокер, не запускать Opus через скрипт |
| Явный запрос Sonnet на Google | `agy models`, затем wrapper с возвращённым Sonnet ID |

Это симуляция действий, не запуск модели и не проверка сети.
`quick_validate.py`, `git diff --check` и доставка
`sync_simple_projections.py 1t3-codex --write --install` завершились с exit 0.
Установленный пакет совпал с владельцем; установщик пропустил Claude:
`owner отсутствует`. Скрипты пакета не изменены.

Финальные тексты: [тело](../../codex/1t3-codex/SKILL.md),
[маршрут Claude](../../codex/1t3-codex/references/claude.md),
[справка wrapper](../../codex/1t3-codex/references/gemini-media.md).
