# Проверяемые случаи запуска

| Вход | Ожидаемое применение |
| --- | --- |
| «1interview-tool: проверь эту главу, здесь два решения» | Прямой вызов; допустимы два вопроса |
| «Перепиши скил 1interview-tool» | Авторинг скилла; не создавать интервью вместо правки |
| Работа по документации обнаружила пять существенных вопросов владельцу | Автоматический вызов ещё не допускается |
| Работа по документации обнаружила шесть независимых существенных вопросов владельцу | Допускается автоматический вызов |
| Было шесть; при исследовании три получили ответы | Не добивать форму до шести, полезные закрытые — в конец |
| Другой скил делегировал один вопрос | Само делегирование не обходит порог |
| «1interview-tool»; все обнаруженные неясности оказались временной недоступностью картинки | Не создавать пустое интервью; объяснить в чате |

Это ожидаемые критерии, не результаты прогона.
