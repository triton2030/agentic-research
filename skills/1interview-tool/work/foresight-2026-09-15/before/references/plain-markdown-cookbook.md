# Plain Markdown cookbook

Момент: карта вопросов допущена и нужно собрать форму. Файл владеет
разметкой; отбором вопросов и lifecycle владеет `SKILL.md`.

Каждый вопрос — отдельный H3-заголовок `### <N>. <вопрос>`; не прячь вопрос
в абзаце, жирной строке или пункте списка. Поле ответа — H4-заголовок
`#### Ответ пользователя — <уникальная метка>`; метка уникальна в форме.

## Общий каркас

```md
# Интервью: <тема>

Отвечайте прямо в файле: отмечайте варианты и заменяйте строки
«Напишите ответ здесь». В конце отметьте «Готово к проверке» или напишите
в чате «проверь».

<details>
<summary>Для агента — контракт результата</summary>

- Разблокирует: <решение или действие>
- Итог: <тип результата> → <owner/path>
- Достаточно, когда: <критерий>
- Уже проверено, поэтому не спрашиваем:
  - <факт или снятый кандидат> → <owner/source либо куда ушёл>
- Карта ответов:
  - <уникальная метка вопроса> → <owner/path#claim или решение caller-а>
    - Если угадать неверно: <материальное последствие>

</details>

---

## Вопросы
```

## Блок вопроса — базовая форма

Варианты должны различаться последствиями, а не формулировками; нет честного
выбора — сними чекбоксы и оставь свободный ответ.

```md
### <N>. <вопрос>

<Что это решение изменит в результате.>

**Моя рекомендация:** <ход и основание>.

- [ ] <вариант A> — <отличающее последствие>
- [ ] <вариант B> — <отличающее последствие>
- [ ] Другое — опишите ниже

<details>
<summary>Для агента</summary>

- Адрес ответа: <owner/path#claim или решение caller-а>
- Если ошибиться: <материальное последствие>

</details>

#### Ответ пользователя — <уникальная метка>

_Напишите ответ здесь, заменив эту строку._

---
```

Дельты от базовой формы:

| Вид вопроса | Отличие |
| --- | --- |
| Свободный ответ | чекбоксы сняты, остаётся поле ответа |
| Несколько вариантов | та же форма + строка `Отметьте всё подходящее` |
| Решение по элементу | вопрос «Что сделать с «<единица>»?» — о её функции («Функция сейчас: <какое решение или действие она меняет>»), не о происхождении текста; чекбоксы `- [x] Оставить · - [ ] Слить · - [ ] Перенести · - [ ] Удалить`, default отмечен; подсказка в поле ответа: «_Если default неверен, напишите почему и что сделать._» |
| Воротный вопрос | та же форма: один вопрос в маленькой форме со своим каркасом и готовностью; в контракте каркаса `Итог: owner unresolved` |

## Готовность

Каждая форма заканчивается одинаково (гейт согласия — `SKILL.md`, шаг 2):

```md
## Готовность

- [ ] Готово к проверке
```
