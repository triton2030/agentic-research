# Кабинет бронирования мастер-классов

Будущий агент реализует запись, отмену и лист ожидания строго по docs/. В docs/rules.md и docs/screens.md описана одна текущая версия продукта; ни один из этих документов не старше другого. Принятые уточнения владельца в docs/decisions.md дополняют правила. Агент самостоятельно выбирает техническую реализацию, но продуктовые обязательства выбирает владелец.
