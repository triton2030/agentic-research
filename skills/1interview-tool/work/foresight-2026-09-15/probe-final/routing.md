# Действия при новых состояниях работы

| Состояние | Выбранное действие | Основание |
| --- | --- | --- |
| 1. Прямого вызова нет; исследование выявило пять существенных документальных вопросов. | Автоматически не запускать интервью. Продолжить обычную работу с источниками; оставшиеся неопределённости сообщить в чате. | Порог автоматического запуска — больше пяти существенных вопросов. Пять его не достигают. |
| 2. Прямого вызова нет; исследование выявило шесть существенных документальных вопросов. | Запустить скилл автоматически: проверить вопросы по источникам, отобрать требующие решения владельца и сохранить ценные найденные ответы. В обычной работе подготовить интервью по результату этого отбора. | Шесть существенных вопросов дают ясное основание для автоматического запуска. Число вопросов после исследования может уменьшиться. |
| 3. Владелец прямо вызвал скилл для двух вопросов. | Выполнить прямой вызов: исследовать обе развилки и подготовить интервью с оставшимися вопросами и ценными найденными решениями. | Прямой вызов владельца допускает любое число вопросов; порог автоматического запуска к нему не относится. |
| 4. Автоматический вызов начался после шести существенных вопросов; затем четыре ответа найдены в источниках. | Продолжить начатое интервью с двумя оставшимися вопросами, если они по-прежнему требуют решения владельца. Пересмотреть их с учётом найденного. Из четырёх закрытых развилок сохранить в конце только полезные будущему агенту, с вариантами, выбранным ответом, источником, условиями и авторством. | Порог относится к запуску, а не к итоговому количеству вопросов. Дополнять форму до шести не нужно; разрешённые источниками развилки не следует повторно спрашивать у владельца. |

Это выбор действий для заданных состояний. По этому поручению новые формы не создаются. Если в ходе любого разрешённого запуска не останется ни вопросов, ни ценных найденных решений, результат следует сообщить в чате без пустого файла.
