# Правила записи

## Отмена
Участник может отменить подтверждённую запись до начала мастер-класса. При разрешённой отмене возвращается стоимость записи.

## Лист ожидания
Когда место освобождается, его предлагают людям из листа ожидания. Запись в лист ожидания бесплатна.

## Передача записи
Запись именная, на входе сверяют имя участника со списком.
