# Решения владельца

## Сумма возврата — 2026-09-10
«При разрешённой отмене возвращаем всю уплаченную сумму. Комиссию платёжного сервиса берём на себя». Решение принято владельцем, относится ко всем мастер-классам текущего кабинета.

## Вместимость
Мест больше вместимости зала продавать нельзя. Предварительное согласие в листе ожидания ещё не является оплаченной записью.
