# Маршруты стадий

Закрой этот reference с названием одной следующей стадии.

- Новая карта или изменение состава: `опора → композиция → валидация → дашборд`.
- Событие эпика: `состояние → фронтир → валидация → дашборд`.
- Ремонт прибора: `валидация`.
- Ремонт человеческой поверхности: `дашборд`.
- Допуск задачи маршрутизируй в `1planning`, файл задачи — в `1plan-task`.

Файлы стадий: [опора](map-source.md),
[композиция](epic-composition.md), [состояние](epic-state.md),
[фронтир](frontier.md), [валидация](map-validation.md),
[дашборд](dashboard.md).
