# Схема карты, эпика и дашборда

## Задача

Оформи новую карту или изменяемые файлы эпиков и дашборда по общей конвенции.

## Цель

Файлы читаются одной картой: эпики задают границы задач, а представления показывают человеку согласованное состояние и историю.

## Зачем

Obsidian связывает файлы по точным именам, ключам и фильтрам. Готовые заготовки создают эту форму, а схема содержит решения, зависящие от живой работы. Копирование структуры по таблице требует помнить каждое поле и позволяет пропустить его незаметно.

## Файлы из заготовок

- Новый эпик — заполненный [шаблон эпика](../assets/epic-template.md): ключи и разделы уже стоят на своих местах, поэтому форма не сочиняется заново.
- Путь эпика — `_ops/plans/эпики/<Имя эпика>/<Имя эпика>.md`: одинаковое имя папки и файла делает владение задачами видимым.
- Задачи лежат в папке своего эпика; общая папка задач скрыла бы их принадлежность. Их форму задаёт `1plan-task`.
- Для новой карты скопируй содержимое [каталога заготовки](../assets/map/) целиком в `_ops/plans/`: совместимые фильтры, формулы и представления уже записаны в нём.
- Файлы вопросов располагаются в `_ops/plans/вопросы/` с `тип: вопрос`: так их найдёт представление «Открытые вопросы».
- Существующая отличающаяся форма не заменяется попутно; расхождение получает отдельное решение владельца, иначе обновление состояния превращается в миграцию.

## Производные значения

- `health` равен значению последнего `## Апдейты`: иначе поле и история одновременно показывают владельцу разные состояния.
- `задач` обновляет создавший задачу агент тем же ходом: иначе число созданной работы отстаёт от папки.
- `задачи` обновляет создавший задачу агент тем же ходом: иначе новая задача отсутствует в связях эпика.
- `задач-готово` обновляет закрывший задачу агент тем же ходом: иначе доказанный результат не уменьшает показанный остаток.
- `evidence` эпика обновляет закрывший задачу агент тем же ходом: иначе у показанного результата нет проверяемого основания.

## Статусы

✅ готово · 🔨 в работе · ◽ в очереди · 🔒 заблокировано · 🛑 затык · ⏳ отложено

Словарь принадлежит этой схеме, задача зеркалит его: расхождение обозначений ломает общую карту.

- `🔒 заблокировано` означает незакрытую необходимую зависимость; иначе удобный порядок выглядит невозможностью работать.
- `⏳ отложено` означает решение владельца; иначе агент выдаёт собственное бездействие за выбор человека.
- Отложение старше выведенной блокировки: иначе владелец ищет блокер у работы, которую сам отложил.

## Сохранность карты

- Завершённые файлы остаются на своих местах: архивирование убирает их из представлений, а владелец считает видимость сделанного частью ответа «сколько осталось».
- Живая задача вне текущего места последовательности `порядок`/`запуск` показывается конфликтом: иначе карта обещает один порядок, а работа идёт в другом.
