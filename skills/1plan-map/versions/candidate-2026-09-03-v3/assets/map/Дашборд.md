# Карта проекта

Эпики показаны в порядке работы. Завершённые результаты остаются видимыми.
Счётчик эпика показывает закрытые задачи среди уже созданных; следующие задачи
могут появляться позже, поэтому процента готовности эпика здесь нет.
Процент задачи относится к её явному списку подзадач.

Статусы: ✅ готово · 🔨 в работе · ◽ в очереди · 🔒 заблокировано ·
🛑 затык · ⏳ отложено.
