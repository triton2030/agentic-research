# Стадия состояния эпика

## Цель

Одно доказуемое событие меняет только состояние эпика; композиция и файл
задачи сохраняют своих писателей.

## Владение состоянием

- Событие эпика владеет `статус`, `health`, `evidence` и только дополняемыми
  «Апдейтами». `health` и `обновлено` выводятся из последнего апдейта.
- `задач`, `задач-готово` и `задачи` выводятся из файлов задач и пишутся только
  прибором. Статус самой задачи пишет `1plan-task`.
- Обратный `эпик-снимок` пишет ответственный писатель задачи после полного
  чтения эпика, а прибор проверяет его. Если прибор не задал нормализацию,
  снимок включает только поля композиции `описание`, `область`,
  `порядок`, `запуск`, `критерий`, `ранний-индикатор`, `зависит-от` и тело вне
  «Апдейтов». Он исключает поля состояния и производные поля `статус`,
  `health`, `evidence`, `обновлено`, `задач`, `задач-готово` и `задачи`.
