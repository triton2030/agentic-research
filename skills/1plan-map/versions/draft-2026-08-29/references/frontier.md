# Стадия фронтира

## Цель

Только первый запускной эпик, который ещё не готов и не отложен, образует
фронтир последовательного проекта и может иметь живую задачу.

1. Фронтир `◽` без живой задачи вызывает `1planning`. `1plan-task` пишет файл и
   статус задачи; отдельное событие карты переводит только эпик в `🔨`.
2. Эпик вне фронтира содержит лишь закрытые или явно отложенные вместе с ним
   задачи. Другая живая задача блокирует перестановку и валидацию.
