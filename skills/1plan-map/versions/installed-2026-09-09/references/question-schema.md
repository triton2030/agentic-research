# Видимый вопрос владельцу

Вход: ответ владельца меняет допуск или продолжение работы.
Выход: один адресуемый вопрос в `_ops/plans/вопросы/`, видимый в Дашборде.

Файл заполняется из [шаблона](../assets/question-template.md). У задачи поле
`вопрос` ссылается на него; её «Состояние» показывает влияние на следующий ход,
не копию вариантов и ответа. Независимая разрешённая работа продолжается.

Если нерешённый выбор пришёл из `1planning` до допуска, вопрос связывается с
существующим эпиком либо предложением эпика с `допуск: ""`. Это запись уже
выявленной развилки, а не повод снова передавать её в `1planning` или начинать
исполнение. После ответа меняется соответствующий владелец истины.

| Поле | Значение |
| --- | --- |
| `тип` | `вопрос` |
| `статус` | `открыт` или `отвечен` |
| `касается` | однозначный wikilink на эпик или задачу |
| `адресат` | непустая строка: кто принимает решение |
| `срок` | дата ISO либо `""`, когда срока нет |
| `ответ-опора` | адрес ответа владельца; `""` до ответа |
| `обновлено` | дата ISO |

H2 по порядку: «Вопрос», «Влияние», «Варианты», «Ответ». «Влияние» отделяет
зависимую работу от той, которую можно продолжать. «Варианты» содержит
содержательные альтернативы и рекомендацию с основанием. До решения
«Ответ» может быть пустым; после решения он содержит принятый ответ и адрес
его источника.

Ответ не заменяет изменение владельца истины: продуктовый ответ записывает
владелец правды по критерию «Основание не выдумано» тела скила, сдвиг эпика —
`1plan-map`, допуск — `1planning`. После этого состояние задачи и снимок сверяются с новым
основанием; вопрос становится `отвечен`. Старое решение остаётся доступно.
