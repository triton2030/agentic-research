# Restoring meanings

## Protocol

1. Use this as a dedicated session, never as a side effect of ordinary Capture
   or Retrieval.
2. Start only from a completed Retrieval packet for an explicit subject or time
   boundary.
3. For each applicable position, locate the existing plan, documentation,
   specification, instruction, or Product Frame that owns that meaning.
4. Write the meaning in the owner's language and cite the literal record
   address; do not turn agent synthesis into owner speech.
5. When corpus evidence and the live owner disagree, show both addresses rather
   than deciding silently.
6. Exclude one-off assignments and working remarks; do not create a new file
   when an owner exists or a derived summary/profile layer beside the corpus.
7. Report changed owner files with record addresses and every remaining gap.
