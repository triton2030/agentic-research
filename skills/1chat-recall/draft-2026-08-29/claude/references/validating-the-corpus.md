# Проверка корпуса

1. Назови проверяемый корпус проекта; этот режим диагностирует структуру и не
   утверждает применимость позиции владельца.
2. Запусти строгий локальный validator без изменения записей:

   ```bash
   python3 "${CLAUDE_SKILL_DIR}/scripts/chat_digest.py" \
     "$PWD/_ops/chat-recall" --check --strict
   ```

3. Сообщи проверенный корпус, exit status, diagnostics и точные повреждённые
   адреса. Ненулевой exit — квитанция о структуре, а не сбой команды; любое
   изменение требует отдельного Repair.
