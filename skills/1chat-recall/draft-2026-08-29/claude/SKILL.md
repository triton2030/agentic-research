# Память чата

## Цели

- Сохранять в том же ходе самостоятельные слова владельца, способные изменить
  будущее решение, границу, критерий, предпочтение или понимание. Простое
  согласие смысла не несёт; выбор предложенного варианта — несёт.
- Перед существенной работой, которая может зависеть от прежних слов владельца,
  восстанавливать применимую позицию по дословным свидетельствам либо выдавать
  `abstain`.
- После проверяемой квитанции выбранного режима продолжать исходную работу, а
  не считать работу с памятью конечным результатом.

## Уникальный контекст

Корпус хранит датированные свидетельства, а не текущую картину мира. `quote` —
дословные слова владельца, `selection` — выбранный им вариант, `note` — текст
агента, `raw` — повреждённая структура. Поисковая метадата только ведёт к
чтению и не становится словами владельца или текущей правдой. Живое слово и
применимый действующий owner сильнее старой записи. Корпус остаётся локальным:
его содержимое нельзя отправлять в сетевые инструменты.

Момент записи — единственное место, где соседний контекст ещё доступен без
догадок. Поэтому находимость покупается именно там: тема выбирается только
после чтения всей карты существующих границ; `context-note` работает как
короткий индекс из ключевых именных фраз, а `session-context` сохраняет сцену
разговора. Эти поля направляют будущий поиск, но не пересказывают решение.

## Выбери ровно один текущий режим

Полностью прочитай один подходящий reference и заверши его режим, прежде чем
выбирать следующий:

1. Слова владельца могут понадобиться после этого хода либо завершённый Repair
   вернул `capture-needed` → [Capture](references/capture.md).
2. Прежние слова владельца могут повлиять на существенную работу или поздний
   ответ → [Retrieval](references/retrieval.md).
3. Retrieval завершился `recovery-needed`, потому что обычный маршрут не дал
   опоры для решения →
   [восстановление покрытия](references/reading-the-log.md).
4. Эта сессия явно переносит восстановленные смыслы в существующие owner-файлы
   после завершённого Retrieval →
   [восстановление смыслов](references/restoring-meanings.md).
5. Записи нужен ремонт provenance либо владелец просит pre-capture backfill →
   [Repair](references/repairing-the-log.md).
6. Владелец просит проверить структуру корпуса →
   [проверка корпуса](references/validating-the-corpus.md).
