# Решение после Fable

Fable claude-fable-5-1, effort medium, session 98aa1245-8120-4560-925f-1a6fbb1dabeb.
Выбрано: независимый dense для цитат + provenance каждой цитаты + число
лексических совпадений и warning. Причина: gate препятствует смысловому
поиску при нуле лексики, но после одного совпадения dense-only уже проходит.
Значит честная маркировка нужна всему существующему пути, не только новому.

Полное dense-расширение тем отложено: отдельные темы без lexical допуска
могут добавлять шум, а польза сверх независимого dense цитат не измерена.
Для текущих тем исправляется admitted_by по реальному пересечению каналов.
Явный --topic остаётся строгим. Card consensus остаётся прежним и явно
назван в search-mechanics. Модель и пороги не меняются.

Возражение Fable принято: при близком вопросе без ответа in-domain не
доказывает наличие позиции. Даже дословная dense-only выдача — кандидат
до чтения разговора и проверки применимости. Обновляется Retrieval.

Мой план независимых каналов принят в части цитат; расширение тем сужено
по возражению Fable. Согласие не заменяет A/B и негативные проверки.
