## Тройка проверяющих (Sonnet, по указанию владельца)

| Находка | Решение |
| --- | --- |
| Механика описана неверно: при `--supersedes` старая запись уходит из обычной выдачи, при `--contested` уходят обе | Принято: capture.md и retrieval.md называют `--topic … --timeline` и `conflicts`; `--contested` не советуется |
| «Перенеси слова владельца в документ» — добавка автора, делает цитату каналом в канон | Принято: в retrieval.md, рамке и `_ops/chat-recall/AGENTS.md` — находка или вопрос владельцу |
| Нет второй половины смены правила | Принято: «запись — не правило; правило в живом файле меняют его маршрутом» |
| Запрет искать цитаты в обсуждении не перенесён в скил | Принято: строка в «Modes» |
| Причина строгого отбора осталась из прежнего смысла | Принято: лишняя запись искажает картину того, как владелец думает |
| Потеряно «дочитывай вывод до конца» | Принято |
| В description пропало исключение об обновлении документов | Принято |
| Справка `--contested` и `--supersedes-unresolved` хранила прежнюю механику | Принято: справка переписана |
| Авторство `selection` при предъявлении цитаты | Принято: строка в retrieval.md |
| Выкатывать тексты, helper и глобальные файлы вместе | Исполнено одной установкой |
| Снять в Retrieval проверку более поздних разговоров | Отклонено частично: оставлена одна строка — поздний разговор показывает, что владелец передумал; это нужно, чтобы понять его ход мыслей |
