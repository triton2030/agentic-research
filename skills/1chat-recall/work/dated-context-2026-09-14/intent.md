# Датированный контекст — адресная правка

Заказ: улучшить применение найденной истории в `1chat-recall` Claude и Codex.
Текущий разговор и проверенная ситуация определяют применимость прежних слов;
старое найденное не становится новым указанием. Дата должна влиять на оценку
изменений, а не оставаться подписью. Важная локальная поправка сохраняет scope.
Согласованное ранее удаление посредника и улучшение поиска остаются в силе.

Источник — текущая реплика владельца 2026-09-14; значимая дословная выдержка:
`_ops/chat-recall/2026-09-13-191128-codex-01a09b1a.md#L19`. Пользователь просил
ёмкий авторинг по науке, а не перенос всей своей речи в инструкцию.

Граница: тело скила, применение Retrieval, необходимые согласования общей
рамки и глобального маршрута. Capture, schema, scripts, topic/ranking и
свежая кодовая проверка не затронуты. Кодовая консультация Fable и проверки
хранятся в соседнем `search-algorithm-2026-09-14/`.

## Карта сохранности

| Свойство | Решение и проверка |
| --- | --- |
| История как опора нынешнего заказа | Задача называет добычу датированного контекста; цель исключает подмену текущего намерения. Проверяются синтетические случаи. |
| Дата, scope, сила, прямое чтение | Сохранены; оценка изменений со времени высказывания добавлена при выборе цитаты. |
| Явная нынешняя коррекция против старой позиции | Получает приоритет при применении; повторный вопрос о уже решённом расхождении не нужен. |
| Совместимое полезное прошлое | Сохраняется без произвольного срока годности и без отмены несвязанных решений последним сообщением. |
| Существенная неопределённость | Вопрос после учёта текущего разговора и состояния, независимая работа продолжается. |
| Capture, Integrity, CLI, ранжирование | Не изменены, прежние тесты применимы к тем же байтам кода. |

Авторский контракт: `1skill-creation`, refactor/behavior-protocol/check-approve;
`1agent-steering` и steering-science. Контекст объясняет потерю времени реплики;
условие приоритета включается при применении найденного. Нет отдельного
списка критериев, повторяющего этот смысл.

Стадия: рефактор завершён; независимая проверка закрыта, оба runtime установлены.
Итог — [verification.md](verification.md).
