# Датированный контекст — установленная редакция

Уточнены `SKILL.md`, `references/retrieval.md` обоих runtime, общая продуктовая
рамка и глобальные инструкции Claude/Codex. Алгоритм поиска и Capture этой
правкой не менялись. Заказ и [карта сохранности](intent.md) соблюдены.

## Что изменилось

Прошлые слова служат датированным контекстом нынешнего заказа. Текущие слова
по тому же вопросу и проверенное состояние дел определяют применимость
истории. Явное уточнение снимает повторное согласование расхождения с архивом;
совместимое старое пожелание остаётся полезным. Возраст требует оценки
изменений, а не автоматического срока годности. Значимость и scope сохранены.

По steering-science контекст объясняет конкретную потерю времени высказывания;
задача называет добычу контекста, цель — понимание нынешнего заказа. Правило
приоритета действует при применении, оценка даты — при выборе источника.
Новый список дублирующих критериев не добавлен.

## Границы

Проба подтверждает выбранные ответы на данных случаях, не выполнение
редактирования отчёта и не рост надёжности относительно старого текста.
Предварительного атомарного снимка входа нет: файлы сохранены после прогона,
их неизменность до сохранения подтверждена автором по операциям этой сессии.
Отдельного повторного теста продолжения после ответа владельца не было;
этот переход проверен по тексту. Семантический кандидат по-прежнему требует
чтения: близость текста и его возраст не устанавливают нынешнее намерение.
