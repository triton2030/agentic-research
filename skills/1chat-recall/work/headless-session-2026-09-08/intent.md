# Намерение — психолог Claude как отдельная headless-сессия, 2026-09-08

Маршрут: адресная правка раздела «Психолог» Claude-варианта после установки
v6. Источник — предложение другого агента (пересланный отчёт: `SendMessage` в
desktop-приложении вырезан deny-правилом командной строки; контекст переносится
через `claude -p --session-id/--resume`), одобренное владельцем: «Это сказал
другой агент и мне кажется это хорошая идея чтобы исправить наш скил именно
клод версию» — `_ops/chat-recall/2026-09-08-161113-claude-4c325be0.md#L29`.
Текст отчёта — слова агента, не владельца; в корпус не записан.

## Что меняется

- Психолог в Claude — не субагент `Agent`, а отдельная сессия `claude -p` с
  адресом `<uuid>`, назначенным заранее; продолжение — `--resume <uuid>`.
  Адрес живёт в `_ops/chat-recall/psychologist-session.txt` (`<uuid><TAB><дата>`),
  как у Codex-варианта `psychologist-thread.txt`: оба runtime теперь дают
  «одну сессию на проект», к которой обращаются все сессии (`#L20`, `#L22`).
- Аварийный режим «новый Agent с прежними ответами» снят: он терял накопленное
  окно (аудит Codex B3); `SendMessage` и `Agent` убраны из `allowed-tools`.
- Роль передаётся каждым вызовом через `--append-system-prompt`; `Skill` и
  `Agent` запрещены психологу (`--disallowedTools`), чтобы глобальная
  инструкция владельца не увела его в этот же скил за собственным психологом;
  `Edit`, `Write` запрещены — психолог в корпус не пишет; `--permission-mode
  dontAsk` с `--allowedTools Bash,Read,Glob,Grep` даёт запуск `chat_digest.py`
  без интерактивных разрешений; `--model fable` — «умного агента» (`#L20`).
- Контекст роли Claude уравнен с Codex: вопросы из разных сессий, память
  между ними сохраняется; добавлена строка «психолог здесь ты».
- Среда: картина копится между сессиями, пока сессия психолога жива.

## Проверено до черновика (haiku, тестовый корпус /tmp/recall-probe)

- T1: `claude -p … --session-id <uuid> --append-system-prompt <роль>
  --allowedTools Bash,Read,Glob,Grep --disallowedTools Skill,Agent,Edit,Write
  --permission-mode dontAsk --output-format json` — 5 ходов, `chat_digest.py`
  запущен без запросов разрешений, ответ по форме с адресами, `session_id`
  равен назначенному.
- T2: тот же вызов с `--resume <uuid>` и вторым вопросом — 1 ход, без
  повторного чтения, ответ по форме с адресами из первого хода: контекст
  пережил границу процессов внутри сессии, где `SendMessage` вырезан.

## Открыто

- Два одновременных `--resume` одного uuid из разных сессий — поведение не
  проверено.
- Рост сессии психолога между сессиями: auto-compact Claude Code сожмёт
  историю; картина после сжатия — summary, не полное окно.
- Контракт `_ops/chat-recall/AGENTS.md` этого репо при установке получает
  строку про `psychologist-session.txt`.
