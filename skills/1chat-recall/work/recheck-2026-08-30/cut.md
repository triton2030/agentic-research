# Cut — candidate 2026-08-30

Статус: exact candidate; official/tracked/live не меняются до approval.

## Сохранено

- full topic map и полный session holder до Capture, актуальный однострочный
  `session-context` и короткий noun-phrase `context-note`;
- отдельный keyword route по handle/description из единственного `topics.md`;
- полное чтение выбранного holder и не более одного неблокирующего фонового
  Retrieval для важной темы;
- direct-author ownership: user-visible tool-delivered agent message не capture;
- literal evidence, поздние слова/live owner и position/`abstain`;
- retrieval quote cards carry absolute `date` and relative `age`; explicit
  same-scope `supersedes` makes the newer position the decision result while
  timeline keeps chronology;
- decision query не применяет `contested`, undated или `note/raw` как позицию;
- source-bound Repair → обычный Capture с native target/session/timestamp;
- raw/native source неизменны, mutation требует owner authority;
- русский runtime prose, короткий English trigger description.

## Поглощено целью, контекстом и helpers

Payload fields, transaction/format, metadata vocabulary, search syntax, transcript
subcommands, ranking/coverage formulas, повторные receipts и каталоги исключений.
Новый topic создаётся только после полного сравнения карты; прежняя коллизия
«верни gap при отсутствии подходящей темы» снята.

## Снято

Отдельные Recovery/Restoration, direct reference chains, profile/summary surfaces,
optional verifier, mandatory scouts, безусловный `--prepare` и постоянные
transcript-links в corpus. Не возвращены per-topic файлы, derived facts,
reconciliation, manifests/horizons или второй topic owner.

## Residual

Cold hybrid recovery, `capture-needed` и mutation Repair слегка выходят за 20,
потому что держат одновременно доказательство provenance/authority и coordinates
перехода. Их нельзя снять без ложного owner-evidence, неверного target или
необратимой source mutation.
