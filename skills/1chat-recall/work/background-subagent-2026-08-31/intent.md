# Candidate — дешёвый фоновый Retrieval subagent

Статус: `installed 2026-08-31`; owner-пакеты и живые проекции несут эти bytes.

## Новое owner-evidence

- Владелец потребовал, чтобы агент вызывал дешёвого субагента для поиска
  полезных цитат и продолжал работу, пока тот работает:
  `_ops/chat-recall/2026-08-29-150002-codex-01a04cf3.md:33`.
- Более раннее точное решение сохраняет форму: ровно один субагент только для
  важной темы; основной поиск уже выполнен, результат не блокирует работу и
  может принести новые адреса:
  `_ops/chat-recall/2026-08-25-215514-codex-01a039d8.md:24`.

## FAST

- **Зачем:** не пропустить применимые слова владельца, не останавливая его
  текущую работу ради ожидания поиска.
- **Функция:** после собственного поиска важной темы получить независимые
  candidate addresses от одного дешёвого исполнителя.
- **Как:** нативный фоновый субагент ищет только сохранённый corpus, а главный
  агент продолжает работу и потом сам читает принесённые holders.

## Принятое решение

В уже существующем шаге Retrieval «можно передать» заменено на обязательное
«запусти» для важной темы. Brief ограничен read-only corpus-only поиском и
address/date/age/gaps; результат subagent не становится position.

Не зафиксирован конкретный model ID. Локальная проверка показала выбор модели
у обоих runtime, но модель и цена — platform configuration, а не глобальный
контракт. Codex вызывает `spawn_agent` с изолированным `fork_turns: "none"`;
Claude — фоновый `Agent` без `context: fork`. Оба явно выбирают самый дешёвый
доступный нативный model profile.
Claude `allowed-tools` теперь явно разрешает `Agent`; иначе этот runtime не мог
бы выполнить собственный Retrieval-контракт.
Если такого субагента нет, основной агент не подменяет его дорогим и честно
называет gap, продолжая собственный поиск.

## Сохранено и снято

- **Сохранено:** ровно один субагент, primary search сначала, важная тема,
  обычный corpus-only Retrieval, date/age, root reread и nonblocking lifecycle.
- **Усилено:** дешёвость и обязательный запуск вместо необязательной возможности.
- **Не добавлено:** новый reference, новая стадия, raw transcript, запись в
  corpus, hardcoded model name, shell workaround или ожидание результата.

## Фальсификатор

Candidate неприемлем, если Retrieval снова допускает «можно», разрешает ждать
subagent, подменяет недоступный дешёвый поиск дорогим, даёт ему raw
transcript/mutation, принимает его вывод за position или не требует
address/date/age/gaps.
