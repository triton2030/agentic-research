## Функция (FAST)

Результат: перед существенным решением рабочий агент располагает позицией
владельца — прямыми словами или выводом из его картины — с адресами, и
поступает так, как поступил бы владелец, не спрашивая его заново. Момент
включения: существенное решение, где важно, чего хочет владелец; новая
материальная реплика; заказ validation/repair/backfill.

Подъём по «зачем»: буквальный поиск → «найти, что говорил» → «понять, чего
хочет» → «сделать, как он хотел бы, без повторного вопроса» (product-frame:
«продолжает работу без повторного вопроса владельцу»). Способ, на котором
владелец настаивает: только субагент-психолог читает корпус (`#L21`).

## Затронутое намерение

### SKILL.md

- description по форме `skill-short-description.md`: «Use when a material
  decision needs the owner's intent, feelings and attitudes recovered from
  recorded words, or the owner states something material; also corpus
  validation, repair or backfill.» — 192 символа; `attitudes` = «отношению к
  тем или иным вещам» (`#L19`). Use: «сделай как я обычно хочу, но не помню,
  говорил ли», «что я решал про X», «запиши моё решение». Skip: «составь
  handoff» (1handoff), «обнови GOAL» (1goal), «запиши как работает продукт»
  (1docs-write). Near-miss: «прочитай мои прошлые сессии» → это скил, корпус;
  «спроси Codex, что он думает» → 1codex.
- Задача, Цель, Зачем: понимание владельца как человека; «между репликами»
  (`#L18`, `#L23`, `2026-08-14-124028-codex-019fff2e.md:33`); сбой «дефолт
  вместо понимания» (`#L18`); «говорит обрывками» — глобальная инструкция
  владельца и `2026-08-14-201233-codex-01a000d3.md:16`; «означает сразу кучу
  вещей» — `2026-08-09-030700-codex-019fe36a.md:22`.
- Новый раздел «Психолог»: причины из `#L20`; Claude — `Agent` + `SendMessage`
  тому же агенту (`#L20`); Codex — тред на проект (`#L22`).
- Режимы: строка Retrieval «Существенное решение, где важно, чего хочет
  владелец» — прежняя «Решение зависит от прежних слов» была рамкой сбоя.
- Среда: картина живёт в окне психолога (`#L20`), профиль не заводится
  (product-frame, аппетит), выводы психолога не становятся `note` в корпусе
  (находка проверяющего: «записанная позиция» читалась как запись в корпус).
- `allowed-tools` Claude: добавлен `SendMessage`.

### references/retrieval.md — протокол вызывающего агента

Задача: получить позицию у психолога и применить с её силой; корпус сам не
читать (`#L21`). Критерии: вопрос называет решение, класс и обратимость;
позиция применена с состоянием, силой, датой, адресом; поздние слова, отмены,
живые документы, конфликт → вопрос владельцу при продолжении независимой
работы; разрушительное, платное или внешнее действие по одному выводу — вопрос
владельцу, обратимый выбор — по выводу; «ни опор» ≠ «ничего не хочет»; смена
предмета — новый вопрос. Таблица состояний ответа.

1. Граница вопроса владельцу по одному выводу: сначала авторская
   («разрушительное, платное, внешнее»), затем заменена словами владельца,
   которые нашёл живой психолог (см. таблицу и `verification.md`).
7. `SendMessage` в этой сессии недоступен: в SKILL.md добавлен запасной путь —
   новый `Agent` с той же ролью и прежними ответами психолога; роль получила
   строку «начни с переданных опор»; путь проверен живым вторым вопросом
   (`verification.md`, «Вопрос 2»).
2. Codex-вариант не проверен в Codex-сессии. Первая редакция строилась на
   `codex exec resume` (подтверждён документацией), но второй проверяющий
   показал: бинаря `codex` нет в PATH (только внутри ChatGPT.app), а «фоновые
   треды» владельца (`#L22`) — нативная механика Codex из его `1orchestration`
   (`clientThreadId → threadId`, `wait_threads`, имена операций из callable
   schema). Раздел переписан под неё; файл-указатель
   `_ops/chat-recall/psychologist-thread.txt` (strict check его игнорирует —
   проверено) остаётся единственным невыводимым фактом. Гейт до принятия —
   живой запуск из Codex-сессии.
3. Тесты изменены в обоих runtime под новую топологию.
4. Description переведён в форму «Use when …» по правилу скила; граница
   «Excludes handoffs and project-truth updates» снята ради 200 символов,
   near-miss записан выше.
5. Возвращено полное чтение holder-а (см. раздел выше).
6. Прежний comparator старого и нового текста retrieval на синтетическом
   корпусе из 6 записей (haiku, 2×2 прогона) не различил версии: оба вывели
   «минимум» из ценностей. Сбой владельца не воспроизводится на малом корпусе;
   он ожидаем на большом (этот проект — 319 файлов, ≈1.75 МБ), где агент
   ищет по фразе и не читает широко — что и есть довод за отдельное окно
   психолога.
