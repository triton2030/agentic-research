# Проверка одного неизменного черновика

Два независимых чистых окна: review_instructions и review_trajectory.

| Находка | Решение | Проверка |
| --- | --- | --- |
| Capture не имеет собственного входа в поиск отменяемой цитаты | Принята: локальный chat_digest CLI + corpus path и lexical/topic/timeline | ссылки и команды локальны режиму; final link/CLI checks |
| Brief фонового поиска не содержит целевой корпус | Принята: абсолютный путь + фактически проверенный корпус в возврате | текст обеих runtime версий |
| Description несёт команды и >200 chars | Принята: trigger-only описание <=200 | parser/length check |
| Кодовое evidence ещё не сохранено | Закрыта terminal regression результатами и cli-probe.json | 125 Codex + 122 Claude; lexical/hybrid conflict-only, first capture, unresolved, strict |

Существенных потерь Capture/Integrity trajectory-reader не нашёл на построенных
сценариях. Это предсказания по тексту, не фактические прогоны агента.
Интерфейсные/механические свойства проверены CLI, семантические — независимым
чтением. Удалённых дорогостоящих обязательств нет: они остаются явными
критериями; снята нумерация когнитивного маршрута, а не само обязательство.

Консервативная оценка проверяющего до локальных исправлений: редакционные
единицы SKILL 31, Capture 29, Retrieval 36, Integrity 24; совместные активные
обязательства после объединения повторов примерно 22/25/20. Это оценка, не
измерение adherence. Добавленные сведения о CLI и корпусе — интерфейсное
знание; новый четвёртый режим и дополнительное деление не введены.
Отклонённых существенных находок нет. Дополнительная волна не требуется:
правки закрывают адресные интерфейсные пробелы, не меняют принятое намерение.
