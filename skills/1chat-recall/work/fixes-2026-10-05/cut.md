# Граница и сохранность правок

Заказ — адресные А–Ж из [intent.md](intent.md), без ремонта старого корпуса.
Продуктовая рамка — `skills/shared/1chat-recall/product-frame.md`.
Прежний пакет — `versions/installed-2026-09-22-stable-records/`;
неизменённые runtime-specific файлы сохраняются у своих владельцев.

| Пункт | Изменение | Сохранённое условие | Проверка |
| --- | --- | --- | --- |
| А | Agent нормализуется для новых записей и env; поиск по UUID без регистра agent | Имя и шапка существующего файла не переписываются; другой agent и дубликаты отклоняются с адресами | `tests/test_capture_fixes.py` |
| Б | Help и Capture разрешают отсутствие времени и source-ref в том же ходе; дробный ISO и implicit microseconds сохраняются | Backfill требует исходное время; отсутствие identity честно исключает обещание идемпотентности; строгая chronology не ослабляется | Там же |
| В | Несколько адресов, включая повтор флагов; reader связывает каждый | Один адрес сохраняет прежний формат; hash legacy, scope, chronology и запрет смешанных ответов остаются | Новые и прежние Capture/Digest tests |
| Г | `--add-subjects` дописывает ключи к карточке в Capture | Полная первая карточка обязательна; полная замена требует чтения разговора; слова владельца не меняются | Новые tests |
| Д | Пример локального выбора модели; поиск отмены по теме и типу | Чтение выбранных разговоров целиком, расширение поиска, адрес отмены и unresolved gap остаются | Независимая проверка текста |
| Е | В Codex перенесён тип «разрешение»; уточнено отличие значимого согласия от обычной операционной реплики | Разрешение не даёт общего полномочия и не меняет прошлые записи | Capture → Digest roundtrip |
| Ж | Отдельные runtime snapshots и Codex projection | Runtime-specific документы, тесты и UI metadata не унифицируются | Полные tests, внешние probes, byte manifest |

Дословность, авторство, сокращение только удалением, словарь тем,
локальный поиск и запрет производного слоя сохранены.
Новых ссылок на transcript нет; указание искать transcript ради времени текущей записи снято.

Стадия: адресные правки, независимая проверка, полные тесты и доставка завершены.
Финальное evidence — [verification.md](verification.md).
