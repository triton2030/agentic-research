# Product Frame — `1index` — candidate 2026-08-31

## Цель

Холодный агент по рабочему намерению за один переход достигает точного места,
которое прежняя сессия обнаружила дорогим поиском, и понимает следующий шаг.
INDEX выносит маршрут к знанию из длинного документа, неочевидно названного
файла или нескольких разнесённых sources, не копируя само знание.

## Приёмка

- Намерение подтверждено живой задачей или owner-ом.
- Каждый source имеет evidence наблюдаемой цены обнаружения либо прямое слово
  владельца о конкретном трудно находимом месте.
- Запись связывает намерение, exact source и следующий шаг.
- INDEX не копирует правило, вывод, status, number или promise source owner-а.
- Очевидный или неподтверждённый маршрут не записывается.
- Существующий INDEX можно обновить в разрешённой области; новый требует
  отдельного approval.
- Изменённый route проходит one-hop check от намерения вне INDEX до живого
  semantic owner-а.

## Не-цель

Скилл не строит оглавление, не заменяет semantic search и не анализирует
причины ошибок сессии.

## Тайбрейкеры

1. Пропущенный route дешевле ложного.
2. Наблюдаемая цена сильнее правдоподобной полезности.
3. Exact section сильнее ссылки на весь длинный файл.
4. Ближайший существующий INDEX сильнее нового owner-а.
