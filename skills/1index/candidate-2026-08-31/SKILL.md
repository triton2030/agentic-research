# Индекс оплаченных маршрутов

## Цель

- Холодная сессия использует уже оплаченный маршрут вместо повторного поиска.
- Рабочее намерение приводит её прямо к живому владельцу знания и следующему
  действию.
- `INDEX.md` остаётся навигацией, а не оглавлением или копией знания.

## Уникальный контекст

Полезное знание может быть фактически недоступно обычному листингу: нужное
место спрятано в длинном документе, не обещано именем файла или распределено
по нескольким источникам.

## Критерии

- Подтверди намерение живой задачей или владельцем.
- Для каждого источника отдельно подтверди наблюдаемо дорогой поиск либо прямое
  слово владельца о конкретном трудно находимом месте.
- Начни маршрут с подтверждённого намерения.
- Для каждого источника добавь точный раздел или якорь.
- Для каждого источника назови действие у него.
- До записи начни проверку от намерения вне `INDEX.md`.
- Подтверди, что один переход ведёт к живому владельцу знания.
- После проверки выбери ближайший существующий `INDEX.md`.
- Записывай только в разрешённой области.
- Если `INDEX.md` отсутствует, предложи владельцу создать его в названной
  области.
- Не создавай новый `INDEX.md` без отдельного «да».
