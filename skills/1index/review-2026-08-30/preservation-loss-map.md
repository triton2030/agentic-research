# Preservation / loss map — `1index`

## Цель

Показать смысловую дельту clean-room candidate 2026-08-30 против прежнего
пакета, не требуя совпадения структуры.

| Прежний смысл | Решение в exact candidate |
| --- | --- |
| Строка длинного документа, неочевидное имя, несколько sources | Сохранены в `SKILL.md#Уникальный-контекст`. |
| Только оплаченный маршрут | Сохранён наблюдаемым admission gate; без цены INDEX не меняется. |
| Intent → exact source → next action | Сохранён как единственная форма маршрута. |
| INDEX не вторая правда | Сохранён запретом копировать знание. |
| Существующий INDEX можно дописать, новый требует approval | Сохранена точная authority boundary. |
| One-hop verification | Сохранён как falsifier одного изменённого маршрута. |
| Admission/writing/upkeep references | Clean-room сначала поглотил их; буквальный checker показал перегрузку; после снятия выводимых предикатов итоговый prompt снова помещается в один `SKILL.md`. |
| Пять внешних намерений | Сняты: не имеют отдельного owner-evidence и превращают точечную проверку в bulk audit. |
| Обязательный `1md-graph` | Поглощён прямым one-hop falsifier exact source. |
| Конец длинной сессии как trigger | Поглощён фактом дорогого обнаружения; завершение без находки не меняет INDEX. |
| Знание имени upstream caller-а | Снято: зависимость должна оставаться только `1context-refactor → 1index`. |

Остаточный риск: clean probe должен показать, что короткий prompt одновременно
отклоняет очевидный route, сохраняет multi-source route и не копирует решение.
