# Simplicity receipt — `1index`

## Цель

Оправдать каждую оставшуюся runtime-сложность конкретным вредом при удалении.

| Оставлено | Counterfactual harm без него |
| --- | --- |
| Цена поиска или прямое owner-evidence для каждого источника | Один дорогой source легитимирует очевидные строки оглавления. |
| `намерение · точный раздел/якорь · следующий шаг` | Холодный агент снова ищет нужную строку внутри длинного файла. |
| Знание не копируется | INDEX становится stale вторым owner-ом. |
| Только существующий INDEX; новый — proposal | Автоматический вызов создаёт новый semantic owner без approval. |
| Проверка candidate до записи | Сломанный путь остаётся в живом INDEX.md. |

Удалено или поглощено: три runtime references; bulk-check пятью intents;
обязательный `1md-graph`; long-session trigger; upstream skill name; отдельные
upkeep, отдельное durable evidence цены и output schemas. Их польза выводится
из цели либо не меняет решение.
