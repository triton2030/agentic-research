## FAST

- **Frequently discussed.** Агент уже заплатил долгим поиском: прочитал
  длинный документ ради одной строки, нашёл нужный раздел в неочевидно
  названном файле или собрал маршрут через несколько документов.
- **Ambitious.** Следующая холодная сессия получает пользу этого поиска без
  повторного расследования.
- **Specific.** Скилл сохраняет доказанно трудно найденный маршрут к точному
  живому источнику знания; он не превращает `INDEX.md` в оглавление или второй
  источник правды.
- **Transparent.** Результат проверяем по одному переходу от рабочего
  намерения вне INDEX до владельца знания и понятному следующему действию.

## Единственная функция

Превращать уже оплаченный поиск скрытого знания в долговечный маршрут для
следующей холодной сессии.

## Уникальный контекст

Полезное знание может существовать и оставаться фактически недоступным: нужная
строка спрятана в длинном документе, имя файла не обещает тему, а ответ
распределён по нескольким источникам. Обычный листинг не показывает ни точное
место, ни уже понесённую цену его обнаружения.

## Цели пользователя

1. Холодный агент не повторяет уже оплаченный поиск скрытого знания.
2. По рабочему намерению он за один переход достигает точного живого владельца
   знания и понимает следующий шаг.
3. `INDEX.md` остаётся картой подтверждённых маршрутов, а не оглавлением или
   копией знания.

## Неизменяемые решения для проверки потерь

- Намерение подтверждает живая задача либо владелец.
- Конкретный трудно находимый источник допускается по наблюдаемой цене поиска
  либо прямому слову владельца об этом месте; для нескольких источников
  условие проверяется отдельно.
- Существующий `INDEX.md` можно дополнить только в разрешённой области; если
  его нет, результатом служит предложение, а не самовольный новый owner.
