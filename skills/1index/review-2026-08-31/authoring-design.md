# Авторское решение

## Кнопка запуска

Сохранена ранее проверенная trigger-only фраза:
`Use when costly search or a direct owner statement identifies a specific
hard-to-find location.`

- Use: после чтения длинного документа ради одной нужной строки.
- Skip: известный путь к обычному config без дорогого обнаружения.
- Near-miss: повторные ошибки сессии без нового трудно находимого маршрута;
  это не момент запуска `1index`.

Codex `short_description` совпадает с frontmatter, а `default_prompt` называет
те же две admission-ветви. Эти surfaces не менялись.

## Форма body

Outcome/decision contract, один `SKILL.md`, без references и стадий. В начало
возвращён содержательный раздел `Цель` из трёх законченных результатов; за ним
идёт неинструктивный `Уникальный контекст`.

Отдельный «Протокол поведения» не нужен. Единственный обязательный порядок —
проверка one-hop до записи: без него сломанный или вторичный адрес попадёт в
живой INDEX. Остальная работа допускает профессиональное суждение агента.

## Дефолты и оставленные гейты

| Дефолт | Механизм | Изменяемое решение | Вред без строки | Цена строгости |
| --- | --- | --- | --- | --- |
| Индексировать полезную тему | Список файлов кажется достаточным evidence | Допуск источника | INDEX разрастается очевидными или придуманными ссылками | Пропущенный маршрут при недоказанной цене |
| Считать один дорогой source основанием для всех | Общая тема скрывает разную цену обнаружения | Допуск каждого source | Очевидный source попадает рядом с действительно трудным | Отдельная короткая проверка каждого source |
| Создать отсутствующий INDEX | Новый файл кажется полезным локальным улучшением | Authority записи | Возникает новый неутверждённый semantic owner | До approval остаётся только proposal |
| Записать до проверки адреса | Ссылка выглядит правдоподобно | Момент мутации | INDEX закрепляет сломанный путь или пересказ | Один one-hop check |

Точная схема маршрута сохранена: без неё холодный агент снова ищет место внутри
источника или не понимает следующий шаг. Третья цель заменяет отдельный каталог
запретов на TOC, пересказы и копирование знания.
