# Preservation / loss map — `1index` — 2026-08-31

## Цель проверки

Сопоставить новый clean-room candidate с установленным пакетом и принятыми
смыслами, не требуя совпадения структуры.

| Прежний смысл | Решение в candidate |
| --- | --- |
| Холодный агент получает подтверждённый маршрут | Усилен второй целью: путь начинается от рабочего намерения, за один переход достигает живого owner-а и сообщает следующий шаг. |
| Длинный документ, неочевидное имя, несколько источников | Сохранены и объяснены в `Уникальном контексте` как фактическая недоступность существующего знания. |
| Не повторять уже оплаченный поиск | Возвращено отдельной первой целью; прежний runtime оставлял этот результат только неявным. |
| INDEX хранит маршрут, не знание | Возвращено отдельной третьей целью вместе с границей оглавления. |
| Намерение подтверждает живая задача или владелец | Сохранено буквальным admission-гейтом. |
| Источник допускается после дорогого поиска либо прямого owner-evidence | Сохранено явно и применяется отдельно к каждому источнику. |
| `намерение → точный адрес → действие` | Сохранено как единственная схема записи. |
| One-hop от намерения вне INDEX до живого владельца знания | Сохранено как проверка перед записью. |
| Существующий разрешённый INDEX можно дополнить; отсутствующий — только proposal | Сохранена authority boundary. |
| Один self-contained runtime-файл | Сохранён; references, scripts и новые стадии не добавлены. |

## Поглощено

- Старая общая фраза «дать маршрут» поглощена второй целью и точной схемой.
- Отдельные запреты на обзорные, очевидные и предположительные ссылки поглощены
  admission-гейтом и третьей целью.
- Output schema `update | propose | skip` из clean-room предложения снята:
  authority-гейт уже однозначно определяет эти исходы.

Потерь результата, требуемого способа или принятой authority не найдено.
