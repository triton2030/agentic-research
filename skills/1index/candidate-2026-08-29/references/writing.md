# Запись маршрутов

## Цель

Записать допущенные маршруты без второй правды.

```markdown
## <намерение — зачем пришёл>
- [файл#раздел](path.md#anchor) — что там узнать или сделать
```

- Действие называет следующий ход, а не пересказывает содержание owner-а.
- Для темы из нескольких документов каждая ссылка допускается отдельно.
- Ссылки идут по важности; при равенстве: ограничение → решение/owner →
  реализация/evidence.
- Папка, инструмент или skill входят только когда без них следующий ход неполон.
- Обнови эквивалентный intent-router и используй ближайший INDEX.
- Папочный INDEX создаётся только рядом с папочной инструкцией.
- Новый INDEX создаётся после «да» владельца; корневой указатель ставится через
  `1instruction-authoring`.

Не копируй в INDEX статус, решение, число или обещание owner-а.

После записи пять намерений, выбранных вне INDEX, должны привести к источнику
за один переход. Изменённые ссылки и якоря проверь через `1md-graph`.
