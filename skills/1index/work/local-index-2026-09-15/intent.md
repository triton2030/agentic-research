# Локальные индексы и авторинг инструкций

15 сентября 2026 пользователь ответил «Да отлично делай» на предложение согласовать два скилла: 1instruction-authoring учитывает 1index при размещении навигации; 1index разрешает создавать полезные локальные индексы. В принятом предложении правила, необходимые до выбора источника, остаются в инструкции; индекс помогает выбирать маршруты по задаче. Исходная идея владельца: /Users/triton/Documents/My_projects/mavo3/_ops/chat-recall/2026-09-14-140506-Codex-01a09f28.md#L36. Предложенное распределение — реализация агента, не дословное утверждение владельца.

Адресная правка. Меняются 1index (триггер, соответствующая цель/контекст и выбор размещения), его Codex metadata/принципы и один самостоятельный случай в writing.md скилла 1instruction-authoring. Остальные части сохраняются. Реальные INDEX/AGENTS и продуктовые документы MAVO этим заказом не переписываются.

Цель: агент сохраняет обязательную местную правду до выбора и получает подробные подтверждённые маршруты только когда они нужны. Уменьшение строки AGENTS не является достаточностью; источник, ясный вход и условие чтения должны сохраняться. Новые индексы допускаются в разрешённой области при реальной пользе, без повсеместной генерации из дерева.

У 1instruction-authoring уже есть чужая незакоммиченная редакция, совпадающая с установленной. Она сохраняется; наше добавление — отдельный раздел в конце writing.md. Для Git будет сохранено только наше добавление, исходное состояние дополнительно зафиксировано в before и preexisting snapshots. Предшествующие изменения не объявляются нашими и не откатываются.
