# Первая волна

Intent (local_index_case_a): необходимых находок нет; общий смысл, глобальность, описание вызова и сохранённые обязательства подтверждены.

Requirements (local_index_case_b): необходимо проверять вход не только нового, но любого выбранного индекса. Иначе существующий INDEX без входа может остаться недоступен при самостоятельном вызове. Принято: в v2 проверяется выбранный индекс, недостающий вход добавляется в пределах поручения, незакрытый переход явно называется.

Application: полный возврат — review-application.md. Необходимых исправлений не найдено; три результата и 40 ссылок проверены по файлам, обязательства/исходники сохранены. Ограничения: явное предъявление кандидатов, нет автоматического trigger-теста, сравнения со старой версией или холодного чтения; existing создан этим же агентом до роли проверки, его независимость ограничена. Третья нативная ветка запущена через codex exec после отказа spawn_agent из-за общего лимита потоков; это отдельный контекст, thread 01a0a17a-6793-7fe2-9f3f-af6173ef8cd1.

Действия в пробах относятся к v1. Отличие v2 — только восстановление общего требования о доступном входе; в результатах new/existing вход уже есть, simple остаётся прямым. Вторая волна проверяет это изменение, не запускает тот же авторинг снова.
