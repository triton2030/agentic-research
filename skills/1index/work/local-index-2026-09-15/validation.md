# Проверка результата

Финальные владельцы заданы в final-candidate-hashes.json; доставка обеих сред побайтно проверена в delivery.json. Описание 1index и Codex short_description одинаковы (147 символов). Новые инструкции размещены только в заявленных владельцах двух скиллов; реальные INDEX/AGENTS MAVO этой работой не изменялись.

Три самостоятельных случая проверяют авторинг: new создаёт локальный индекс для четырёх рабочих маршрутов, existing дополняет существующий, simple сохраняет достаточную прямую ссылку без изменений. Исходные правила, источники и рабочие действия сохранены; 40 переходов и якорей разрешаются. Воспроизводимые входы — probe-input.tar.gz, результаты — results/, сравнения — case-*.diff, адресная проверка — probe-validation.json.

Пробы выполнены на v1 с явным чтением скиллов. В финальной v2 условие доступного входа относится ко всякому выбранному индексу; tested-to-final.diff фиксирует единственную правку. Три полученных состояния совместимы с v2, но не являются повторным запуском v2. Ветка, где вход невозможно закрыть в разрешённой области, не испытана. Автоматическое срабатывание скилла, холодное чтение, экономия контекста и поведение Claude не измерялись. Проверка не доказывает улучшение над прежней версией.

Две волны review завершены: wave-1.md, wave-2.md. Отдельная acceptance использует агента, не писавшего текущие изменения; контекст его прежней задачи переиспользован из-за лимита новых потоков. Это независимость от авторства текущей правки, не новый пустой контекст.

Предшествующие незакоммиченные изменения 1instruction-authoring сохранены побайтно перед нашим добавлением. Их исходные байты лежат в before/ и preexisting-*.txt; запись в Git должна включить только добавленный раздел и адресные изменения навигации. Остальные незакоммиченные изменения мастерской принадлежат прежней или параллельной работе.
