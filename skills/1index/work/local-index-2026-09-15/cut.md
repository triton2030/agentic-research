# Сохранность

Сохраняются: подтверждённость каждого маршрута/источника, условие работы и точные адреса, отказ от индекса как копии знания или листинга, 1instruction-authoring как владелец обязательств и способа доставки, прежние правила автора и действующая чужая редакция.

Изменяется по новому заказу: допуск 1index охватывает подтверждённую навигацию, отделяемую при авторинге инструкций; отсутствующий подходящий локальный INDEX можно создать в пределах поручения. Прежний обязательный возврат предложения при отсутствии файла снимается только для этого разрешённого выбора. Произвольные новые предметы/правила/массовая индексация не разрешаются.

Конкретный переход: рабочий вход с условием → локальный INDEX → точный владелец знания. Каждая содержательная запись индекса ссылается прямо на источник, а индекс доступен до зависимого решения. Обязательные ограничения не переносятся в необязательное чтение.

Уточнение финальной версии: доступный условный вход проверяется у любого выбранного индекса, а не только у нового. Буквальный один переход от внешнего намерения до источника заменён явной цепочкой вход → индекс → источник; запись индекса по-прежнему ведёт прямо к владельцу, без цепочки пересказов. Это необходимое согласование принятого локального размещения.
