# Loss map — functional repair — 2026-08-31

## Возвращено

| Жёсткая строка | Почему commander's intent недостаточен | Вред без строки |
| --- | --- | --- |
| Три точных поверхности | «Полная пара» не задаёт файловый output contract | Появляется неполная или параллельная правда; история смешивается с current state |
| `P-NNN` как высотное правило класса выборов | Модель умеет писать правдоподобные принципы, но не отличает регулятор от детали | Деталь или лозунг получает authority и не разрешает будущую развилку |
| Только подтверждённые решения владельца | Правдоподобное заполнение пробела выглядит как полезная полнота | Агент создаёт новые полномочия P-003… без owner evidence |
| Выводимое не документируется | Стремление сохранить полезный вывод естественно раздувает нижние слои | Возникает дублирующая правда и будущий дрейф |
| Пять обязательных разделов Frame | Слово `Frame` не раскрывает локальную схему | Чистый probe пропускает привязку, тайбрейкеры, старшинство или аппетит |
| Пустое поле остаётся gap | Требование полноты подталкивает достроить правдоподобный default | Неподтверждённое получает печать завершённой пары |
| Чистовики без истории и provenance | Без отрицательной границы evidence кажется полезным внутри канона | Читатель вынужден вычислять, что действует сейчас |
| Append-only квитанция истории | Отделение истории не задаёт минимальный проверяемый состав | Точная owner-граница и причина изменения теряются |
| Два выхода при конфликте с `GOAL` | Проверка через цель не определяет действие после найденного противоречия | Агент молча объявляет победителем просьбу, пару или `GOAL` |
| Editorial merge без нового смысла | Exact approval для содержательной правки не различает чистую дедупликацию | Канон сохраняет явные дубли либо владелец платит вниманием за правку без смены authority |
