# Origin — рефактор 2026-08-09 «чистовик + журнал»

Запрос владельца: рефактор скилла по канону `1skill-shaping` + пересмотр
формата пар, «не превратились ли принципы в помойку».

Диагноз (Claude + независимый Codex, сошлись): один корпус нёс три роли —
дословное свидетельство, действующий регулятор, карта состояния мира.
Следствия: надгробия и частичные вытеснения, Frame-миниспеки до 214 строк,
протухшие «Влияет на», 30 из 47 блоков без `Commitment`, противоречие
чистовика и Frame внутри одной пары.

Решения владельца (дословно — recall
`_ops/chat-recall/2026-08-09-172500-claude-6745a7b2.md`, mavo-short2):

- чистовики без летописи, переписываются с кристаллизацией; история
  обоснований с цитатами — один журнал, только дописывается;
- принципы вечны и выше канона: «канон должен доехать до принципов»;
  принципы — не канон, жанр «высота птичьего полёта»;
- цепочка: цель → принципы → бизнес-канон → спецификация → код;
  спецификация черпает и из принципов/цели напрямую;
- принципы существуют, чтобы не документировать: тысячи мелких решений
  выводятся, выводимое не записывается;
- содержательная переписка чистовиков — только с «да»; редакционное
  слияние дублей — агент сам с записью в журнал;
- стадийная механика — не принципы;
- журнал один на проект, рядом с рамками.
