# Контракт файла принципов

## Цель

Файл принципов области даёт чистому агенту только текущую подтверждённую
правду и достаточную структуру, чтобы автономно разрешать класс будущих
решений; история, пробелы и выводимые следствия не получают authority рядом с
ней.

## Поверхности

```text
<project-root>/_ops/product-frames/<scope>.md   — один файл на область
<project-root>/_ops/product-frames/history.md   — общий журнал, только дописывается
<project-root>/_workspace/_archive/…            — прежние версии целиком
```

Заголовок файла — по моменту чтения: `Product Principles — <Область>`,
`Brand Principles — <Область>`, `Engineering Principles — <Область>`.

## Фронтматтер

```yaml
описание: одна строка — что здесь решается и чем область не такая, как ждут
момент: строим | говорим | держим — и грузится ли всегда или по адресу
выше: старшая правда (GOAL, родительская область)
соседи: файлы других моментов, ссылающиеся сюда
детали-в: двери канона, куда ведут строки «Точно»
```

## Шапка

- **Сцена** — три-пять строк: картина, по которой агент опознаёт «ещё один из
  таких». Без чисел и правил.
- **Тайбрейкеры** — до восьми строк «X против Y — побеждает Z (`P-NNN`)».
  Это индекс принципов по ситуации; каждая строка называет конфликт и адрес.
- **Аппетит** — разрешённые жертвы, запретные жертвы, событие пересмотра.

Приёмка области живёт на карте эпиков, не здесь. Старшинство — поле `выше`.

## Принцип

```markdown
## P-NNN · Название, которое само по себе ломает стереотип

**Когда** <класс ситуаций>, — **<действие: нет / да / выбирай X>**: <одна-две
фразы, что именно делается>.
**Почему.** <обоснование в одну фразу>.
**Следствия.** <одно-три следствия для стройки, без чисел>.
**Точно.** <адрес двери канона или соседнего принципа>.
```

Не больше восьми принципов на файл; девятый — сигнал слить или спустить в
канон. Принцип без «Почему» или «Следствий» не проходит. Номера `P-NNN`
переназначаются при переписывании, перенаправления — в квитанции `history.md`.

## Чистота

Файл не содержит статусов, вытеснений, надгробий, дословных цитат,
provenance, карт влияния, гипотез, открытых вопросов, истории, чисел,
перечней экранных слов и точных правил — всё это живёт в каноне, спецификации,
журнале и recall, а здесь стоит адрес.
