Date: 2026-10-18. Status: confirmed для локальной доставки и перечисленных проверок.

Общий исходник — `skills/shared/1google-drive-archive/portable/`; отдельная
дельта Codex — `platforms/codex/agents/openai.yaml`. Из него штатным
`sync_simple_projections.py 1google-drive-archive --write --install` созданы
tracked и installed проекции Codex/Claude. `--check` и повторная сверка SHA-256
подтвердили совпадение всех файлов: 9 у Codex, 8 у Claude; лишних файлов нет.
Receipt: [installation.json](installation.json).

  snapshot. Один повтор удалён без потери условий. Материальных открытых findings нет.
- Baseline и candidate разобрали одинаковый синтетический plan-only CASE.
  Оба сохранили файлы; выявленной регрессии нет. Улучшение вероятности успеха
  этим опытом не измерено. CLI-проверка helper из чужого cwd успешна.
- Свежий Codex CLI (gpt-6.1-sol/high) увидел имя в Available skills, прочитал
  установленный SKILL.md и четыре references; use/skip/use решения корректны.
- Claude Code 2.1.302 (claude-opus-5-5), существующий вход Claude Max:

Промпты, санитизированные tool traces и ответы сохранены рядом. Эти runtime
пробы проверяли обнаружение, чтение и учебные решения, а не реальную архивную
операцию и не частоту автоматического срабатывания на свободных запросах.

## Обнаруженные особенности среды

Первая проба Claude была неправильно изолирована: `--setting-sources ''`
скрывал пользовательские skills. После изменения только harness на `user`
тот же установленный пакет обнаружен; переустановка не требовалась. Hooks
оставались отключены, MCP пустым, инструменты ограничены Skill/Read.
Официальные справки: [CLI flags](https://code.claude.com/docs/en/cli-reference),
[skill locations](https://code.claude.com/docs/en/skills#choose-where-skills-load).
Это наблюдение конкретной CLI-пробы, не отсутствие пакета на диске.

Каталог skills текущего долгого Codex-чата не обновился после установки;
свежий CLI-контекст увидел навык. Для штатного выбора в старой сессии может
потребоваться новый контекст. Файлы установленного пакета доступны по пути.

`claude auth status --json` внутри sandbox показал отсутствие входа, а та же
read-only проверка вне него — действующий Claude Max. Это ограничение среды,
не доказательство утраты аккаунта. Токены и credentials не извлекались.

## Границы результата

Новый Code.gs прошёл offline mocks, включая schema interoperability, но ещё
не был развёрнут или запущен в Apps Script. Ранее проверенная настоящая INSV-пара
доказывает доступность метода, а не live-исполнение новых байтов.
Восстановление набора и фактическое освобождение места этой работой не проверены.
Google auth не переносится установкой скилла; runtime проверяет свой доступ.
Работа по вызову; расписания не создавались. Новых uploads, удалений, OAuth,
cloud updates и платных ресурсов в этой работе не было.

Блокеров локального создания/установки нет. Следующий практический шаг — вызвать
скилл на уже известном архивном файле и обновить его evidence через существующий
доступ. Если выбран новый cloud adapter, сначала согласовать его конкретное
развёртывание и проверить одну настоящую пару; затем масштабировать набор.

Доставка исходника сохранена в локальном Git. GitHub repository мастерской
оказался публичным (`gh repo view`: isPrivate=false); текущая работа не
публиковала туда историю с локальными диагностическими адресами и словами
владельца. Публикация не требуется для глобальных локальных установок.
