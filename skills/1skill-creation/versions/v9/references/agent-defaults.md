# Дефолты агентов

Вход: автор хочет добавить в скил строку сверх слов пользователя.
Цель: решить, изменит ли она поведение или только добавит нагрузку.

1. Закончи фразу: «без этой строки агент сделает X, потому что Y выглядит
   разумным».
2. Не принимай симптом, название исследования или недоверие к агенту за
   механизм поведения.
3. Не добавляй строку, если цель или существующая инструкция уже меняет тот же
   выбор.
4. Добавляй знание только тогда, когда оно меняет названное действие, решение
   или границу агента.
5. Учитывай, что требование против дефолта и новое активное обязательство
   повышают риск отказа.
6. Учитывай, что жёсткая инструкция закрывает допустимые пути к цели.
7. Оставляй добавку, только если предсказанный вред без неё дороже потерянной
   автономности.
8. Если нарушение недопустимо, убери путь к нему вместо усиления формулировки.
9. Если скил не может убрать путь к нарушению, не выдавай текст за гарантию.

Выход: для каждой принятой добавки — `дефолт → механизм → изменяемое решение →
вред без строки → цена строгости`.

- Сними добавку, если её цепочка неполна.
