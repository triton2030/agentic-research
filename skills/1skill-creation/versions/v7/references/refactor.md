# Рефактор

Вход: пользователь просит рефактор скила, или живой скил раздут либо
ритуален.

Рефактор — ускоренное создание нового скила на месте старого. Этот файл даёт
рефактор-специфичный выход; оставшиеся стадии назначает тело.

1. Прочитай рефакторимый скил полностью вместе со всеми его
   референс-файлами.
2. Прочитай в папке-истории функцию, `cut.md` и буквальные цитаты пользователя.
3. Если папки-истории нет, заведи её по ходу работы.
4. Заново восстанови функцию, момент вызова и желаемое поведение.
5. Предложи Уникальный контекст и не более трёх целей, которые вместе с ним
   удерживают правильное направление.
6. Спрашивай только о материальном выборе, который нельзя вывести из
   прочитанного.
7. Выпиши старые указания плоским списком.
8. Сгруппируй старые указания по обслуживаемой цели.
9. Замени группу инструкцией высшего порядка, только если чистый агент выведет
   из неё снятые частности.
10. Проверь, что новая версия сохраняет прежнюю функцию и принятые смыслы.
11. Для каждого нового ограничения назови закрываемый провал и вытесненную
    свободу.

Выход: функция, Уникальный контекст, Цель пользователя, перекроенный черновик и
карта поглощённых либо оставленных указаний в папке-истории.
