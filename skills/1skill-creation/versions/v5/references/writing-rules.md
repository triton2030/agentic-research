# Правила написания

Вход: скил вызван; эти правила действуют на всё письмо до самой записи.

- Агент мощный: в создаваемый скил не добавляй ничего сверх буквальных слов
  пользователя.
- Строку сверх его слов предлагай только с основанием из `agent-defaults.md`.
- Обязательный шаг создаваемого скила предлагай подпирать следом, который
  нельзя произнести не сделав, — например, цитата из середины файла
  доказывает чтение.
- Буквальные цитаты пользователя о скиле сохраняй в папку-историю в момент
  обсуждения.
- Инструкции не дублируются.
- Каждая инструкция пишется с новой строки: выполняемая по порядку —
  нумеруется, любая другая — bullet point; прозой — только общая информация
  вроде цели и контекста.
- Тело — меньше 20 единиц инструкций, желательно около 10; единица — одно
  несущее указание, включая Уникальный контекст и Цель пользователя; одно
  предложение может нести несколько единиц.
- Порядок шагов пиши, только когда важен сам путь; важно состояние после
  шага — пиши критерий, не последовательность.
- Сомневаешься в формулировке — прочитай `formulation.md`.

Адреса:

- Папка-история скила — `skills/<имя>/` в репо `agentic-research`: функция,
  черновик, `cut.md`, продуктовая рамка, буквальные цитаты пользователя.
- Адреса установки — живой пакет каждого рантайма: `~/.claude/skills/<имя>/`
  и `~/.codex/skills/<имя>/`.
- Есть tracked owner `skills/shared/<имя>/portable/` — сначала правь его,
  живой пакет — projection; нет — живые пакеты и есть правда, второй source
  tree не создавай; реестр владельцев — `skills/shared/README.md`.
- Репо недоступно — спроси пользователя, куда писать.
