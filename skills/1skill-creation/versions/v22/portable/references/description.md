# Имя и description

Нужно, когда пишутся или чинятся имя и `description`: скил не вызывается,
вызывается слишком рано или сталкивается с соседом. До выбора скила тело
недоступно: имя и `description` — вся поверхность запуска.

1. Кандидат по форме: `Use when <наблюдаемый момент> требует <функцию>.
   <Ближайшая граница — только при реальной коллизии>.`
2. Имя — по операции или моменту, а не по общей теме.
3. Проверь голыми фразами пользователя в 5–10 слов: use вызывает этот скил,
   skip — нет, near-miss выбирает соседа. Для позднего момента — до и после
   его наблюдаемого признака.

`description` — по-английски, до 200 символов, состояние и функция в первой
фразе, без инструкций тела. Фразу, которая не меняет решение
**use now · not yet · neighbor**, удали.
