# Восстановление намерения

Вход: новый скил либо затронутое намерение существующего; доступны слова
пользователя и граница текущего заказа. Роли разделов и их смысловой отбор
принадлежат разделу «Когда собираешь намерение» в теле скила.

## Когда основания ещё не собраны

По Function Analysis / FAST восстанови результат и момент вызова. Подъём
по «зачем» (Action Identification) помогает найти намерение за способом;
неудачный подъём означает пробел в основании, а не ненужность способа.
Неизвестность, меняющую результат, выясни у пользователя. Выбор, уже
определённый его словами, не требует повторного вопроса.

Свяжи существенные сведения о мире и желания пользователя с его словами
или проверяемыми источниками. Авторская правдоподобная история не становится
контекстом. При адресном изменении сохраняй незатронутые части намерения.

## Когда намерение собрано

Различай однократное достижение и поддержание состояния (KAOS Achieve /
Maintain), если от этого меняются действия после первого успеха.
Сохрани отдельно способ, на котором пользователь настаивает. Для скила,
передающего знание, назови канонического владельца этого знания.

В рабочих материалах сохрани функцию, источники, границу изменения и
намерение. Для оставленных критериев запиши остаточную лазейку, наблюдаемый
след и того, кто его проверит; при отсутствии критериев достаточно назвать,
почему Контекст, Задача и Цель уже определяют необходимое.
Покажи пользователю существенные решения и оставшиеся материальные пробелы.

Выход: адресуемое намерение для авторинга; при рефакторе оно возвращается
в сохранённый маршрут. Проверку достаточности разделов не подменяет наличие
файла с их заголовками.
