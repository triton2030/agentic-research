# Рефактор

Вход: пользователь просит рефактор скила, или живой скил раздут либо
ритуален.

Рефактор — ускоренное создание нового скила на месте старого: цель —
привести скил к структуре и правилам этого скила. Иногда это полное
переписывание; скил, уже похожий на нужную форму, проходит тот же полный
процесс.

1. Прочитай рефакторимый скил полностью: тело и все его референс-файлы.
2. Прочитай папку-историю скила: функцию, `cut.md`, буквальные цитаты
   пользователя; истории нет — заведи её по ходу этого прохода.
3. Пройди разделы создания по порядку, начиная с «Цели и контекста»
   (`goal-context.md`), с одной заменой: Уникальный контекст и Цель
   пользователя не спрашивай, а предложи сам — из прочитанного скила и его
   истории — и обсуди с пользователем.
4. Из подтверждённой цели выстрой остальные разделы маршрутом создания.
   - Старые указания переноси абстрагированием:
     1. Выпиши несущие указания тела и references плоским списком.
     2. Сгруппируй их по цели.
     3. Выведи каждой группе инструкцию высшего порядка; частность снимай,
        только если агент с чистым окном выведет её из общего.
5. Сверь новый набор с прежним смыслом и функцией: потерянного нет.

- Модель умеет весь скил целиком — предложи пользователю снять скил: снятие —
  лучший исход.
- Наблюдаемый сбой скила совпал с известным — прочитай
  `refactor-failures.md`.
- Перед собственной сдачей прочитай `refactor-check.md`.

- Выход: перекроенный черновик в папке-истории + таблица объединений (какая
  высшая инструкция что поглотила, что осталось явным) — с ними иди в
  «Проверку и утверждение».
