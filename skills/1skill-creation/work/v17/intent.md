# Стадия намерения — v17

## Шаг 1 · Функция по FAST

**Основная функция:** программировать поведение агента.
Вспомогательные: добыть намерение владельца · отобрать инструкции · проверить ·
установить. Момент вызова: скил надо создать, переработать или починить его имя,
`description`, момент вызова.

Наблюдение: функция не изменилась с v10. Изменилось то, что Цель её не выражала.

## Шаг 2 · Подъём по «зачем» (Action Identification)

| Строка Цели v16 | Подъём | Состояние мира |
| --- | --- | --- |
| «выражает поведение… **чёткой понятной целью**» | зачем чёткая цель? → чтобы агент выбрал нужное поведение → зачем? → чтобы он вёл себя так, как хочет пользователь | агент, вызвавший скил, ведёт себя так, как хочет пользователь |
| «текст не противоречит себе, не дублируется, однозначно понятен» | зачем? → чтобы разделы не отменяли друг друга и агент не выбирал между ними | разделы держат направление вместе |
| «не перегружает контекст» | уже состояние | без изменений |

**Результат подъёма:** «чёткой понятной целью» — способ, вросший в цель; снят,
его состояние поднято. Тип по KAOS: строки 1 и 2 — **Maintain**, строка 3 —
**Avoid**. Ни одна не Achieve: все три обязаны быть истинны в каждой будущей
версии скила, а записаны были как однократное достижение.

## Шаг 3 · Препятствия отрицанием цели (obstacle analysis)

Отрицаю цель 1 «агент ведёт себя как хочет пользователь, дешёвого способа
объявить это сделанным нет» у самой конкретной формулировки:

| Препятствие | Контрмера |
| --- | --- |
| O1 · намерение сочинил агент — цель звучит верно, но она не пользователя | критерий 2 |
| O2 · намерение не порождает поведение, его тянут инструкции | критерий 1 |
| O3 · выполнение инструкции объявлено пересказом | критерий 3 |
| O4 · свойство достигнуто опустошением, а не переписыванием | критерий 4 |
| O5 · скил не доходит до своего момента: не установлен либо не вызывается | критерий 5 |

Пять препятствий — пять критериев, ровно предел. O5 несёт две контрмеры на одно
препятствие: неустановленный и неверно названный скил одинаково не срабатывают.
