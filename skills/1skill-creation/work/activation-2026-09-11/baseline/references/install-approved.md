# Установка утверждённой версии

## Контекст

Пользователь утвердил конкретную версию. В проекте может существовать tracked
owner с проекциями либо только установленный пакет; это разные схемы владения.

## Задача

Доставь утверждённую версию в предназначенные для неё среды.

## Цель

Сохраняй одну правду пакета и точность доставки; удобство копирования не
оправдывает создание второго владельца или установку другого текста.

## Когда определяешь место записи

Применимо до изменения пакета; выход — установленный владелец.

- Найди владельца по принятому в проекте реестру пакетов.
- Если tracked owner существует, запись начинается с него.
- Если tracked owner отсутствует, не создавай второй source tree.

## Когда владелец известен

Применимо к утверждённой версии; выход — записанные файлы нужных сред.

1. Запиши утверждённую версию во владельца.
2. Синхронизируй существующие проекции.
3. Установи эту версию в предназначенные для неё среды.

## Когда файлы доставлены

Применимо после записи; выход — подтверждённая доставка либо конкретное расхождение.

- Проверь состав и содержимое установленных пакетов против утверждённой версии.
- Проверь существование всех внутренних ссылок в установленных пакетах.

## Когда сообщаешь о результате

Применимо после проверки доставки; выход — понятная пользователю сдача.

- Дай прямые ссылки на установленный скил и связанные reference-файлы.
- Назови выполненную функцию, решения по существенным находкам, снятое
  с причиной и остаточные риски.
- Среду, в которую версия не доставлена, назови явно.

Выход: одна утверждённая версия у владельца и во всех заявленных средах.
