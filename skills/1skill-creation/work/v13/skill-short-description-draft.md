# Кнопка запуска

Вход: пишутся или чинятся имя и `description`; скил не вызывается, вызывается
слишком рано или сталкивается с соседом.

Тело недоступно до выбора скила. Имя и `description` — вся поверхность запуска;
всё «когда использовать» живёт здесь и не дублируется в теле.

## Порядок

1. Сформулируй кандидат по форме: `Use when <наблюдаемый момент> требует
   <конкретную функцию>. <Ближайшая граница, только при реальной коллизии>.`
2. Выбери имя по операции или моменту, а не по общей теме.
3. Проверь trigger голой фразой пользователя в 5–10 слов: use вызывает этот скил,
   skip не вызывает, near-miss выбирает соседа.
4. Для позднего момента повтори trigger-проверку до и после его наблюдаемого
   признака.

## Условия для `description`

- Называй наблюдаемое состояние задачи, а не широкую тему или предполагаемые
  слова пользователя.
- Для позднего момента различи состояние до и после его наблюдаемого признака.
- Ставь состояние и функцию в первую фразу.
- Пиши `description` по-английски.
- Удерживай `description` и короткие аннотации к references либо соседям в
  пределах 200 символов.
- Не переноси в `description` инструкции тела или сведения о владельце.
- Удали фразу, если она не меняет решение **use now · not yet · neighbor**.

Выход: изменённые имя и `description`, представительные use, skip и near-miss.
