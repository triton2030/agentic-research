# Установка утверждённой версии

Вход: пользователь безусловно утвердил точную проверенную версию, и после его
ответа она не менялась.

1. Найди владельца пакета по реестру владельцев `skills/shared/README.md` в репо
   `agentic-research`.
2. Если tracked owner существует, сначала запиши утверждённую версию туда.
3. Синхронизируй проекции существующего tracked owner.
4. Если tracked owner отсутствует, не создавай второй source tree.
5. Установи ту же неизменённую версию в живые пакеты сред, для которых она
   предназначена.
6. Проверь совпадение состава и содержимого установленных пакетов с утверждённой
   версией.
7. Проверь существование всех внутренних ссылок установленных пакетов.
8. Покажи в чате прямые ссылки на установленный скил и каждый его
   reference-файл.
9. В сдаче назови функцию словами пользователя, находки двух проверяющих, свои
   решения по ним, снятое с причиной и остаточные риски.

Выход: одинаковая утверждённая версия в owner-пакете и его проекциях, либо явно
названная среда, в которую она не установлена.
