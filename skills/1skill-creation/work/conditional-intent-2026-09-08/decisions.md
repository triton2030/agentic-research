| Изменение | Основание | Проверка, способная опровергнуть |

| Критерии — остаточные уникальные уточнения | #L17 | Случай, где Контекст и Задача достаточны: критерии не сочиняются ради шаблона |
| Цель — высшее намерение и тайбрейкер, допустима повелительная форма | #L17 и утверждённое тело | Случай конфликта способов; существенное условие не снимается ради удобства |
| До семи активируемых наборов знаний/инструкций | #L15–17 | Проверка не только маркеров, но и самостоятельных элементов; пересечения учитываются |

| Новый путь между стадиями | Утверждённое тело сняло старый нумерованный router | Все переходы refactor.md указывают на существующие условные разделы |
| Review prompts применяют тот же метод | Необходимая сопутствующая работа | Проверяющий не требует старый порядок, обязательные критерии или Цель только как состояние |

Сохранены: источники намерения, Function Analysis / FAST, Action Identification,
KAOS для различения однократного и поддерживаемого результата, Minimal Critical
Specification, отбор пользовательского протокола, существующий механизм перед
дополнительной инструкцией, TWI для необходимого порядка, наблюдаемое evidence,
две независимые роли, предел двух волн, loss map, один owner и точная доставка.

Сняты по новому решению: обязательное название Зачем, старый порядок разделов,
запрет повелительной Цели, ориентир 500 символов для описания мира, производство
критериев из одной верхней Цели и ориентир пяти критериев. Полный негативный
анализ результата сохранён как поиск остаточной лазейки в Контексте и Задаче.
Семь и максимальная длина строки не становятся научными утверждениями.

Прямые адреса текущего репозитория убраны из изменяемых global references.
Вызов всего скила через description отделён от внутренних условий активации:
старое «всё когда использовать только в description» противоречило бы новому телу.

В самом теле оставлен один критерий: правило 7 × 7 невыводимо из описанного
мира и общего задания. Лазейка без него — перенос прежнего плоского перегруза
в новый текст; самостоятельное активируемое знание тоже занимает место.
Остальные прежние защитные смыслы перенесены в соответствующие условные случаи.
