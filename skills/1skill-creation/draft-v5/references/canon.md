# Канон методик

Момент: сдача скила или свода инструкций. Владелец блока — этот файл;
соседние скилы держат только строку-обязанность и адрес сюда.

- Имя методики — указатель, а не процедура.
- Голый ярлык запрещён: имя без процитированного пункта не является
  применением.

| Методика | Что она задаёт |
| --- | --- |
| Minimalism (Carroll) | состав от реальной задачи; починка ошибки дешевле запрета |
| Cognitive Load Theory (Sweller) | redundancy, split-attention, expertise reversal |
| Checklist Manifesto (Gawande) | killer items; pause point; read-do против do-confirm |
| TWI Job Instruction | причина при ключевом пункте, не при каждом |
| Грайс, максима количества | информация = сюрприз; известное агенту не пишется |
| Commander's intent | цель вместо способа |

Законная компактная форма применения:

`когда <наблюдаемый триггер> — примени <точное имя метода>; оставь <наблюдаемый
след>; остановись при <критерии>`

След и стоп в этой форме и есть проверка применения. При local deviation,
execution-critical параметрах, recovery или обязательном порядке имя не
заменяет минимальный SOP.

- Локальное отклонение от канона пишется явно.
