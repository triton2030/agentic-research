# Кнопка запуска

Вход: скил не вызывается, вызывается не в свой момент, сталкивается с соседом
— или пишутся имя и описание нового скила.

Тело скила недоступно модели до срабатывания: скил с плохим описанием не
существует, каким бы ни было тело.

- Держи лимит 200 символов: короткое описание скила и каждая строка-аннотация
  в теле — указатель на референс или соседний скил — не превышают его; не
  влезло — режь фон, а не условие вызова.

1. Пишется или чинится имя либо описание — прочитай `description.md`.
2. Проверь без подсказок: голая фраза пользователя в 5–10 слов, без имени
   скила, поднимает именно этот скил; близкий по словам, но другой по нужде
   запрос — не поднимает.

- Выход: для нового скила — вернись в маршрут создания; для живого — дальше
  «Проверка и утверждение»; изменённые имя и описание, представительные use и
  skip, проверенные near-miss — в чате.
