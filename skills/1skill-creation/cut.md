# Cut — 1skill-creation

2026-08-26, при переписывании из `1skill-authoring` («уберем все, что там до
этого было» — слова владельца):

- Протокол «дефицит и класс → триада цель/выполненность/не-цель → пакеты
  behavior/knowledge» — снят целиком; функция закрепляется словами
  пользователя без классовой машинерии. Различие «когнитивный протокол или
  знание» осталось одним упоминанием в origin, не веткой протокола.
- `interview.md`, `behavior-package.md`, `knowledge-package.md`,
  `reference.md`, `audit.md` — сняты как файлы; выжившие смыслы переехали:
  «налог на строгость» и «что инструкция отменяет» → `agent-defaults.md`;
  «владелец истины снаружи», деление тело/references, признаки готовности →
  `skills-science.md`; расплывчатое → стоп-условие и причина против дефолта →
  `formulation.md`/`agent-defaults.md`. Остальное (степени свободы списком,
  «шаг или постусловие» как отдельный разбор, двухчастная типология references,
  бюджет «~10 обязанностей») не перенесено: владелец поднял бюджет до мягких
  ~20 и просил протокол короткий и чёткий, без жёстких правил.
- `canon.md` перенесён без правок: на него ссылаются сдачи всех четырёх
  соседей семьи.
- Порог «больше десяти инструкций — делить на скилы» из первой диктовки снят
  самим владельцем в той же сессии («давай увеличим все-таки, не больше 20
  единиц») — в тело вошли только мягкие ~20.

2026-08-26, после вердиктов пары субагентов — отклонённые кандидаты сокращения
с причиной:

- «Агент мощный…», «скил из собственной базы бесполезен», «запрограммированное
  поведение ровно так, как хочет пользователь», «идеал — одно предложение» —
  прямые слова владельца, заказанные им для раздела Контекст; дублем не
  считаются.
- Нефейкуемый след («цитата из середины файла») в теле — владелец явно велел
  сказать об этом в обоих мета-скилах; копия у agent-defaults остаётся
  evidence-обоснованием.
- «имя без пункта — не применение» в Завершении — семейная строка всех пяти
  скилов; локальное снятие сломало бы симметрию (кандидат для отдельного
  семейного прохода).
- Тело — 22 единицы при мягком бюджете ~20: владелец задал бюджет как
  нестрогий; сверхлимитные единицы — его собственные формулировки.

2026-08-26, после пары субагентов по правилу разбора-в-чат:

  все три части — прямые слова владельца (raw L25).
- «Открытый побег — либо закрой, либо назови риском» не добавлено отдельной
