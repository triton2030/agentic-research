# Cut

- Reviving the deleted Gemini MCP: official `agy` already owns headless JSON,
  resume, models, permissions, and account authentication.
- OAuth extraction or private backend calls: outside the official binary
  boundary and incompatible with the terms-risk decision.
- Silent Gemini API, Vertex, or SDK fallback: different authentication,
  billing, quota, and privacy surface.
- Folder and batch upload: one explicitly named media file prevents accidental
  disclosure and is enough for the current archive workflow.
- Persistent health state, tmux, run logs, Node server, and model roster cache:
  no current decision requires them.
- Direct native audio delivery: official support exists, but repeated 2026-08-27
  WAV runs terminated while an equivalent MP4 carrier completed. Avoid a
  second-call fallback; use one disclosed carrier call so uncertain runs are
  never retried.
- Project mutation and nested Antigravity agents: the product is an external
  advisor, not a second autonomous implementer.
