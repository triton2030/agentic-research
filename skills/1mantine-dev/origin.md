# Происхождение функции — 1mantine-dev

## Восстановленная функция

Скилл вмешивается в момент реализации или проверки Mantine UI, когда сильный
generic React/CSS prior агента может обойти уже существующий публичный механизм
Mantine либо применить устаревший API.

Результат вмешательства: агент сверяется с текущей официальной документацией,
начинает с самого высокоуровневого подходящего компонента, hook, form-механизма,
manager или Styles API и оставляет читаемый локальный custom-код только там,
где Mantine повышает совокупную сложность.

## Commander's intent

### Уникальный контекст

Generic React/CSS prior агента может обойти существующий public-механизм Mantine
или применить API другой версии.

### Цели

Получать соответствующую текущей официальной документации Mantine реализацию,
которая полно использует релевантные public-компоненты и возможности, сокращает
объём кода и остаётся понятной для изменения.

Mantine не самоцель: читаемый локальный custom допустим только когда
public-механизм повышает совокупную сложность.
