# Контракт моста — открывать перед составлением `--tasks`

| Факт | Дословно |
|---|---|
| `--tasks` ждёт голый JSON-массив | `Expected a non-empty JSON array of tasks` |
| `files` обязателен и непустой даже для read-only аудита | `files is required and must be a non-empty list` |
| В `files` нельзя класть директорию | `files entry points to a directory: …` |
| Новый файл воркера требует `"allow_create": true` | `file does not exist (use allow_create=true)` |
| `--dry-run` создаёт run-dir, боевой прогон в него не пишет | `Run dir already exists` |
| Материал аудитору — инлайном в промпт | worktree не видит untracked и ignored файлы основного дерева |
| Сырой `events.jsonl` не читать | `codex_progress.py "$RUN_DIR"` → `stalest`, `idle_sec` |
| Счёт живых прогонов | `ps -eo command= \| grep -c 'codex_orchestrate\.py --tasks'` |
| Перед сносом ветки | `git merge-base --is-ancestor <ветка> main` |
| `node_modules/` в `.gitignore` не матчит симлинк | `echo node_modules >> .git/info/exclude` |
| Заголовок `> [!note]- Отчёт` зарезервирован `scripts/check-map.py:47` | свою заметку называй иначе |
| PostgreSQL в песочнице прогона не поднимается | `shmget … Operation not permitted` — граница среды, не дефект |
| `chat_capture.py --session` | полный канонический UUID |
| macOS: `timeout` нет; `cd` не переживает вызов | абсолютный путь первой командой |
| Уборка IPC | `ipcs -mo \| awk '$1=="m" && $7+0==0 {print $2}' \| xargs -n1 ipcrm -m` |
