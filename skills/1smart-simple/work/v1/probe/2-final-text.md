# Оркестратору флота

Founder: «о таких всяких мудростях и важных находках и советах будущему себе
лучше помнить а значить стоит записать отдельным файлом».

**Цель:** ни один круг флота не теряется из-за того, что ты поверил журналу,
отчёту, счётчику или своей уверенности вместо прибора. Журнал фиксирует
запрос, не исход; отчёт воркера — слова, не дерево; уверенность при
неоткрытом первичном источнике — сигнал открыть файл.

1. **Перед платным или необратимым шагом проверяй состояние прибором.**
   `interrupt_requested` не убивает процесс — `ps -o stat=`, потом `kill`;
   `nohup … &` возвращает 0 до старта — смотри, растёт ли `events.jsonl`;
   нет `result.json` — работа может лежать целиком в
   `~/.codex-bridge/worktrees/<run>/<task>`; красный PostgreSQL — сначала
   `ipcs -mo` (32 сегмента на хост, NATTCH — седьмая колонка).
2. **Принимай по `git status --porcelain` интегрированного дерева**, не по
   diff и не по числу коммитов: воркеры не коммитят, новые файлы untracked.
3. **Называя прибор, называй условия его запуска:** зависимости — в worktree
   нет `node_modules`; файлы шва — в allowlist; способ красной мутации —
   копия вне дерева, мутация в продуктовый файл, не в помощник теста.
   Аудитора сажай на интегрированное дерево.
4. **После волны прогоняй полный набор сам** и в поручении называй, что могло
   сломаться от класса правки: зелёные зоны не складываются в зелёный проект
   (миграции ломают жёсткие списки, правка байтов движка отзывает допуск
   каталога).
5. **Перед волной с тёплыми тредами:**
   `codex_threads.py unarchive <THREAD_ID> --project <корень>` на каждый —
   закрытие волны их архивирует, `codex` CLI на хосте нет.
6. **Дефект в двух зонах — твой промпт** (Деминг); три ракурса одной зоны —
   одна причина. Считай зоны, не отчёты.
7. **Пересечения считай по контрактам, не по файлам,** и называй соседу его
   красный как возможный артефакт изоляции. Allowlist выводи из поля
   «граница», не из того, что работа тронет.
8. **Знание доходит до воркера только адресом в поручении;** отчёт решений он
   не читает. Нужен файл вне зоны — пусть назовёт путь и команду, не создаёт
   молча.

Перед составлением `--tasks` открой `МОСТ-КОНТРАКТ.md` рядом с этим файлом:
там дословно формат задач, поля `files`/`allow_create`, что делает
`--dry-run`, заголовок, зарезервированный `check-map.py`, и правило
`.gitignore` для `node_modules`.

ожидал.
