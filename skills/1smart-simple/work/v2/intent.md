## Препятствия (отрицание цели) → критерии

1. Сокращение внутри структуры под именем порождения → критерий 1.
2. Тихая потеря блока → критерий 2.
3. Деление по теме, а не по моменту: файлы читаются вместе, удержание не
   снизилось (новое, из режима разделения) → критерий 3.
4. Невыводимый факт заменён советом → критерий 4.
5. Счёт обойдён группировкой или по символам → критерий 5.
6. Замена без «да» → шаг 5: гейт до необратимого действия, критерий конечного
   состояния до замены не срабатывает.
7. Предел заполнен фактами раньше правил; перенос без условия открытия —
   `work/v1/intent.md` препятствия 6–7 → хвосты критериев 1 и 3.
Тип целей по KAOS: Achieve (замена) и Maintain (архив держится по адресу).
