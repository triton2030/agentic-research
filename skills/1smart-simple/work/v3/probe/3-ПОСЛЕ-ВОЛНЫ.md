# После волны — приёмка и уборка

Приёмка:
- Новые файлы воркера untracked, `git diff` их не показывает: сверяй
  `git status --porcelain`, иначе аудитор судит неполную работу.
- Воркер, упёршийся в узкую зону, оставляет алиас на старое имя — снимай его
  явным пунктом ремонтного круга.
- `node_modules` симлинком на главное дерево: `.gitignore` `node_modules/`
  матчит только директорию, симлинк выходит untracked и снимает приёмку;
  изоляция при этом протекает. Лечение без остановки агента:
  `echo node_modules >> .git/info/exclude`. Проверяй деревья `ls -ld` во время
  прогона, а зелёные приборы без зависимостей в дереве перепроверяй своим
  прогоном после интеграции.
- Смена identity движка (content-addressed ref) отзывает допуск каталога:
  ремонт — повторный допуск (live-запись, прежняя в `retired-retained`),
  прецеденты `ed69a18a`, `33b49d8b`; отставший ref ищи так:
  `grep -rl 'render-engine@' apps packages --include='*.json' --include='*.mjs' --include='*.ts' | xargs grep -l -v '<живой ref>'`.
  Ловушки — места, где сходятся замороженное и живое (фикстуры двух поколений);
  зелёный привратник допуска при красном потребителе — подпись этого дефекта.
- Слабый фальсификатор: под мутацией время прогона вырастает на порядок и
  тест падает по таймауту. К паре exit `0 → 1 → 0` добавляй время.

Уборка:
- Мост умер — работа воркера цела в `~/.codex-bridge/worktrees/<run>/<task>`:
  `git worktree list | grep codex-bridge`, забери файл, потом снимай дерево.
- `interrupt_requested` процесс не завершает: `ps -o stat=`, `kill`, затем
  `git worktree list` и `git branch --list 'codex-fleet/*'`. Процессы считай
  только `ps -eo command= | grep -c 'codex_orchestrate\.py --tasks'`. Перед
  сносом ветки — `git merge-base --is-ancestor <ветка> main`. Под
  `~/.codex/worktreesered` — деревья Codex Desktop, не трогать.
- Уборка — отдельной командой после `git show HEAD --stat` с файлами работы;
  `git branch --list` помечает занятую ветку `+`, текущую `*` — снимай оба.
  При `scope_status: failed` мост не сливает: `git show <ветка>:<файл>`, затем
  `git merge --no-ff`.
