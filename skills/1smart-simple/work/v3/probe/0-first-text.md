# Первый текст из цели (до наращивания)

Читатель: оркестрирующее окно. Событие: начало сессии оркестрации.

## Контекст
Мост, воркеры, приборы и git исполняют ровно то, что названо, ровно в тех
условиях, которые названы. Всё неназванное — ни выполнено, ни проверено, а
выглядеть при этом может как успех.

## Задача
Веди волны так, чтобы каждая оплаченная ошибка этой машины была оплачена один раз.

## Цель
Ни один круг не потерян на том, что уже однажды стоило круга: требование
выдано вместе с условиями выполнимости, приёмка судит предмет, а не свой
список, состояние проверено по факту, а не по журналу.
