# Умное упрощение

## Уникальный контекст

Читатель текста — агент. В точке действия он удерживает не больше восьми
обязательств и теряет лишние в случайном порядке; знание пределу не
подчиняется — факт открывают в момент нужды, а не держат в голове.
Модель-редактор по умолчанию сжимает формулировки внутри структуры оригинала и
режет заметное вместо лишнего. Понятая цель текста разрешает сменить жанр:
сотню описанных находок или длинную процедуру заменяют несколько принципов —
как выводить нужное самому и когда это правило применять.

## Задача

Возьми один текст и назови, какой агент после какого события его читает.
Оставь в точке входа новый текст, который читатель удержит целиком; оригинал
перенеси в архив и запиши владельцу его адрес.

## Цель

Каждый файл, который открывает читатель, служит одной цели после одного
события и несёт не больше восьми обязательств; функция оригинала из этих
файлов выводима; каждая потеря названа владельцу до замены.

## Принципы

- Переписывание, не сокращение. Способ владельца дословно: «удалить всё и все
  сотни строк заменить одной целью и уже потом наращивать цель так чтобы она
  была ближе к оригиналу». Порядок «сначала из цели, потом из оригинала» — след
  того, что текст порождён, а не урезан.
- Момент чтения важнее темы. Разные события — разные файлы; переход в другой
  файл — тоже обязательство и входит в счёт. Имя и дом файла — по
  `1document-system`: у каждого вопроса один дом.
- Невыводимое — дословно. Решение владельца, контракт инструмента, число,
  адрес, цитата стоят в файле своего момента; пересказанное evidence перестаёт
  быть evidence.
- Потеря — только явная. Каждый блок оригинала получает судьбу: остался ·
  перенесён в файл момента · свёрнут в правило вывода с условием применения ·
  потерян и хранится в архиве.
- След в чате. Владелец не видит мышления, поэтому каждый метод озвучен в чате
  одной строкой «имя → что увидел», а первый текст из цели показан до того,
  как начато наращивание; пропущенная строка — непройденный метод.
- Одна остановка. Точный текст каждого файла показан владельцу целиком; после
  «да» — замена и архив, и больше ни одной правки.

## Методы, по порядку

1. **Function Analysis / FAST** — функция оригинала одним глаголом и одним
   существительным.
2. **Action Identification** (Vallacher & Wegner, 1987) — подъём по «зачем» до
   governing thought по **Pyramid Principle** (Minto); выше не подниматься —
   более общая цель ничего не порождает. Подъём даёт несколько целей или
   событий — это несколько файлов, каждый с шага 1.
3. **Commander's Intent** — первый текст из одной цели в форме контекст →
   задача → цель → критерии. Жанр нового текста выбирает момент читателя, а
   не жанр оригинала: что должно стать правдой — цель и критерии; как
   поступать в повторяющихся ситуациях — **принципы по Далио**, «ещё один из
   таких»: ситуация такого рода → действие → причина, и принцип покрывает
   все будущие случаи класса, поэтому ни один прошлый случай в текст не
   входит; процедура — только там, где порядок сам является фактом и чистый
   агент его не выведет.
4. **Лестница абстракции** (Hayakawa) — наращивание от оригинала до предела:
   условия, невыводимые факты, принцип вместо серии случаев, пример последним.
   Упёрся в предел — ищи событие для второго файла; сверх восьми только там,
   где второй файл запрещает схема дома или решение владельца.
