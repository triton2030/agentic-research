# Цель — Корзина

## Контекст

Покупатель пришёл по ссылке своей студии и уже настроил вещь на странице товара. Он не хочет регистрироваться и не хочет ничего объяснять: конкурент — мессенджер, где всё это делается за два сообщения. Каждый лишний шаг здесь работает против студии, а не против MAVO. Деньги и доставка его со студией не касаются: об этом они договорятся в переписке.

## Цель

Покупатель за один шаг превращает настроенную вещь в заявку студии и уходит с вечной ссылкой на неё, не оставив ни телефона, ни адреса.

## Критерии принятия

- Заявка отправляется без регистрации и без полей контакта.
- Одна отправка — одна заявка одной студии, с любым числом позиций.
- До отправки покупатель видит полную цену студии по каждой позиции.
- Отправленная заявка доступна по ссылке, которую нельзя угадать.
- Оплаты внутри MAVO нет.
- Аккаунт покупателя не строим.
