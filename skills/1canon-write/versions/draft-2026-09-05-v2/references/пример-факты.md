# Факты — Деньги

## Контекст

Единицы и события, по которым MAVO берёт деньги со студии. Их не выводят из принципов — их назначил Founder. Читают витрина, кабинет и админка.

## Факты

| Факт | Значение |
|---|---|
| Кто платит MAVO | только студия |
| Платное событие | принятие заявки целиком |
| Единица списания | дизайн внутри заявки; тираж одинаковых — одно |
| Чем платит студия | предоплаченные кредиты |
| Стартовые кредиты | нет |
| Деньги покупателя через MAVO | нет |
| Карта при регистрации | нет |
| Premium | отдельный счётчик, не подписка |
