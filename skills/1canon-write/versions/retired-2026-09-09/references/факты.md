# Написание фактов

Вход: утверждённые значения и определения, выбранный дом.
Выход: файл «Факты — предмет» с разделом «Контекст» и разделом «Факты», где
каждый факт — заголовок третьего уровня со значением под ним.

## Задача

Зафиксируй назначенные владельцем значения так, чтобы читатель применял
решение, а не выводил собственное.

## Цель

У связанных ролей одинаковое понимание значения, единицы и области
применения каждого факта.

## Зачем

Принципы не определяют конкретную цену или единицу списания. Если раздел
не отделяет назначенное от вычисленного, следующий агент может пересчитать
величину и незаметно заменить коммерческое решение.

## Форма смысла

- Контекст фактов — дельта о том, почему значения назначены, а не выведены:
  что владелец видит и чего читатель не знает. Область применения пишется,
  только если её не выдают имя файла и дом.
- «Утверждено владельцем» и фраза-заполнитель не пишутся: утверждённость
  следует из нахождения файла в `_canon`, обоснование приходит со входом, и
  уверенная формулировка его не создаёт; нет дельты — вопрос владельцу.
- Один заголовок — один факт с областью применения, значение под ним;
  числовое значение имеет единицу измерения, иначе одинаковое число допускает
  разные решения. Заголовки вместо таблицы выбрал владелец: по таблице
  агенту труднее искать факт.
- Уточнение заменяет действующее значение после разрешения противоречия,
  а не добавляет рядом старую и новую версии. История значений не становится
  ещё одним источником текущей цены.

Отдельный файл предназначен нескольким читателям — ролям или поверхностям.
Факт одного читателя сохраняется в его цели, чтобы два файла не стали
конкурирующими ответами на один вопрос.

## Пример формы

Учебный пример назначения значений; не источник коммерческих решений проекта.

```markdown
---
description: "Плательщик, платное событие и единица расчётов платформы."
aliases: []
---
# Факты — Деньги

## Контекст

Кредит студия покупает заранее, а цена одного принятия из принципов не
выводится, поэтому значения назначены и одинаковы для витрины, кабинета
студии и админки.

## Факты

### Кто платит платформе
Студия.

### Платное событие
Принятие заявки целиком.

### Средство расчёта
Предоплаченные кредиты.

### Стартовые кредиты
0 кредитов.

### Деньги покупателя через платформу
Не проходят.
```
