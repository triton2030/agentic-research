# Написание фактов

Вход: утверждённые значения и определения, выбранный дом.
Выход: файл «Факты — предмет» с разделом «Контекст» и таблицей
«Факт | Значение» в разделе «Факты».

## Задача

Зафиксируй назначенные владельцем значения так, чтобы читатель применял
решение, а не выводил собственное.

## Цель

У связанных ролей одинаковое понимание значения, единицы и области
применения каждого факта.

## Зачем

Принципы не определяют конкретную цену или единицу списания. Если таблица
не отделяет назначенное от вычисленного, следующий агент может пересчитать
величину и незаметно заменить коммерческое решение.

## Форма смысла

- Контекст называет предмет, читающие роли и то, что значения утверждены
  владельцем. Обоснование утверждённости приходит со входом; уверенная
  формулировка контекста его не создаёт.
- Одна строка содержит один факт с областью применения; числовое значение
  имеет единицу измерения, иначе одинаковое число допускает разные решения.
- Уточнение заменяет действующее значение после разрешения противоречия,
  а не добавляет рядом старую и новую версии. История таблицы не становится
  ещё одним источником текущей цены.

Отдельный файл предназначен нескольким ролям. Факт одной роли сохраняется
в её цели, чтобы два файла не стали конкурирующими ответами на один вопрос.

## Пример формы

Учебный пример назначения значений; не источник коммерческих решений проекта.

```markdown
# Факты — Деньги

## Контекст

Владелец назначил следующие правила расчётов. Их одинаково используют
витрина, кабинет студии и админка.

## Факты

| Факт | Значение |
|---|---|
| Кто платит платформе | Студия |
| Платное событие | Принятие заявки целиком |
| Средство расчёта | Предоплаченные кредиты |
| Стартовые кредиты | 0 кредитов |
| Деньги покупателя через платформу | Не проходят |
```
