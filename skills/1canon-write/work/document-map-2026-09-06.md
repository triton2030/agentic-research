# Метаданные и карта канона

Основание: `_ops/chat-recall/2026-09-05-210608-codex-01a07250.md#L20`.
Владелец заказал общий скрипт и метаданные в обоих скилах.

Адресная доработка установленной v4: YAML description и aliases, связь
алиасов с цитатами и кодом, команда карты и обновлённые примеры всех трёх
видов документов и первой инструкции канона. Метаданные входят в прежний
предел 2000 символов; имена реализации разрешены только как поисковые
подсказки в aliases, не как новые продуктовые требования. Запрет ссылок,
истории и цитат сохраняется для тела документа.

Общий код принадлежит 1docs-write; установленный пакет канона получает
полную копию. Решения, фальсификаторы, тесты и ограничения:
[общая запись](../../1docs-write/work/document-map-2026-09-06.md).
Снятых продуктовых обязательств нет. Примеры используют aliases: [],
поскольку учебный пример не имеет реальных цитат и кода для их подтверждения.
