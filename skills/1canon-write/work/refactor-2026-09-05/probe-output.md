# Результат учебного переноса

Это один демонстрационный прогон по полному корпусу из задания. Настоящий
канон не менялся; статусы источников не дополнены внешней историей.

## Выбранное место

`_canon/Покупатель/Витрина/Цель — Заявка.md` — существующий пустой дом для
итогового состояния покупателя при подаче заявки. Область проверки — всё
дерево учебного корпуса: этот файл и соседний сценарий компании. Пустота
подходящего файла не требует нового дома. Сценарий компании описывает момент
доступа студии к печатным файлам и не заменяет цель покупателя.

## Текст цели

```markdown
# Цель — Заявка

## Контекст

Студия и покупатель обсуждают оплату и выдачу в переписке. Платформа не
участвует в расчётах между ними.

## Цель

Покупатель отправляет заявку одной выбранной студии без регистрации и
передачи контактов и сохраняет доступ к ней по постоянной ссылке.

## Критерии принятия

- Полная цена каждой позиции видна до отправки заявки.
- Ссылку доступа к заявке нельзя угадать.
```

## Конфликт с предложением

`_canon/Компания/Сценарий — Принятие.md:1` допускает доступ к печатным файлам
только при принятии заявки. `NEW.md:1` предлагает доступ уже при поступлении,
то есть раньше указанного события. Это изменение прав доступа, а удобство
само по себе не подтверждает разрешение владельца.

Предложение: оставить соседний сценарий без правки и не включать ранний
доступ в цель заявки; перед изменением получить решение владельца о моменте
открытия печатных файлов. Вопрос для решения: должны ли файлы открываться
студии при поступлении заявки или только при её принятии? Подтверждение
утверждённости прежнего условия также отсутствует в данном корпусе.

Неподтверждённое списание 5 кредитов не объявлено прямым противоречием
`owner.md:1`: участие платформы в расчётах студии с покупателем и отдельное
кредитное списание не тождественны без дополнительных оснований. Вопрос
о существовании такого списания остаётся открытым; для подготовленной цели
он не заполнен догадкой.

## Проверка результата

- У цели три раздела: контекст, итоговое состояние и два наблюдаемых критерия.
- Все утверждённые продуктовые условия `owner.md:1–3` имеют покрывающие места.
- Дешёвые детали `owner.md:4` оставлены исполнителю без выдуманных значений.
- Ни 5 кредитов, ни ранний доступ к печатным файлам не стали правилом цели.
- Источники, статусы и история обработки находятся за пределами текста цели.
- Проверен только единичный перенос этого учебного корпуса; надёжность
  скилов на других входах этим результатом не установлена.
