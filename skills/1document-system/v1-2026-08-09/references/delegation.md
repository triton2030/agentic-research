# Adaptive Delegation

Subagents are not a generic quality ritual; direct mode stays with the root by
default.

## Fan-out gate

Delegate only when independent evidence streams or disjoint corpus slices
exist and fan-out reduces root context or latency. The number of outputs is
not a gate.

## Staged DAG

1. Root fixes outcome, scope, mode and write boundaries.
2. First wave independently collects inventory shards (and future-scenario
   evidence when taxonomy may change).
3. Root builds the candidate type/authority map and spot-checks source
   addresses.
4. IA reviewer checks the already-proposed shape — never before evidence.
5. Root selects templates, resolves conflicts, synthesizes.
6. Metadata audit checks the already-created artifact/map.

Template selection, conflict resolution and final integration are never
delegated. Independent expert critique of an assembled architecture goes to
`1fresh-eyes`; an inventory worker must not silently become a reviewer.

## Worker return contracts

- **Inventory:** examined/uncovered scope, `path#heading`, observed purpose,
  explicit authority evidence, conflicts, gaps — no final IA verdict.
- **Future scenarios:** actor/reader, lifecycle change, information
  obligation, pressure on types/topology, evidence vs assumption, trigger.
- **IA review:** `pass/risky/fail/unknown`, owner evidence, false seams,
  smallest repair or alternative.
- **Metadata audit:** artifact path, core fields, lifecycle/authority result,
  hard edges, missing sections, not-checked.
- **Compaction verifier:** baseline claims absent from the new version and the
  named owner — quote, address, why not derivable; verdict per claim. Works
  from the pre-cut revision; never the same agent as the executor. Full
  contract → [compaction-safety](compaction-safety.md).

Give workers exact paths and minimal task-local context. Root waits for all
mandatory shards, admits uncovered scope, and never masks a conflict with
voting.
