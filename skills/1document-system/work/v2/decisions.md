# Решения допуска — 1document-system v2

Выход `behavior-protocol.md` после возврата к стадии цели. Пакет: тело
`draft/SKILL.md` (11 единиц) + `draft/references/type-selection.md` (7 единиц),
оба под лимитом 20. `name` и `description` английские по контракту
`skill-short-description.md`, 194 знака; тело русское по решению владельца.

## Что поглотила новая цель

Цель «вопрос назван в имени, отвечен полностью и больше нигде не отвечен; всё,
что ему не служит, ушло к владельцу или удалено» выводит пять прежних
инструкций. Каждая проверена вопросом: выберет ли чистый агент это поведение,
держа только контекст, задачу и цель. Шестая единица — блочный допуск — целью
не выводится: она перестала быть отдельной инструкцией, свернувшись внутрь
шага 5 как проверка на закрытии. Всего тело потеряло шесть самостоятельных
единиц, но поглощений цели — пять.

| Прежняя единица | Чем выводится |
| --- | --- |
| Найти существующий дом ответа до создания файла | «больше нигде в проекте не отвечен» нельзя выполнить без поиска |
| Разделы — список слотов, а не шаблон | Пустой слот вопросу не служит, значит не появляется |
| Уводить чужой по жанру смысл к владельцу | «ушло к своему владельцу ссылкой» |
| Бездомное содержимое вытесняется | «или удалено» — вторая развязка той же фразы |
| Сам факт вытеснения замещённого | «замещённый текст не остался рядом с тем, что его заместило» |

Не выводится и остаётся инструкцией то, что цель не называет: сделка со
стереотипом, что именно считать вытесненным, устаревание пересказов, уступка
локальному словарю, чужие семьи артефактов и переросший файл.

## Допущенные инструкции тела

| № | Дефолт агента, который чинится | Материальный вред без неё | След исполнения |
| --- | --- | --- | --- |
| 1 | Приносит свой словарь в проект, у которого есть свой | Два словаря в одном корпусе — адрес мёртв. В mavo-short2 это ветка по умолчанию | Имена и разделы нового файла совпадают с лежащими в проекте |
| 2 | Выбирает тип по наитию, не открывая методику | Нестандартный термин прайор не включает: имя выглядит типизированным и пусто | Открыт `references/type-selection.md`, возвращён термин и имя |
| 3 | Берёт у стереотипа весь пакет разом, включая объём | Возвращается раздувание, ради которого заказан рефактор | В файле нет блока, объяснимого только жанровым приличием |
| 4 | Считает вытесненным всё, что сформулировал бы иначе | Удаление живого текста владельца: границы по авторству он сам снял | Diff несёт удаления; удалено только то, на место чего встал новый текст |
| 5 | Считает работу законченной по собственному отчёту | Дрейф поздней стадии: стереотип возвращается после первых разделов | Названо действие или вопрос для каждого блока готового файла |
| A1 | Читает локальный контракт как разрешение не судить жанр | Уступка словаря забирает с собой жанровую дисциплину | Локальные имена приняты, мнения и летопись не написаны |
| A2 | Типизирует чужие артефакты, раз момент широкий | Ломаются контракты `1planning`, `1findings`, `1product-shaping`, `1instruction-authoring` | Маршрут во владеющий скил вместо правки |
| A3 | Пишет служебные семьи: они читаются как структура | Провенанс вносит летопись, summary вносит пересказ мимо блочной проверки | Названных семей нет в документе, который ими не владеет |
| A4 | Пишет в пересказе факт, которого в источнике нет | Пересказ становится второй правдой, и оба документа выглядят верными | Каждый факт найден в названном источнике |
| A5 | Считает пересказ текущим, пока файл выглядит свежим | Источник ушёл вперёд, а действуют по пересказу — он короче | Названо состояние источника на момент снятия |
| A6 | Чинит переросший файл письмом: сжимает или дописывает | 267 KB в mavo-short2 письмом не лечится, а сжатие прячет объём вместо снятия | Маршрут в `1ia-audit` вместо правки на месте |

## Допущенные инструкции `references/type-selection.md`

Вход: у проекта нет живого словаря типов и тип документа корпусом не задан.
Выход: термин типа и имя файла. Самостоятельна: выполнима по телу и этому
файлу, третьего не открывает.

| № | Дефолт агента | Вред без неё |
| --- | --- | --- |
| 1 | Выбирает тип по теме материала | Тип-однодневка под повод; типов больше, чем документов |
| 2 | Выбирает объём документации на глаз | Нет опоры для «сколько нужно стартапу»; берётся корпоративный набор |
| 3 | Изобретает точное описательное имя | Прайор не включается |
| 4 | Переводит термин на язык тела | «Техническое задание» приносит регламентный прайор вместо стартапного |
| 5 | Заводит тип, папку и скелет заранее | Пустой дом читается как приглашение заполнить ради покрытия |
| 6 | Называет файл по поводу написания | Ответ ненаходим, появляется второй файл о том же |
| 7 | Молчит о типе там, где имя задано конвенцией | `README.md` остаётся без жанра |

## Trigger-проверка

Выход `skill-short-description.md`, шаг 3. `description`:
«Use when about to write or substantially edit a project document: give it a
standard type name and hold it to what must be acted on. Not for artifacts
another skill owns, code comments, or chat.»

| Фраза | Ожидание | Результат |
| --- | --- | --- |
| «напиши спеку на новый флоу оплаты» | use | вызывает: письмо документа проекта |
| «заведи документ с правилами скидок» | use | вызывает |
| «приведи этот документ в порядок» | use | вызывает: существенная правка |
| «поправь опечатку в README» | skip | не вызывает: правка не существенная |
| «напиши сообщение коммита» | skip | не вызывает: не документ |
| «объясни в чате, как работает роутинг» | skip | не вызывает: документа нет |
| «перепиши инструкцию агентам в этой папке» | near-miss | уходит в `1instruction-authoring` фразой «artifacts another skill owns» |
| «запиши задачу по этой работе» | near-miss | уходит в `1plan-task` той же фразой |
| «раздели этот огромный документ на части» | near-miss | **вызывает этот скил**, и правило тела маршрутизирует в `1ia-audit`. Осознанно: разделение требует жанровой дисциплины, поэтому граница проведена внутри, а не в `description` |

## Сознательно не допущено

| Отклонено | Причина |
| --- | --- |
| Отдельный тест «что считается живым реестром» | Свёрнут в шаг 1: сильный агент отличает действующую конвенцию от заброшенного файла сам |
| Правила регистра, тона и голоса | Следствие снятого отсутствующего читателя в Уникальном Контексте |
| Числовые бюджеты длины и счётчики разделов | Произвольны между проектами, создают добивание до числа |
| Правила расположения по папкам | Адрес — имя файла; раскладку держит проект, и шаг 1 ей уступит |
| Индекс или карта корпуса | Цель требует находить по имени; индекс протухает и становится вторым домом |
| Обязательные поля метадаты | Адрес даёт имя; живой реестр с front matter принимается шагом 1 |
| `derived-from` и `depends-on` как обязательная схема | Правило требует источника и его состояния, но не диктует носитель |
| Форматирование Markdown | Очевидно передовой модели и принадлежит проекту |
| Как писать хорошо внутри жанра | Это стереотип даёт бесплатно; повтор возвращает корпоративный шаблон |
| Цикл ревью готового документа | Момент вызова — письмо; протокол приёмки удвоил бы пакет |
| Правило «слишком коротко» | Владелец жалуется на раздувание, а не на худобу |

## Язык пакета

«И пиши скил на русском» (`#L24`) отменяет решение от 2026-08-09: его
основание — английские термины корпоративных типов — отпало вместе с каталогом.
Английскими остаются `name` и `description` по контракту
`skill-short-description.md` и сам термин типа документа, потому что прайор
привязан к деловому английскому термину (записано в reference, шаг 4).
