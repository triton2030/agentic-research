# Решения допуска — 1document-system v4

Выход `behavior-protocol.md` и `reference-files.md`. Пакет — тело плюс четыре
стадии.

## Карта стадий — выход `reference-files.md`

Каждая стадия самостоятельна: выполнима по телу, одному своему файлу и
артефактам предыдущих стадий. Ни одна не запускает чтение другой — складывание
состояний держит таблица в теле.

| Стадия | Вход | Выход |
| --- | --- | --- |
| `existing-home.md` | вопрос с найденным документом-владельцем и установленный ответ | ответ стоит в доме; строки перечня по изменениям, снятиям и нерешённым расхождениям |
| `new-home.md` | вопрос без владельца в проекте и установленный ответ | новый документ; ссылка на него из уже читаемого; строки перечня |
| `derivative.md` | записываемое пересказывает правду, которой владеет другой документ | пересказ с атрибуцией; пометки на пересказах изменённого источника |
| `overgrown.md` | целевой документ несёт две работы либо заметно крупнее обычного для типа | ответ записан; работа по разделению названа и не начата |

## Бюджет обязательств — измеренный, а не заявленный

Счёт по отдельно нарушаемым условиям, той же методикой, что и разбор v3 в
`old-mechanics-map.md`.

| Файл | Критериев | Единиц протокола | Отдельно нарушаемых условий |
| --- | --- | --- | --- |
| `SKILL.md` | 5 | 2 | **18** |
| `existing-home.md` | 5 | 1 | 13 |
| `new-home.md` | 5 | 1 | 11 |
| `derivative.md` | 3 | 0 | 6 |
| `overgrown.md` | 3 | 0 | 4 |

**Одновременно активно: 18 + от 4 до 13 = 22…31** против **40** в v3.

Улучшение меньше, чем я обещал владельцу до написания (обещал 14 в теле). Причина
названа прямо: чистая комната принесла шесть обязательств, которых в v3 не было
вовсе — полнота покрытия, биекция диффа и перечня, ордер перед заменой, ссылка
ради находимости, отвергнутые кандидаты, форма строки предложения. Именно они
закрывают лазейки, через которые v3 проигрывал джину. Разгрузка и защита в этом
раунде конкурировали, и защита выиграла.

## Снятое при переписывании — не сжатие, а вывод из вышестоящего

По `reference-files.md`: свернуть единицу в правило высшего порядка можно только
вместе с переписыванием механики.

| Что снято | Почему это не потеря |
| --- | --- |
| «Адрес вида „мы обсуждали", „в этой сессии" — не успех» | Выводится из «резолвится вне этого хода»: несуществующий файл не резолвится |
| «Мнение, хроника, пересказ разговора» как три условия | Переписано одним классом: «текст жанра, которым этот документ не владеет», с теми же тремя примерами |
| «Пересказ вместо перечня — не успех» и «перечень богаче файлов — не успех» | Оба выводятся из биекции: пересказ не встаёт в биекцию, и лишний пункт перечня не имеет адреса в дифе |
| «Открывай только кандидатов» | Выводится из стоп-правила обхода |
| «Своя схема рядом со сложившейся — не успех» | Выводится из «те же, что у соседей того же класса» |
| Четыре вида обрамления как четыре условия | Переписано одним классом «обрамление» с теми же четырьмя примерами |

## Дефекты намерения — где закрыт каждый

| № | Дефект | Где закрыт |
| --- | --- | --- |
| D1 | «Две работы» × «нетронуто» | `overgrown.md`: запись идёт, разделение называется и не начинается |
| D2 | Два живых ответа без отмены | `existing-home.md`, критерий 2: выбор есть установление, уходит владельцу |
| D3 | Момент вызова × слова владельца | Цель: установленное — то, у чего проверяемый источник, включая повторимое наблюдение |
| D4 | Имя дома вводит слово | `new-home.md`, критерий 1: имя — адрес, а не утверждение |
| L1 | Выборочное покрытие | Критерий 2 тела |
| L2 | Свалка предложений | Критерий 4 тела: вопрос и два прочтения |
| L3 | Богатый перечень при тощем файле | Критерий 3 тела: биекция |
| L4 | Архивация вместо разрешения | Цель, второе предложение |
| L5 | Отмывание прежних фабрикаций | Цель (непропагация) + Уникальный Контекст (часть текста написали прошлые агенты) |
| H1 | Мандат на удаление | `existing-home.md`, критерий 1 |
| H2 | Верность терминам против читаемости | Критерий 1 тела: «узнал бы как своё» вместо «в терминах и дробности» |
| H3 | «Живые поверхности» без границы | Цель: живые документы проекта; ни код, ни артефакты чужих скилов |

Неопределённость, оставшаяся открытой: **дробность вопроса**. «Как мы пишем
документы» — один вопрос или пятьдесят; оба прочтения проходят «один вопрос —
один дом». Ни владелец, ни чистая комната границы не дали, и вывести её из цели
нельзя. Предъявляется владельцу как остаточный риск, а не закрывается догадкой.

## Препятствия для критериев стадий — выход `goal-context.md`

Каждый критерий стадии — контрмера отрицанию Цели **этой стадии**.

### `existing-home.md`

| № | Препятствие |
| --- | --- |
| 1 | Абзац снесён как «прежняя версия» вместе с исключением и причиной, которых новый текст не несёт |
| 2 | Приведение к согласованности по вкусу: увидел старое — переписал, хотя владелец его не отменял |
| 3 | Правка расползается за пределы места записи — сначала по файлу, потом по маршруту |
| 4 | Обрамление дописывается ради связности и выглядит защитимым построчно |
| 5 | Имя дома приводится к типу заодно, и ломаются все ссылки, включая ссылки-источники |

### `new-home.md`

| № | Препятствие |
| --- | --- |
| 1 | Файл кладётся в корень или в первую попавшуюся зону — «рандомный артефакт» в зонированном репо |
| 2 | Изобретённое точное имя либо имя-контейнер: жанр не виден до открытия файла |
| 3 | Дом заводится без поиска существующего, и «один вопрос — один дом» выполняется взрывом файлов |
| 4 | Файл создан и ни с чем не связан: существует, но не найден |
| 5 | Новый тип вводится вопреки гейту проекта; пустые разделы копируются из соседа ради формы |

### `derivative.md`

| № | Препятствие |
| --- | --- |
| 1 | Одна ссылка на источник без его состояния: через месяц оба документа выглядят одинаково свежими |
| 2 | Пересказ дополняется собственным выводом и становится второй правдой |
| 3 | Источник ушёл вперёд, пересказ выглядит свежим, и следующий агент действует по нему |

### `overgrown.md`

| № | Препятствие |
| --- | --- |
| 1 | Документ делится заодно с записью, потому что шов кажется очевидным |
| 2 | Строка «файл слишком большой», по которой следующий ход не начнётся |
| 3 | Дробление по заголовкам: много слабых поверхностей правды вместо одной сильной |
