# Product Frame — 1orchestration v9 candidate

## Цель-сцена

Перед поручением root восстанавливает влияющую правду, формирует один brief и
выбирает простейшую выполнимую форму для actor-ов и своей следующей точки
решения. Существующие owners сохраняют authority; зависимый ход открывает
только актуальное evidence каждого обязательного критерия.

## Граница простоты

Runtime остаётся одним `SKILL.md` без references. Поля brief — точный интерфейс
передачи; оценка выбранной формы — одно решение вместо отдельных capability,
budget и decomposition стадий; acceptance и upstream invalidation защищают от
ложного и устаревшего результата. Authoring checks остаются в history.

## Тайбрейкеры

1. Выполнимый связный набор сильнее формального числа агентов.
2. Адрес owner-а и отсутствующая `delta` сильнее пересказа канона.
3. Около `20` — сигнал риска, а не приказ делить.
4. Деление окупается только реальным уменьшением набора участника.
5. Актуальное evidence всех обязательных критериев сильнее process-report.

Это рамка candidate, а не утверждённого owner-а. Official и projections не
меняются до отдельного решения владельца.
