# Карта влияния

## Цель

Root понимает общую цель, полную приёмку и каждый канонический источник,
который способен изменить поручаемый результат.

Вход: исходная работа до формирования контракта. Выход: актуальная карта общей
цели, полного `done_when` и влияющих источников.

1. Назови одну общую цель.
2. Назови полный глобальный `done_when`.
3. Найди канонические источники, способные изменить цель, критерий,
   ограничение, решение или полномочие.
4. Найди доступные входы задачи с таким же влиянием.
5. Root сам прочитывает каждый найденный адрес.
6. Для каждого адреса запиши, на какую часть контракта он влияет.
7. Неизвестную полноту поиска оставь видимым `gap`.
8. Найденный, но непрочитанный источник не позволяет перейти к поручению.
