# Контракт результата

## Цель

Передать один результат без второго канона и без потери критериев его
приёмки.

Вход: актуальная карта влияния. Выход: предварительный контракт одного
результата.

1. `outcome` называет конкретное состояние, которое исполнитель должен сделать
   истинным.
2. Свяжи `outcome` с общей целью.
3. Включи в `done_when` применимые локальные критерии общей цели.
4. Включи критерии каждого адресованного источника.
5. Включи критерии применимых входов задачи.
6. Включи критерии применимой `delta`.
7. Для каждого критерия `done_when` назови адресуемое evidence.
8. `read` перечисляет точные адреса применимых источников.
9. `read` перечисляет точные адреса применимых входов задачи.
10. `delta` содержит только относящуюся к результату информацию, которой нет ни
   в одном адресованном входе.
11. `limits` называет `scope`.
12. `limits` называет зависимости.
13. `limits` называет применимые границы полномочий.
14. Исполнитель читает весь `read` до работы.
15. Не пересказывай доступный источник в контракте.
