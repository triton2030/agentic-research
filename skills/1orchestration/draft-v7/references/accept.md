# Приёмка результата

## Цель

Открыть зависимый ход только доказанным результатом и сохранить связь с полным
глобальным `done_when`.

Вход: один возвращённый результат, его контракт, актуальные источники и
зависимость, которую он должен разблокировать. Выход: `accepted`, `rework` либо
`gap` с адресуемым evidence.

1. Проверь фактическое состояние по каждому атомарному критерию контракта.
2. Проверь обязательное evidence действующего владельца.
3. Для каждого критерия запиши `pass`, `fail` либо `gap` с прямым адресом.
4. Следы работы — например сообщение о процессе, diff или число вызовов — не
   заменяют evidence фактического состояния.
5. `accepted` требует `pass` каждого обязательного критерия.
6. При исправимом провале верни только точную недостающую `delta` как
   `rework`.
7. При неустранимой неизвестности назови `gap`.
8. Освободи только доказанную зависимость.
9. Обнови глобальную карту `done_when`.
10. Финальный успех возможен лишь после отдельной сверки всех обязательных
    глобальных критериев.
