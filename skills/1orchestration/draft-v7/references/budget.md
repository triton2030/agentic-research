# Бюджет внимания

## Цель

Отдельно решить, посилен ли уже перечисленный активный набор предполагаемому
исполнителю и root в его следующей точке решения.

Вход: два реестра активных единиц. Выход: отдельные вердикты
`manageable` либо `overloaded` для исполнителя и root.

1. Оцени число единиц каждого набора.
2. Оцени связанность каждого набора.
3. Оцени горизонт его удержания.
4. Ориентир около `20` мягкий.
5. Сильная связанность или длинный горизонт могут дать `overloaded` раньше.
6. Превышение ориентира не требует вредного деления.
