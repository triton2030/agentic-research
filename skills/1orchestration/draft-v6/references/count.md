# Собрать active-unit ledger

Вход: provisional brief сформирован. Выход: для каждого actor, включая root в
его следующей точке решения, записан внешний active-unit ledger.

1. Единица — одна независимо забываемая вещь, которую actor должен применить
   в этой точке решения.
2. Переноси влияющие owner units и task delta в ledger по одной; синтаксическая
   склейка требований число не уменьшает.
