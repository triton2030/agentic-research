# Собрать реестр активных единиц

## Цель

Сделать спорную когнитивную нагрузку проверяемой для конкретного исполнителя и
конкретной следующей точки решения root.

Вход: предварительное поручение сформировано. Выход: для каждого исполнителя и
для root в его следующей точке решения записан внешний реестр активных единиц.

- Единица — одна независимо забываемая вещь, которую участник должен применить
   в этой точке решения.
- Запиши каждую влияющую единицу источников и `delta` отдельно;
   синтаксическая склейка требований число не уменьшает.
- Итоговое число равно количеству записей реестра.
