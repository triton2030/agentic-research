# Карта и briefs

Вход: форма допущена, root прочитал load-bearing owners. Выход: в чате есть
карта, а у каждого окна — self-contained brief, достаточный для первого решения.

Покажи карту до launch. Для каждого потока назови:

- outcome;
- независимость или место в staged-порядке;
- обязательный барьер;
- write ownership;
- instruction focus;
- return packet.

Дай каждому окну self-contained brief: outcome · live-адреса исходных данных и
обязательных инструкций его момента · границы · write ownership · return packet
`результат · адресуемое evidence · gaps · blockers`.

Активные инструкции не отменяются; root решает, что достаточно дать адресом, что
повторить в момент действия и где нужен отдельный evidence owner. Весь свод в brief не
выгружай.
