# Выбрать форму и исполнителя

Вход: каждый возможный исполнитель получил вердикт либо обнаружен
специализированный владелец схемы. Выход: терминальный `no-delegation` либо
`controller-handoff`, или собственная минимальная схема.

1. Специализированному владельцу сразу верни контракты и вердикты: границы и
   схему выбирает он.
2. Иначе выбери самую дешёвую схему, которая удовлетворяет `goal/done_when` и
   явным ограничениям на исполнителя либо схему.
3. `no-delegation` допустим, только если делегирование не входит в требуемый
   результат.
4. Назначай результат только исполнителю с доказанной достаточной способностью;
   точный способ запуска выбирает живой владелец среды выполнения.
