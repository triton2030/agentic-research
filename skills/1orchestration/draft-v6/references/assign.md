# Назначить результат

## Цель

Каждый результат принадлежит способному исполнителю, а запуск — живому
владельцу среды выполнения.

Вход: выбрана форма. Выход: назначения готовы; каждый обязательный результат
получил слот приёмки.

- `no-delegation` создаёт один слот результата root, а `direct-assignment` —
  один слот результата исполнителя.
- Собственная многослотовая схема получает по слоту на обязательный результат и
  переходит в `map`.
