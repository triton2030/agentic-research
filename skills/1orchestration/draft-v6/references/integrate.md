# Acceptance и synthesis

Вход: обязательные returns приняты либо получили terminal blocker. Выход: root
собрал и проверил один результат либо остановил зависимую ветку.

- Root разрешает конфликты по load-bearing owner-источникам.
- Root проверяет load-bearing claims и интегрирует; число согласных агентов
  решением не является.
- В чате остаются launch map, принятые результаты, gaps/blockers, проверка
  интеграции и следующий ход.
