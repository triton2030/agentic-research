# Acceptance и synthesis

Вход: returns приняты либо получили terminal blocker. Выход: root закрыл одну
evidence-backed orchestration и синхронизировал созданный state owner.

1. Разреши conflicts и load-bearing claims по owner evidence, не голосованием.
2. Интегрируй один результат и проверь его против общей цели.
3. Покажи в чате map, принятое evidence, gaps/blockers и следующий ход.
4. Append финальный transition в state owner; переживающую работу правду
   перенеси к canonical owner-у.
