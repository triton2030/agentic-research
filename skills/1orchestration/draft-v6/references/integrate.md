# Acceptance и synthesis

Вход: mandatory packets получены или поток вернул terminal blocker. Выход: root принял
возвраты, собрал и проверил один результат либо остановил зависимую ветку.

- Адресуемое evidence подтверждает результат; progress report — нет.
- Если независимая приёмка обязательна, её делает окно, не писавшее проверяемую
  работу.
- Синтезирует только root: он разрешает конфликты по owner-источникам, проверяет
  load-bearing claims, интегрирует и не голосует по числу агентов.
- В чате остаются принятые результаты, gaps/blockers, проверка интеграции и следующий ход.
