# Карта волны

## Цель

Сделать запуск однозначным.

Вход: `shape` выбрал собственную схему делегирования. Выход: до запуска в чате
показана карта минимальной формы.

Сначала назови адрес владельца общей цели и траектории.

Для каждого потока назови:

- адрес поручения;
- исполнителя;
- порядок выполнения;
- обязательный барьер;
- владение записью;
- идентификатор обязательного слота и канал возврата доказательств против
  `done_when` либо `terminal blocker`;
- владельца приёмки.
