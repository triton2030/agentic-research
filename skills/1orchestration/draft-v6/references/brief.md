# Поручение окну

## Цель

Поручение — достаточный контракт задачи, а не новый канонический владелец.

Вход: root прочитал карту источников. Выход: заполнены поля контракта ниже.

- `goal/outcome` — состояние, которое должен сделать истинным исполнитель.
- `done_when` — полный набор критериев из цели, адресованных источников и
  относящейся к задаче `delta`; для каждого названо адресуемое доказательство,
  а вместе они доказывают цель.
- `read` — точные адреса принятой карты владельцев и доступных релевантных
  входов задачи.
- `delta` — только относящаяся к задаче информация, которой нет ни в одном
  адресованном источнике.
- Доступный источник не пересказывай; требуемая его живым владельцем выдержка
  сохраняет адрес и считается в активном наборе.
