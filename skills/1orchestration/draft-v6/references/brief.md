# Brief окна

Вход: карта готова. Выход: каждое окно получило self-contained brief,
достаточный для первого решения.

- Передай потоку его строку карты как контракт.
- Добавь live-адреса исходных данных и границы работы.
- Для instruction focus выбери: адрес · повтор в момент действия · отдельный
  evidence owner.
- Весь свод активных инструкций в brief не выгружай.
