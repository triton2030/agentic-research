# Проверить исход

## Цель

Установить, доказывает ли один исход каждый `done_when`.

Вход: слот получил возврат либо `terminal blocker`. Выход: вердикт `proven`
либо адресуемый `terminal blocker` с `unknown`.

- `proven` требует адресуемого доказательства каждого `done_when`.
- Независимый проверяющий нужен только по риску или живому контракту и не
  может быть автором проверяемой работы.
- Недоказанный критерий или отсутствующая обязательная проверка дают
  `terminal blocker`; иначе исход получает `proven`.
