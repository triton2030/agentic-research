# Вернуть специализированному владельцу

## Цель

Специализированный владелец сохраняет свою схему и приёмку.

Вход: нагрузка разрешена и обнаружен специализированный владелец. Выход:
терминальный `controller-handoff` с поручениями и имеющимися вердиктами.

- Владелец сам выбирает границы, схему и приёмку, а root получает обратно
  доказательство каждого `done_when`.
