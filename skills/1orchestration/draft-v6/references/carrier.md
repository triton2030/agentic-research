# Носитель без живого плана

## Уникальный контекст

Носитель восстанавливает следующий безопасный ход, но не становится владельцем
правды задачи.

## Цель

Сделать дорогую потерю контекста root восстановимой минимальным числом
адресуемых переходов.

Вход: собственная карта запуска не имеет живого владельца состояния, а потеря
контекста дороже переиздания. Выход: до запуска создан адресуемый реестр
восстановления.

- Создай узкий исключённый из Git носитель и назови его адрес.
- Носитель адресует карту запуска и принимает каждый значимый для
   восстановления переход до следующего зависимого хода.
- Решение, меняющее ветку, записывается как переход с основанием и
   доказательством.
