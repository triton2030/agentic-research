# Носитель без живого плана

Вход: собственная карта запуска не имеет живого владельца состояния, а потеря
контекста дороже переиздания. Выход: до запуска создан адресуемый реестр
восстановления.

1. Используй объявленного локального владельца состояния либо создай узкий
   исключённый из Git носитель и назови его адрес.
2. Носитель адресует карту запуска и принимает каждый значимый для
   восстановления переход до следующего зависимого хода.
3. Решение, меняющее ветку, записывается как переход с основанием и
   доказательством.
