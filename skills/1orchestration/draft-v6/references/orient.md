# Прочитать влияющие источники

Вход: известна поручаемая работа, но карта источников не принята. Выход: root
прочитал каждый канонический источник, способный материально изменить результат.

1. Запиши каждый найденный источник как `точный адрес → влияние`.
2. Неопределённость блокирует карту, только если мешает честно сформировать
   `goal/done_when/read/delta`; разрешимую исполнителем неопределённость запиши
   как вход, `delta` или критерий результата.
3. Root сам читает каждый адрес принятой карты.
