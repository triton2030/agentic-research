# Прочитать влияющие owners

Вход: известна поручаемая работа, но owner ledger не принят. Выход: root прочитал
каждый canonical owner, способный материально изменить результат.

1. Запиши каждый найденный owner как `точный адрес → влияние`; unresolved
   gap/conflict блокирует ledger.
2. Root читает каждый адрес принятого ledger-а сам.
