# Декомпозиция cognitive work

Вход: active set actor-а получил `decompose`. Выход: меньшие candidate sets или
явно принятый overload.

1. Проведи первую границу, после которой следующий actor может отбросить часть
   owner units; зависимости стадируй, независимые outcomes можно распараллелить.
2. Тот же приём применяй к root; целая траектория остаётся во внешней карте.
3. Если честная граница не уменьшает overload, назови риск и усили checkpoints
   вместо вредного дробления ради числа.
4. Для каждого нового set тело заново выбирает cognitive stage.
