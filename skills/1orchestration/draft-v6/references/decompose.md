# Декомпозиция когнитивной работы

Вход: активный набор участника получил `decompose`. Выход: меньшие наборы либо
явно принятый перегруз.

1. Проведи первую границу, после которой следующий участник может отбросить
   часть активных единиц; зависимости разделяй на стадии, а независимые
   результаты можно выполнять параллельно.
2. Тот же приём применяй к root; целая траектория остаётся во внешней карте.
3. Если честная граница не уменьшает перегруз, назови риск и усили точки проверки
   вместо вредного дробления ради числа.
4. Для каждого нового набора тело заново выбирает когнитивную стадию.
