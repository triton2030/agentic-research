# Декомпозиция когнитивной работы

## Цель

Провести границу, после которой следующий участник действительно может забыть
часть прежнего набора; деление без такого выигрыша не считается решением.

Вход: активный набор участника получил `decompose`. Выход: меньшие наборы либо
явно принятый перегруз.

- Зависимости разделяй на стадии, а независимые результаты можно выполнять
  параллельно.
- Если честная граница не уменьшает перегруз, назови риск и усили точки проверки
   вместо вредного дробления ради числа.
- Для каждого нового набора тело заново выбирает когнитивную стадию.
