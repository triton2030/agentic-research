# Product Frame — 1orchestration v6 candidate

## Цель-сцена

Root собирается поручить работу либо сам не удерживает её активный набор. Он
читает влияющие канонические источники, формирует поручение из цели, полного
`done_when`, адресов входов и отсутствующей в них `delta`, затем перечисляет
независимо забываемые единицы каждого исполнителя и своей следующей точки
решения. Декомпозиция законна только когда следующий участник сможет отбросить
часть активных единиц. `shape` выбирает минимальную схему с достаточной
способностью, а root принимает доказательства и сохраняет переходы до
интеграции, если для работы существует владелец состояния.

Приёмка: наблюдаемы карта источников · поручения · перечисленные реестры
активных единиц · вердикты · решение о форме · при собственной схеме карта
запуска · приёмка каждого обязательного возврата · общий результат · условные
переходы состояния.

## Привязка к цели проекта

Это межпроектный контракт качества делегирования. Поручение не создаёт второй
канон, специализированный контроллер не получает второго оркестратора,
жизненный цикл среды выполнения не дублируется, а носитель остаётся только
реестром переходов.

## Тайбрейкеры

1. Выполнимость активного набора и способность исполнителя сильнее числа окон.
2. Адрес источника + `delta` сильнее пересказа; живой владелец может требовать
   адресованную критичную выдержку.
3. Порог 20 мягкий; честная неразложимость сильнее дробления ради соответствия.
4. Root владеет общей траекторией, но его точки решения оцениваются так же.
5. Специализированная схема и жизненный цикл среды сильнее общего механизма.

## Аппетит

- Тело — 17 единиц; каждый reference и каждый одновременно активный набор
  остаются в пределах 20 по карте в `refactor-map.md`.
- Цитаты владельца живут в истории и доказательствах, а не в runtime body по
  прямому решению `_ops/chat-recall/2026-08-29-160553-claude-0bee3f3d.md:18`.
- Тело и references — по-русски; `description` — короткий английский trigger
  без процесса и рекламы по решению
  `_ops/chat-recall/2026-08-29-163434-codex-01a04d4a.md:20`.
- Пересмотр: поручение пропускает источник или критерий, реестр даёт голое
  число, root не оценён, исполнитель неспособен, специализированная схема
  перехвачена, обязательный возврат не принят либо условный носитель стал
  безусловным.
