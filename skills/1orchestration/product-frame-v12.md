# Product Frame — 1orchestration v12 candidate

## Цель-сцена

Перед поручением root понимает весь влияющий контекст, сохраняет владение
пользой и общей траекторией и выдаёт конкретному actor/model посильный
результат с посильной совокупностью работы и инструкций.

## Центральная модель

Когнитивная нагрузка поручения складывается из работы и всех влияющих
инструкций. Их цена зависит от actor/model; около 20 одновременно удерживаемых
единиц — мягкий сигнал риска, а не hard cap.

## Граница простоты

Runtime остаётся одним `SKILL.md` без references. V12 добавляет только
потерянный rollback и устраняет две двусмысленности v11; новая независимая
обязанность честно поднимает body-active set с 20 до 21.

## Приёмка

- Root читает все влияющие на качество источники до brief.
- Brief полон по критериям, адресует источники и содержит только недоступную в
  файлах дельту.
- После brief оцениваются работа, инструкции, когнитивная цена и fit каждого
  предполагаемого actor-а, а также следующего решения root.
- `Done` не открывает зависимый ход без актуального наблюдаемого `pass` всех
  критериев.
- Изменение входа возвращает downstream-работу к первому устаревшему
  результату.
