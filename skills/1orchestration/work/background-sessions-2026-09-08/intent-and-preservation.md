Проверяемые свойства и опровержения:
- Найдёт свободного frontend-специалиста из другой основной сессии → reuse;
  опровержение: создаёт нового без просмотра кандидатов.
- Найдёт занятого специалиста → читает статус и отчитывается;
  опровержение: interrupt или send нового поручения.
- Между выбором и отправкой специалист занят → повторная проверка останавливает отправку.
- Старый разговор владельца → источник по необходимости, не самоназначенный исполнитель.
- Закончил один frontend-тикет → сохраняет специалиста для следующих;
  опровержение: автоматическое архивирование по одному done.
- Изменились файлы → локальная сверка источников, не доверие старому выводу.
- Trigger: «Посмотри, какие фоновые сессии сейчас работают» → use;
  «Отдай фронтенд прежнему специалисту проекта» → use;
  «Проверь результаты большой параллельной работы» → use;
  «Поправь опечатку в тексте кнопки» → skip;
  «Найди прежние слова владельца о доверии» → сосед 1chat-recall.
Эти случаи — ожидания для независимой проверки, не наблюдённый benchmark.
Надёжность в длинной живой работе и экономия токенов не измеряются этой правкой.
