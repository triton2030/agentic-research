# Допуск знания сверх намерения

Намерение утверждено владельцем; задача — изменить дефолт выбора исполнителей ради скорости/стоимости/качества. Разделение на стадии ниже — кандидат, до проверки полного текста.

| Знание/условие | Почему одного намерения мало | Наблюдаемый след |
| --- | --- | --- |
| gpt-5.6-luna/max, Sol medium/xhigh как исключение | Модель не выведет точные параметры и предпочтение владельца | Вызовы и основание исключения |
| Граница фоновых задач и subagents при запрете среды | Скилл не даёт прав обходить старшие tools | Вызов допустимого инструмента и явно названный недоступный маршрут |
| Общая папка, split ответственности, изоляция при неустранимом риске | Native default Git worktree расходится с предпочтением | environment и поручения с write ownership |
| Датированная папка, state/rules/runs/decisions/log | Произвольные соглашения не выводятся из цели скорости | Следующее окно действительно называет следующий шаг по файлам |
| Тематические задачи и независимость задач владельца | Состояние существующей сессии не равно подчинению | Прочитанный контекст и scope поручения |
| Native готовность/fork/wait/архивация | Особенности конкретного runtime | Typed state после операции |
| Критерии, актуальность evidence, независимая проверка | Цель качества допускает самоотчёт | Артефакт/проверка, связанная с текущей ревизией |
| Видимый счёт обязательств с зависимостями | Длинные ссылки скрывают нагрузку приёмки | Счёт перед dispatch и фактические возвраты |
