Снижение цены, задержки и статистическое улучшение качества этим рефактором не измерены. Проверены текст, структура, сохранность байтов и реальное использование Luna+Opus в текущем авторинге. Текстовые счётчики не объявляются тестом поведения агента.

## Добавленная Claude-дельта

Новое решение владельца задаёт другой состав: Codex через отдельный 1codex, дешёвые собственные субагенты и собственные Opus для аудита Codex. Falsifier — Claude снова делает всё внутренним веером, импортирует Desktop API либо теряет отдельный 1codex. Проверено структурно: claude-structural.json; независимое буквальное review — runs/05-claude-instruction-review.md. Поведенческий end-to-end прогон из Claude не выполнен; это открытая граница доказательства, а не успешный тест маршрута. Реальный Opus review этой дельты оценивает текст и не подменяет такой прогон.
