# Проверка маршрутизации по тексту

Это семантическая проверка root, не замер автоматического discovery.

| Реплика / момент | Ожидается | Основание |
| --- | --- | --- |
| «Делай автономно с несколькими исполнителями» | orchestration | delegation + выбор состава |
| «Запусти фоновую задачу для этого проекта» | orchestration | background Codex tasks; разрешённость по tools |
| «Продолжи ту фоновую задачу» | orchestration | lifecycle/тематическое переиспользование |
| «Форкни эту задачу и продолжи там» | orchestration | управление задачами, текущая callable schema |
| Исполнитель вернулся с изменениями | orchestration | accepting agent returns |
| Появился второй независимый участок записи | orchestration | пересмотр распределения |
| «Объясни разницу между Git и GitHub» | не этот скилл | нет распределения или управления задачами |
| «Спроси Opus про этот вывод» | 1claude-mcp для механики; orchestration только общий контракт поручения | не присваивать транспорт Opus |
| «Запусти 1deep-agents» | named skill владеет составом панели | orchestration не заменяет специализированную методологию |

Поздний вход: до возврата работает execute, после возврата — accept; модельный выбор не повторяется без изменения состава или проблемы с ним.
