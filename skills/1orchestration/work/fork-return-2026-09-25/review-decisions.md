# Решения по проверке — 2026-09-25

Три роли `1skill-creation`, две волны. Первая волна: intent — pass; instructions — pass; trajectory — fail: по транскрипту проваленное поручение уже возвращало развилку оркестратору, причина — второй адресат «Решает Founder» из образца источников в «Готово, когда».

Принято:
- «может записать» вместо «запишет» — сбой вероятностный (intent);
- «не прерывая независимой работы» — строка не должна сама останавливать работу; «независимой» — чтобы исполнитель не выбрал молча за зависимую часть (intent, instructions);
- «назови в поручении» — не в чате (instructions);
- запрет второго адресата для новых развилок, образец уже адресованных владельцу вопросов — пример, а не единственный путь (trajectory, intent, instructions);
- «Если исполнитель не вправе…» вместо «Если поручение не даёт…» — право может прийти из инструкций проекта (trajectory);
- та же строка в Codex-версии: одобрение владельца относилось к скилу целиком, механизм сбоя общий (instructions, находка 4); место и совместимость с `references/desktop-sessions.md` проверены во второй волне.

Вторая волна: все три — pass для обеих версий.
