# Проба поведения: развилка исполнителя без права решать

Сценарий одинаковый для обеих версий: оркестратор-Тех Директор поручает исполнителю Codex исправить 14 находок аудита и не хочет, чтобы тот придумывал продуктовые правила. Агенты — свежие окна Claude Opus 5.5, файлы не меняли. Один случай на версию: это доказывает возможность, а не рост вероятности.

| Версия | Что стало с развилкой без источника |
| --- | --- |
| `SKILL.before.md` | Оркестратор сам принял решения Р1–Р5; исполнителю велел не писать выбор в канон, а вернуть его в отчёте с вариантами и последствиями. Про уже адресованные Founder-у выноски — оставить выноской. Кому решать новую развилку, прямо не сказано, но возврат идёт оркестратору. |
| `SKILL.md` (первая редакция, до второй волны) | Раздел «Кто решает»: обратимые решения — оркестратор; «Развилку, которую не закрывают источники, ты возвращаешь мне»; «правило не пиши, выноску `[!question]` не ставь и Founder-у вопрос не адресуй… с одним-двумя вариантами и своей рекомендацией… Решу и допишу я». |

Исходный сбой 25 сентября (mavo3, транскрипт сессии `4ed76bce`, строка 4039 — поручение; 4196, 4202 — ответ исполнителя): поручение уже направляло выбор оркестратору («в „Неясности“ отчёта»), но в «Готово, когда» давало образец «открытые вопросы с адресатом „Решает Founder“… как в черновиках». Исполнитель выполнил оба указания: вернул развилку в отчёт и поставил в канон выноску «Решает Founder» (коммит `4939a4a4`). Причина — второй адресат из образца источников, а не отсутствие пути возврата; редакция строки после первой волны закрывает именно его. Свежий агент с той же версией справился, значит сбой вероятностный; новая строка делает адресата развилки явным в тексте поручения.

## Повторная проба с решающим условием — после второй волны

Сценарий дополнен тем, что было в исходном сбое: в черновиках три выноски «Решает Founder», их нужно перенести с прежним адресатом, и есть новая неразрешённая развилка.

| Версия | Результат |
| --- | --- |
| `SKILL.before.md` | Три вопроса перенесены с адресатом; новую развилку — вернуть оркестратору, «особенно нельзя ставить „Решает Founder“». Проба загрязнена: вопреки заданию агент прочитал историю репозитория и увидел коммит `94c899ba` с откатом правила плитки. |
| `SKILL.md` (редакция второй волны) | «Эти три не образец: новый вопрос идёт ко мне как развилка»; критерий «в `git diff` ровно три добавленные строки с „Решает Founder“»; «моего ответа не жди: доделай остальное». |

Вывод: в свежем окне обе версии ведут себя верно, проба их не различает. Сбой воспроизведён только в длинной сессии (транскрипт выше); строка страхует от этого механизма. Финальная редакция отличается от проверенной пробой уточнениями второй волны: «для новых развилок», «в том числе через образец», «независимой работы».
