# Намерение — папка сессии (стадия goal-context внутри названного изменения)

## Функция (FAST)

Дать root рабочую память, переживающую сжатия окна, чтобы многодневная
оркестрация со многими пишущими исполнителями продолжалась без владельца, а
владелец потом прочитал её решения за один присест.

## Подъём способов по «зачем» (Action Identification)

| Способ владельца | Зачем | Состояние, которого хочется само по себе |
| --- | --- | --- |
| файл для себя ≤1000 знаков, переписывающийся | после сжатия читать одно место | после любого сжатия следующее действие называется без чата |
| файл решений для владельца | он видит только чат, а чат дней не прочесть | владелец читает каждое решение без него и знает, чем отменить |
| короткие файлы прогонов с целями | поручение и возврат живут дольше окна; окно не съедается возвратами | возврат не входит в окно целиком; поручение переиздаваемо |
| файл истории | порядок событий за дни | хронология читается без чата |

Ни один способ не остался без «зачем»; все четыре подняты до состояний в Цели
файла. Способ «≤1000 знаков, переписывающийся» сохранён как решение владельца
его словами.

## KAOS

Цель файла — **Maintain**: в каждый момент многодневной работы `state.md`
достаточен для продолжения, `decisions.md` полон, зоны не пересекаются.
Поэтому нужна не однократная запись, а перезапись при каждой смене положения и
дописывание в момент решения — это и есть правила файлов.

## Отрицание цели (obstacle analysis) → критерии

| Лист цели | Как джин закроет формально, а мне плохо | Критерий |
| --- | --- | --- |
| следующее действие по одному `state.md` | пишет `state.md` как журнал дописыванием; после сжатия там 6000 знаков истории и нет «следующего» | 1 |
| владелец читает каждое решение без него | решения записываются в конце «по памяти», часть теряется, работа уже оперлась | 2 |
| возврат не входит в окно целиком | root «на всякий случай» читает весь возврат; окно съедено | 3 |
| папка — рабочая память | слово владельца, находка, решение проекта записаны только в папку и умирают с ней | 4 |
| исполнитель пишет только в свою зону | два поручения дают право на один файл, зона не названа | 5 |

Пусто не вышло: пять препятствий — пять критериев.
