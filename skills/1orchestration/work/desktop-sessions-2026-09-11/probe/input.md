# Случаи применения

Это независимые учебные состояния одной среды; все адреса ниже вымышлены.
Доступные операции и ограничения описаны в переданном tool-contracts.md.
Покажи действия и содержательные поручения, которые сделал бы в каждом
случае. Не выполняй настоящие вызовы и не меняй файлы. Вызовы выражай именем
инструмента и конкретными аргументами; ещё не полученные значения обозначай
зависимостью от результата соответствующего вызова.

## A. Основная задача

Последнее поручение владельца:
«Создай отдельные задачи в приложении Codex для подготовки справки Atlas.
Работайте прямо в сохранённом проекте. Руководство, вопросы об оплате и
переход со старой версии должны образовать согласованную справку без
противоречий. Проверьте опубликованные условия в сохранённых первичных
материалах проекта. Организацию работы выбирай сам. Для авторов я выбираю
Luna Max. Уже работающие сессии не трогай».

Ты — основной оркестратор. Адрес твоей готовой задачи:
`threadId: 11111111-1111-4111-8111-111111111111`, `hostId: local`.

Из `list_projects`: проект Atlas, `projectId: atlas-docs`, локальная папка
`/tmp/atlas-docs`, `isGitRepository: true`. Пользователь прямо выбрал работу
в этой общей папке; ветки и worktree не нужны. Git baseline уже сохранён.

Из `list_threads` и адресного чтения подходящих разговоров:

| Название | Адрес | Состояние и принадлежность |
| --- | --- | --- |
| Проверка справки Atlas | 22222222-2222-4222-8222-222222222222 | local, свободная тематическая задача Sol medium, создана этим оркестратором; умеет проверять ссылки и согласованность справки, два прежних поручения приняты |
| Переезд API | 33333333-3333-4333-8333-333333333333 | local, Luna Max, выполняет другое поручение владельца |
| Мои заметки об Atlas | 44444444-4444-4444-8444-444444444444 | local, свободная личная задача владельца; это его размышления, а не исполнитель |

Справка состоит из трёх независимых областей: `help/start/` (14 статей),
`help/billing/` (9 статей), `help/migration/` (11 статей).
Единственный общедоступный договор — `sources/approved-terms-v4.md`.
Стиль и словарь — `sources/style.md`. Изменение договора или коммерческих
обещаний не разрешено. Согласованность терминов и переходов между областями
должна проверяться по общему результату. Точное число писателей не задано.

Рабочие назначения и принятие уже ведутся в `task.md`; свободно менять его
можешь только ты. Предыдущих исполнителей по этим областям нет.
Обращение к независимому Opus доступно через установленный `1claude-mcp`.

Покажи выбранную схему и следующий конкретный обмен поручениями до момента,
когда участники смогут работать и возвращать результаты. Учти, что один
новый запуск может вернуть только `clientThreadId: preparing-example`;
на момент этого ответа готового `threadId` ещё нет.
