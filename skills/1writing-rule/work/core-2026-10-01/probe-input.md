# Вход пробы ядра

Учебный пример, не правило реального продукта.
Напиши для нового участника короткое объяснение сверки общего списка расходов.
Текст предназначен для сообщения в чате.

Исходные данные:
черновик — список ещё не проверенных записей; итог — записи после сверки.
В каждой записи нужны дата, категория, сумма и валюта.
До переноса записи в итог участник сверяет сумму с чеком и выбирает категорию.
Если чека нет, запись остаётся в черновике с пометкой «не подтверждено».
Записи в разных валютах не складывают: итоги показывают отдельно по каждой валюте.
Временная пометка помогает найти запись и не меняет её статус подтверждения.
После сверки участник сообщает число перенесённых записей и суммы по валютам.
