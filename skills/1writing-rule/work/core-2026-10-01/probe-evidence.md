## Общее поручение

Выполни одну пробу текста для чата.
Прочитай только `candidate/SKILL.md` и `probe-input.md` этой рабочей папки.
Считай это вызовом `1writing-rule` для готового заказанного текста,
который остаётся в чате: сам пакет разрешает этот маршрут только по ядру.
Напиши готовое объяснение по входным данным; верни только результат без рассказа о работе.
Не открывай references или другие документы, не меняй файлов, не запускай других агентов.
Это учебный пример, а не изменение продукта.
Ты работаешь рядом с другими агентами, их файлы не затрагивай.

Это изложение поручения с сокращёнными до локальных имён абсолютными путями.
Фактические чтения, скрытый контекст и runtime-модель не сверены по независимому trace.
Один случай показывает наблюдаемое оформление, а не надёжность исполнения.
Иерархия большого документа и отображение в Obsidian здесь не проверялись.
