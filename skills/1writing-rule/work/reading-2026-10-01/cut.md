# Сохранность смысла

Исходник — действующий shared owner, равный сохранённой версии v4.
Ядро SKILL.md не меняется.
Все прежние абзацы reference сохранены; раздел оформления дополнен.
Снятых обязательств нет.

Добавлены только принятые предпочтения чтения:

| Изменение | Основание и смысл |
| --- | --- |
| Порядок объяснения и первое употребление терминов | Читателю должны быть понятны связи и необходимость следующего сведения |
| Абзацы и смысловые переносы | Точная формулировка владельца, включая мягкий ориентир длины и исключения |
| Вертикальные перечисления, нумерация и таблицы | Исправление фактического нарушения чтения перечислений |
| Иерархия заголовков, деталей и выносок | Принятая многоуровневая подача; обязательное не скрывается |
| Исходник Markdown и отображение Obsidian | Вопрос владельца об отступах; синтаксические рекомендации не выданы за пиксельные требования |

Незатронуты достоверность, полномочия, видимые пробелы, граница метаобсуждения,
размер файла, его дом и маршруты к другим скиллам.
Повторная защита сохранности знаний из нового дополнения снята после независимой проверки:
она уже есть в прежнем reference и ядре.
Отдельное предпочтение технического сжатого стиля для объясняющих документов сохранено.
Карта потерь приведена к финальным байтам: адресный рефактор завершён;
[независимая проверка](review.md) принята.
