# Как выгрузить коллекцию заметок

В приложении можно выгрузить рабочую коллекцию — именованный список заметок,
доступный участникам проекта. Для выгрузки достаточно права чтения. Менять
состав коллекции может только редактор.

## Выберите параметры

Выберите формат, язык оформления и включать ли вложения.

| Формат | Для чего подходит |
| --- | --- |
| PDF | Для чтения |
| Markdown | Для дальнейшего редактирования |

В выгрузку попадут только те вложения, к которым у вас есть доступ.
Недоступное вложение будет пропущено, а в отчёте будет указана причина:
отсутствие вложения не скрывается.

## Подтвердите и дождитесь сборки

Перед запуском система покажет выбранный формат, число заметок и список
пропускаемых вложений. После подтверждения параметров она создаст снимок —
сохранённый состав заметок и их содержимое на момент подтверждения.
Последующие правки коллекции не изменят уже запущенную выгрузку.

Система поставит сборку в очередь — список заданий, которые выполняются
в фоне. Страницу можно закрыть: выполнение продолжится. При сбое повторяется
сборка того же снимка; новая версия коллекции в повтор не попадёт.

## Скачайте архив

Готовый архив доступен семь дней после завершения сборки. Письмо со ссылкой
служит уведомлением. Если письмо не пришло, откройте архив в истории
выгрузок. При повторном скачивании вы получите тот же архив: сборка заново
не запускается.

После истечения семи дней нужна новая выгрузка. Она создаст новый снимок
из текущей коллекции.

Если права на проект отозваны, доступ к архиву прекращается сразу,
даже если семь дней ещё не прошли.
