# Вход пробы

Заказ: перепиши объяснение для человека, который впервые пользуется системой
экспорта исследовательских заметок. Сохрани все знания, без новых правил.

Исходный текст:

В приложении можно выгрузить рабочую коллекцию заметок. Пользователь выбирает PDF или Markdown, язык оформления и включение вложений. PDF подходит для чтения, Markdown — для дальнейшего редактирования. Коллекция — именованный список заметок, доступный участникам проекта. Участник с правом чтения может выгрузить коллекцию, но изменить её состав может только редактор. Вложения включаются только при наличии доступа к каждому из них. Недоступное вложение пропускается, а в отчёте указывается причина; отсутствие вложения не скрывается. Перед запуском система показывает выбранный формат, число заметок и список пропускаемых вложений. Пользователь подтверждает параметры, система создаёт снимок и ставит сборку в очередь. Снимок — сохранённый состав заметок и их содержимое на момент подтверждения. Последующие правки коллекции не меняют уже запущенную выгрузку. Очередь — список заданий, которые выполняются в фоне. Пользователь может закрыть страницу: выполнение продолжается. При сбое повторяется сборка того же снимка; новая версия коллекции в повтор не попадает. Готовый архив доступен семь дней после завершения сборки. Письмо со ссылкой служит уведомлением; если письмо не пришло, архив можно открыть в истории выгрузок. При повторном скачивании выдаётся тот же архив, сборка не запускается заново. После истечения срока нужна новая выгрузка, которая создаёт новый снимок из текущей коллекции. Когда права на проект отозваны, доступ к архиву прекращается сразу, даже если семь дней ещё не прошли.
