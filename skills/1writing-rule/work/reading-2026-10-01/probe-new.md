# Как выгрузить коллекцию заметок

В приложении можно выгрузить рабочую коллекцию — именованный список заметок,
доступный участникам проекта.
Для выгрузки достаточно права чтения.
Изменить состав коллекции может только редактор.

## Выберите параметры

Выберите формат по тому, что хотите делать с заметками:

| Формат | Для чего подходит |
| --- | --- |
| PDF | Для чтения |
| Markdown | Для дальнейшего редактирования |

Также выберите:

- язык оформления;
- включать ли вложения.

В выгрузку попадут только те вложения, к которым у вас есть доступ.
Недоступное вложение система пропустит и укажет в отчёте причину:
его отсутствие не будет скрыто.

## Подтвердите выгрузку

Перед запуском система покажет:

- выбранный формат;
- число заметок;
- список вложений, которые будут пропущены.

Подтвердите параметры.
Система создаст снимок — сохранённый состав заметок и их содержимое на момент подтверждения.
Последующие правки коллекции уже не изменят эту выгрузку.

## Дождитесь сборки

После создания снимка система поставит сборку в очередь — список заданий,
которые выполняются в фоне.
Можно закрыть страницу: выполнение продолжится.

При сбое система повторит сборку того же снимка.
Новая версия коллекции в повторную сборку не попадёт.

## Скачайте архив

Готовый архив доступен семь дней после завершения сборки.
Письмо со ссылкой уведомляет о готовности.
Если письмо не пришло, откройте архив в истории выгрузок.

При повторном скачивании вы получите тот же архив:
сборка заново не запускается.
После истечения семи дней нужна новая выгрузка.
Она создаст новый снимок из текущей коллекции.

Если права на проект отозваны, доступ к архиву прекращается сразу,
даже если семь дней ещё не прошли.
