# Уведомления

Уведомления приходят только по email. Пользователь может отключить их в настройках.[^decision]

[^decision]: Решение владельца от 17 сентября, изложенное в заметке проверочного запроса. SMS отклонены, поскольку пока нет бюджета на провайдера.
