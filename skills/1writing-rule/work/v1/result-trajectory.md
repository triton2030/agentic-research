# Уведомления

Уведомления приходят только по email. Пользователь может отключить их в настройках.[^decision]

SMS не поддерживаются: пока нет бюджета на провайдера.[^decision]

[^decision]: Решение владельца от 17 сентября; источник — заметка в проверочном запросе: «Принято: уведомления приходят только по email; пользователь может отключить их в настройках» и «Объяснение отказа от SMS: пока нет бюджета на провайдера».
