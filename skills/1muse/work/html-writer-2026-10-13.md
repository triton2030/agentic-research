# Проба исполнителей на HTML-странице, 2026-10-13

Владелец попросил дать Muse задачу на красивый HTML-артефакт и оценить,
удобно ли агенту запускать его исполнителем, а затем проверить то же у Gemini.
Оба получили один бриф в четырёх разделах: страница «три чужих агента: кому
что поручать» в `_workspace/HTML_artifacts/` по стандарту скила `1html`.

| | Muse Wonder | Gemini 3.8 Flash High |
| --- | --- | --- |
| запуск | `muse.py`, права по умолчанию | `gemini.py --full` |
| время | 2 мин 14 с, один ход | около 13 минут, два хода |
| исход обёртки | `ok` | оба хода `FAILED`: сетевая ошибка сервера после сделанной работы |
| страница | 25 КБ, проверка `check_html.mjs` проходит | 71 КБ, проверка проходит |
| своя проверка в браузере | не смог: Chromium падает в песочнице | запустил сам и исправил ошибки Alpine и прокрутку вбок |
| границы брифа | соблюдены | соблюдены |
| неизвестное в источниках | помечено прочерком с пояснением | заполнено словом «нет» |

Что изменено в обёртках по итогам:

- `changed:` строился через git и показал `nothing`, хотя Muse записал три
  файла в игнорируемую папку `_workspace/`. Теперь список строит `find` по
  времени правки, git не спрашивается; `gemini.py` печатает его в режиме
  `--full`.
- Во время прогона карточка запуска была пустой, и владелец дважды спросил,
  жив ли агент. Обе обёртки теперь печатают в stderr строку на каждый вызов
  инструмента.
- При сбое в конце `gemini.py` терял уже написанный ответ. Теперь он печатает
  последний текст Gemini и подсказку с `--resume`.

Страницы: `_workspace/HTML_artifacts/chuzhie-agenty.html` (Muse)
и `chuzhie-agenty-gemini.html` (Gemini); папка `_workspace/` в git не входит.
