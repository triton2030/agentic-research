# Проба T3 Code, 2026-10-14

Вход в заказ владельца о переводе Gemini и Muse на T3 Code[^order]. Итоги по
каждому агенту записаны в справках: `skills/claude/1muse/references/muse-code.md`,
раздел «Muse через T3 Code», и `skills/claude/1gemini/references/agy.md`,
раздел «Gemini через T3 Code». Здесь — как мерили и что относится к самому
T3 Code.

## Как мерили

T3 Code 0.0.46-nightly, вход клиента с уровнем `full-access`. Проект
`t3-probe-2026-10-14` заведён через `t3_project_create` одним названием:
T3 Code сам создал git-репозиторий `~/.t3/projects/t3-probe-2026-10-14`.

В репозитории две зоны с одинаковой задачей, `muse/` и `gemini/`: два бага
в `calc.py` и падающие тесты, новая функция, запись файла в домашнюю папку,
отчёт `REPORT.md`. В корне лежит `AGENTS.md` с канареечным правилом,
в `gemini/` — синтезированные `audio.mp3` и `clip.mp4`. Оба треда запущены
в корне проекта одновременно; через 20–25 секунд каждому послана поправка
режимом `auto`.

## Вопросы прошлого пакета

| Вопрос | Ответ |
| --- | --- |
| видит ли новая сессия приложения `mcp__t3__*` | да; субагент этой сессии тоже |
| работает ли Muse под T3 Code при `full-access` | да; границы рабочей папки при этом нет |
| грузятся ли в Muse личные правила и скилы владельца | да |
| правит ли Muse файлы через T3 Code | да |
| работает ли Gemini через T3 Code | как исполнитель — да; аудио и видео не открывает |
| замена квитанции обёртки | запись `checkpoint` и лента `activity` в `t3_thread_read`; автора правки она не различает, как и `changed:` |
| замена закреплённой модели | нет: модель задаёт вызывающий |
| замена приписки с общими правилами | нет |
| вызов без запущенного T3 Code | нет |

Не мерилось: вызов из Codex (по документации — `codex mcp add t3`),
регистрация уже существующей папки через `t3_project_create`
с `workspaceRoot`, уровень `approval-required`.

## О самом T3 Code

- Вызывающий вне треда обязан дать `projectId` или `scratch: true`. Проекта
  `agentic-research` среди зарегистрированных нет.
- Без `workspaceStrategy` тред работает в корне проекта: рядом с другими
  тредами и поверх незакоммиченных правок. В новое рабочее дерево
  незакоммиченное не копируется — по описанию инструмента.
- Ни один из двух агентов без просьбы не коммитил.
