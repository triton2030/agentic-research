# Аудит 1muse самим Muse, 2026-10-13

Владелец сменил умолчание на `muse-wonder-full-1.0` + `xhigh` и попросил
вызвать Muse аудитором собственного скила и кода. Прогон: 8 минут 39 секунд,
права по умолчанию, в брифе «файлы не меняй». Вердикт Muse: «держится
с оговорками». Проверочные скрипты он положил в `/tmp/muse-audit/`.
Эта временная папка не сохранилась: поддельный `muse` со сценариями придётся
писать заново по таблицам ниже.

В квитанции стояло `changed: skills/1muse/README.md`: это правка вызывавшего
агента, сделанная во время прогона. Сам аудитор файлов не менял.

## Код обёртки

| Находка Muse | Исход | Чем закрыта |
| --- | --- | --- |
| при отказе теряются `changed:` и частичный ответ | принят | обёртка печатает их во всех ветках отказа; сценарии `fail_write`, `empty_write` |
| убитая обёртка живёт до конца `--timeout` из-за потока таймера | принят | таймер стал демоном, обработчик выходит сразу; скрипт аудитора `sigterm2.py`: выход на 1,0 с вместо 8,1 с |
| таймаут шлёт один SIGTERM и ждёт без срока | принят | через 5 секунд следует SIGKILL; сценарий `sleep_ignoreterm` при `--timeout 2s` — выход на 7,0 с, код 4 |
| сверка модели молча отключается без каталога | принят | квитанция несёт пометку `model name NOT checked` |
| сверка пропускает скрытые модели и любое усилие у модели без ярусов | принят | принимаются только видимые модели и только предложенные каталогом уровни |
| с `--schema` не-JSON ответ сдаётся как `ok` | принят | отказ с кодом 1; сама схема проверяется до вызова |
| `changed: nothing` совместимо с удалением | принят | добавлен список `deleted:`; сценарий `delete` |
| `changed: nothing` совместимо с правкой, вернувшей старое время файла | не решён | вне модели угроз; ограничение записано в справке |
| `--resume` с несуществующим id молча начинает новый разговор | принят | обёртка ищет сессию в хранилище Muse и без неё отказывает |
| формат `--timeout` проверяется после запуска `muse` | принят | проверка перенесена в разбор аргументов; то же в `gemini.py` |
| фильтр stderr глушит строки со словом `skills` и печатает только `warning` | принят | отбрасываются пять известных служебных строк, остальное печатается |
