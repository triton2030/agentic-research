# Карта сохранности

| --- | --- | --- |
| Учитель-стратег, сомнение в постановке | Сохранено по исходному заказу | Контекст, Задача, выбор подхода |
| Ручной вызов до конца сессии, новые ответы и задачи, сжатие, выключение | Сохранено | Frontmatter, Задача, продолжение сессии |
| Богатый первый урок: опора, сработало, упущено, будущее, простое объяснение | Сохранено | При включении режима |
| Обязательные три заголовка и таблица | Форма свободна по нынешнему запросу меньшей предзаданности; содержание удержано | При включении режима |
| Отдельный activation.md | Логика первого урока теперь целиком в теле; ссылка и файл снимаются вместе | При включении режима |
| Единая цепочка: узкое место, альтернативы, evidence, прогноз probe, фальсификатор, ограниченная проверка, закрытие, прогноз действия, сверка | Фиксированный сценарий снят по нынешнему уточнению. Порядок и проверки определяет выбранный метод; наблюдаемая связь объяснения с действием остаётся | Выбор подхода, применение метода, критерий 1 |
| Метод назван, цитата проверена | Сохранено и дополнено объяснением механизма, оснований полезности и границ; цитата одна недостаточна | Выбор подхода |
| Разные книги и методы | Сохранены примеры без обязательного обхода | Выбор подхода |
| Объяснение до действия, разбор результата, урок дальше | Сохранено без заранее единого бланка | Критерий 1, применение метода |
| Честность прошлого метода и неизвестного | Сохранено | Критерий 1, первый урок, источники, пропуск объяснения |
| Продолжение исходной работы без новой команды; завершённое не возобновляется | Сохранено | Применение метода |
| Объём, результат, критерии готовности, полномочия | Сохранено | Критерий 2 |
| Обоснованный простой ход не усложняется | Сохранено | Выбор подхода |
| Объяснение каждого содержательного шага, объединение механики | Сохранено | Задача, продолжение сессии |
| Размышляющий голос CTO стартапа | Добавлен по текущему уточнению; относится к разговору и письму в режиме | Контекст, Задача, Голос режима |
| Стратегия как польза с учётом последствий | Уточнено по нынешним словам: прогноз шагов и траектории, мнение о направлении и свои варианты | Контекст, Цель, выбор подхода |

При изменении формулировки не заявляется полное раскрытие внутренних
размышлений: публичный результат — объяснение рекомендаций и их оснований.
Постоянные цели и критерии не повторены в заключительном «Готово когда».

Карта сверена автором с полным исходным пакетом. Стадия: рефактор завершён,
независимая проверка завершена без обязательных правок. Поведенческая проба
сохранила существенную рекомендацию после снятия универсального протокола;
рост надёжности не заявляется. Доставка входит в уже разрешённый заказ.
