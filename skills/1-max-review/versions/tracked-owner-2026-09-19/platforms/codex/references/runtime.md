# Codex: запуск

Вызывающий запускает одного native subagent-координатора в свежем контексте
(`fork_turns: "none"`, где доступно). Передай ему SKILL.md и явный пакет
входа. Координатор ведёт чтение, распределение и приёмку; вызывающий получает
короткий итог. Модель координатора и проверяющих определяет тело SKILL.md.

Проверяющих запускает общий CLI `max-review`, поэтому native-лимит дочерних
агентов не определяет число его процессов. Проверь CLI и доступный вход
через doctor; рабочую параллельность измеряй, не обещай сто процессов по
одному удачному запуску. Отчёт CLI об успехе процесса не равен PASS проверки.

Свежая CLI-сессия не отменяет автоматически доставляемые инструкции.
Не обещай пустой контекст. Requested model сохраняется в run; если runtime
не раскрывает resolved model, это остаётся границей знания. Отдельно храни
расход токенов и фактическое покрытие, когда сравниваешь результаты.

Не создавай пользовательские задачи приложения ради внутренних исполнителей
без прямого запроса. Если отдельный координатор недоступен, объясни потерю
изоляции вызывающего окна и предложи ему режим диспетчера либо сохранение
очереди для другой среды. До выбора статус incomplete; ранее данное согласие
на такой путь сохраняет силу. `max-review run` работает, пока жив его
процесс; это не постоянно работающий сервис после завершения сессии.
