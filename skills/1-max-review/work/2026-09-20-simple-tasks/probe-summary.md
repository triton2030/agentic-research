# Проверка простых заданий

Четыре реальных вызова через существующий `max-review run`, параллельность 3, без output-schema и без prepare. Запрошена Luna Max; resolved model CLI не сообщил. Все четыре процесса завершились с первого раза. В одном leaf был один read-only вызов: чтение глобального 1writing-rule. В остальных трёх вызовов инструментов не было; техническая изоляция от всех инструкций не доказана.

| Случай | Наблюдаемый ответ | Приёмка root |
|---|---|---|
| Ошибка в копии реального документа | Найдены складской учёт и требование остатка, точная строка 11 | pass |
| Действующий документ о предложении | «Ошибок не нашёл» по узкому вопросу отсутствия складского учёта | pass |
| Нет свидетельства чтения AGENTS | Прямо назван недостающий журнал; соответствие не выдумано | pass |
| Связь предложения Студии и покупательского выбора | Короткий ответ верно различает оставшиеся варианты, отсутствие всех и сохранность заказа | pass |

Задания, заявленные проверки и ответы — `probe/{tasks.jsonl,prompts/,assertions.json,results.json,run/}`. Правило о складе передано как авторский пересказ действующего ограничения; это не буквальная цитата владельца. Копия с ошибкой — искусственная мутация реального текста. Случай связанных документов воспроизводит класс прежнего q108: оба конца теперь доставлены. Это не повтор прежних байтов и не количественное сравнение моделей.

Четыре случая доказывают работоспособность простого маршрута, а не увеличение вероятности находить ошибки. Полнота большого аудита зависит от разбиения координатора; прошлый Max MAVO остаётся incomplete.
