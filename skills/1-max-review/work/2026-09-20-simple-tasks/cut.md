# Сохранность смысла

Основания — новая прямая коррекция владельца 20 сентября и исходные слова 19 сентября. Техническая форма старого пакета не является целью.

| Что было | Что стало и почему | Проверка |
|---|---|---|
| Много небольших проверок, все применимые правила | Сохранено в теле; реальная нагрузка и зависимости — в prepare | Независимые роли и ограниченная проба |
| Отдельный координатор, caller читает сводку | Сохранено, runtime-дельты короче | Чтение обеих сред, ссылки |
| Luna Max через общий CLI | Сохранено в теле и действующем launcher | doctor и реальный run |
| Обязательные plan → prepare → schema → check | Сняты по прямому уточнению владельца. Используется уже существующий run обычных prompts | Проба без output-schema; транспорт run не менялся |
| Специальные ID:line и JSON finding | Обычный путь/строка и короткая проза; содержательные замечания принимает координатор | Ошибка, чистая цель и нехватка evidence в пробе |
| Механическая матрица каждой строки source × target | Координатор сохраняет адресное распределение исходных участков и области между заданиями в state; полнота не снята | Проверка потерь и итогового маршрута |
| Доказывать процесс по каждому готовому файлу | Одна отдельная проверка по следу действий, отсутствие следа — один явный пробел | Проба отсутствующего evidence |
| Зависимости вне пакета порождали unknown | В простое поручение входят оба конца конкретной связи | Проверка заданий и сценария |
| Audit/repair, версии, удаления, изменения после проверки, честное непроверенное | Сохранено в коротких местах применения | Независимая проверка |
| Retry и бесконечное исправление | Технический retry сохранён; одна перепроверка исправлений, затем явный остаток | Контракт результатов |

Старый prepare получает прежний JSON-контракт из assets/packet-reviewer.md; изменён один путь в CLI и усилен существующий тест контракта. Это устраняет противоречие с новым plain-text reviewer. Новый рабочий путь prepare/check не использует. Отдельной новой оболочки и формата ответа не добавлено.

Последнее уточнение владельца (цитата L18) задаёт смысл результата: ложные находки допустимы, их проверяет вызвавший скилл главный агент. Координатор собирает сигналы и дубли, но не скрывает отвергнутые им находки. Trigger и вопрос допускают бизнес-ревью. Это не обещание безошибочности и не новое проектирование транспорта. Четыре пробы подтверждают существующий путь; рост надёжности и масштабирование не заявляются.
