# Проверка готовых пакетов

Проверено 19 сентября 2026. Текущий маршрут: prepare → run → check.
Проверяющие получают исходные фрагменты правил, цели и контракт сразу
в prompt. Учёт связывает участок/цель с пакетом и ответом; атомарный
реестр требований больше не требуется.

## Подтверждено

- 24 теста: 16 транспортных и 8 для готовых пакетов. Проверены пропуски покрытия,
  исключения, изоляция контекста пакетов, partial-target marker, несовпадение
  версии prompt, malformed/missing/unknown/stale ответы и JSON CLI.
- Два независимых Sol Medium окна приняли смысл и инструкции. Третий
  проверил применение и исполняемые границы; замечание к устаревшему
  validation устранено этой редакцией.
- Реальная проба: 3 небольших пакета Luna Max одновременно, 3 успешных ответа,
  без retry и tool-call events. Чистая цель → clean; известное отсутствие
  адреса доставки → findings с правильной строкой; фрагмент 1 из 3 строк → unknown.
  Check сохранил общий incomplete из-за намеренно неполного случая.
- Длительности 7,5–24,3 секунды; сумма input tokens 48 606, output 948.
  Resolved model CLI не раскрыл; requested gpt-5.6-luna/max сохранены.
  Это маленькая синтетическая проба, не доказательство ускорения полного
  аудита и не измерение вероятности обнаружения ошибок.

Свидетельства локально в `_workspace/orchestration/2026-09-19-maxrevie/simplify/`:
`acceptance.md`, `probe/prepared/`, `probe/run/` и `probe/summary.md`.

Установленные Codex/Claude проекции совпадают с владельцем и проходят
quick_validate; локальные Markdown-ссылки разрешаются. Установленный CLI
повторно выполнил prepare (345–350 слов на пакет) и check с ожидаемыми
clean/findings/unknown. Повторных вызовов модели для доставки не потребовалось.

## Границы

Полноту обнаружения источников и истинность выводов helper не доказывает.
Отсутствие инструментов у leaf задаётся инструкцией; read-only CLI не является
запретом всех вызовов инструментов. Системный контекст остаётся даже при
небольшом задании. Новые глобальные лимиты слов, автоматический кэш результатов
и перевод семантических правил в код не добавлены.

Полная БД, сотня параллельных процессов, запуск из реального Claude-сеанса
и статистическое сравнение методов этой редакцией не проверялись.
