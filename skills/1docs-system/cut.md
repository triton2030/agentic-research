## Снято с причиной

| Смысл | Причина |
|---|---|
| «Причина решения — в документ класса „решение“; класса нет — строка предложения» | Владелец: папка решений превращается в свалку и дубли (#L38). Причина живёт в Контексте «Цели» или в «Решения и почему» проекта |
| Ссылка из читаемого документа на новый дом; связь ссылками в шапке | Владелец запретил ссылки между файлами канона (f6af07ee#L25); навигация — имена |
| Новый тип документа только через гейт проекта | Виды фиксированы файлом правил проекта; новый вид — его правка, не гейт скила |
| «Архив, датированные записи и код не правятся вовсе» | Держит красная линия 3 корневого AGENTS.md проекта и природа chat-recall; в скиле размещения это не размещение |
| Стадии-файлы new-home / existing-home / derivative / overgrown как четыре reference | Переписаны как режимы: поиск, архитектура, правка, инструкция папки; derivative и overgrown стали правилами внутри них |

## Инструкции, которые нельзя было вывести из намерения

Все перечислены в самих файлах с причиной внутри единицы; сводно: читать имена, не содержимое; область до поиска; знание чужого вида не селится в файл; один вход — один вопрос; радиус — раздел; перенос — две правки одним ходом; папка на одного жителя не заводится; имя с союзом «и» — два дома; инструкция папки — три вопроса, один экран.
