# Создание инструкций

## Уникальный контекст

Компетентный агент понимает свою рабочую зону, но локальный фокус скрывает
невыводимую правду, которая меняет решение. Общий свод лечит эту слепоту
перегрузкой; полезная инструкция вместо этого доставляет нужный смысл вовремя.

## Цель пользователя

Создай или перепиши минимальный граф, который доставляет невыводимую внешнюю
связь или локальный hard line от единственного владельца до первого зависимого
решения без перегрузки и закрытия законного пути.

## Протокол поведения

> «мы создадим сразу несколько пошаговых протоколов, независимых… все
> протоколы должны быть по порядку, как агент должен думать.»

1. Из цели проекта, слов владельца и действующей цепочки инструкций получи карту
   `первое зависимое решение → невыводимая правда → единственный владелец`.
2. По этой карте проверь реальный текущий путь ко всей цели. Верни `no-change`
   только когда наблюдение подтверждает доставку всей нужной правды; текст,
   ссылка и самоотчёт сами по себе не являются evidence.
3. Из доказанного пробела установи владельца и межзонное ребро. Если они
   неизвестны, передай ограниченное поручение независимому
   [чистому разведчику](agents/zone-scout.md) и продолжай только по его evidence.
4. По подтверждённой карте выбери самый узкий слой, который сработает до
   решения. Изменяемая правда остаётся у канонического владельца, а инструкция
   даёт условный маршрут к ней.
5. В выбранном слое сначала перепиши цель и уникальный контекст как commander's
   intent для первого зависимого решения.
6. Из этого намерения собери минимальный граф. Добавляй только невыводимые
   связи, точные CLI/API/schema-контракты, safety/authority, критический порядок
   и фальсифицируемую приёмку; пиши полными однозначными предложениями.
7. Собранный точный кандидат передай в самостоятельную
   [стадию проверки](references/verification.md).
8. Из её квитанции установи только пакет, один идентификатор которого покрывают
   `pass` и безусловное exact approval: сначала измени существующего tracked
   owner, синхронизируй только его существующие projections и live, затем
   проверь состав, байты и ссылки. Несовпадение идентификатора, отсутствие
   tracked owner или иной вердикт оставляет все адреса неизменными.
