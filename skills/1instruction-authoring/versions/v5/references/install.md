# Установка

## Уникальный контекст

Хороший текст, записанный не в semantic owner или не во все существующие
проекции, создаёт расходящиеся источники правды.

## Цель

Запиши неизменённый одобренный пакет в разрешённого владельца и его
существующие проекции.

Вход: одобренный артефакт проверки точного кандидата.

1. Сверь fingerprint, положительный вердикт и безусловное разрешение с точной
   версией; несовпадение оставляет итоговые адреса неизменными.
2. Найди владельца по реестру проекта; существующий tracked owner изменяется
   первым, а при его отсутствии новое дерево источника не создаётся.
3. Синхронизируй только существующие проекции и live-пакеты.
4. Проверь состав, побайтовое совпадение переносимых файлов и внутренние ссылки.
5. В сдаче назови установленную версию, проверки и оставшийся пробел.

Выход: установленная точная версия либо неизменённые адреса с недостающим входом.
