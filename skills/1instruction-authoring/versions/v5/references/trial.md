# Чистый опыт

## Уникальный контекст

Самоотчёт исполнителя и правдоподобный текст не доказывают причинность.

## Цель

Получи наблюдаемую дельту, меняя только instruction-tree.

Вход: точный кандидат с допустимым активным бюджетом.

1. Материализуй исходное и кандидатное деревья в изолированных временных
   адресах; до exact approval не записывай candidate в official owner,
   projections или live.
2. Проведи слепой matched trial для целевого, нерелевантного и законного
   альтернативного сценариев, меняя только instruction-tree.
3. Для долгоживущего правила добавь решение после отвлекающей траектории.
4. Не сообщай исполнителям ожидаемое решение.
5. Зафиксируй первое решение, использованное evidence, изменения файлов и
   итоговый результат; самоотчёт не засчитывай.

Выход: `acceptance` с адресованными наблюдениями всех применимых сценариев.
