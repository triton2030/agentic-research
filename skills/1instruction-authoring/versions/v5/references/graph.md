# Сборка графа

## Уникальный контекст

Сборка по старым строкам переносит в новый граф дубли и выводимые процедуры.

## Цель

Собери минимальный граф из подтверждённых владельцев и зависимых решений.

Вход: допущенная карта решения и выбранная поверхность.

1. Сначала перепиши цель и уникальный контекст затронутого файла.
2. Оставь hard lines только для точных невыводимых CLI/API/schema-контрактов,
   safety/authority, критического порядка и фальсифицируемой приёмки.
3. Храни изменяемую правду у канонического владельца; другие инструкции дают
   условный маршрут к нему.
4. Локальное невыводимое правило оставь у своей зоны.
5. Если изменение владельца требует реакции потребителя, назови потребителя и
   требуемую реакцию.

Выход: `wording` с полным графом, картой владельцев и пробелами.
