# Проверка слоя

Текст, который выглядит верным, поведения не доказывает; доказывает след
свежего агента.

До проверяющих запусти в Claude Code `/doctor prompt-audit <путь>`
(с 2.1.283): он ищет строки под старые модели, ссылки на несуществующее
и противоречия между файлами. Его находки — кандидаты для проверки
по источникам, а не приёмка.

Три проверяющих, каждый в свежем окне и своей копии проекта. Сначала —
только рабочие задания своих случаев и слой тем путём, каким его грузит
рантайм, без роли и подсказки правил. После действий — черновик, источники
и роль.

| Роль | Случай | Вопрос |
| --- | --- | --- |
| Смысл | применимость: местная правда меняет выбор | объясняют ли местные факты важность; нет ли общих советов |
| Необходимость | неприменимость: лишнее условие не вызывает работы | что вредное вернётся без каждой строки |
| Доставка | конфликт с привычным кодом, пересечение условий | встретил ли агент правило до решения; папочный слой — сессией, открывшей файл в папке |

Сохрани след: файлы до решения, действия, результат. Находки принимай
по источникам. Допустима одна повторная волна по затронутому. Непроведённый
или проваленный случай оставляет приёмку открытой.
