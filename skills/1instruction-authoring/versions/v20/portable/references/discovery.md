# Поиск местной правды

Вход — предстоящая работа и её зоны: из задачи, git, целей проекта или слов
владельца; не нашлось — спроси владельца. Для этого хватает дерева файлов,
содержимое зон пока не открывай.

1. По каждой зоне запиши, что сделал бы ты, не читая проект: чем правят, что
   читают до правки и обновляют после, какой файл владеет правдой, чего
   нельзя, что решает владелец. Уже открытую зону пометь: прогноз по ней
   слабее.
2. Разошли читателей по `../agents/zone-reader.md` на каждую отслеживаемую
   папку, а не только на зоны работы: связь, управляющая зоной, бывает
   заявлена в любой другой. Мелкие соседние папки — одному читателю; папки
   без читателя назови с причиной.
3. Отбери кандидатов по «Когда решаешь, нужна ли строка» в `SKILL.md`.
   Вычитание прогноза находит расхождения; дорогой поиск, наблюдаемое
   нарушение и записанная необратимая граница проходят и при совпадении.

Выход: кандидаты с зоной, дословной строкой правды и основанием допуска;
папки без читателя; вопросы владельцу одним пакетом.
