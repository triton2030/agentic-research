# Выбор поверхности

## Уникальный контекст

Слишком ранняя поверхность перегружает все задачи, а слишком поздняя не
достигает решения, которое должна изменить.

## Цель

Доставь допущенный смысл самым дешёвым слоем, который достигает первого
зависимого решения, и сохрани одного владельца.

Вход: смысл, область действия, момент применения и цена промаха.

| Поверхность | Естественная область |
| --- | --- |
| корень / папка | все задачи проекта / одно поддерево |
| скил / план / чат | повторяемый момент / длинная работа / текущая задача |
| принуждение / правда | жёсткий инвариант / изменяемое каноническое значение |

1. Сравни доставку «никогда», «всегда» и «в нужный момент».
2. Постоянная строка допустима, только если нужна большинству задач области и
   меняет наблюдаемое действие.
3. Если применимый владелец уже существует, исправь его и не создавай дубль.

Выход: выбранная поверхность, владелец смысла, момент доставки и постоянная
цена.
