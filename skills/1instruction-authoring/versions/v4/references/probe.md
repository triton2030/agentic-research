# Пробник

## Уникальный контекст

Правдоподобный текст и самоотчёт агента не показывают, что именно инструкция
причинила нужное решение.

## Цель

Фальсифицируй кандидата сравнением с исходным деревом: нужное действие должно
измениться из-за подключённого дерева инструкций без закрытия законного пути и
лишнего чтения.

Вход: точный кандидат, текущее дерево и задачи для дорогих ошибок.

1. Материализуй кандидата во временном дереве, не меняя итоговые адреса.
2. Выбери задачу для самой дорогой межзонной ошибки и отдельный случай для
   каждого правила «Нерушимо:».
3. Запусти чистую пару на одной модели, настройках, задаче и рабочих файлах;
   единственная переменная — подключённое дерево инструкций целиком.
4. Сравни действия, изменения файлов и прочитанные адреса; самоотчёт агента не
   является доказательством.
5. Считай кандидата опровергнутым, если решение не изменилось, результат
   ухудшился, законный путь закрылся или чтение стало лишним.
6. Для постоянно действующего правила проверь решение после отвлекающей
   траектории либо назови утверждение о долгом удержании непроверенным.

Выход: причинные доказательства, покрытые и опровергнутые утверждения, пробелы
и вердикт по кандидату.
