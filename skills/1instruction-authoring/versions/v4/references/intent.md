# Замысел

## Уникальный контекст

Проект уже объясняет большую часть правильного поведения через цель, текущие
владельцы правды и существующую цепочку инструкций. Новая строка легко
дублирует этот вывод или закрывает полезный путь.

## Цель

Найди самое маленькое изменение контекста, которое даёт невыводимую пользу
решению и стоит дороже создаваемого ограничения.

Вход: запрос и существующий проектный контекст.

1. Восстанови цель проекта, применимые слова владельца и текущую цепочку
   инструкций.
2. Для затронутых зон назови цель, не-цель и цену ошибки; при одном правиле не
   картируй незатронутый проект.
3. Для каждого кандидата назови уже выводимое без него поведение, закрываемый
   законный путь и возможный вред соседней задаче.
4. Не превращай нерешённый вопрос или догадку в правило.

Выход: «изменение не нужно» с адресом текущего владельца и доказательствами
либо «допущено» с кандидатом, затронутыми зонами, их целями, не-целями, ценой
ошибки, текущими владельцами и пробелами.
