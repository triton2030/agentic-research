# Зонная разведка

## Уникальный контекст

Связи между зонами нельзя надёжно вывести из дерева папок, а подсказанное
разведчику ребро превращает поиск в подтверждение ожидания.

## Цель

Верни минимальную карту подтверждённых внешних рёбер затронутых зон и честную
границу покрытия.

Вход: допущенный кандидат; для каждой зоны — цель, не-цель, цена ошибки,
текущая цепочка инструкций и перечень соседних зон без предполагаемых рёбер.

1. Запусти по одному независимому чистому агенту на зону по
   [контракту разведчика](../agents/zone-scout.md) и передай весь вход этой
   зоны дословно.
2. Объедини отчёты без дублей; вопросы без ответа оставь пробелами.

Выход: прочитанные адреса, покрытие, рёбра с моментами, неочевидные правила и
нерешённые вопросы по каждой зоне.
