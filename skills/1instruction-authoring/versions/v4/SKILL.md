# Создание инструкций

## Уникальный контекст

Инструкции нужны там, где сфокусированный на своей зоне агент иначе пропустит
внешнюю правду, меняющую решение.

## Цель пользователя

Создай или перепиши и установи минимальный причинно проверенный граф
инструкций, который доставляет эту правду до первого зависимого решения.

## Пять нерушимых правил

1. Корень не владеет смыслом, изолированным в одном поддереве.
2. В одной точке решения действует не больше двадцати самостоятельных смыслов.
3. Папочная инструкция хранит только невыводимый контекст своего поддерева.
4. Один смысл имеет одного владельца.
5. Итоговые адреса меняются только по безусловному разрешению владельца на
   точный пакет.

## Маршрут самостоятельных стадий

В текущей стадии читай только один справочный файл. Справочный файл возвращает
артефакт стадии и никогда не требует чтения другого справочного файла.

1. Перед изменением восстанови замысел по [Замыслу](references/intent.md);
   выход «изменение не нужно» завершает работу без чтения следующих стадий.
2. При создании графа зон или неизвестных зависимостях проведи
   [Зонную разведку](references/zones.md).
3. Когда не определён владелец одного допущенного смысла, используй
   [Выбор поверхности](references/placement.md).
4. Когда строка допускает несколько честных прочтений, используй
   [Формулировку](references/wording.md).
5. Когда обязательные решения и доказательства собраны, выполни
   [Сборку](references/assembly.md).
6. Для готового кандидата проверь [Активный бюджет](references/budget.md).
7. Для точного кандидата с допустимым бюджетом проведи
   [Пробник](references/probe.md).
8. Перейди к [Установке](references/finish.md), только если пробник причинно
   подтвердил нужное действие без названного вреда; неизвестный или
   отрицательный вердикт оставляет адреса неизменными.
