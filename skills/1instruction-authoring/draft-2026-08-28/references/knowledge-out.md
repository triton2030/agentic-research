# Значение вон, указатель остаётся

Вход: в файле-источнике адреса смешаны со знанием или правилами.

- Классифицируй каждый смысл и отдай его слою-владельцу:

| Класс | Где живёт |
| --- | --- |
| поведение | самый дешёвый instruction layer в момент решения |
| ориентировка | слой своей частоты; с причиной, зачем туда смотреть |
| изменяемое значение | canonical owner: code, config, docs, decision file |
| дорогой найденный маршрут | INDEX.md |

- Версия, число, статус, перечень сущностей и «у нас используется» —
  кандидаты на значение; в инструкции остаётся адрес owner-а, если он меняет
  действие.
- Ориентировка не входит в поведенческие обязанности — её цену и размещение
  решает placement; голый список, который агент восстановит listing-ом, не
  ориентирует.
- Готово, когда instruction surface не может молча разойтись с изменяемым
  владельцем, а каждый оставшийся указатель объясняет момент захода.
