# Замысел

Вход: стадия 1 — вызов скила на создание или переписку слоя инструкций.

1. Восстанови цель проекта из файлов, GOAL и прежних слов владельца.
2. Цель не восстановилась — задай владельцу один вопрос, назвав развилку из
   двух реалистичных ответов, которые материально меняют результат; серию
   вопросов не задавай.
3. Составь карту зон: где живёт каждая крупная зона работы — например код,
   планирование, документация, спецификации.
4. Назови цель каждой зоны — чем она служит цели проекта.
5. Существующий свод — тоже вход: пометь файлы, нарушающие цель, форму или
   граф связей; переписываются только они.
6. Прежние провалы дают случаи, существующий свод — карту смыслов; готовое
   правило не переписывается без расхождения с целью.

Выход: цель проекта · карта зон с целями · список нарушителей · нарезка веера
для стадии 2.
