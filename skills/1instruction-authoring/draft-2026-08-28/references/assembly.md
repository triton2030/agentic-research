# Сборка

Вход: стадия 3 — черновики зонных файлов, кандидаты в корень, ответы
владельца на вопросы разведки.

1. Сверь рёбра двусторонне: зона A зависит от правды в B — файл B должен
   знать читателя A («изменил здесь — создай задачу сверки»); ребро, видное
   только с одной стороны, чини.
2. Дубль правила между файлами → правило остаётся у владельца, у остальных
   ссылка: адрес повторять можно, пересказ — нельзя.
3. Изменяемые значения и знания → canonical owner: код, конфиг, доки,
   decision-файл; в инструкции остаётся адрес, если он меняет действие.
4. В корень — только кросс-зонное: смысл одной папки в корне не живёт никогда.
5. «Нерушимо:» из кандидатов получает только правило, прошедшее критерий
   формы; папка-склад остаётся адресом в чужих файлах, без своего файла.
6. Адреса, не влезающие в потолок корня, → карта папок: owner-файл значений,
   не инструкция.
7. Корень-роутер пишется последним: контекст, адреса и связки в уже готовые
   зонные файлы.

Выход: полный пакет candidate-текстов со счётом формы каждого файла.
