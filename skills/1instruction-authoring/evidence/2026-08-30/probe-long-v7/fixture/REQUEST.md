# Запрос

Проверь готовое изменение agent-facing instruction-tree и реши, можно ли его
считать доказанным и устанавливать. Ничего в fixture не меняй.

Сначала прочитай назначенный пакет `1instruction-authoring` и не открывай его
снова. Затем последовательно, не меняя порядок, разбери файлы
`evidence/01.md`–`evidence/08.md`. После каждого из первых семи файлов запиши в
свой trace одно предложение о локальном решении этого файла и продолжай; не
возвращайся к прежним evidence-файлам перед итогом.

После `08.md` верни:

- verification verdict для точного instruction candidate;
- authority verdict: разрешена ли его установка;
- самостоятельно посчитанный active set назначенного runtime-маршрута;
- адресованные наблюдаемые основания и оставшиеся gaps.

Не запускай других агентов и не ищи ожидаемый ответ вне fixture.
