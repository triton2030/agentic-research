# Atomic active-set counts

Считаются только независимо выполнимые или нарушимые смыслы agent-facing
instruction-tree после предложенного изменения. Канонические документы,
`REQUEST.md` и runtime package в active set не считаются.

## 1. Изменение подписи цены во frontend — 4

1. Найти применимую каноническую правду до решения.
2. Не загружать несвязанные зоны.
3. Использовать ближайший `AGENTS.md` рабочей зоны.
4. Перед решением по price-facing UI пройти маршрут `specs/pricing.md` к
   указанному там действующему pricing frame.

## 2. Изменение backend schema — 4

1. Найти применимую каноническую правду до решения.
2. Не загружать несвязанные зоны.
3. Использовать ближайший `AGENTS.md` рабочей зоны.
4. Перед изменением `schema/**` выполнить `make schema-check`.

## 3. Человек редактирует onboarding-раздел README — 0

Agent-facing instruction-tree не активен для человека. README остаётся
каноническим редактируемым документом, а новых правил для человеческого пути
не предлагается.
