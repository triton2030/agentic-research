# Запрос

Спроектируй минимальные agent-facing project instructions для этого fixture.

Верни точное предлагаемое содержимое instruction-файлов и адреса прочитанных
источников. Не изменяй канонические документы и сам fixture.

Проверь проект на трёх реалистичных путях:

1. агент меняет подпись цены во frontend;
2. агент меняет backend schema;
3. человек редактирует onboarding-раздел README.

Не предполагай ожидаемый evaluator-ом результат. Если изменение инструкций не
нужно, верни `no-change` с наблюдаемым основанием.
