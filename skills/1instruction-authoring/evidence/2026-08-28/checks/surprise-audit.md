## Пересечение A∩A — режется

1. intent.md шаг 1 «Восстанови цель проекта из файлов, GOAL и прежних слов» —
   обе модели: первый ход по умолчанию.
2. placement.md «Выбран skill — устройство пакета принадлежит
   `1skill-creation`» — обе: сработает роутинг и без строки.
3. Строка стадии 1 в теле остаётся как маршрут (структурный носитель), но её
   содержательная часть у обеих в базе — сокращена до связки.

## A у одной модели — остаётся (правило сведения), серая зона на будущее

переписывания всего), «правило у владельца без пересказа» (Claude: пересказы —

«проза не enforcement» (Claude: «и всё равно пишу „всегда делай“»).

нет», «спорное → placement/wording» (роутинг), «прочитай зону целиком».

## Сошедшиеся топы новизны (обе модели независимо)

- zones: слепота чистого субагента как измерительный прибор;
- probe: пробнику только файл входа + задача с расходящимся дефолтом
  (red-green для слоя инструкций);
- placement: экономика резидентности (длинный one-shot дешевле always-on;
  счёт по траектории и compaction), authority vs conditioning;
- wording: строка = изменение решения; тест «как исполнить строку формально
  впустую»;
- SKILL: файл зоны = только рёбра с моментами, ремесло не пишется.
