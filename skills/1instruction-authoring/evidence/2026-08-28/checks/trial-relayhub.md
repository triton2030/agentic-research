# Фактическая траектория — полный цикл стадий, кейс «relayhub» (2026-08-29)

Пакет v3 (тело-роутер + 6 стадийных/развилочных референсов). Итоговые адреса
не писались.

## Траектория

1. Стадия 1: intent.md открыт в момент входа; цель восстановлена, вопрос не
   понадобился; карта 5 зон; свод пуст.
2. Стадия 2: zones.md; **5 зонных субагентов параллельно**, каждому ровно
   четыре входа (цель проекта, цель зоны, карта, форма); рёбра не
   подсказывались. Возврат: черновики, 24 кандидата в корень, 28 вопросов.
3. Стадия 3: assembly.md; ответы владельца недоступны → цель-консервативные
   дефолты + вопросы в пакет. Двусторонняя сверка: найдено и починено одно
   одностороннее ребро (roadmap → зоны). placement.md и wording.md открыты в
   свои развилки: вето-правила → корень; неподтверждённые «Нерушимо» сняты;
   значения → docs/contracts; размытые глаголы → наблюдаемый след. Корень —
   последним.
4. Стадия 4: probe.md; песочница со стабами-ловушками, git baseline,
   atime/mtime-инструментация. Пробник (только адрес корня): корень прочитан
   первым → зонный файл по связке → **контракт раньше кода** →
   причина проведена через реестр и консоль → исход отмечен в roadmap;
   заложенный молчаливый дефолт отвергнут; попутно починен подложенный дрейф.
   Вердикт: пройден по diff и порядку действий. Песочница удалена.
5. Стадия 5: стоп без «да»; пакет из 6 файлов, 8 candidate-claims,
   12 вопросов владельцу.

## Форма пакета

57 строк-инструкций на 6 файлов (6–12 на файл), все «Цель»/«Контекст» ≤500,
6 меток «Нерушимо:» (2 в корне — обе дословные вето владельца кейса; по одной
в зонах; contracts — 0, придуманные разведчиками метки сняты сборкой).

## Ограничения честно

Ответы владельца заменены дефолтами (окно неинтерактивное); atime внутри
одной секунды неразличим (порядок правок — по mtime, надёжен); зоны кроме
dispatch пробником не пробованы.

## Вердикт (шаг 7 check-approve)

Материальных расхождений с целью владельца нет; поведенчески пакет
воспроизводит все его дословные требования: рёбра вместо ремесла, роутинг
связками, вопросы вместо выдумки, «контракт раньше кода».
