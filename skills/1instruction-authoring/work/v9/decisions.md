# Решения допуска — 1instruction-authoring v9, редакция 2

Выход гейта `references/behavior-protocol.md`, 2026-08-31. Вход — намерение
`commander-intent.md` (редакция 2).

## Что прошло сверх намерения и почему

| Единица | Исправляемый дефолт агента | Материальный вред без неё |
| --- | --- | --- |
| 1. Назвать предстоящую работу | берётся писать инструкции «для проекта вообще» | достаточность слоя нечем измерить, набор пишется для работы, которой нет |
| 2. Прочитать `discovery.md` до первого файла | читает проект, потом вспоминает свою привычку | привычка вытеснена прочитанным, вычитание даёт выдуманную добросовестность |
| 3. Объявить разделение в чате | пишет корневую и папочные по очереди | строка одной снимает нужду в другой, дубликация замечается после написания |
| 6. Двадцать единиц на голову зоны, не на файл | считает лимит по файлу | зона отсылает к скилу на 15 единиц, файл «в пределах», голова переполнена |
| 9. Отбор ближайшим артефактом только при обязанности его нести | берёт отбор у артефакта, не требуя его там | эпик без принципов — агент молча получает ноль, правило проваливается открыто |
| 10. Проход маршрутом и вывод «недостаёт ссылки» | на недоставку добавляет ещё инструкцию | слой растёт числом единиц вместо связей, попадая в собственную ловушку |

Единицы 4, 5, 7, 8 и часть 9 — дословно требуемые владельцем способы, они
проходят по правилу «пользователь потребовал именно способ», а не по выводимости.

## Что отклонено и каким ситом

| Кандидат | Сито |
| --- | --- |
| Проверять, что все ссылки слоя разрешаются | сильный агент сделает сам в контексте задачи |
| Не повторять одну правду в двух файлах | подразумевается третьей целью |
| Спрашивать владельца при неуверенности | очевидно передовой модели |
| Читать ближайший wisdom-файл перед правкой | project-specific, скил обязан быть переносимым |
| Сохранять карту потерь слоя | принадлежит другому владельцу, не этому скилу |
| Не подтверждать подсказанное межзонное ребро | поглощено правилом 5 `agents/zone-reader.md` |

## Как чистый агент прочтёт неверно

| Место | Неверное прочтение | Закрыто |
| --- | --- | --- |
| Шаг 1, «зоны» | одна папка, где лежит задача | «и зоны, которых она коснётся» — включая те, куда ложится результат |
| Шаг 2, «до первого файла» | шаг невыполним, корневой файл уже загружен | `discovery.md` шаг 1 разрешает пометку «предсказать не могу» |
| Шаг 6, «двадцати единиц» | лимит на файл, как в прежней версии | «не файл, а голову агента в зоне» с перечислением слагаемых |
| Шаг 9, отбор артефактом | инструкцию можно не писать вовсе | «лишь когда тот обязан отбор нести» |
| `discovery.md` шаг 2 | субагент нужен на каждую папку любого проекта | вход стадии ограничен зонами предстоящей работы |
| Правило про пробу | проверять слой не нужно вообще | шаг 10 тела остаётся обязательным проходом маршрутом |

## TWI Job Instruction

| Ступень | Где в пакете | Найденный разрыв |
| --- | --- | --- |
| Подготовка | шаг 1 | прежняя версия начинала с целей проекта, минуя предстоящую работу |
| Ключевой момент | шаг 2 | необратимый порядок: после чтения привычку не восстановить |
| Действие | шаги 3–9 | прежняя версия не знала бюджета головы и отбора артефактом |
| Проверка результата | шаг 10 | прежняя версия проверяла доставку, но не достаточность набора |

## След выполнения, который нельзя подделать пересказом

| Единица | След |
| --- | --- |
| Шаг 1 | названная работа с адресом источника: коммит, строка `GOAL`/статуса или цитата владельца |
| Шаг 2 | записанные ответы на семь вопросов; загрязнение видно по именам файлов проекта внутри них |
| Шаг 3 | сообщение в чате, стоящее раньше первой написанной строки любого файла слоя |
| Шаг 6 | арифметика зоны числом: слагаемые и сумма |
| Шаг 10 | пройденный маршрут с названием зоны и набора, который агент в ней получил |
| `discovery.md` 2 | возвраты субагентов с адресами и дословными строками |
| `discovery.md` 8 | пакет вопросов владельцу |
| `zone-reader.md` | список связей, где у каждой стоит дословная строка-источник |
