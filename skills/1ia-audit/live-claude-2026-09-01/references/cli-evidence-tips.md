# Evidence For IA Judgment

Use the chain `signal → candidate smell → read bodies → confirm authority → IA
judgment → smallest repair`. Length, headings, links, similarity, cluster and
rank are signals, never verdicts.

## Route Once

| Evidence needed | Owner route | IA receives |
|---|---|---|
| Addressable Markdown file, section or folder bodies | `md` CLI (`1cli-tools`) | addressed bodies, actual scope and gaps |
| Unknown semantic owner/duplicate | `1md-search` | ranked candidates, read bodies, effective scope and gaps |
| Holders, anchors, cycles or mutation impact | `1md-graph` | change-contract packet |
| Exact refs, terms, numbers or counts | `1cli-tools` | scoped exact evidence |

Do not copy their command order, index recovery, schema or closeout rules into
this skill. Give the owner project root, bounded zone and one independently
retrievable question; consume its actual coverage and gaps.

## IA-Owned Candidate Channels

Два bounded IA-вопроса не сводятся к direct reading и не получают shape verdict
из tool output:

| Candidate question | Channel |
|---|---|
| Повторяющаяся form family, near-duplicate pair или intra-file drift на bounded cohort | `md audit CORPUS --path-include GLOB --json` |
| Нормативный claim против уже принятого канона | `md canon-check FILE CORPUS --json` |

Оба cost-bearing и требуют тёплого индекса. `audit` возвращает ranked findings
с собственной severity; это nomination, не mechanism. `canon-check` возвращает
claim/authority-quote pairs, но retrieval не доказывает противоречие: прочитай
обе стороны и проверь attribution. Пустая выдача означает `no candidate in this
probe`, а не отсутствие IA-дефекта.

## Interpret Candidates

| Signal | Required body check | Possible judgment |
|---|---|---|
| Same idea in several files | explicit responsibility, unique obligation, lifecycle | duplicate truth / truth + view / legitimate siblings |
| Search top result is not owner | live responsibility and retrieval surface | retrieval gap; authority unchanged |
| View contains unique rules | canonical home of the rule | view became truth |
| Large or mixed container | reader action, update unit and validation | cohesive / mixed functions / unknown |
| Topic cluster differs from folder | actual owner workflow | topology smell, not automatic move |

Semantic overlap only nominates a pair. Read both bodies. Repeated-concept
components do not appoint an owner. A corpus health score does not decide a
split/merge/move.

## Confidence

- Search rank can prove discoverability, not authority.
- A cold/partial/busy index lowers coverage confidence; recovery belongs to
  `1md-search`.
- Threshold tuning is justified only when it changes a material candidate set
  and can be calibrated against one known positive and negative pair.
- When move/rename/delete, holders, anchors, links, cycles or changed-claim
  propagation can change the operation pair, request a read-only graph-impact
  packet before IA verdict. After an accepted and authorized shape change,
  return edge mutation and structural closeout to `1md-graph`. A local
  section/form edit without graph effects stays in the current layer.

Return to `1ia-audit` once candidates are addressable, bodies are sufficient,
authority is confirmed or explicitly unresolved, and scope/gaps are named.
