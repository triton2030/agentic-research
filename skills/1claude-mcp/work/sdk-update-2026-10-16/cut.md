# Адресное обновление справки Claude Bridge

Заказ — реализовать согласованный технический апдейт и согласовать справку.
Живой владелец: `experiments/claude-bridge/codex-skill/1claude-mcp/`.
Исходник до правки: Git `c6521453ada6010ca0125f66f91819644a54a7d8`.
`SKILL.md`, модельный выбор, полномочия и четыре MCP-инструмента сохранены.

| Изменение | Сохранённый смысл и основание |
| --- | --- |
| `prompting.md`: буквальная передача текста | Добавлена особенность SDK 0.3.300; путь остаётся доступен для намеренного чтения Claude. Live slash-prefixed prompt вернул заданный маркер. |
| `tools-and-sessions.md`: контекст в diagnostic | Новая возможность существующего observe; неизвестная оценка отличается от нулевого расхода. Live-проба вернула только четыре числовых/типовых поля. |
| `results-and-recovery.md`: runtime, rate_limit, startup error | Сведения для решения при сбое; не новая процедура и не гарантия отсутствия расходов. Проверены typed fixtures и живые ответы. |
| `native-capabilities.md`: маршрут контекста и дата API | Summary перенесён в возможности моста; full остаётся native API. Остальные возможности сохранены; объявлена граница между чтением API и live-проверкой. |

Полная переработка скила и расширение набора операций не входят в этот проход.
Карта потерь: удалённых пользовательских условий нет.
## Проверка и доставка

Три независимых агента `gpt-6.1-sol` проверили основания утверждений,
сохранность условий и применение в пяти случаях. Приняты две находки:
указан пропуск начальных вложений в `verbatimPrompts`; категоричный запрет
повтора после startup failure заменён зависимостью действия от причины.
Других существенных замечаний к справке не осталось. Финальные формулировки
сверены с `sdk.d.ts` установленного SDK 0.3.300. В README также уточнена
граница между auth preflight и поздним событием overage.

Установленная копия в `~/.codex/skills/1claude-mcp/` совпадает с владельцем
по `diff -r`. Корневой `SKILL.md` не менялся. Внутренние ссылки проверены
`lychee --offline` 0.24.2.

Живые receipts: `~/.codex/claude-bridge-evidence/2026-10-16-live.json` и
`2026-10-16-host.jsonl`. Последний содержит реальные вызовы всех четырёх
инструментов из свежего Codex, новые runtime/rate/context-поля и stop.
Diagnostic передаёт только четыре поля оценки; детали Read в него не входят.
Fixtures покрывают timeout, unavailable, closed и startup failure до init.

Ограничения evidence: живая оценка контекста получена после завершённого
хода при небольшой заполненности, не у предела и не в активном ходе.
Живой literal-test проверяет начальный `/`; отсутствие раскрытия `@path`
подтверждено контрактом SDK и переданным флагом, отдельной live-пробы нет.
Наличие rate event не подтверждает запрет Usage credits перед запросом.

Независимое техническое ревью Opus 5.5 Max выявило две ошибки: pre-init result
без reason терял исходную причину, а rate event между result и idle не попадал
в итоговое поле. Обе исправлены. Добавлены проверки one-shot с reason и без,
доставки новых полей через MCP и таймаута внутри auth preflight с завершением
реального fixture-процесса. Итоговый `npm run ask:test`: 50/50, exit 0.

Отдельная native-проба с ошибочным `HTTPS_PROXY` после успешного auth preflight
вернула `claude_startup`, `startup_failure_reason: proxy_invalid`, ноль ходов
и `resumable: false`. Receipt —
`~/.codex/claude-bridge-evidence/2026-10-16-startup.json`.
Это подтверждает порядок доставки pre-init result в SDK 0.3.300 / CLI 2.1.300.
Reasonless startup остаётся проверенным fixtures и разбором CLI, не live-сбоем.

Замечания об отсутствии fresh-host evidence и оговорки verbatim относились
к неполному входу ревью: receipt хоста уже существовал, оговорка внесена до
получения заключения. Дополнительное предупреждение о несовпадении версий
не добавлялось: ревью не установило сбой совместимости текущей проверенной
пары; смена системного CLI остаётся отдельным обновлением.
