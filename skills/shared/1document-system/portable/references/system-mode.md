# System Mode

Design the smallest useful documentation system now and an explicit change
path later. Do not materialize future taxonomy.

## Order

```text
future scenarios → information obligations → owners and types → lifecycle
→ metadata → topology → minimum materialization
```

Read the live project first — progressively: known target directly; known
folder via `1md-read` (map → select → bounded extract); unknown semantic owner
via scoped `1md-search`. Then ask only questions whose answers change owners,
types, lifecycle or topology.

## Zones

`canon/` = current truth · `_ops/` = control and change state · `projections/`
= derived reader views. Map existing homes onto these roles first; never
create parallel zones or rename automatically. Contract:
[topology-contract](topology-contract.md).

## Greenfield

Fix boundary, readers, edit/retrieval scenarios, nearest decisions. Admit only
types whose absence leaves a live information gap ([catalog](catalog.md)).
Materialize `_ops/documentation/` with one substantive Documentation System
Map; every other home appears together with its first admitted artifact.
Future types live in the roadmap as scenario + observable trigger — no
folders, templates or registry entries in advance.

The map keeps: boundary · zone contract · retrieval paths · admitted registry
with default homes and token budgets (number per file + executable check) ·
folder-axis policy · metadata profile · topology · roadmap · open questions ·
stop conditions.

## Refactor

The result is a target map with per-file dispositions — `keep / merge / split
/ projection / archive / unresolved` — not a rewritten tree. Cover the whole
corpus except projection content; give mixed files section-level dispositions;
for every duplicated mutable answer name the occurrences, the confirmed owner
(or `owner unresolved`) and the fate of the other occurrences. Similarity and
text quality are discovery signals, never authority verdicts.

Stop at mapping. Rewrite, move and delete belong to a separately accepted task
under [compaction-safety](compaction-safety.md).

## Closeout

Zones distinguishable · current types separated from roadmap · no empty
taxonomy · ops did not become truth · projections have lineage · the map stays
a router, not a second canon. Large corpus → [delegation](delegation.md) only
after independent split.
