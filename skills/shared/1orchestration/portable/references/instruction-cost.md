# Цена инструкций

Вес класса решает, кому инструкция выдаётся и каким приёмом. Лёгкий
класс остаётся в своде без повтора; тяжёлый получает приём: окно
советника · повтор в промпте в момент действия · наблюдаемый след.

| Класс инструкции | Цена | Приём |
|---|---|---|
| Формат, стиль, шаблон | лёгкая | свод; не повторять |
| Запрет «не делай X» | средняя | в задании переписать позитивной операцией |
| Сработать в далёкий момент («в конце не забудь…») | тяжёлая | повтор в промпте агента, в чей момент стреляет |
| Экстраполяция, генерация нового (принципы, достройка пустот) | тяжёлая | окно советника |
| Самопроверка своей работы | невыполнимая | только другое окно |
| «Учитывай», «помни о» — узнавание без операции | тяжёлая | заменить операцией с предъявляемым следом |

Дешёвые окна на лёгком классе — минимум два с перекрытием зон:
слепая зона одного окна невидима снаружи (2 из 5 извлекателей в
живом прогоне 2026-08-10 на одном корпусе).
