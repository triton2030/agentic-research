# Предполёт записи

Один момент: перед запуском пишущих. Пропуск = перетёртые правки
или потерянная чужая работа.

- Футпринты собраны и непересекаемы по контракту
  `1planning`/delegation; только конечные файлы, не каталоги.
- `git status`: чужие незакоммиченные правки не трогать — это может
  быть живая параллельная работа владельца. Сузить футпринт мимо;
  не выходит — стоп и вопрос владельцу.
- Зафиксировать `git rev-parse HEAD`; после полёта `git diff --stat`
  подтверждает: изменения легли в футпринты, оркестратор писал
  только в носитель режима.
- В плановом режиме бюджет каждого модуля заполнен: N шагов и
  «достаточно, когда …».
