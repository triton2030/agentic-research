# Product Frame — 1deep-agents

## Цель-сцена

Работа упёрлась в пустоту или конфликт: решения нет ни у одного владельца
истины (принципы, GOAL, спеки, доки, прошлые цитаты) либо источники
несовместимы. Агент предъявляет след поиска, запускает минимум три чистых
субагента — каждому одна профессиональная методология целиком — и
принимает решение автономно, с видимым следом методов, не спрашивая
владельца.

## Тайбрейкеры

1. След поиска сильнее скорости: пустота доказывается, не заявляется.
2. Долговечная правда владельца и конфликт его решений — стоп и вопрос;
   порог — корневое правило записи, не собственная формулировка.
3. Метод целиком сильнее адаптации: гибрид = один вывод под ярлыками.
4. Решение с победившим основанием сильнее совета и сильнее консенсуса.
5. Панель линз по траектории — `1fresh-eyes`, не сюда.

## Аппетит

Тело ≤ ~100 строк: три зонтика + два наблюдаемых гейта; каталог методов —
только в references/frameworks.md. Пересмотр: прогон показывает решение
без следа поиска, смешанные методы или подъём на уже решённое.
