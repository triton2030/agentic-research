# Claude

Отдельный свежий координатор получает область, режим, решения пользователя,
адрес скилла и папку сессии. Листовые задания запускает общим CLI через
установленный Codex и его ChatGPT-вход: Luna Max, без перехода на Sonnet.

Установка скилла не устанавливает Codex и не авторизует его. Отсутствующий
маршрут остаётся препятствием. Вызывающий получает короткий итог координатора;
если отдельное окно недоступно, координирует сам и называет отсутствие изоляции.
Запрошенная модель не доказывает фактически resolved model.
