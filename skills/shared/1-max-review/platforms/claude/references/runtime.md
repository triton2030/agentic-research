# Claude

Передай сбор и приёмку отдельному свежему координатору с сильной доступной
моделью. Листовые проверки запускаются общим `max-review` через Codex CLI:
Luna Max фиксирована, автоматического перехода на Sonnet нет.

Передай область, режим, существенные решения, адрес скилла и папку сессии.
Координатор возвращает короткий итог; вызывающий не загружает все переписки.
Если отдельное окно недоступно, явно назови ограничение: координация остаётся
в текущем контексте и обещанная изоляция не достигнута.

Установка скилла не устанавливает Codex и не авторизует его. Нужен существующий
ChatGPT-вход Codex CLI. Отсутствующий маршрут сохраняется как препятствие.
Готовые пакеты не отменяют системные инструкции, лимиты подписки или накладные
расходы запуска. Запрошенная модель не равна доказанной resolved model.
