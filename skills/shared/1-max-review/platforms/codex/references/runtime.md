# Codex

Отдельный свежий native subagent координирует проверку. Он получает область,
режим, решения пользователя, адрес скилла и папку сессии. Листовые задания
запускает общим CLI через установленный Codex и его ChatGPT-вход: Luna Max.

CLI-процессы не занимают слоты native subagents, но используют лимиты сервиса.
Вызывающий получает короткий итог координатора. Если отдельное окно недоступно,
координация остаётся у вызывающего; отсутствие изоляции назови явно.
Запрошенная модель не доказывает фактически resolved model.
