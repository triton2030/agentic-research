# 1md-read

## Цель

Знать доступные способы исследовать множество Markdown-файлов по описаниям и
заголовкам, не открывая их тела, — и вернуться к исходной задаче.

## Критерии успеха

Каталог вызван, найденный способ назван своим именем, исходная задача
продолжена. Строка о готовности без вызова каталога критерием не является.

## Инварианты

Живая поверхность возможностей принадлежит `md tools --json` и описаниям
`1md-*`. Копия команд внутри скила устаревает вместе с инструментами и
размывает главный сигнал.

## Дельта

Ни один соседний скил не называет команды слоя чтения: `1md-search` ведёт к
поиску по смыслу, `1md-graph` — к влиянию правки. Без этого скила дешёвый
маршрут по описаниям и заголовкам остаётся невидимым, и много файлов читаются
по одному.

## Известные сбои

- команды слоя вписаны внутрь скила → снимки протухают вместе с инструментом →
  `sync-skill-docs.py --check` краснеет на обеих копиях → Инварианты

## Механика

```bash
md tools --json
```

Вернись к исходной задаче.

## Завершение

Одной строкой назови найденный способ и продолжай:

```text
Читаю много файлов через <способ>, продолжаю работу.
```
