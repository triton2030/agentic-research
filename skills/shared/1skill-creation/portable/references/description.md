# Имя и description

Нужно, когда пишутся или чинятся имя и `description`: скил не вызывается,
вызывается слишком рано или сталкивается с соседом.
До выбора скила тело недоступно: имя и `description` — вся поверхность запуска.

1. Форма — `Use when <наблюдаемый момент> требует <функцию>. <Ближайшая
   граница — только при реальной коллизии>.`; ключевой случай стоит первым.
2. Имя — по операции или моменту, а не по общей теме.
3. Слова, которыми пользователь зовёт скил, оставь: это разные двери.
   Синонимы одного смысла сними. Фразу, которая не меняет решение
   **use now · not yet · neighbor**, удали.
4. Вызов проверяют фразами пользователя в 5–10 слов: use вызывает этот скил,
   skip — нет, near-miss выбирает соседа; для позднего момента — до и после
   его наблюдаемого признака. Замер частоты вызова в `skill-creator`
   предлагается пользователю вместе с остальной проверкой.

`description` — по-английски, до 200 символов, без инструкций тела.
