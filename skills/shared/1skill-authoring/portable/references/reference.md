# Reference-файл

Кому: агенту, пишущему `references/` создаваемого скила, обоих классов.
Reference — не приложение и не склад: открытый файл попадает в тот же
контекст, что и тело, его правила тратят тот же бюджет внимания.

## Бюджет — траектория, не строки

Статического порога правил нет — бюджет задаёт владелец (для скилов ~10
обязанностей), а счёт ведётся по траектории (владелец счёта — `placement.md` в
`1instruction-placement`). В agentic coding OctoBench (2026) при среднем
наборе 32.7 проверок модели выполняли отдельные пункты в 79.75–85.64%, но весь
набор — лишь в 9.66–28.11%; у большинства adherence снижался с накоплением
ходов. VerIFY отдельно показал на тестировавшихся моделях, что паттерн прежних
ответов ассистента влияет сильнее простой позиции инструкции: нарушающая
история тянет следующее нарушение, соблюдающая — помогает удержать правило.

Следствие: каждое правило reference платит не один раз, а в каждом решении,
которое должно изменить. Считай active obligations, число decision points,
конфликты, историю/tool output и ожидаемые compaction boundaries. Длинный
справочник фактов на один момент законен, когда точность знания окупает context
cost; длинный список persistent правил может перегрузить короткий файл при
любом числе слов. Источники и ограничения переноса — в history/evidence пары.

## Один файл — один момент

Под один конкретный ход открывается ровно один файл. Не влезло — в файле два
момента: режь по моменту, не по языку и не по объёму. Первые строки файла
называют момент и что файл даёт; дальше — операции и точные факты этого
момента. Философия, вторая теория и «на всякий случай» не кладутся: нужный
факт тонет, агент не дочитывает. Reference не повторяет и не оспаривает ни тело, ни
соседний reference: перед записью процитируй строку, с которой новая могла бы
столкнуться, и назови, кто владелец смысла. Не нашёл столкновения — так и
напиши; молчание не считается проверкой.

## Повтор тела — только помеченной копией

Независимый пересказ правила тела — вторая правда и дрейф. Повтор допустим в
точке действия, помечен как копия формулировки владельца и правится вместе с
ней.

## Признак готовности

Под реальный ход: файл открыт в свой момент, момент закрыт одним этим файлом,
ни одно правило файла не повторяет тело без пометки копии и не оспаривает его.
