# Применение продуктовой правды

## Уникальный контекст

Без проверки агент заменяет продуктовую правду отраслевым дефолтом.

## Цель

Закончи текущую работу в рамках утверждённой продуктовой правды.

## Границы решений

- Прочитай `<project-root>/_ops/GOAL.md`.
- Прочитай применимые канонические пары `<project-root>/_ops/product-frames/`.
- Считай готовым только полномочный непротиворечивый ответ.
- Проверь готовый ответ по всей применимой правде.
- Исполни готовый ответ.
- Не создавай варианты при готовом ответе.
- При отсутствии готового ответа или расхождении источников переходи к выводу.
- Выведи обратимый ход из применимой правды для конкретной пользовательской сцены.
- Проверь сильнейшее возражение.
- Пометь новый локальный вывод `выведено`.
- До действия сохрани адресуемое основание вне
  `<project-root>/_ops/product-frames/`.
- Закончи всю разрешённую работу.
- Дополни след наблюдаемым результатом.
- Повторившийся пробел передай `1product-shaping`.
- Неразрешимый конфликт верных принципов передай `1product-shaping` сразу.
- Не меняй канон этим сигналом.
