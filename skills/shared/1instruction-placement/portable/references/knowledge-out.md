# Значение вон, указатель остаётся

Классифицируй каждый смысл:

| Класс | Где живёт |
| --- | --- |
| поведение | самый дешёвый instruction layer в момент решения |
| ориентировка | слой своей частоты; с причиной, зачем туда смотреть |
| изменяемое значение | canonical owner: code, config, docs, decision file |
| дорогой найденный маршрут | INDEX.md |

Версия, число, статус, перечень сущностей и «у нас используется» — кандидаты на
значение. В инструкции остаётся адрес owner-а, если он меняет действие.

Ориентировка не входит в число поведенческих обязанностей, но платит context
cost. Голый список, который агент восстановит listing-ом, не ориентирует.

Готово, когда instruction surface не может молча разойтись с изменяемым
владельцем, а каждый оставшийся указатель объясняет момент захода.
