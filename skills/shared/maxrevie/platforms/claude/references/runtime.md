# Claude: запуск

Вызывающий передаёт координацию отдельному свежему агенту, который читает
SKILL.md по абсолютному адресу и получает область, режим и адрес сессии.
Координатор использует сильную доступную модель; проверяющие по выбору
владельца — Sonnet 5 с effort medium.

Точное имя модели и настройку effort проверь по текущему API/CLI и
установленной конфигурации. Имя «Sonnet» само по себе не подтверждает пятое
поколение. Перед запуском установи поддержку вложенной оркестрации, свежих
контекстов, лимит конкурентности и доступ к отчётам. Сохраняй requested и
resolved model, если последняя доступна. Отсутствие поля resolved отметь
как границу знания; отсутствие доступного маршрута — как пробел,
не успешный запуск Sonnet 5.

При недоступности вложенной оркестрации используй отдельный разрешённый
процесс-координатор, если он уже есть и поддерживает нужные инструменты.
Иначе объясни владельцу потерю режима «запустил и ждёт»: предложи вызывающему
только запускать пакеты и передавать ID/пути координатору либо сохранить очередь
для другого запуска. До выбора статус incomplete; ранее данное согласие
на такой путь сохраняет силу. Не устанавливай новый launcher/SDK ради обхода
ограничения. Недоступность Sonnet 5 Medium предъяви отдельно: другая модель
требует явно названного решения, а не скрытой замены.

Фоновые агенты и краткие финалы применяй только при поддержке среды.
Без неё называй выполнение синхронным. Скилл не создаёт постоянный сервис
после завершения сессии. Старшие автоматически доставляемые инструкции
продолжают действовать и в свежем окне.
