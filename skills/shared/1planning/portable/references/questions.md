# Вопросы владельцу

Момент: работа упёрлась в решение владельца — до создания плана (гейт
вопросов) или по ходу (новая развилка). Вопрос живёт отдельной заметкой в
папке вопросов проекта, не разделом плана и не репликой чата: реплика умирает
с окном, раздел плана владелец не открывает.

## Все вопросы доходят до владельца

- **Блокирующий** — ответ меняет цель, эпик, критерий успеха, первый маршрут
  либо входит в Founder-only зону проекта (деньги, обязательства): стоп только
  затронутой ветки; незатронутая работа продолжается. Этот список — владелец
  словаря блокировки, гейт тела ссылается сюда.
- **Мелкий** — ответ не меняет следующую ветку: заметка-вопрос без стопа,
  копится и ждёт владельца пачкой; работа идёт по помеченному допущению с
  trigger пересмотра. Молча превращать вопрос в допущение без заметки нельзя:
  владелец сказал «все вопросы должны быть заданы мне».
- Выводится из Goal, принципов, записей владельцев → `1use-principles`, не
  вопрос.

## Заметка-вопрос

```markdown
---
тип: вопрос
статус: открыт | отвечен | архив
касается: "[[<эпик или работа>]]"
ответ: ""
срок: <дата дефолта>
обновлено: <дата>
---

# <вопрос одной строкой, в предметных словах владельца>

**Что меняет ответ.** <какая ветка ждёт>

**Варианты.** <варианты с ценой каждого; рекомендация помечена>
```

Вопрос отвечаем одним действием владельца — механику (кнопки, свойство
`ответ`) задаёт инструкция проекта. ID и внутренний жаргон в тексте вопроса —
признак непереведённого вопроса.

## Срок и дефолт

У вопроса есть срок; по его истечении мелкий вопрос закрывается дефолтом —
помеченным допущением с trigger пересмотра, — а блокирующий эскалируется
живым каналом. Молчание владельца планируется, не игнорируется.

## После ответа

Ответ принят, когда слово владельца получено любым каналом — свойством
заметки, кнопкой или репликой в чате. В том же ходе:

1. записать слово владельца в chat-recall (ответ кнопкой — тоже его слово);
2. перенести решение его владельцу — план, эпик, канон, инструкция; заметка
   решением не владеет;
3. `статус: архив` с адресом recall-записи; разблокированная ветка
   продолжает работу.

Заметка — временный конверт: живой список вопросов короткий.
