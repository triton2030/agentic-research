# Зонная разведка

Вход: стадия 2 — карта зон с целями из стадии «Замысел».

Протокол главного агента:

1. Запусти по субагенту на каждую зону, параллельно; в задание каждому передай
   цель проекта, цель его зоны, карту зон и раздел «Форма каждого файла
   инструкций» из тела скила.
2. Рёбра субагенту не подсказывай: субагент с чистым окном сам чувствует, чего
   ему не сказали, — его слепота и есть искомое измерение.

Протокол зонного субагента:

1. Прочитай свою зону целиком.
2. Выпиши исходящие рёбра: от каких внешних правд зависит работа в зоне и в
   какой момент каждая из них нужна — прежде чем начать работу · когда
   меняешь конкретную вещь · перед сдачей работы.
3. Выпиши входящие рёбра: кто за пределами зоны сломается от изменений,
   сделанных внутри неё.
4. Если у зоны нет собственных рёбер — она папка-склад: файла для неё не
   собирай, верни только её адрес; иначе собери черновик файла зоны — разделы
   «Цель» и «Контекст», рёбра шагами по их моментам и закрывающая строка
   «больше ничего не читай».
5. Ремесло зоны — то, как писать её код, — в файл не пиши: агент прочитает
   папку сам.
6. Кандидатов в корневую инструкцию — кросс-зонные правила — и вопросы
   владельцу отдай отдельным списком; сам их не решай.

Выход: черновики зонных файлов · кандидаты в корень · вопросы владельцу.
