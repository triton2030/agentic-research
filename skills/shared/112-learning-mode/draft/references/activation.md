# Активационный урок

## Цель

Дай владельцу честный урок на текущей работе и назови стратегический следующий
ход.

## Урок

Назови конкретные источники урока.

1. **Сработало.** Покажи, почему метод подтвердил или изменил реальный выбор
   против жизнеспособной альтернативы.
2. **Упущено — и чему учит.** Покажи наблюдаемое последствие пропущенного
   метода.
3. **Пригодится дальше.** Назови метод и момент его применения в предстоящей
   задаче.

Если для раздела нет evidence, пометь его `не подтверждено` и назови
просмотренный scope.

Для каждого метода назови устойчивое имя принципа и дай точную цитату с адресом
либо помеченный пересказ по памяти.

Пиши по Фейнману: просто и с высоты птичьего полёта.

Используй Markdown-разделы и одну сравнительную таблицу.

Вернись в основной файл скила для стратегического выбора следующего хода.
