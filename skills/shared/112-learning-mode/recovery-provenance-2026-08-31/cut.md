# Cut — восстановление книжной provenance

## Снято из старой версии

- `точная цитата с адресом либо явно помеченный пересказ по памяти` — снята
  только ветка пересказа по прямой коррекции владельца о буквальных цитатах;
  теперь отсутствие проверки остаётся `PROOF GAP`.

## Не принято из clean-room

- Уникальные event ordinals для каждого packet: не нужны для заявленной
  функции, пока чат уже даёт наблюдаемый порядок и адрес.
- Полный session coverage ledger: усиливает отчётность после действия, но не
  forcing function до действия.
- Отдельная owner-policy для edition/source whitelist: во входе её нет;
  кандидат требует только фактически проверенный и повторно находимый адрес.
- Автоматическая остановка исходной работы при proof gap: противоречит
  неблокирующему режиму и старшинству исходного authority/safety contract.

## Не сокращено

- Богатый одноразовый урок.
- Длинный публичный когнитивный протокол каждой существенной развилки.
- Отдельное называние метода, аббревиатуры, книги, автора, буквальной цитаты,
  адреса, проблемы мышления, операции и причинного влияния.
