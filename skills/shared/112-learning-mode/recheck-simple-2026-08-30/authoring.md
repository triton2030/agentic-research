# Authoring modes — простая candidate

## `skill-short-description`

Exact description: `Use only when explicitly invoked.`

- Use: «Используй `$112-learning-mode` для этой текущей работы».
- Skip: «Продолжай работу и объясняй важные решения».
- Near-miss: «Используй `$123-explain` для статуса и причин решений».

Description содержит только English manual trigger; функция остаётся в body.

## `behavior-protocol`

Владелец требует именно причинный порядок:

> «если он пишет в чат, какие методики и почему он выполнял, тут он не сможет
> отвертеться, чтобы не исполнять эти методики»

> «этот скил не должен прерывать текущую работу»

Материальный TWI-разрыв один: метод и различающая проверка должны существовать
до действия, а наблюдаемый след сразу возвращает агента к исходной работе.
Candidate кодирует этот порядок двумя шагами после зонтичной цели; checker- и
authoring-бюрократура в runtime не входит.

## `reference-files`

References не нужны. У скила один непрерывный режим; отдельный activation lesson
не имеет самостоятельной поздней функции и создаёт второй адрес истины.

## `agent-defaults`

| Оставшаяся дельта | Дефолт → механизм → изменяемое решение → вред без строки → цена строгости |
|---|---|
| Только существенные развилки | Полезный отчёт хочется повторять → scope граница → когда включать trace → ритуал на рутинных ходах → мелкие решения остаются автономными. |
| Метод и проверка до действия | Метод легко подобрать после выбора → pre-action trace → какой ход принять → post-hoc рационализация → существенный ход нельзя сначала выполнить, затем объяснить. |
| Немедленно продолжить работу | Объяснение выглядит завершённым deliverable → continuation boundary → продолжать ли заказанный ход → curriculum вытесняет результат → объяснение остаётся коротким. |
| Недоступная проверка названа непроверенной | Завершённый trace хочется показать даже без наблюдения → honesty boundary → считать ли прогноз подтверждённым → выдуманное evidence становится доказательством → один честный статус вместо result-процедуры. |

Hard manual flag и session persistence являются ранее утверждёнными runtime
границами, а не новыми авторскими добавками.
