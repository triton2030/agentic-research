# Cut — простая candidate

## Поглощено commander's intent

- `следующее узкое место`, обязательная реактивная альтернатива и отдельный
  прогноз сняты: верхняя цель + различающий evidence/falsifier дают умному
  агенту тот же стратегический контраст без фиксированного маршрута.
- Стадии `активация → сессионный контракт → готово` поглощены одной целью:
  pre-action влияние метода остаётся наблюдаемым, а работа продолжается.
- Result-closure снят из skill-specific delta: живой корень и обычная
  acceptance работы уже требуют проверять действие.

## Удалено вместе с curriculum

- `references/activation.md`;
- три раздела «Сработало / Упущено / Пригодится»;
- обязательные цитаты, таблица, Фейнман-формат и просмотренный scope;
- запрет повторять полный урок.

Поздняя owner-коррекция снимает обучение как самостоятельный результат; его
смысл был forcing function для стратегического поведения. Поэтому удалённая
форма не имеет отдельного counterfactual harm после сохранения pre-action
следа.

## Сохранено против конкретного вреда

- manual-only trigger — против самопроизвольного curriculum;
- до конца сессии, но только существенные развилки — против одноразового
  отчёта и ритуала на каждом ходе;
- метод + предварительный взгляд + различающая проверка до действия — против
  post-hoc рационализации;
- короткое объяснение и немедленное продолжение — против подмены работы
  отчётом.
