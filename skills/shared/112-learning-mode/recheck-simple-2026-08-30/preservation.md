# Preservation map — простая candidate

Старый package используется только как evidence после clean-room draft.

| Старый смысл или форма | Candidate | Решение и counterfactual |
|---|---|---|
| Только ручной вызов | Exact description + hard manual flag | Сохранено: иначе режим включается без выбора владельца. |
| До конца сессии | `Цель пользователя` | Сохранено: одноразовый отчёт не меняет последующие решения. |
| Метод влияет до действия | `Цель пользователя` + `Протокол поведения`, шаги 1–2 | Сохранено: без следа возможна постфактум-рационализация. |
| Верхняя цель + различающее доказательство/фальсификатор | `Цель пользователя` + `Протокол поведения`, шаг 1 | Сохранено как минимальное различие стратегии от локальной реакции. |
| Исходная работа продолжается | `Цель пользователя` + `Протокол поведения`, шаг 2 | Сохранено: иначе отчёт подменяет заказанный результат. |
| Недоступная проверка не становится результатом | Одна honesty-строка протокола | Сохранено после наблюдаемого clean-probe провала: агент объявил предполагаемую трассировку подтверждённой. |
| Активационный урок отдельной стадией | Поглощён целью | Снято: поздний owner снял curriculum как самостоятельную потребность; стадия повторяет тот же forcing function. |
| Reference `activation.md` | Отсутствует | Снят вместе с самостоятельной стадией; без неё reference не владеет отдельным режимом. |
| «Сработало / Упущено / Пригодится» | Поглощено умным выбором примера | Снято: фиксированный учебный формат не меняет strategic decision. |
| Таблица, цитата, Фейнман-формат, Markdown-секции | Отсутствуют | Сняты: меняют форму отчёта, но не причинность решения. |
| Жизнеспособная реактивная альтернатива и узкое место | Поглощены верхней целью и различающим evidence | Сняты: компетентный агент выводит нужный контраст без обязательной церемонии. |
| Отдельная no-method ветка | Отсутствует | Снята: порождала логический escape и новую процедуру; режим требует наиболее релевантный корневой метод. |
| Сверка результата и `не проверено` | Поглощены живым корневым gate и обычной проверкой работы | Сняты как дубль project-wide/root acceptance, не дельта learning-mode. |
| Запрет повторять полный урок | Поглощён scope существенной развилки | Снят вместе с уроком; рутинные ходы прямо не требуют отчёта. |

## Active set

После второго независимого recount и снятия двух дублей candidate содержит три
frontmatter surfaces и семнадцать одновременно применимых context/goal/protocol
предикатов: итоговый active set — **20**. Финальный clean checker проверяет этот
счёт; дроблением на references лимит не обходится.
