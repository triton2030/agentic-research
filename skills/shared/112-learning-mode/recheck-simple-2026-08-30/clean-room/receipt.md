# Clean-room receipt

## Не создано

- Поля frontmatter: `argument-hint`, `allowed-tools`, `compatibility`, `license`,
  `metadata`, `user-invocable`. Они не требуются intent и не меняют поведение
  этого ручного режима.
- Стадии и форматы: активационный урок, три учебных раздела, таблица, цитаты,
  Фейнман-формат, обязательная альтернатива, список узких мест, отдельная ветка
  отсутствия метода, фиксированные заголовки и повторные отчёты.
- References и другие runtime-resources: самостоятельный режим полностью задан
  в `SKILL.md`; внешняя опора добавила бы второй адрес истины без новой функции.
- Checker protocol: не является поведением режима и в runtime не добавлен.

## Независимый active set

Единица подсчёта — независимо удалимая runtime-обязанность или поле, после
удаления которого возникает отдельный наблюдаемый вред. Active-set count: **7**.

| # | Оставшаяся runtime-единица | Concrete counterfactual harm при удалении |
|---|---|---|
| 1 | `name: 112-learning-mode` | Пакет потеряет стабильный идентификатор загрузки и явного вызова. |
| 2 | Exact trigger-only `description` | Каталог перестанет сообщать, что режим нельзя выбирать неявно. |
| 3 | `disable-model-invocation: true` | Runtime сможет активировать режим по собственной эвристике, нарушая hard manual boundary. |
| 4 | Сохранение режима до конца сессии только после явного вызова | Режим станет одноразовым отчётом и не повлияет на следующие существенные развилки. |
| 5 | Применение только на существенных развилках и связь выбора с верхней целью | Церемония засорит мелкие действия, а локальная реакция сможет разойтись с исходным результатом. |
| 6 | Видимые до действия предварительный взгляд, метод и различающая проверка | Агент сможет подобрать убедительное обоснование уже принятому решению. |
| 7 | Короткий результат проверки и немедленное продолжение исходной работы | Объяснение перестанет показывать влияние метода либо вытеснит заказанную работу. |
