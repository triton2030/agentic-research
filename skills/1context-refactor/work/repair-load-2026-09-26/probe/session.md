# Контекст

Это полный доступный след учебной сессии. Содержимое проекта далее дано
дословно; иных файлов и фактов для вывода нет. Рабочие инструменты сейчас
недоступны, разрешено вернуть разбор и точные предлагаемые изменения.
Пользователь заранее разрешил менять инструкции и хуки проекта.

В одном рабочем дереве Git параллельно работают несколько сессий агентов.
Корневой `AGENTS.md` проекта агент получает в начале каждой сессии.

Выдержка из `AGENTS.md`, раздел «Коммиты»:

> Коммить только перечнем своих путей: `git add -- <пути>`, затем
> `git commit -m … -- <пути>`. `git add -A` и `git add .` запрещены: в дереве
> работают несколько сессий, и так в коммит уходят чужие правки.[^c1]
>
> [^c1]: Добавлено 12.09 после инцидента: коммит захватил 14 чужих файлов.
> 19.09 строка перенесена в начало раздела и выделена после второго случая.

Из истории файла: за последние десять дней `AGENTS.md` вырос со 140 до 230
строк; 9 из 11 правок — новые строки после разборов сессий.

Среда агента поддерживает хуки перед вызовом инструментов: в проекте уже
есть такой хук `.agent/hooks/deny-rm.py`, отклоняющий `rm -rf` с объяснением
причины. Хук `pre-commit` проверяет ссылки и секреты.

# Переписка и действия

1. Пользователь: «Поправь опечатку в docs/pricing.md и закоммить».
2. Агент прочитал `AGENTS.md` целиком и исправил опечатку.
3. Агент выполнил `git add -A && git commit -m "fix typo"`. Коммит включил
   23 файла: 22 из них — незакоммиченные правки другой сессии в `docs/catalog/`.
4. Пользователь: «Ты опять закоммитил чужое. Разбери сессию».
5. Агент выполнил `git reset --soft HEAD~1`, затем
   `git commit -m "fix typo" -- docs/pricing.md`. Правки другой сессии снова
   не закоммичены и остались в рабочем дереве.

# Текущее состояние

Опечатка закоммичена одна. Пользователь ждёт разбор сессии.
