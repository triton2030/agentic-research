# Цель

Зафиксировать проектные решения чистой реализации `1context-refactor` без
обращения к какой-либо прежней форме пакета.

## Как применены методы

**Clean-room reimplementation.** Пакет построен только вокруг наблюдаемого
post-factum эпизода, проверки причинного механизма и маршрутизации последствий
к владельцам. Направленная зависимость существует только от
`1context-refactor` к отдельному `1index`.

**Zero-based design.** В `SKILL.md` остались входной фильтр, маршрутизатор
владельцев и проверка завершения. Один справочный файл выделен только для
шестишагового причинного теста:
это самостоятельный протокол, который используется целиком и не нужен
навигационному скиллу.

## Отброшенные альтернативы

- слияние с `1index` — смешивает причинный разбор с навигационной памятью;
- профилактическое проектирование инструкций — не опирается на произошедший
  сбой;
- аудит всего доступного контекста без границы эпизода — размывает причинную
  проверку;
- причинность по последнему прочитанному файлу или симптому — не различает
  альтернативы;
- универсальное право ремонтировать владельцев — превышает полномочия;
- обязательный артефакт после каждого разбора — сохраняет недоказанные или
  ненужные следы;
- дополнительные справочные файлы по каждой ветке — дробят короткий
  маршрутизатор владельцев.

## Активные инструктивные единицы

- квалификация эпизода: 3 единицы — повторение, post-factum граница,
  наблюдаемая ошибка;
- причинный разбор: 6 единиц — предшествование, сцепление, активация, цепочка,
  альтернатива, контрфакт;
- ветка без долговечного действия: 2 единицы — назвать механизм или предел,
  не создавать артефакт;
- ветка `1index`: 3 единицы — доказать цену, передать четыре поля маршрута,
  не передавать причинный разбор;
- ветка `1findings`: 3 единицы — системность, ненужность для текущего
  завершения, разделение факта и решения;
- ветка совета пользователю: 3 единицы — конкретные слова, доказанное влияние,
  минимальное уточнение;
- ветка разрешённого ремонта: 4 единицы — точный владелец, существующее право,
  минимальное изменение, воспроизведение;
- завершение: 3 единицы — соразмерность, owner-проверка, неизвестное.

С учётом общей квалификации, причинного теста и завершения ожидается 14
активных единиц в ветке без артефакта, 15 в ветках `1index`, `1findings` и
совета пользователю, 16 в ветке разрешённого ремонта.
