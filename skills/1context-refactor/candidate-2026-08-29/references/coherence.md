# Связность контекста

## Цель

Разрешить только материальные пересечения смыслов, способных одновременно
изменить одну реальную задачу.

1. Для пары выбери один verdict: дополняют · конфликтуют · дублируют · одно
   поглощает другое · одно меняет силу другого.
2. Если hierarchy и scope уже дают один надёжный ответ, нового правила не пиши.
3. Hook или validator побеждает prose только в покрытом событии.
4. Конкретный user task побеждает resident guidance, пока у boundary нет более
   сильной authority.
5. Для материального пересечения оставь одного owner-а и одно операционное
   разрешение.
