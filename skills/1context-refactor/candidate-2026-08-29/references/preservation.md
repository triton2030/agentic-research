# Сохранение postmortem

## Цель

Разнести только доказанные результаты причинной трассы по их владельцам.

- Неочевидное место найдено дорогим поиском → через `1index` дозапиши
  существующий INDEX; новый файл требует «да» владельца.
- Отложенная системная проблема не нужна для честного текущего результата →
  через `1findings` сохрани сырую находку; blocker находкой не маскируй.
- Слова владельца повлияли на ошибку → в финале назови эпизод и посоветуй, что
  ему стоит или не стоит говорить.
- Source repair уже разрешён исходным запросом → адресуй его семантическому
  owner-у; тело или routing скила принадлежит `1skill-creation`.

Сдай применённые ветки и оставшиеся causal candidates. Неприменимые outputs не
фабрикуй. Дозапись INDEX проверяй более коротким маршрутом к той же находке.
