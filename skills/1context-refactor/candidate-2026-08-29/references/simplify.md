# Смысловое упрощение

## Цель

Снять semantic load и resident context cost, не потеряв невыводимые решения.

1. Ранжируй смыслы по решениям, которые они изменяют.
2. Удали то, что target model надёжно выводит без строки.
3. Поглоти частное общим только когда каждый снятый смысл из него выводится.
4. Сохрани число, authority, local exception, decision rule и anti-pattern,
   если они меняют решение.
5. Замени путь результатом только без потери safety, recovery,
   reproducibility и обязательной проверки.
6. Канонический метод назови вместе с trigger и невыводимыми инвариантами.
7. Редкую деталь доставь позже к моменту решения.

Верни `снятые обязанности · удалённый resident context · сохранённая Delta ·
непроверенные потери`.
