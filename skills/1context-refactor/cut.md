## 2026-08-29 — postfactum и владельцы результатов

**Сохранено:** полное чтение текущего диалога · точные места шероховатостей ·
причина до ремонта · настоящий виновник не всегда инструкция · repair-
references · проверка той же шероховатостью · советы владельцу.

**Усилено:** automatic trigger по повторяющимся ошибкам · отдельные
`Уникальный контекст` и `Цель` · причинный контрфакт · прежние ответы агента и
tool output как части контекста · постфактум-граница с профилактическим
`1instruction-authoring`.

**Добавлено:** автономная дозапись только существующего INDEX через `1index` ·
обязательная сырая находка через `1findings` для системной проблемы вне
текущего результата · отдельный совет владельцу ·
`references/failure-signals.md` как стадийная диагностика повторяющихся
паттернов.

**Сужено:** automatic invocation не даёт права молча переписывать документы,
скилы и инструкции. Эти правки выполняются только в scope исходного запроса и
по owner-контракту; автоматически разрешены лишь INDEX-дозапись и находка.

## 2026-08-29 — цена новых ограничений

| Добавка | Дефолт → механизм → изменяемое решение → вред без строки → цена строгости |
| --- | --- |
| Поздний source не причина | Модель объясняет эпизод всем известным сейчас → смешивает хронологию → исключает невидимый до ошибки source → ложный causal repair → надо точно восстановить порядок чтения |
| Нет механизма — нет ремонта | Модель принимает правдоподобие за диагноз → переписывает первый похожий контекст → оставляет claim кандидатом → новые противоречия и потеря полезных правил → часть проблем останется нерешённой до probe |
| Только две автономные durable-записи | Модель расширяет автоматический trigger до общего write-доступа → отделяет сохранение опыта от ремонта owners → без запроса пишет только существующий INDEX и finding → скрытая переработка всей системы → доказанный owner не чинится без исходного разрешения |
| Finding не маскирует blocker | Модель считает запись проблемы завершением → откладывает нужную текущую коррекцию → требует честно закончить текущий результат → сдача остаётся неверной при наличии карточки → blocker приходится решать сейчас |
| Сигнал не диагноз | Модель узнаёт типовой паттерн и сразу назначает виновника → требует цепочку до/ошибка/после и контрфакт → отделяет симптом от причины → ремонт не того слоя → диагностика занимает отдельную стадию |
| Условные outputs | Модель исполняет весь список завершения буквально → фабрикует INDEX, finding или совет → отмечает ветвь неприменимой → ложные durable artifacts → сдача содержит явные отрицательные результаты |
| Matched falsifier | Модель принимает самоотчёт о контрфакте за proof → сравнивает ту же шероховатость → оставляет правку candidate до различающего сигнала → недоказанный behavioral claim становится каноном → проверка может потребовать отдельного replay |

`check.md` сокращён до одной claim-specific стадии: resolved environment,
matched comparator, наблюдаемая цепочка до завершения и verdict. Полный каталог

Правило «пересобирай от оригинала» возвращено в `refactor.md`: предыдущая
