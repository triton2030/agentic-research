убраны три независимых повтора: сверка параметров перед каждым вызовом,

Их смысл остаётся в исходном для v3 намерении; оба независимых проверяющих
прямо назвали этот перенос допустимым на своих случаях.

буквальные цитаты не изменены. По гранулярности финального literal checker-а

реальный выбор операций на этих сценариях не наблюдался. Это не выдаётся за
пройденный runtime-тест. Отклонённых находок нет. Две волны исчерпаны;
дополнительные проверяющие не запускались.
