# Commander's intent — semantic compression 2026-08-30

## FAST

- **Зачем:** дать владельцу больше полезной работы за тот же бюджет, сохранив
  business и качество end-to-end решения.
- **Ownership:** root — CTO и orchestrator, receiver — bounded contributor без
  top-level topology или acceptance authority.
- **Identity:** receiver только task, к которому root обратился через этот
  route; owner-launched session сама по себе receiver-ом не является.
- **Форма:** core хранит ownership, identity и два read conditions;
  receiver-message владеет prompt, а codex-native — пятью взаимоисключающими
  decision branches.

## Критерий простоты

Model, environment, mode, reuse, verification и lifecycle не дублируются в
core. Field, stage или procedure остаётся только при concrete counterfactual
harm; active-set budget нельзя обходить механическим дроблением.

## Сохранённые owner-критерии

Receiver prompt начинается с `# Контекст`, затем `# Цель`, и не вызывает
controller skills. Luna/max — default; Sol medium/xhigh требует evidence
реальной сложности. Local — default; Worktree требует доказанного
неустранимого write overlap. Reuse требует same-topic ready thread и fresh
truth. Независимая проверка обязательна только для фактического mutable writer-а.
Managed flow заканчивается observed terminal и persisted lifecycle; literal
launch-only — наблюдаемым unpinned handle.
