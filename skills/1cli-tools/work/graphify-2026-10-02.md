Доставка — существующие пакеты `~/.claude/skills/1cli-tools/` и

## Основание

Проверено 2026-10-02 из cwd MAVO:

- `command -v graphify` → `/Users/triton/.local/bin/graphify`.
- `graphify --version` → `graphify 0.9.73`.
- `graphify --help`: `query` обходит граф, `affected` ищет затронутые узлы
  обратным обходом; граф по умолчанию — `graphify-out/graph.json`.

Одна строка передаёт неизвестный модели факт среды и назначение инструмента.
Отдельная процедура не нужна для этого заказа; правила конкретного проекта
остаются у проекта. Дополнительных критериев к скилу не добавлено.
