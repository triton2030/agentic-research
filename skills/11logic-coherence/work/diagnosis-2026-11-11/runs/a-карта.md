# Карта логики: сервис «Разминка»

Корень документов: папка `case`. Адреса ниже — от этого корня.

## 0. Что из чего вырастает и какие цепочки выбраны

`Цели.md` задаёт три стороны и знание о клиентах. Из него вырастают:

- путь клиента до записи: `Каталог.md` → страница занятия в `Запись и оплата.md` → цвет кнопки по `Интерфейс.md`;
- путь денег: блокировка и списание в `Запись и оплата.md` → удержание в `Отмена.md` → выплата в `Выплаты тренеру.md` → комиссия владельца в `Цели.md`;
- абонемент: два предложения в `Запись и оплата.md`, которые должны войти в путь денег.

Документов шесть, поэтому прослежены все три цепочки. Самый большой риск несёт путь денег: он заканчивается деньгами для всех трёх сторон и проходит через четыре документа. Старшинства документов проект не описывает; явная связь между документами одна — ссылка в З18.

## 1. Стороны и цели

| Сторона | Цель | Происхождение |
| --- | --- | --- |
| Владелец | Комиссия 15% с оплаченной записи; оплаченных записей больше | З1 |
| Клиент | Быстро записаться на подходящее занятие; не терять деньги за неиспользованное | З2 |
| Тренер | Предсказуемый доход; деньги без задержек | З3 |

Целей, приписанных сторонам от себя, нет. Других сторон (платёжный провайдер, владелец зала) документы не называют.

## 2. Обязательные условия

Выведены из целей до сверки с документами механизма.

| № | Цель | Что обязано быть правдой | Статус |
| --- | --- | --- | --- |
| У1 | Владелец: больше записей | Клиент находит подходящее занятие тем способом, каким он на деле выбирает | противоречит: главный критерий З4 отсутствует в каталоге (З25), порядок списка другой (З7) |
| У2 | Владелец: комиссия с оплаченного | Сервис платит тренеру только за то, что клиент оплатил | по срокам противоречит (З29); по сумме — расходится в отдельных случаях (З30) |
| У3 | Владелец: комиссия | Доля сервиса определена для каждого вида денег: обычная запись, удержание при отмене, абонемент | обеспечено для обычной записи (З21); для удержания и абонемента нигде нет |
| У4 | Клиент: подходящее занятие | Место занятия видно до записи, по нему можно искать | нигде нет (З25, З26) |
| У5 | Клиент: быстро | Кнопка записи читается как безопасное главное действие, без лишних шагов | противоречит для записи раньше чем за 24 часа: З11 против З12 (З28) |
| У6 | Клиент: не терять деньги | За неиспользованное клиент не платит либо заранее знает условие и может его избежать | обеспечено для отмены раньше чем за 24 часа (З18); противоречит: поздняя отмена (З17), запись в последние сутки (З31), неявка (З42), сгорание абонемента (З33); отмена занятия тренером — нигде нет |
| У7 | Клиент: не терять деньги | Условия отмены клиент видит до записи | нигде нет: состав страницы занятия (З10) их не содержит; в З16 условие не названо, оно есть только в З18 |
| У8 | Тренер: предсказуемый доход | Сумма за занятие известна заранее и определена для каждого случая | обеспечено для состоявшихся обычных записей и неявок (З21, З42); для отменённых записей, удержания и абонемента нигде нет (З32) |
| У9 | Тренер: без задержек | Деньги приходят сразу после занятия | обеспечено: З20, З22 — при условии У10; для занятия, которое идёт после 23:00, выплата придёт до его конца или начала |
| У10 | Тренер: без задержек | В день занятия у сервиса есть деньги на выплату | нигде нет: деньги клиентов к этому часу только заблокированы (З14, З15, З29) |
| У11 | Тренер: предсказуемый доход | Поток клиентов к тренеру не зависит от правил, которых он не знает | нигде нет: порядок в каталоге держится на рейтинге (З7), происхождение рейтинга не описано (З35) |

## 4. Решения и конфликты

### Лестница «зачем»

| Решение | Что стоит выше | Кому хуже, если решить иначе | Итог |
| --- | --- | --- | --- |
| Порядок списка по рейтингу (З7) | В документах ничего; З40 — допущение | По документам никому; тренерам с высоким рейтингом — допущение | Решение без причины; спорит с З4 |
| Красная «Записаться» (З11) | «Решение владельца» — адрес, а не ступень; З36 — допущение | По документам никому | Решение без причины; для ранних записей спорит с З12 |
| Красный для необратимых + подтверждение (З12, З13) | Норма ремесла; выше — цель клиента «не терять деньги» (З2), эта ступень допущена | Клиенту: случайная потеря денег | Держится |
| Блокировка при записи, списание после (З14, З15) | В документах ничего; З37 — допущение | Клиенту, если списывать до занятия | Срок «три дня» без причины: если списывать в день занятия, по документам хуже никому |
| Удержание 30% (З17) | Причина названа: место тренера → цель тренера (З3) | Тренеру | Причина есть, но деньги до тренера не доведены (З32) |

| Выплата в день занятия (З20) | Цель тренера «без задержек» (З3) | Тренеру | Держится как цель; источник денег не обеспечен (З29) |

| Сгорание абонемента (З24) | «Решение владельца» — адрес; З39 — допущение | По документам никому | Решение без причины; спорит с З2 |

## 5. Прогоны

### Прогон 1. Обычный случай

Анна хочет йогу рядом с домом в четверг вечером. Занятие стоит 1 000 ₽, в группе 10 записей.

| Шаг | Что происходит | Опора |
| --- | --- | --- |
| 1 | Вход, список на 7 дней по рейтингу | З6, З7 |
