## Что изменено против `candidate-2026-10-23`

- Контекст: записанное не значит верное; пример ответа «кнопка красная, потому что вы так решили».
- Критерии приёмки подняты из конца файла к началу: скил вырос примерно до 4 950 токенов `cl100k_base`, а после сжатия разговора Claude Code возвращает первые 5 000 токенов.
- Шаг 1: цели — то, относительно чего судится решение; список сторон и целей показывается в чате сразу (строка перенесена из раздела «Отчёт»).
- Шаг 3: у записанного утверждения о людях или рынке называется опора.
- Шаг 4, теперь «Решения и конфликты»: подъём по «зачем» до цели стороны; «так решил владелец» — адрес, норма ремесла — ступень; достроенная ступень — «допущено»; проба наоборот с конкретной альтернативой.
- Разрывы: форма «факт без следа» с двумя исходами; проверка, настоящий ли разрыв; наименьший набор столкнувшихся звеньев, опора каждого и подозреваемый.
- `attack.md`: строка о записанном факте, принятом без проверки.

Из `logic-audit` не перенесены: типы утверждений [Ц], [Ф], [Р], [В], шаблон отчёта, правило «решение пользователя не объявляй ошибкой» — оно расходится со словами владельца.
