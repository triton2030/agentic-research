# Карта изменений

| Прежний смысл | Новый носитель и причина |
| --- | --- |
| Только явный вызов | Снят по выбору владельца от 2026-09-21; description и Codex policy разрешают implicit invocation. |
| Кандидат не является доказательством | Контекст, Цель, чтение и Результат; проверка опирается на прочитанные тела. |
| Не выводить owner, дубль, конфликт, отсутствие из ранга и оформления | Сохранено без обязательного словаря `owner: unresolved`; незнание явно названо в обычном ответе. |
| Scope и разрешение до отправки данных | Сохранено в Выборе корпуса; уже данное разрешение действует, новый trigger его не создаёт. |
| Предложение узкой области, dry-run и path_scope | Сохранено; имена папок не назначают авторитет. |
| Query pack, язык, последовательные обращения к индексу | Сохранено по месту поискового действия. |
| Карта, затем тела и бюджет | Сохранено с уточнением: повтор expanded заново ранжирует, а не выбирает произвольные строки. |
| Recovery, transaction identity, исключения из warmup | Переписано в index-lifecycle; команды берутся из текущего envelope. |
| Статический список числовых exit codes, весов и модели | Снят: текущее состояние, live schema и диагностика надёжнее копии меняющихся настроек. |
| Полный packet при любом отчётном продукте | Оставлена достаточная адресуемая выдача; полный контекст поиска передаётся при отдельном retrieval/handoff. |
| Ссылки на другие md-скиллы и 1document-system | Сняты как лишние зависимости обычного поиска; чтение файла доступно напрямую. |
| Список повторяющих инварианты сбоев и датировка модели | Снят; причины отказов находятся у соответствующих действий. |

Добавлено явное чтение `engine.dense`: код способен вернуть успешную
лексическую выдачу после сбоя dense-канала. Это непосредственно влияет
на честность обещанного поиска по эмбеддингам.

Статус: карта первого черновика; независимая проверка и поведенческая проба
ещё не завершены. Сравнение вероятности успеха старой и новой версий не заявлено.
