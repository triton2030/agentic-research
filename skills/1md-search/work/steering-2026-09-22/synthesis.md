# Решение

Уточнить существующий маршрут. Базовая проба выполнила задачу правильно;
полная замена контроллера или новый backend не обоснованы. Наблюдаемая
неоднозначность — status после ограниченного прогрева показывал более
широкую конфигурацию, потому что пример не сохранял фильтр.

## Независимые результаты

| Линза | Собственный итог | Решение автора |
| --- | --- | --- |
| [Ladder](reports/ladder.md) | ladder_holds | Сохранить semantic retrieval как средство достаточного чтения. |
| [Solvent](reports/solvent.md) | assumption_untested | Metadata разрешает автоактивацию; не выдавать это за измеренную надёжность выбора. |
| [Prospector](reports/prospector.md) | different_class_exists | Сохранить файловый маршрут для подходящих задач и при отсутствии разрешения. |
| [Expansionist](reports/expansionist.md) | opportunity_to_test | Заменить ручной пример expanded чтения ссылкой на существующий executable action. |
| [Premortem](reports/premortem-correction.md) | signal_watchable | Уточнить источник статуса документа; не вводить классификацию каждой выдачи. |

Premortem выполнен первым в Claude Fable 5.1 medium. Четыре остальные
линзы — отдельные свежие Sol medium с собственными профилями и одинаковым
замороженным предметом. Отчёты не передавались между линзами. Исходный
[Premortem](reports/premortem.md) сохранён вместе с фактической коррекцией:
chat-recall содержит прямые реплики, а скилл не требует новых документов
после каждого поиска. Риск вторичного пересказа остался условным.

## Альтернативы

| Вариант | Польза и цена | Выбор |
| --- | --- | --- |
| next: адресно уточнить момент чтения правил и перенос scope | Небольшая дельта; объясняет наблюдённый разный scope status и поиска. | Принят. |
| alternative: обязательная развёрнутая машина состояний с отчётом по каждой фазе | Явные переходы, но дублирует CLI и увеличивает объём обязательств для готового индекса. | Не оправдан наблюдениями. |
| unchanged: сохранить байты | Baseline уже получил правильный ответ без выхода за scope; остаётся двусмысленный пример status. | Уступает адресной правке. |

## Проверенные основания

- `src/navigator/config.py:181` действительно добавляет CLI include к config;
  OR задан в фильтрах. Поэтому узкий include не обещает узкую область.
- [Baseline](evidence/baseline.md) сохранил разрешённые пути и прочитал тело,
  но unfiltered status сообщил ожидающий архив вне разрешённой папки.
- `src/navigator/api_search.py:43` переносит параметры в `read_next`;
  `src/md_cli/next_steps.py:588` проецирует это в `_envelope.next_step`.
  Существующий тест `test_search_read_read_next_preserves_contract_args`
  проверяет этот контракт; частота человеческих/агентских ошибок не измерена.
- [Anthropic: context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  поддерживает достаточные инструкции и загрузку контекста по необходимости.
  Из этого не следует гарантия соблюдения границ текстом скилла.

## Неопределённость

Пробы на loopback проверяют порядок действий, фильтры и использование
прочитанного текста. Постоянные синтетические векторы не проверяют качество
модели, ранжирование на реальных корпусах или надёжность автоактивации.
Один успех подтверждает исполнимость. Рост вероятности успеха не заявляется.
