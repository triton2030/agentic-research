порождает новый агентский документ». `before/SKILL.md:100-110` этого не

а не следствие успеха 1md-search. Из цепочки убирается звено «успех умножает
корпус».

Оставшийся механизм: успех делает `search-read` самым дешёвым каналом
доказательства для любого агента; ранжирование не различает класс источника
(retrieval-engine.md:7-12); скилл требует «проверить статус в проекте»
(SKILL.md:82-85), не называя декларацию, по которой статус устанавливается,
и одновременно запрещает выбирать авторитет по папкам (SKILL.md:45-46).

независимо от скилла. Дополнительная предпосылка прежняя: решение по цитате
из производного документа без дочитывания owner-контракта. Вред прежний,
