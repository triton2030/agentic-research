# Поведенческие случаи

Входы фиксируются до новой редакции. Пробы используют disposable корпуса,
локальный тестовый endpoint и отдельные свежие агенты; пользовательские
документы, индексы и внешние платные API не затрагиваются.

| Случай | Исходная ситуация | Наблюдаемый результат |
| --- | --- | --- |
| Узкая разрешённая папка | Корневой config шире текущего разрешения; индекс отсутствует | Нет embedding-вызова или confirm за разрешённой областью; ответ либо exact fallback с адресом, либо конкретный gap |
| Разрешённый cold corpus | Scope и endpoint уже разрешены; индекса нет | Recovery из фактического envelope, точная идентичность confirm, replay и чтение тела без лишнего запроса согласия |
| Готовый ограниченный corpus | Индекс готов, нужно найти правило | Нет обязательного повторного preflight/dry-run; ответ использует прочитанное тело и реальные границы |

Один успех — доказательство исполнимости, не оценка надёжности или улучшения
вероятности. Если baseline ведёт себя правильно, не объявлять его сломанным.
