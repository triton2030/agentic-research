# Проверка необходимости требований

Вердикт: одно существенное условие сохранено неполно. Остальные изменения в пределах этой роли не показали потери или новой обязанности без причины. Проверены байты редакции из `draft-sha256.json`.

## Находка: область для уточнения стала неразличимой

- **Адрес:** `before/SKILL.md:42–46` → `draft/SKILL.md:51–54`; карта `preservation.md:11,21–22` считает это условие сохранённым. Владелец выбрал один корневой индекс с выбираемыми папками (`intent.md:8–10`).
- **Основание:** прежний текст при неопределённом разрешении требовал показать, какие исходники предлагается искать и какие производные исключить. Это делает запрашиваемую область видимой до решения об отправке и индексации. Нынешнее «подготовь узкую область» не передаёт различие исходников и производных; фраза об авторитете папок решает другой вопрос.
- **Неверный выбор без условия — прогноз:** агент может спросить разрешение на «узкую папку docs» и не выявить входящие в неё производные материалы. Пользователь согласится, не увидев фактическую границу. Проба `evidence/scope-after.md` проверяет уже заданную политику `docs/current/**` и не различает эти формулировки.
- **Минимальная правка:** вернуть в абзац `draft/SKILL.md:51–54` требование при неопределённой границе показать предлагаемые исходники и исключаемые производные до уточнения разрешения. Оно применяется только при выборе области, без общего списка для каждого поиска.
