# Карта изменений

| Свойство | Before → draft-v2 | Основание и проверка |
| --- | --- | --- |
| Автовызов по смыслу, known/exact skip | Description и metadata без изменений. | Сверка байтов; надёжность произвольных будущих вызовов не измерена. |
| Один корень, выбранные папки | Основной текст даёт lifecycle до выбора фильтров. | config/filter code; scope before/after. |
| Авторизация и fallback | Сохранены повторное использование разрешения и точный поиск без него. | Карта потерь; исходная проба ограниченного scope. |
| Dry-run | Уточнено: первая индексация или новый scope; проверенный scope переиспользуется. | Cold и последующий warm сценарии. Правило не отменяет разрешение на отправку запроса. |
| Область status | Все фазы сохраняют CLI-фильтры. | Baseline наблюдал более широкий status; after сравнивает фактический scope. |
| Карта → тело | Ручной повторный пример заменён действием текущего envelope; прямое чтение сохранено. | Existing contract test + фактические пробы; гарантия роста adherence не заявлена. |
| Авторитет | Сохранена проверка статуса, указан owner: декларация/контракт чтения корпуса. | Premortem с коррекцией; не приписывает вторичность цитатам владельца. |
| Вторая попытка | Счётчик явно относится к одному аспекту. | Согласование с уже существующим раздельным поиском аспектов. |
| Dense, truncation, чтение источников, stop | Сохранены. | Before/draft diff и behavioral evidence. |
| Индексация и опасные recovery | ID/fingerprint того же плана; cleanup/rebuild/model отдельно. | Lifecycle сохранён; cold trace. |
| Выдача и handoff | Обычный ответ без обязательного технического отчёта; отдельный handoff полный. | Финальный раздел без изменений. |

Реально удалён только самодостаточный пример expanded-команды, не переносящий
параметры конкретного поиска. Контракт чтения тела и лимиты сохранены.
Добавлено описание lifecycle для обнаружимости карты документов.

В первой проверяемой редакции условие показа предлагаемых исходников
и исключений было сохранено неполно. В `draft-v2` оно восстановлено;
уточнены реальные поля scope. См. [решения приёмки](review-decisions.md).
