# Намерение

Владелец попросил проверить и улучшить 1md-search через 1fresh-eyes.
Ранее принято автоматическое подключение при смысловом поиске неизвестного
Markdown; поиск должен работать глобально в Codex и Claude. Последнее
уточнение — один индекс в корне с выбираемыми папками корпуса.

Прямые слова: [записи разговора](/Users/triton/Documents/My_projects/md-tools/_ops/chat-recall/2026-09-21-223200-codex-01a0c503.md).
Проверяется управляющий текст и его доставка. Backend, модель эмбеддингов,
полномочия на данные и runtime API сохраняются. Индексы пользовательских
корпусов не прогреваются ради проверки.

Цель — достаточное прочитанное основание для исходной задачи в разрешённой
области. Успех установки и качество текста не доказывают автоматический
выбор на произвольной будущей задаче или повышение вероятности успеха.

Заморожены [before](before/SKILL.md), [draft](draft/SKILL.md), их SHA256
и [пять исходных пакетов](packets/ladder.md). Дальнейшие исправления
фиксируются отдельно от проверенной редакции.
