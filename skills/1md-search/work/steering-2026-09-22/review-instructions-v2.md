# Проверка требований: вторая редакция

Вердикт: прежняя находка закрыта. В затронутой дельте не нашёл потерянного или лишнего самостоятельного требования. Хеши всех файлов `draft-v2/` совпадают с `draft-v2-sha256.json`.

`draft-v2/SKILL.md:51–56` теперь требует при неопределённой границе показать предлагаемые исходники и производные материалы для исключения по правилам корпуса. Это восстанавливает выбор, который ранее исчез из `before/SKILL.md:42–46`: пользователь видит область до уточнения разрешения. Условие действует только в момент выбора области.

`draft-v2/SKILL.md:46–49` и `draft-v2/references/index-lifecycle.md:22–25` различают `path_scope` в status и `engine.path_include` / `engine.path_exclude` в search-read. Такая конкретизация нужна для сверки фактической области: в `evidence/baseline.md` status показал общий scope конфигурации после ограниченной индексации, а `evidence/scope-after.md` показал фильтры в ответе поиска. Она не создаёт отдельной проверки при каждом запросе: для уже проверенного разрешённого scope повторный dry-run прямо снят, а status вызывается после изменения корпуса или при диагностике.
