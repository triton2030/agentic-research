# Сохранность редакции

Граница и основания — intent.md; точные исходники — before/. Черновик прочитан целиком и сопоставлен с прежним пакетом.

| Прежнее обязательство | Новая форма и проверка |
|---|---|
| Папка-предмет/группировка, родитель, масштаб, одиночная статья, запрет смешения | Сохранены в 1folder-tree; критерии и условные разделы дома/родителя. Парные примеры пересобраны без обязательных файлов-жанров. |
| Короткие имена, речь владельца, нет тёзки/версий, граница по вопросу | Сохранены; краткость имени явно не ограничивает ответ. Существующая карта меняется только в разрешении. |
| Один дом и цельное взаимодействие | Сохранены в обоих владельцах на своих решениях: адресация против письма. Ссылка не заменяет собственный ответ, но исключает копию внешнего правила. |
| Полный аспект, техническое вместе с предметом | Уточнено до достаточности работы с предметом и нужными зависимостями. Словарь не становится полной спецификацией. Проба applicable/baseline. |
| Источники, точные сноски, авторство, код не намерение, честный пробел | Сохранены. Принятое решение агента в полномочиях отличается от невыбранного предложения. Проба conflict. |
| Связная проза, визуальная структура, местная читалка, description/aliases | Сохранены; нет единого шаблона, карточка не определяет предел полноты. Скрипт карты без изменений. |
| Сначала источник, разбор смешанного старого, исходник как свидетельство | Сохранены в reference; единица источника не становится файлом, исходник не переписывается при переносе. |
| Любой перенос/конфликт требует нового ответа владельца | Переформулировано: новое согласование только вне решения/делегирования. Основание — последняя авторизация и полномочия MAVO; право произвольно менять карту не добавлено. |
| Отдельный проход на каждый критерий, повтор входа/выхода у каждой стадии | Снята процедура, сохранён наблюдаемый результат проверки в границе задачи; сравнение applicable/baseline и local. Не заявляется вероятностный выигрыш. |
| Сверка с именем и description как полнота | Ограничена навигацией. Применение идёт от назначения и работы читателя, затем сверка с источниками; одинаковые разделы не требуются. |
| Обновление любого плана после документа | Условие сужено до действующего планирования; архив не возобновляется. |
| check_tree, полный скилл, Sol low, ограничения names-only | Сохранены без изменения скрипта и блока запуска. Это не проверка полноты. |
| Примеры reference | Сохранены решения: действие/вопрос, термин, part-of/owner/consumer, масштаб, grouping/mixing, technical ownership, ссылка/история, имена. Удалены повторные схемы <техническое>/<как устроено>, способные выглядеть шаблоном. |

## Местные инструкции
Изменён только _docs/AGENTS.md: два читателя и нынешний этап, ссылка на делегирование вместо копии полномочий. Карта и особые правила имён/словаря/преимуществ, источники и ссылки сохранены. Корень, обе студийные инструкции, все прочие зоны и импорты не изменены.

## Версия и допуск
Карта потерь принята автором для передачи на независимую проверку; behavioural evidence пока выполняется. Доставка ещё не произведена.

Финальная сверка после первой волны: три уточнения сохранённого смысла 1docs-write перечислены в review-decisions.md; без расширения границы.
