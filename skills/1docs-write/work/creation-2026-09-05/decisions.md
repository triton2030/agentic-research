## Препятствия под критериями (обе стороны)

1. достраивание правдоподобного → адрес источника у каждого утверждения
2. переполнение и лишние разделы → размер/состав/порядок названы числом, ссылок нет
3. цель-задача и UI-критерии → состояние; критерий = дорого переделать
4. молчаливый выбор при конфликте → два адреса, диффа нет
5. потеря или свалка при рефакторе → судьба каждого утверждения

## Снятый протокол владельца

Владелец назвал пять reference-файлов: цель, контекст, критерии, рефактор, вне-docs.
