# Функция словами владельца

«заголовок соответствовал абзацу»; «убираем ограничения в 2000 символов»; «Использовать подзаголовки ... разделы»; «подсвечивал где-то жирным, где-то списком»; «чтобы сам документ был знанием в чистом виде»; «после заголовка не должно быть дополнительной пустой строки».

Подтверждённый результат: определение зоны, ручная настройка и повторное использование получили отдельные разделы, вспомогательные изображения перечислены, ключевые выводы выделены, источники и пояснения статуса доступны по сноскам. Владелец сказал «Да отлично, тогда исправь инструкции и скил».

Остальные функции 1docs-write: размещение по содержанию, один дом, сохранность знания, авторство, различение решения/предположения, конфликт возвращается владельцу, раскрытие канона и metadata — сохраняются; пользователь их не пересматривает. Это ограничение текущей задачи по старшим инструкциям, не выведенное новое продуктовое решение.

Разрешение на установку дано прямым поручением. Отдельная повторная проверка пользователем каждого байта не требуется по developer-инструкции текущей сессии.
