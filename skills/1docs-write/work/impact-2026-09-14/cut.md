# Дельта и сохранность

| Место | Изменение | Что сохранено |
|---|---|---|
| 1docs-write, контекст и задача | Цитата не назначает дом; локально верный текст может противоречить базе | Две аудитории, инженерная достаточность, свобода формы |
| 1docs-write, до правки | Дом проверяется и у существующего файла; зависимости ищутся за пределами соседства и ссылок | Поиск через карту и прочитанные источники; использование уже актуального контекста |
| 1docs-write, сдача | Смысл, имя и адрес проверяются по последствиям для потребителей; непроверенное видно | Полномочия, исторические источники, пределы поручения; чистая редактура не вызывает полный аудит |
| MAVO root | Краткая защита на первом маршруте; разрешённое исключение из запрета повторов | Иерархия, CTO-автономия, архивы и планы, все другие маршруты |
| MAVO _docs | Конкретная защита перед локальной правкой и короткое завершение по зависимостям | Карта предметов, словарь, примеры, разметка, импорты |

1folder-tree и scripts/references 1docs-write не меняются. Продуктовые документы, старые планы и объяснения для пользователя не входят в правку. Реалистичные проверки выполняются в изолированных копиях; новые продуктовые условия в них — тестовые данные, не решения для MAVO.
