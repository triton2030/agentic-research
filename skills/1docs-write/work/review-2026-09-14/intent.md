# Распределённая проверка документов

Адресная правка 1docs-write: один новый reference для основной сессии, запускающей проверку документов, и короткий вызов из тела. Источник — новая точная реплика Founder-а в _ops/chat-recall/2026-09-14-140506-Codex-01a09f28.md, начинающаяся «Я думаю слишком много вещей которые надо помнить для одного агента». Пользователь предлагает распределить критерии по нескольким субагентам на основе 1agent-steering.

Контекст: после предыдущего усиления автор отвечает и за запись, и за подробную сверку источников, инженерной полноты и неочевидных связей. Перенос всего этого в соседний файл сам по себе не разгрузит основной выбор; проверяющим нужны самостоятельные вопросы и ограниченные входы. Проверка места до записи сохраняется: последующая независимая приёмка не заменяет своевременного решения автора.

Задача: передать три непересекающихся вопроса проверки самостоятельным read-only субагентам; основной агент выбирает применимость, передаёт одинаковую версию и достаточные адреса, проверяет существенные находки и принимает результат. Цель: адресуемая проверка пригодности связанного описания без удержания всех частных критериев одним автором и без трёх копий полного аудита.

Граница: SKILL.md, один новый references/проверка-документов.md, существующие tracked/installed Codex и Claude проекции; запись маршрута в shared README. Роли не создаются отдельными пакетами или agents-файлами. Инструкции MAVO и недавно согласованный краткий дубль сохраняются. Продуктовые документы, планы, архивы и explain-to-user не правятся.

Сохранить: две аудитории, достаточность по работе читателя, один владелец знания, предправочная проверка дома/связей, полномочия и авторство, прямое чтение слов владельца основным агентом, ограниченную редактуру, различение документального ответа и готовности реализации. Распределение ответственности — инженерное применение 1agent-steering, не эмпирическое обещание повысить надёжность. Проверяем реальное делегирование и находки на закрытом сценарии, отдельно — неприменимость к опечатке, затем три независимые роли и auditor.
