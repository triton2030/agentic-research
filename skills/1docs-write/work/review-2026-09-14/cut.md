# Сохранность и распределение

| Обязательство | Доставка в кандидате | Что изменено |
|---|---|---|
| Дом до любой правки, имя/адрес через 1folder-tree | SKILL: задача и «Когда ищешь необходимое знание» | Снято повторное объяснение роли цитаты и дома; сам выбор остался до записи |
| Зависимости до смыслового/адресного изменения | SKILL: первые абзацы поиска | Компактнее; сохранились инструкции, карта, источники, скрытые связи и граница чистой редактуры |
| Сверка фактов/источников/статуса | Reference: «Основания и статус» | Передана отдельному read-only проверяющему; нормы написания и полномочия остаются в теле |
| Понятность и инженерная достаточность | Reference: «Работа читателя» | Проверяется конкретный случай, не единый набор заголовков |
| Дом и внешние последствия после записи | Reference: «Место и связи», принятие возвратов | Переданы независимому читателю с интеграцией основным агентом |
| Границы знания, готовности реализации и исторических источников | SKILL: критерий/сдача; reference: принятие | Сохраняются; незакрытые последствия точны и видны |
| Прямое понимание слов владельца | Тело + общий пакет reference | Основной агент не передаёт поиск/интерпретацию цитат; даёт опору проверяющему |
| Чистая редактура | SKILL: сдача + вход reference | Diff и затронутый текст без субагентов |
| Самостоятельное окно проверки | Reference: общий контекст + одна строка роли, запуск, read-only и запрет рекурсии | Новый механизм по просьбе владельца; нет отдельных role-файлов, новые пользовательские задачи не создаются |

Инструкции MAVO, включая краткий дубль, неизменны. Старый reference и doc_map.py не меняются. Снятие подробной итоговой самопроверки не снимает её критерии: новый владелец их исполнения — назначенный проверяющий, владелец интеграции — основной агент. Сравниваются самостоятельные решения и фактические запуски, не количество строк.
