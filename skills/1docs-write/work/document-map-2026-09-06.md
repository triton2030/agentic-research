# Метаданные и карта документов

Основание: `_ops/chat-recall/2026-09-05-210608-codex-01a07250.md#L20`.
Владелец заказал скрипт в обоих скилах, description и aliases у документов,
алиасы из его прежней речи и действующих имён кода. Предыдущая дискуссия
определила stdout вместо автоматически сохраняемого map.md.

Адресная доработка установленной v4. Имена, триггеры, виды документов,
полномочия, правила сохранности и согласования продукта сохраняются.
Авторизация реализации и установки — текущая команда владельца; нового
общего рефактора и повторного утверждения задания нет.

## Решения и опровержение

| Изменение | Причина и проверяемое свойство | Опровергающая проверка |
|---|---|---|
| Обязательные description и aliases | Карту можно читать до тел; старые файлы без полей не исчезают | CLI на смеси заполненных и пустых документов |
| aliases: [] допустим | Нет кода или цитат — не выдумывать связь; поле всё равно присутствует | Пустой список проходит, отсутствующий — отмечается |
| Короткие реальные слова и точные идентификаторы | Связать словари без случайных тегов | Сверить правило с цитатой владельца и read-only review |
| Карта stdout без записи | Каждый запуск отражает текущее дерево | Изменить fixture между запусками, сверить байты файлов |
| Один аргумент — корень | Нет зависимости от имени Docs/_docs/_canon и текущей папки | Запуск на временном дереве с кириллицей и вложениями |
| PyYAML safe_load | Не писать собственный YAML parser | Block/inline YAML, ошибки типов и небезопасный tag |
| Симлинки перечислены, не обходятся | Цикл или чужой корень не раздувает карту | Fixture с симлинком на себя |

Метаданные Markdown применимы к .md/.markdown; папки, скрытые записи и
не-Markdown вложения тоже перечисляются. Последние не получают выдуманных
описаний. Коды выхода: 0 — полная карта без ошибок, 1 — ошибки метаданных или
чтения, 2 — неверный корень. Нет отправки содержимого в сеть; uv может скачать
объявленную зависимость при первом запуске.

Владелец кода: `skills/shared/1docs-write/portable/scripts/doc_map.py`.
`1canon-write/portable/scripts/doc_map.py` — относительный симлинк на него;
существующий sync копирует байты в каждый runtime, установленный пакет
самодостаточен. Нового механизма сборки не требуется.

Наука: 1agent-steering разделяет механизм и недоступное ему суждение.
Скрипт проверяет форму и полноту карты, агент подтверждает семантическую связь
алиаса адресом цитаты или кода. Карта не считается прочитанным каноном.

Готовое решение: python-frontmatter найден через Firecrawl developer index;
для двух полей достаточно уже используемого PyYAML и чтения заголовка до
разделителя. API: https://pyyaml.org/wiki/PyYAMLDocumentation.

Тесты: `skills/shared/1docs-write/tests/test_doc_map.py`.
Шесть CLI-тестов прошли; запуск через uv в установленной копии показал
документ без метаданных (код 1) и вложенный документ с русским речевым алиасом
и accessToken (код 0). Скрипт запущен из обеих сред; четыре installed-пакета
прошли quick_validate, ссылки разрешаются, sync подтверждает byte parity.
Два независимых read-only проверяющих (буквальный контракт и траектория)
не нашли адресных нарушений. Их прогноз не считается поведенческим прогоном.
Остаточная неопределённость: тесты формы не доказывают качество выбранных
агентом алиасов и улучшение retrieval; массовая миграция проектных документов
не входит в обновление скилов.
