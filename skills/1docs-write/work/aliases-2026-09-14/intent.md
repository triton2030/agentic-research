# Использование алиасов в поиске

Адресная правка по конкретному согласию владельца «да ок добавь» на предложенное правило: при поиске владельца знания и зависимостей использовать относящиеся к вопросу aliases как дополнительные варианты запроса и проверять найденную связь по источнику.

Контекст: doc_map показывает aliases, обычный текстовый поиск находит их, но поисковый раздел 1docs-write явно не связывал эти метаданные с поиском владельца и зависимостей. Пользователь утвердил одно короткое дополнение, а не новый поисковый инструмент.

Граница: один абзац поискового раздела SKILL.md, доставка в существующие Codex/Claude-проекции и история. Reference проверки, инструкции MAVO и документы продукта сохраняются. Новый standalone поиск, индекс или обязательный перебор всех алиасов не создаются.

Цель: алиасы помогают искать предмет под известными альтернативными именами и выходить к связанным источникам. Совпадение остаётся кандидатом; связь подтверждается содержанием. Дополнение нужно в момент поиска, поэтому оно помещено рядом с картой документов по принципу условий применения 1agent-steering.
