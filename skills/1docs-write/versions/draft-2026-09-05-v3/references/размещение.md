# Размещение знания

Вход: отдельное знание или разобранный набор утверждений.
Выход: существующий дом, обоснованное новое место или передача владельцу.

## Задача

Определи, кто владеет этим знанием и где его читатель ожидает найти ответ.

## Цель

Статус знания и место записи согласованы, а имя файла объясняет содержимое
ещё до открытия.

## Зачем

Имя папки не доказывает утверждённость её содержимого. В старом документе
может жить вывод агента, а в недавней цитате — решение о другом предмете;
ошибочный перенос превращает их в текущую правду проекта.

## Ступень знания

Статус решения определяется через `1chat-recall`: слова, авторство, контекст,
область действия и поздние поправки. Метка помогает найти запись; отсутствие
подтверждения означает неизвестность, а не доказанное авторство агента.

| Что установлено о знании | Владелец записи |
|---|---|
| План, задача или состояние текущей работы | Планирование в `_ops`; побочная находка — `1findings` |
| Правило работы агента | Скил или инструкция зоны; общая методика — `1instruction-authoring` |
| Инженерный выбор: данные, модули, стек, исследование | `_docs/Разработка` |
| Идея, гипотеза, бизнес-исследование или материал для решения | `_docs/Бизнес` |
| Утверждённая цель всего проекта, граница или тайбрейкер | `1goal` |
| Утверждённое решение о продукте, дорогое после реализации | `1canon-write` вместе с основанием и затронутой ролью |
| Утверждённая дешёвая деталь реализации | Текущая задача или код; при отсутствии работы — `1findings` |

Канон не хранит устройство кода: продуктовое обязательство о данных или
доступе отделяется от выбранной схемы реализации. Папки проекта уточняет их
`AGENTS.md`; общая ступень не предписывает внутреннее дерево.

## Поиск дома

- Имена папок и файлов очерчивают кандидатов, их содержимое подтверждает
  выбор. Указанный владельцем файл тоже кандидат: иначе его указание может
  незаметно завести второй дом.
- Пустой подходящий файл уже является домом. Противоречие в подходящем файле
  остаётся конфликтом в этом доме, а не поводом записать другую версию рядом.
- Новый файл оправдан отсутствием подходящего дома; ответ называет область
  поиска и причину отклонения ближайшего кандидата с исходной строкой, если
  кандидат был открыт. Это делает выбор проверяемым, не перечисляя всё дерево.

Утверждения одной роли передаются в канон вместе: так автор видит связанные
решения до переписывания, а не переписывает файл заново для каждой строки.
