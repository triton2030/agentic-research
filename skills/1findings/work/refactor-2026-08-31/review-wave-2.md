# Решения по второй, последней волне проверки

Оба проверяющих вернули terminal-ответ. После этой волны новые проверяющие не
запускаются; точные исправленные байты проверяет основной автор.

## Принято

- Routing boundary теперь прямо требует, чтобы без исследования сигнала можно
  было честно продолжить.
- Codex `default_prompt` получил ту же границу blocker-а.
- «Сначала ответь» заменено на внутреннее «Перед записью определи», чтобы
  decision gate не становился публичной паузой.
- Валидация аргумента вынесена во внутренний `validate.sh`; `add.sh` остался
  единственной публичной командой, а каждый script теперь ниже лимита двадцати
  самостоятельных единиц.
- Старое решение о коротких route-строках записано как открытая distribution-
  потеря до installation boundary.

## Требует прямой проверки основного автора

- exact `description` на owner-trigger и current-blocker;
- exact `default_prompt` на ту же пару;
- valid, invalid-format и permanent-write-error paths после разделения scripts;
- существование, исполнимость и unit count обоих scripts.
