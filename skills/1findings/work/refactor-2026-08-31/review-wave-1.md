# Решения по первой волне проверки

Проверялась версия `versions/candidate-2026-08-31/` до исправлений этого файла.
Оба проверяющих вернули terminal-ответ.

## Принято

- Цели заменены с нумерации на маркеры: они не являются последовательностью.
- `helper` в body заменён на `помощник`.
- `default_prompt` переведён на русский и расширен до owner-trigger из ощущения
  неладного либо возможного отложенного последствия.
- Неограниченный retry script-а принят как технический дефект: теперь повтор
  происходит только когда target-файл существует, а другая ошибка печатается и
  завершает помощник ненулевым статусом.
- Устаревший статус `evidence.md` исправлен; для материальных свойств записаны
  фактические фальсификаторы.

## Отклонено

- Перевод `description` и `short_description` на русский отклонён. Решение
  9 августа о русском пакете уточнено более свежим общим критерием 29 августа:
  русский body и короткое trigger-description на английском —
  `_ops/chat-recall/2026-08-29-163434-codex-01a04d4a.md:25`.
- Разбиение script из-за подсчёта более двадцати code predicates отклонено.
  Лимит `1skill-creation` защищает активный набор модельных инструкций; script
  загружается только для детерминированного исполнения. Разбиение не уменьшает
  runtime-сложность и разрушает атомарность утверждённого helper-а. Найденный
  реальный дефект цикла исправлен локально.

## Причинно затронутое evidence

Правка script-а отменяет прежний probe только для recovery-ветки. Валидный и
format-error paths должны быть механически прогнаны повторно; неколлизионная
ошибка должна завершиться без повтора. Routing и смысловой trajectory затронуты
только `default_prompt` и должны быть перепроверены второй волной.
