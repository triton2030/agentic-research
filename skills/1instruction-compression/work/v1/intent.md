# Намерение v1 — `1instruction-compression`

Стадия `goal-context.md` при создании нового скила. Решение о форме — отдельный
скил, а не reference-файл: «Нет я передумал, да давай сделаем отдельный
маленький скил» (`_ops/chat-recall/2026-08-31-202215-claude-da15d86c.md#L41`),
предмет — «сжатие инструкций через их перепесиывание с нуля за счёт
абстрагирования до уровня верхнеуровневой цели» (там же, `#L40`).

## Функция (FAST)

Сжать один перегруженный текст инструкции, породив его заново из поднятой цели,
без молчаливой потери обязательства.

## Подъём названного способа (Action Identification)

«переписать с нуля» → чтобы прежняя форма не была образцом → чтобы текст
выражал механику, а не унаследованный маршрут → **состояние:** текст порождён из
цели, и каждая его строка — то, чего агент из цели не выведет.
Тип по KAOS: **Achieve** — одноразовое преобразование одного текста.

Способ владельца — «переписывание с нуля» и «абстрагирование до верхнеуровневой
цели» — сохранён как его решение и остаётся шагом протокола: чистый агент к нему
не приходит, измеренный дефолт редактора — сохранение
(`science/how-to-command-with-goal-not-procedure.md#L230-L237`).

## Отрицание цели → препятствия

1. Косметика: слова сокращены, маршрут тот же (`…goal-not-procedure.md#L51`).
2. Тихая потеря: обязательство исчезло без адресата.
3. Подъём пропущен: агент правил, а в отчёте написал «поднял».
4. Пустая цель: цель списана с прежней или не порождает ни одной единицы.
Результат отрицания не пуст → раздел Критериев есть, четыре критерия.
