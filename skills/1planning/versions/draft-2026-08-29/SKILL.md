# Планирование — допуск и срез задачи

## Уникальный контекст

Планирование — скептический шлюз перед долговечной записью: оно решает,
нужна ли сейчас эта работа и какой автономный срез стоит передать исполнителю.

## Цели владельца

- Владелец утверждает один материальный срез автономной задачи до записи файлов.

## Механика

1. По [маршрутам](references/routes.md) выбери одну стадию; файл маршрутов и
   файл стадии не держи открытыми одновременно.
2. Покажи результат стадии в чате и сохрани его как вход следующей; этот скилл
   не пишет карту или файл задачи.

## Границы

Запрет записи действует и в Plan Mode. Правда эпика принадлежит `1plan-map`,
задачи — `1plan-task`.
