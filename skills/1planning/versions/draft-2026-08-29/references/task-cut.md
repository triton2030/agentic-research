# Стадия среза задачи

## Цель

Один ответственный агент получает одну автономную цель: проверяемый результат,
его эффект, главный предотвращаемый провал, доказательство, границу,
полномочия, ось и ближайший рубеж.

1. Для применённого метода покажи след `пункт метода → изменённый элемент
   среза`. Гола́я ссылка на метод решением не считается.
2. Положительный срез передай стадии контекста и утверждения; там к нему
   добавляются эпик, приоритет, режим и предел усилий.
