# Маршруты стадий

Закрой этот файл с названием одной следующей стадии.

- Новый кандидат: `опора → допуск → срез → режим → контекст → утверждение`.
- Изменилось основание приоритета: начни с `опора`.
- Уже доказан допуск, но нет среза задачи: начни со `срез`.
- Срез готов, но режим или существенная посылка неизвестны: выбери `режим`.
- Материальный срез готов: выбери `контекст`.
- Изменение композиции маршрутизируй в `1plan-map`; утверждённую задачу — в
  `1plan-task`; обычное исполнение не принадлежит `1planning`.

Файлы стадий: [опора](source-check.md), [допуск](admission.md),
[срез](task-cut.md), [режим](mode.md), [контекст](context-budget.md),
[утверждение](approval.md).

Каждая стадия обновляет один пакет решения; новая версия заменяет прежнюю,
поэтому результаты прошлых стадий не остаются отдельными обязательствами.
