# Стадия режима

## Цель

Задача получает Wayfinding, только если до результата ещё нужно изобрести
продуктовое, архитектурное или полномочное решение; иначе она получает
Execution. Существенное неизвестное становится посылкой с условием остановки.

1. Мысленно начни первый ход; при равном исходе предпочти обратимую дверь.
