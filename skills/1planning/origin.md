# Переформирование `1planning` — 2026-08-08

Третий скил кампании через `1skill-shaping`. Класс — поведение в момент.
Дефицит: проза дешевле кода — подробный план ощущается прогрессом до первого
свидетельства; заплатки поверх устаревших вех создают зомби-план.

## Решения владельца

- **План — инструкция:** «файл задач по сути своей можно назвать файлом,
  который влияет на твоё поведение»; «к скиллу планирования отнестись как к
  скиллу создания инструкций, которые называются задачи. И у задач тоже должны
  быть цели и критерии успеха».
- **Связка с целью:** «планирование должно нас вести к великой цели. Цель даёт
  траекторию, а планирование даёт шаги, которые по чуть-чуть приближают нас к
  великой цели».
- **Разбивка внутри:** «скилл разбивки задач мы удалим, потому что это очень
  важная функция планирования, и она должна быть внутри планирования»
  (`1break-down` снят, ядро — в `decompose.md`).
- **Режимы:** «искать путь — это тоже задача, которую надо исполнять… это
  разные режимы задач» — Wayfinding/Execution сохранены как режимы задачи.
- **Гейт создания:** «планы без моего утверждения нельзя писать… надо
  верхнеуровнево, отталкиваясь от пользы и цели, объяснять… и после моего да
  только можно писать планирование».
- **Развилки:** «принципы позволят планам быть закрытыми в случае развилок и
  помогут автономному закрытию» → инвариант «развилка вне плана → сначала
  `1use-principles`».
- **Словарь:** делегирован агенту («выбирай тот, который лучше подходит по
  твоим ощущениям») → русский канон разделов + жанровые имена мод.

## Вчерашний канон владельца (документ 2026-08-07), вошло

Provenance требований (direct/derived/assumed → владелец/Frame/документ/
допущение) · условия входа задачи · контракты стыков с приёмкой потребителем ·
статус-слой как текущая правда.

## Внешнее evidence

- Полный план вперёд + ленивый ре-план не уступает пошаговому контролю по
  качеству при кратно меньших токенах; пошаговый чаще застревает в циклах
  (до 66.9% против 13.9%) — arXiv 2605.08477. Основание для «контроль по
  событиям».
- Milestone-гранулярность как рабочая единица планирования — HiPlan,
  arXiv 2508.19076.
- Сдвиг поля к индексированному опыту и памяти — Awesome-Long-Horizon-Agents
  (RUC-NLPIR).

## Что сохранено из прежнего скила

Veto нативного Plan Mode · Wayfinding/Execution · «текущая правда вместо
хроники» · cold-start проверка · «отложенный состав требует акта вывода»
(оплаченная строка владельца) · file-disjoint контракт флота · sibling только
для независимо закрываемого Outcome.
