# Стадия опоры

Результат — короткий набор источников и принципов, которые меняют допуск.

1. Прочитай `GOAL.md`, текущий эпик и живые задачи.
2. Среди корневых и предметных инструкций и скилов прочитай только применимые к
   кандидату; покажи несколько реально ограничивающих строк.
3. Примени `1use-principles`; покажи `пункт метода → изменённый элемент`.
4. Доступный только владельцу выбор передай через `1interview-tool`.
