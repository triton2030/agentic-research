# Маршруты стадий

Закрой этот reference с названием одной следующей стадии.

- Новый кандидат: `опора → допуск → срез → режим → утверждение`.
- Изменилось основание приоритета: начни с `опора`.
- Уже доказан допуск, но нет task-среза: начни со `срез`.
- Срез готов, но режим или существенная посылка неизвестны: выбери `режим`.
- Материальный срез готов: выбери `утверждение`.
- Изменение композиции маршрутизируй в `1plan-map`; утверждённую задачу — в
  `1plan-task`; обычное исполнение не принадлежит `1planning`.

Файлы стадий: [опора](source-check.md), [допуск](admission.md),
[срез](task-cut.md), [режим](mode.md), [утверждение](approval.md).
