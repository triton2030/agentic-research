# Находки буквального проверяющего

Сводка terminal-ответа чистого Codex reviewer `planning_review_instructions`.
Его вход — `1skill-creation/agents/check-instructions.md`, immutable packages
этой волны, источники владельца, decisions и production-probes. Это сводка,
не выдаваемая за дословную стенограмму.

- При закрытии задачи потеряно обновление evidence эпика. Прямой источник:
  `_ops/chat-recall/2026-09-02-012307-claude-ba9f96c3.md:23`. В task-schema
  осталось только обновление производных, а checker запрещает промежуточное
  evidence эпика. Минимум — восстановить оба носителя обязательства.
- `запуск: null` пропускается условием `launch is not None`, хотя схема
  требует boolean; эпик исчезает из обоих видов true/false. Минимум — sentinel
  MISSING и отрицательная фикстура.
- Пять C1–C5 скрывают больше семи одновременно применимых требований.
  Подготовку оснований, сборку, исполнение и закрытие требуется различить по
  реальным входам/выходам, сохранив все C1–C5 и считая совместную нагрузку.
- Все тела используют прежний порядок намерения. Текущий
  `1skill-creation/references/goal-context.md` требует Контекст → Задача →
  Критерии принятия → Цель. Менять разделы создаваемых планов не требуется.
- `description` planning/map длиннее 200 символов (214/220). Требование:
  `1skill-creation/references/skill-short-description.md:26`.
