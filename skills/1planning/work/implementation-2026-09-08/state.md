# Planning-family — установленная редакция 2026-09-08

Статус: завершено и установлено в tracked owners и обе runtime-проекции.

## Что поставлено

| Скил | Ответственность и существенная правка |
| --- | --- |
| `1planning` | Выбор работы по GOAL и канону; открываемый допуск; автономное продолжение внутри эпика; видимый выход для нерешённого вопроса |
| `1plan-map` | Семь явных разделов эпика, префикс `epic -`, колокация задач, оба Bases, схема вопроса, встроенный checker |
| `1plan-task` | Префикс `task -`, разделы Канон/Состояние, C1–C5 с моментами применения, 3–7 тогл-отчётов, evidence вклада в эпик при закрытии |

Снимок реагирует на преамбулу, намерение эпика, GOAL и канон. `--sync`
меняет только пять производных полей; подготовленные буферы проверяются до
первой записи. Допуск, evidence, снимки, даты и статусы остаются смысловой
ответственностью агента.
