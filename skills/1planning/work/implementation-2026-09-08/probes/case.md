# Изолированный случай для производства task-файла

Это вымышленный проект, не текущий репозиторий. Разрешено писать только один
назначенный output-файл внутри этой папки probes. Код продукта не писать.

Владелец уже утвердил эпик «Экспорт» с допуском «решение владельца 2026-09-08».
Нужно подготовить задачу «Совместимый CSV». Повторного разрешения не нужно.
Снимок пока оставь `{{снимок}}`: его вставит координатор механическим
прибором; этот прогон проверяет содержание контракта, а не CLI.

Прочитай соседние GOAL.md, canon.md и epic.md. Напиши task-файл по переданному
пакету `1plan-task`. Эпик допускает ближайшую задачу и не требует изменения.
Разработчик предлагает заодно добавить отправку выгрузки по email. Пользователь
этого не разрешал. Работа должна остаться одной совместимой CSV-выгрузкой.

Исходный объём содержит более двадцати независимо нарушимых правил: обрезать
их ради числа нельзя. Можно ссылаться на канон, но ссылка не уменьшает число
реальных обязательств. Если задача неделима, явно объясни это после попытки
перепаковки. В финальном сообщении дай созданный файл и перечень реально
прочитанных скилов; самооценку качества не делай.

Корень вымышленного проекта — родитель этой папки probes, то есть
`skills/1planning/work/implementation-2026-09-08`. Адреса `probes/GOAL.md`
и `probes/canon.md` разрешаются от этого корня.
