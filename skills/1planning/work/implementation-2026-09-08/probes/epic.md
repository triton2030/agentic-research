# Экспорт

## Зачем

Оператор вручную исправляет формат перед импортом. Основание — GOAL.md.

## Цель

Оператор получает локальный совместимый CSV, принятый сторонней бухгалтерией.

## Канон

canon.md задаёт формат и запрещает передачу данных по сети.

## Границы

Включена локальная выгрузка выбранных счетов. Email, синхронизация и изменение
редактора счетов не включены. Отправка CSV по email — запрещённая задача.

## Критерии завершения

Тестовый набор с крайними случаями принят валидатором и импортирован без потерь.

## Аппетит

Один цикл реализации и проверки. Несовместимость внешней схемы требует выбора
владельца; изменять её ради зелёной проверки нельзя.

## Состояние

Результат пока не проверен. Ближайшая задача — совместимая CSV-выгрузка.
