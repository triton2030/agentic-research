# Канон CSV

Файл выгружается локально по действию оператора; передачи по сети нет.
Схема сторонней бухгалтерии принимается целиком одним импортом.

Обязательные независимые свойства:

- Кодировка UTF-8 без BOM.
- Перевод строки CRLF.
- Разделитель — запятая.
- Первая строка содержит заголовки в порядке схемы.
- Значение с запятой заключено в двойные кавычки.
- Внутренняя кавычка удваивается.
- Перевод строки внутри значения сохраняется в кавычках.
- id счёта не изменяется.
- id клиента сохраняет ведущие нули.
- Дата счёта имеет формат YYYY-MM-DD.
- Валюта — трёхбуквенный код.
- Сумма использует точку и два знака после неё.
- Нулевая сумма сохраняется.
- Отрицательная сумма сохраняет знак.
- Пустое необязательное поле даёт пустую ячейку.
- Отсутствие обязательного id завершает выгрузку явной ошибкой.
- Порядок строк совпадает с выбранным порядком счетов.
- Число строк равно числу выбранных счетов.
- Скрытые фильтром счета не попадают в файл.
- Повторное действие без изменения данных даёт те же байты.
- Отмена диалога сохранения не создаёт файл.
- Ошибка записи показана оператору и не объявлена успехом.

Доказательство целого — реальные результаты валидатора и импорта тестового
набора с перечисленными крайними случаями. Скриншот кнопки успеха недостаточен.
