# Обновлённое намерение и состояние

Стадия: candidate после первой независимой проверки; official owner, tracked
projection и live package не изменены.

## Функция

Долговечное планирование во всех проектах принадлежит корневой папке `_ops`.
Общие правила, которые должны влиять на каждый запуск, читаются из основного
`SKILL.md`; reference допустим только для условной самостоятельной ветки.

Новая версия сохраняет clean-room структуру предыдущего рефактора и добавляет
только отсутствующую границу размещения и явное чтение живых planning-owner-ов.

## Уникальный контекст и цель

`1planning` решает до записи, стоит ли начинать одну следующую работу. Оно
читает живую planning-правду под `_ops`, показывает ход рассуждения и после
exact approval передаёт один неизменённый результат владельцам карты и task.
