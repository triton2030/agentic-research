# 1codex-image — происхождение

Создан 2026-10-30. Владелец пакета — `skills/claude/1codex-image/`; эта папка —
история, не скил.

## Заказ владельца

Новый скил для генерации картинок моделью OpenAI его ключом, назван «кодекс
Image». Обязательно: примеры структуры промптов — как писать, какая длина,
какой стиль; случаи из интернета — интерфейс, правка картинки, референсы,
удаление фона.[^order]

Маршрут: основной путь всех растровых картинок в Claude; раздел картинок
`1codex` отсылает сюда, Codex остаётся запасным.[^route]

## Решения автора

- Генерирует официальный `image_gen.py` из Codex-скила OpenAI `imagegen`, а не
  свой скрипт: инструмент готов и обновляется с Codex. Его ограничения для
  моделей 2.5 (размеры, `xhigh`/`max`) закрывает рецепт прямого вызова в
  `references/api.md`.
- OpenAI CLI на Go (`brew install openai/tools/openai`) не взят: общий клиент
  API, картинку из base64 разбирать вручную — выигрыша над `curl` нет.
- Ключ скопирован в `~/.config/openai/api-key` (600): скил глобальный и не
  должен зависеть от папки проекта. `_ops/env/` добавлен в `.gitignore`.
- Модель по умолчанию — `gpt-image-2.5-sunburst`: OpenAI рекомендует 2.5 для
  новых интеграций, а в пробе макета Sunburst дал весь текст без ошибок.
