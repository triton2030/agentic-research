# v3.1 → v4: портрет модели в теле, справочники сняты (2026-11-03)

## Граница

Полная переработка по `1smart-simple`.
Основание — слова владельца в этой сессии:

- промпт минимальный, свобода модели, его реакции пересобираются в инварианты[^invariants];
- меньше инструкций — сильнее; главное наверх; reference-файлы агенты читают редко, поэтому важное — в теле[^body].

Знание взято из серии 20 баннеров PERMAFROST (проект subfrost, `_workspace/codex-image/2026-11-03/журнал-промптов-permafrost.md`) и двух обзоров Sonnet: документация OpenAI и опыт практиков (там же, `research-openai-docs.md`, `research-community.md`).

## v4.2 → v5: метод серии, показ владельцу, уроки ~80 баннеров

Основание — серия PERMAFROST v26–v74 и слова владельца в той же сессии: показывать полный промпт в чате с выделенными изменениями, картинки по одной, без коллажа; «больше экспериментов за раз»; «каждое слово важно»; «рефактор скила» после накопления уроков.

- Верх: модули протекают — первая фраза, слова жанра и места тоже задают стиль.
- Уроки в теле переписаны по самым проверенным: жанр и место рисуются буквально (`annual report`, `poster`, `Swiss` — Альпы 3 из 3), цвет акцента и «единственный акцент», фраза о низком контрасте, слова чистоты дают свет и солнце, строка фона отнимает кадр, список и раздел `Text:` дают иконки, при повторах держится названное.
- Доводка: несколько вариантов за заход, по одному изменению; сетка для двух вопросов; проверка «убери слово»; удачный бриф меняют по строке — его «противоречия» могут работать (v62 против v67–v69); повтор победителя, а неповторяемое — назвать или править от картинки.
- Показ: каждая картинка отдельно; в итоговом сообщении полный бриф с изменениями в `diff`, потому что текст между вызовами владелец не видит.
- Пример брифа — v62, любимый владельцем.

Объём тела 1570 → 1747 слов (+11%), из них пример — около 190.
Свежим агентом не проверено.

## v5 → v6: общие уроки ~170 баннеров, пример без проекта

Основание — серия PERMAFROST v75–v172 и слова владельца в той же сессии: задумка остаётся в чате, бриф — промпт-инжиниринг словами по видимому эффекту[^intent]; жанр задаёт вид и живёт в стиле, меняется только контент[^genre]; в скил идёт только общий опыт, шаблоны проекта — нет[^global].

- Верх: задумка владельца — контекст для агента, не текст брифа; слово выбирают по картинке, которую оно дало.
- Модули названы разделами: стиль (с жанром), предмет, контент, инварианты; смена одного предмета двигает камеру при том же виде, смена контента и размера даёт один вид во всех материалах; формат почти не важен, но разделы `Text:` и `Content:` зовут иконки.
- Уроки в теле: предложения стиля про свет, палитру и материал весят как существительные (удаление по одному, v97–v101); жанру нужен простор — `annual report` при предмете на весь кадр ничего не меняет (v89–v91); жанры со спокойным видом работают, бренды и печатные жанры — нет (v140–v146); видимые слова работают, оценки — нет, а `low contrast` и `low detail` рисуются светлой дымкой (v159–v169); молчание даёт штамп жанра, а не разнообразие (v75–v78); слова расстояния двигают камеру (v102–v110); одна строка раскладки выполняется точно (v92–v96, v170–v172).
- Доводка: «темнее» и «мягче» мерят числом — среднее и разброс серого канала; один бриф гуляет на ±5.
- Пример брифа v62 заменён каркасом по разделам с местами для своего содержания; в шаге «контент» — шрифт для каждой строки (без него мелкие строки меняют шрифт), в ограничениях — вариант фона без текста.

Объём тела 1747 → около 2010 слов (+15%): рост — уроки; пример стал короче.
Свежим агентом не проверено.
