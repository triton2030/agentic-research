## Тело

- Индекс репозиториев — только публичные; приватный код читать напрямую (upstream `firecrawl/cli` 028381ea, 2026-09-19).
- `web:` в id — общая веб-страница, не первичный источник (живой вызов).
- HTTP: ключ по умолчанию, запрос без ключа — только запасной путь (решение владельца[^key]). Без ключа — малый дневной лимит на IP и отказы `429`; поиск с ключом стоит 2 кредита за 10 результатов (docs; живой вызов с ключом 2026-09-23).
- На CLI фильтров нет, scope пишется в тексте запроса (`firecrawl developer --help`).
- `search --categories developer`: результаты в группе `web` с `category: "developer"`, другую категорию добавить нельзя — `400` (живой вызов; docs).
- «About to build»: разовый скрипт тоже проверяется одним запросом; сначала проверить установленное и его версию. В пробе с хуком оба выигрыша дала именно проверка `which lychee`.
- «Known bug, or about to work around one»: влитый PR — ещё не релиз; показать версию с фиксом рядом с обходом, решение не принимать (P-003).

Не взято из upstream: раздел «See also» на `firecrawl-build-search` — других скилов Firecrawl владелец не держит[^keep].
Не изменено: `skills="only"` остаётся HTTP/MCP. Docs обещают CLI-флаг `--skills-only`, но в `firecrawl-cli` 1.24.4 его нет.
