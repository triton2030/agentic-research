# Происхождение правил — 1readable-code

## 2026-08-11 · перекройка от исследований

Класс: поведение в момент. Знание (числа исследований) обслуживает разрыв
дефолта, отдельным продуктом не является — поэтому живёт в `evidence.md`, а не
в теле скила.

Прежний текст (78 строк, разделы Outcome / Structural Preference / Quality
Standard / Architecture Owner Gate / Evidence) провенанса не имел: папки-истории
не было, слов владельца о скиле в `_ops/chat-recall/` нет. Весь прежний текст —
агентский, поэтому курировался целиком.

### Owner evidence этой перекройки

`_ops/chat-recall/2026-08-11-050000-claude-ad4c0fa8.md`:

- «Нет это не для меня, надо найти исследования в интеренте какой код любят
  агенты» — содержание скила берётся из внешних исследований, не из читаемости
  для владельца;
- «у нас весь код должен быть чистым как по методикам програмирования брукса
  так и по методикам глубоких модулей, это по исследования улучшает работу
  агентов» — обязательная линия Брукса и Ousterhout;
- «Исследования используем только за последние пол года» — окно источников
  2026-02-11 … 2026-08-11;
- «не только какой они код предпочитают а вцелом какие общие системные промпты
  для агентов прогграмирования помогают агентам писать успешно код, вот эти
  промпты можем использовать в скиле читаемого кода» — второй класс источников.

### Курация владельца, 2026-08-11

Три развилки, предъявленные с картой смыслов и числами до черновика:

1. Каркас → «Оператор в моменте решения». Скил перестал быть списком
   предпочтений; каждый пункт требует предъявляемого следа. Основание в
   выбранном превью: «успешные прогоны правят с шага ~9, провальные с шага 0».
2. Брукс и глубокие модули → «Только роутинг в `codebase-design`». Словарь
   глубоких модулей не дублируется; в теле осталась одна строка карты сбоев с
   ценой перехода.
3. Гейт архитектуры → «Снять весь раздел и reference». Основание — ablation
   контекстных файлов: обзоры архитектуры не двигают correctness.

Утверждение точного полного текста: «да отлично делай» (2026-08-11, эта же
сессия), после предъявления черновика вместе со списком дефектов аудита.

**Изменено после утверждения:** `description`. Утверждённая формулировка не
поднимала скил ни на одной голой фразе — прогон в [`evidence.md`](evidence.md).
Заменена на перечисление узнаваемых случаев запроса вместо требования, чтобы
агент сам классифицировал свой ход как «structural choice». Тело скила не
менялось; повторного «да» на новую строку `description` владелец ещё не давал.

### Что несёт каждое правило

- Владение против места симптома — 10 из 12 провалов: файл найден верно, слой
  неверный (arXiv 2604.02547).
- Назвать владельца до первой правки — отложенная первая правка ρ=+0.68; шаг
  9.4 против шага 0 (там же).
- Разброс дороже лишней обёртки — ремонт разбросанной функциональности 14–57%
  против 60–84% у лишней абстракции (2605.07001); размазывание той же сложности
  по файлам добавляет накладные расходы (2605.20049).
- Комментарии не несут границу — комментарии и suppression-маркеры дают ноль
  эффекта на footprint агента (2605.20049).
- Слой данных первым — дефекты запросов и ORM: главная причина провала под
  структурными ограничениями (2605.06445).
- Явное против конвенций — Flask держится, FastAPI и Django ломаются (там же).
- Проверка против запрошенного артефакта — 221/222 зелёных теста при пустой
  библиотеке (2606.28430).
- Повторный вход — соблюдение падает на ~5.6% с каждой сгенерированной функцией
  внутри сессии, OR 0.944 (2605.10039).

Полные адреса и числа — в [`evidence.md`](evidence.md).

## 2026-08-11 · упрощение по методу

Просьба владельца: «Давай тоггда упростим этот скил по методу упрощение по
обновлённому скилу инструкций» — режим аудита существующего свода,
`1instruction-shaping` / `simplify.md`.

Нагрузка снята с 37 обязанностей до 16; что и почему снято — в
[`cut.md`](cut.md), находки двух линз и прогоны — в
[`evidence.md`](evidence.md).

Курация владельца по двум развилкам, где линзы аудита разошлись принципиально:

1. Правило о владельце против места симптома → **снять как выводимое**. Против
   моей рекомендации оставить: замеру на двух игрушечных ловушках он предпочёл
   доверять больше, чем числу 10/12 из arXiv 2604.02547. Вердикт «модель умеет
   сама» датирован 2026-08-11 и привязан к Opus 5 — при смене рабочего набора
   моделей на более слабый правило возвращается.
2. Маршрут в `1ia-audit` → **снять как бортик без сбоя**, по его же решению
   2026-08-11: уместность — не необходимость.

Точный полный текст после этих двух правок владелец видел в превью развилок
дословно; отдельного третьего «да» на собранный текст не запрашивалось.
