# Рефактор существующего — дельты скила

Источник — [refactor.md](../../1instruction-shaping/references/refactor.md)
пакета `1instruction-shaping` (решение владельца 2026-08-25: основа зеркал
живёт там). Прочитай источник и иди его шагами с
дельтами ниже; полная копия здесь не держится, перечень намеренных расхождений
исчерпывается этим списком. Лучший исход для скила, который модель умеет
целиком, — снятие скила.

- **Шаг 1, оригинал целиком:** тело, все references, история — папка-история
  скила (`origin.md`, `cut.md`, `evidence.md`) и chat-recall.
- **Шаг 2, карта смыслов:** провенанс карточки здесь — текущая задача · слова
  владельца (адрес) · governing context · помеченный вывод · неизвестен.
- **Шаги 3 и 6:** курация и хвост цикла идут через
  [автономную границу](../SKILL.md#автономная-граница) тела, не через «да»
  владельца; неразрешимый остаток — один вопрос по границе.
- **Шаг 4, пересборка:** сила формулировок — владелец операций
  [behavior-package](behavior-package.md).
- **Шаг 5, связность после:** пересобранный текст против живой карты — корень,
  папки, соседние скилы; правило, меняющее смысл или силу другого без общей
  задачи, — тоже находка.
- **Правила упрощения** — владелец в источнике.
