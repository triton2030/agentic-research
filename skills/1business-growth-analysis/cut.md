# Cut

Общее с Codex-копией — в `skills/codex/1business-growth-analysis/cut.md`; здесь
только снятое при переносе на Claude.

- Абсолютный корень проекта в брифе снят: субагент Claude наследует рабочую
  папку, строка была бы шумом.
- `fork_turns`, имя инструмента и способ инвокации сняты из runtime-контракта:
  способ вызова знает платформа, скил хранит только требование отдельного
  чистого окна.
- Раздел `Дельта` у агента сокращён до одной фразы: остальные пункты уже несли
  Инварианты и Критерии — дубль ослабляет все правила сразу.
- Карта сбоев агента сокращена с пяти строк до двух: три из пяти пересказывали
  Критерии и Механику.
- `Bash` в инструментах оставлен вопреки обещанию read-only: без него не
  работает Retrieval `1chat-recall` (`chat_digest.py`). Дыра названа в
  `evidence.md`, не закрыта прозой.
- Продуктовые правила не скопированы из Codex: Claude остаётся runtime twin и
  читает единственную Product Frame-пару общего intent.

  подгоняет прогноз под обвинительный ответ. Перечень соседних скилов снят.
- Повторы критериев перенесены в моменты входа, прогноза и возврата; методы,
  самостоятельное чтение, горизонты и условность сохранены.
