# Файл системного промпта

По прямому заказу владельца создан `agents/prompt.md` внутри обеих runtime-версий
скилла. Текст перенесён без изменения из инструкции аналитика после коррекции
методик. SKILL.md требует прочитать файл и передать его полный текст системными
инструкциями роли. Бриф о конкретной компании передаётся отдельно.

Существующие Codex TOML и Claude native-agent Markdown сохранены как runtime
проекции; их тела сверяются с prompt.md. Название роли без соответствующих
системных инструкций не считается выполнением. Само содержимое роли не менялось.

Источник: [цитата](../../../../_ops/chat-recall/2026-09-16-141210-codex-01a0a968.md:17),
следующая реплика владельца уточнила имя папки: `agents`.

Три адресные независимые проверки не нашли потерь или ошибок маршрута.
TOML и native Markdown bodies совпадают с prompt.md после нормализации
краевых переводов строк; два prompt.md и SKILL.md совпадают побайтно.
Markdown lint проходит. Это проверка текста и доставки, не наблюдение
фактической инъекции runtime в новом вызове.
