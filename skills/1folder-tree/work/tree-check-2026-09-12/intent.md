# Терминальная проверка дерева

Адресное дополнение 1folder-tree: команда для Claude и Codex, gpt-5.6-sol low, дерево имён и полный текущий SKILL.md. История разговора и содержимое базы не передаются. Выход — проверяемый отчёт о понятности и видимом соответствии скиллу, без изменения базы.

Источник: /Users/triton/Documents/My_projects/mavo3/_ops/chat-recall/2026-09-12-181341-codex-01a095bf.md, реплики «Тогда давай добавим этот инструмент…», «через терминал еще лучше, потому что тогда Клод сможет его использовать…».

Состояние: авторский черновик. Owner: skills/shared/1folder-tree/portable. Существующие правила сохраняются; новый режим ограничивает только автоматическую проверку по именам. Базовый контекст Codex не объявляется отсутствующим. Местные решения неизвестны проверяющему; итог интерпретирует вызывающий агент.

Механизмы: имена собираются без чтения файлов и обхода симлинков; JSON экранирует имена. Превышение лимита и ошибка обхода прерывают проверку без молчаливой усечки. Отдельный cwd, ignore-user-config, project_doc_max_bytes=0, запрет инструментов в prompt и проверка событий. Evidence сохраняется вне проверяемого дерева. Shell invocation использует argv, без shell interpolation.
