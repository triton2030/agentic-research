# Проба на независимом небольшом дереве

Файлы в holdout содержат sentinel, который не должен попасть в prompt. В дереве видны файл-тёзка Корзина/Корзина.md и смешение файлов с подпапкой в Корзине. Отдельный путь Деньги/Возврат/Деньги покупателю.md даёт однозначный навигационный запрос. Проверка не должна читать содержимое, менять файлы или утверждать полноту знаний. Вопросы/ожидаемые замечания из этого файла модели не передаются.
