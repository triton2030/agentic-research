# Филиалы
Список филиалов с адресом и часами работы, кнопка «Добавить филиал».

У филиала есть адрес, часы работы и список мастеров; мастер работает только в одном филиале.

Часы работы филиала ограничивают расписание мастеров: смену нельзя открыть вне этих часов.

Администратор добавляет филиал, указывает адрес и часы, затем назначает мастеров.
