# s2 (прежняя редакция), прогон B — финальный ответ агента

## 1. Предлагаемое дерево

- `Админка/`
  - `Экран обращений`
  - `Экран услуг`
  - `Экран филиалов`
- `Правила/`
  - `Бонусы`
  - `Визит`
  - `Запись`
  - `Обращения`
  - `Оплата и штрафы`
  - `Отзывы`
  - `Расписание мастеров`
  - `Уровни мастеров`
  - `Услуги и цены`
  - `Филиалы`
- `Приложение клиента/`
  - `Экран записи`
  - `Экран профиля`
- `Приложение мастера/`
  - `Экран визита`
  - `Экран расписания`

## 2. Куда уходит содержимое

| Сейчас | Остаётся на экране | Уходит в `Правила/` |
|---|---|---|
| `Админка/Обращения` | список, ответ, компенсация → `Экран обращений` | кто и откуда пишет, куда приходит ответ, размер компенсаций → `Обращения` |
| `Админка/Услуги` | таблица, скрытие → `Экран услуг` | базовая цена, наценки уровней, что происходит со скрытой услугой → `Услуги и цены` |
| `Админка/Филиалы` | список, добавление, назначение мастеров → `Экран филиалов` | адрес, часы, мастер работает в одном филиале → `Филиалы`; смена только в часы филиала → `Расписание мастеров` |
| `Мастер/Отзывы` | — | целиком, вместе с рейтингом → `Отзывы` |
| `Мастер/Уровни` | значок уровня → `Экран записи` | уровни и повышение → `Уровни мастеров`; наценка → `Услуги и цены` |
| `Экран записи` | раскладка, кнопка, подсказка при отсутствии карты | порядок выбора, удержание слота, запрет позже чем за 2 часа, SMS → `Запись`; платная отмена, обязательная карта → `Оплата и штрафы`; цена по уровню → `Услуги и цены` |
| `Экран профиля` | раскладка, смена телефона, карта, кнопка «Оставить отзыв» | правила бонусов → `Бонусы`; «без карты запись недоступна» → `Оплата и штрафы` |
| `Экран визита` | карточка клиента, крупные кнопки | приход, завершение, неявка → `Визит`; списания → `Оплата и штрафы`; начисление 5% → `Бонусы` |
| `Экран расписания` | лента дня, закрытие слота | лимит 10 часов, перерыв, открытие смены, SMS при закрытии слота → `Расписание мастеров` |

Экран не копирует правило: он описывает свои действия и ссылается на файл, где правило записано.

## 3. Главные решения (сокращённо автором пробы до сути)

- Каждое правило записано в одном месте, экраны на него ссылаются: цена по уровню в трёх файлах, 5% бонусов в двух, штраф 50% в двух, обязательная карта в двух.
- В корне три интерфейса и общие правила; `Мастер` легко спутать с `Приложением мастера`.
- Отзывы не входят в папку мастера: пишет клиент, проверяет администратор, показывают профиль клиента и страница мастера; мастер — адресат, а не хозяин правил.
- Имена экранов в админке тоже начинаются со слова «Экран».
- Вся цена — в `Услугах и ценах`; штрафы вместе с оплатой, бонусы отдельно.
- Цифр перед именами нет; пустых файлов для пробелов не создаёт, перечисляет пробелы.
- Отклонён вариант «папка на предмет, экран внутри»: экраны одного приложения разойдутся.
