# Тренеры клуба
У каждого тренера есть профиль: специализация, опыт, фото и отзывы.

Тренеры делятся на категории: тренер, старший тренер, мастер-тренер; от категории зависит цена персональной тренировки.

Клиент выбирает тренера по специализации и свободному времени.
