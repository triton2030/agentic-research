2. **Новый прогон сценария не передан независимому проверяющему.** [Основной текст](/Users/triton/Documents/GitHub/agentic-research/skills/1docs-write/work/kinds-and-names-2026-09-27/candidate/SKILL.md:98) требует конкретного примера и места в документах для каждого шага. Проверяющий получает [только свой вопрос](</Users/triton/Documents/GitHub/agentic-research/skills/1docs-write/work/kinds-and-names-2026-09-27/candidate/references/проверка-документов.md:44>), где остаётся лишь общее «пройти существенный случай» ([строка 58](</Users/triton/Documents/GitHub/agentic-research/skills/1docs-write/work/kinds-and-names-2026-09-27/candidate/references/проверка-документов.md:58>)). **Основание:** одобренный [пункт Д4](/Users/triton/Documents/GitHub/agentic-research/skills/1folder-tree/work/kinds-and-names-2026-09-27/intent.md:41). **Неверный выбор — прогноз:** проверяющий признает связный рассказ достаточным, не обнаружив шаг без разрешающего источника. **Минимальная правка:** добавить проверку «конкретный шаг → адрес ответа» в вопрос «Работа читателя».

Есть также **гипотеза о лишней жёсткости**: обязательные «имена и числа» [без условия](/Users/triton/Documents/GitHub/agentic-research/skills/1docs-write/work/kinds-and-names-2026-09-27/candidate/SKILL.md:100) могут заставить выдумывать числа при описании понятия, которому достаточно [одного абзаца](/Users/triton/Documents/GitHub/agentic-research/skills/1docs-write/work/kinds-and-names-2026-09-27/candidate/SKILL.md:28). Это прогноз, а не наблюдённый сбой; минимальное уточнение — требовать числа, когда они меняют проверяемый результат. Поскольку формула взята из одобренного Д4, снимать её без различающей пробы не советую.
