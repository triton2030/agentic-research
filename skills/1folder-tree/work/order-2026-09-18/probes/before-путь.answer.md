# Проба: скил ДО правки, дерево `_docs/Путь дизайна` (Opus, свежий контекст, вход = before-путь.prompt.txt)

## Краткий вывод
Три из четырёх веток читаются с первого взгляда: `Персонализация`, `Заказ и отправка`, `Принт-финал` выглядят стадиями пути и держат файлы с именами-ответами. Главное затруднение одно и крупное: папка `Весь путь` стоит рядом со стадиями, а не над ними, и по имени невозможно понять, где живёт описание целого и где — правила стадии. Второе — несколько имён внутри `Заказ и отправка`, по которым читатель не угадывает ответ.

## Существенные затруднения навигации
- `Весь путь/Персонализация и печать.md` против `Персонализация/` и `Принт-финал/`: имя `Весь путь` обещает целое, части лежат рядом, а не внутри; ребёнок повторяет охват родителя `Путь дизайна`; имя файла составлено из имён двух соседних папок.
- `Заказ и отправка/Устройство-создатель.md`: самое непрозрачное имя; три догадки (устройство покупателя, строение модуля, роль автора заказа).
- `Заказ и отправка/Материалы покупателя.md` против `Персонализация/`: материал появляется на стадии персонализации, адрес помещает его в заказ.
- **Порядок чтения не виден.** Имена не подсказывают, что стадии идут персонализация → заказ → принт-финал; новый человек выводит это из смысла слов, а не из карты.

## Соответствия
«Либо файлы, либо подпапки» — соблюдено; «имя файла — короткое словосочетание об ответе» — для большинства; запрещённых форм нет.

## Расхождения (условные предложения)
| Сейчас | Критерий | Предложение |
|---|---|---|
| `Весь путь/` | имя папки — предмет или признак группировки | стадии его подпапками либо назвать по ответу |
| `Устройство-создатель.md` | понятно, зачем открывать | `Привязка заказа к устройству.md` |
| `Совместимость сохранённых значений.md` | имя об ответе | `Совместимость сохранённой персонализации.md` |
| `Принт-финал без заказа.md` | имя об ответе, не об условии | `Печатный файл для запаса Студии.md` |
| `Получение` ↔ `Выдача` | узнаваемость карты | выровнять глаголы |

## Вопросы читателя
1. «Что покупатель может менять и в каких рамках?» → `Персонализация/`, не находит, возвращается к `Весь путь`.
2. «Что происходит с фотографией?» → ждёт `Персонализация/`, уходит в `Материалы покупателя.md`.
3. «Как Студия получает файл без покупателя?» → `Принт-финал без заказа.md`, не знает, полный ли это ответ.

## Непроверенные
Местные исключения и карта базы; термины продукта; самостоятельность ответов; владение и зависимости; полнота; отношение вложенности для `Весь путь`; одиночный файл в `Весь путь`.

*Наблюдение автора правки: порядок назван одной строкой среди затруднений, к критерию не отнесён, обзор `Весь путь` предложено вложить стадии внутрь — что нарушило бы правило «либо файлы, либо папки».*
