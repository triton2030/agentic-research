# Проба: скил-КАНДИДАТ, дерево `_docs/Путь дизайна` (Opus, свежий контекст, вход = candidate-путь.prompt.txt)

## Краткий вывод
Дерево читается как последовательность стадий, но по именам не восстанавливается ни точка входа, ни порядок чтения. Формальное разделение выдержано. Основные затруднения — вход («Весь путь» против корня «Путь дизайна»), алфавит поперёк процесса и два имени-термина, по которым нельзя предугадать ответ.

## Существенные затруднения навигации
- `Весь путь/Персонализация и печать.md`: папка обещает целое, файл называет две стадии и молчит о заказе; имя почти повторяет корень.
- **Порядок стадий не виден.** Отображение по алфавиту даёт: Весь путь → Заказ и отправка → Персонализация → Принт-финал. Корень называется путём, то есть обещает последовательность, но «Заказ и отправка» стоит раньше «Персонализации». То же внутри `Принт-финал/`: сверху «Выдача», ниже «Подготовка» и «Проверка перед печатью» — первым предлагается последний шаг. **Способ показывать порядок задаёт инструкция базы, которую я не открывал, поэтому нарушением это не называю: наблюдаемо только то, что в именах такого способа нет.**
- `Устройство-создатель.md`: самое непрозрачное имя.
- `Материалы покупателя.md`: два правдоподобных дома (заказ и персонализация).
- `Персонализация/` без видимого входа: три механизма, собственная ответственность папки по именам не пересказывается.
- `Проверка перед печатью.md`: не видно, чья проверка и когда её читают.
- Повтор имени папки в трёх именах из четырёх в `Принт-финал/`.

## Соответствие критериям скила
| Критерий | Наблюдаемо |
|---|---|
| Либо файлы, либо подпапки | Соблюдено; папка `Весь путь` с одним файлом допустима при родителе с подпапками |
| Имя файла — об ответе, имя папки — предмет | В основном; расхождения: «Устройство-создатель», «Совместимость сохранённых значений», «Весь путь» |
| **Дети сверху вниз дают пересказ и первый шаг** | **Расхождение в `Принт-финал/` (первой стоит выдача) и на верхнем уровне (заказ между персонализацией и принт-финалом). В `Персонализация/` первый шаг не выбирается** |
| Имя-жанр, версии, даты, «разное», тёзка | Не встречаются |

## Непроверенное
Инструкция базы: язык, имена, исключения, **способ показывать порядок чтения — если порядок объявлен там, замечание снимается**; есть ли порядок между ветками — знание о предмете; самостоятельность, владение, полнота; статус терминов; решения владельца о «Весь путь» и о «Заказ и отправка».

## Вопросы читателя
1. «С чего здесь начинать?» → `Весь путь/` → внутри про заказ ни слова → возвращаюсь, иду в `Персонализация/` наугад.
2. «Куда покупатель кладёт фото?» → `Персонализация/` — не то → `Материалы покупателя.md`; колебание остаётся.
3. «Как получить файл без заказа?» → `Принт-финал/`, сверху «Выдача» — похоже; ниже «Без заказа»; какой читать первым, имена не говорят.

*Наблюдение автора правки: новый критерий применён по адресам на двух уровнях; способ показа порядка кандидат не изобрёл, отнёс к инструкции базы; стадии внутрь обзора не предлагал.*
