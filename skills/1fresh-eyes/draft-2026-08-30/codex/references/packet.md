# Пакет

Вход: якорь решения и `mode`. Выход: замороженные пакеты, named `blocker` либо
точный `panel_incomplete`.

## Цель

Заморозить достаточно конкретный для независимой работы объект решения без
объяснения, диагноза и желаемого вердикта главного агента. Панель получает
невзаимозаменяемые evidence paths, которые не повторяют текущий рабочий корпус
Main; named-поток — объект доказательства своего родного результата.

1. Для `panel` перечисли текущий рабочий корпус Main и назначь четырём линзам
   разные релевантные главные evidence paths, которые его не копируют.
2. Для `named` проверь явно выбранный профиль; недоступный верни как точный
   `blocker` без подмены, иначе зафиксируй только его.
3. Заморозь все пакеты до первого отчёта.
4. Для `panel`, если paths взаимозаменяемы или четырёх релевантных paths нет,
   верни `panel_incomplete` с точным `blocker`; не выдумывай различие.
