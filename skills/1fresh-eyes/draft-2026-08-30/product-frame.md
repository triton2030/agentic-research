# Product Frame — 1fresh-eyes — candidate 2026-08-30

Статус: candidate. Не live owner; требует exact approval вместе с fingerprint
полного candidate.

## Цель-сцена

Длинная работа дошла до материальной развилки либо пользователь явно запросил
Fresh Eyes.
Главный агент изолирует объект решения от собственного объяснения.
Для широкой проверки он получает четыре отчёта разных направлений и по их
проверенным основаниям выбирает следующий ход, ближайшую альтернативу либо
продолжение без изменений.
Если пользователь явно назвал одну доступную роль, она возвращает свой native
product без панели.

## Тайбрейкеры

1. Названное следствие для решения сильнее ритуала: без материальной развилки,
   явного запроса Fresh Eyes или явно названного специалиста скил не запускается.
2. Изоляция рамки главного агента сильнее полноты его гипотезы: проектная
   правда и наблюдаемое состояние входят как материал, а rationale и желаемый
   вывод — нет.
3. Разные пути проверки сильнее стилистического расхождения.
   - Одинаковый вердикт допустим, если `ladder`, `solvent`, `prospector` и
     cross-family Premortem дали материально разные родные отчёты через разные
     главные evidence paths.
   - Материально одинаковые отчёты либо одинаковые метод, источник и следствие
     дают точный `panel_incomplete`, а не повтор без нового материала.
4. Fixed four-lens panel — default широкой траекторной развилки или явного
   неназванного запроса Fresh Eyes.
   Named exception существует только для явно выбранной пользователем роли и
   возвращает её родную форму без panel synthesis.
5. Критика не самоцель.
   Source-supported `unchanged` полноценен.
   Непроверенное решающее утверждение или недостающая линза дают честный
   `panel_incomplete`; отсутствующий runtime — точный `blocker`, не имитацию.

## Владение

Skill владеет якорем решения, изоляцией входа, фиксированным составом панели и
non-voting handback.
Definitions ролей владеют методом и родной формой ответа.
Runtime-специфичные запуск, cross-family bridge и retained correction живут
только в соответствующей Claude/Codex форме.
История и Product Frame не устанавливаются в runtime package.

Поздний FE-7 задаёт текущую механику четвёртой линзы: Claude вызывает Codex, а
Codex вызывает Claude.
Более ранняя runtime-деталь FE-4 «Codex в панель не входит» не отменяет
cross-family Premortem и читается только как история прежнего состава.
Named exception из FE-4 остаётся действующим.

## Аппетит и пересмотр

Тело остаётся коротким контроллером; references существуют только у
самостоятельных стадий. Число 20 — attention threshold активной стадии, а не
цель, оправдывающая церемониальное дробление.

Пересмотр: панель запускается без decision consequence; packets передают
rationale main или становятся взаимозаменяемыми; named mode включает панель;
Premortem использует ту же model family; synthesis голосует, усредняет либо
теряет native disagreement; одна линза регулярно не даёт отдельного входа в
решение.
