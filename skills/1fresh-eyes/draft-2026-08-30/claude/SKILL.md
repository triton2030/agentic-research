# Свежие Глаза

## Уникальный контекст

Долгая работа сужает рамку главного агента. Новый поток свеж только с
нейтральным объектом решения и независимым путём доказательств. Критика не
обязательна: подтверждённый `unchanged` полезен.

## Цель пользователя

- Материальная развилка или явный запрос Fresh Eyes получает четыре независимых
  отчёта; явно названная роль вместо этого — один родной результат без панели.
- Каждая линза проверяет общий нейтральный якорь через свою главную зону
  источников.
- Контроллер проверяет утверждения, меняющие решение, сохраняет родные
  результаты и не голосует.

## Ход

Переходи к следующему шагу только после результата предыдущего. Любой точный
`blocker`, `panel_incomplete` или `correction_incomplete` завершает текущий
проход без подмены результата.

1. Собери якорь решения: вопрос на столе, что изменит ответ и конечный результат
   из GOAL/Product Frames. Если GOAL/Product Frames не дают конечного
   результата, выведи только его из доступных доказательств и лучших
   профессиональных практик.
2. До первого отчёта собери замороженные [пакеты](references/packet.md).
3. Получи отчёты выбранного режима. Для `named`: `profile: premortem` передай в
   [Premortem](references/premortem.md); иначе запусти ровно один явно названный
   доступный `profile` в новом обычном `Agent`-потоке без fork и передай только
   его пакет. Для `panel`: сначала получи Premortem другой модельной семьи,
   затем три отчёта [нативной панели](references/panel.md).
4. Ошибочную source-bound посылку или недостающий обязательный проверочный
   элемент исправь через [коррекцию](references/steering.md).
5. Для `named` верни родной результат без панели и синтеза. Для `panel` передай
   четыре терминальных отчёта с завершённой требуемой коррекцией в
   [синтез](references/synthesis.md).
