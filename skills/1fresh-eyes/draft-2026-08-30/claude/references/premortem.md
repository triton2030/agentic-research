# Premortem

Вход: замороженный пакет. Выход: терминальный отчёт Codex или точный `blocker`.

## Уникальный контекст

Другая модельная семья разрывает общий prior панели; обратный вызов
модели-родителя создаёт рекурсивное ожидание. Делегирование внутри Premortem
превращает одну четвёртую линзу в скрытую панель и смешивает evidence paths.

## Цель

Получить одной моделью другой семьи проверяемую обратную историю
`achieved success → mechanism → harm` с ранним `signal`, адресуемым
`state_today` и `guardrail` с названной ценой.

1. Если Claude запущен из Codex, верни `premortem_skipped_recursive_parent` как точный `blocker`.
2. Иначе подготовь из замороженного пакета один запрос по `$1codex`; потребуй
   не запускать и не делегировать работу другим agents или subagents.
3. Потребуй первой строкой `fatal_signal_present`, `signal_watchable` или `story_unfalsifiable`.
4. Сохрани терминальный отчёт фактически другой модельной семьи; использование
   ею иных agents либо отсутствие терминального отчёта верни как точный
   `blocker` без собственной подмены.
