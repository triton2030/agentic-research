# Cut — 1fresh-eyes — candidate 2026-08-30

## Runtime package

Первый full authoring pass заново вывел текущий runtime package побайтно.
После независимой проверки сохранены только невыводимые швы:

- `panel_incomplete`, когда нельзя назвать четыре релевантные source zones;
- retained correction для отсутствующего обязательного проверочного элемента;
- retained correction для ошибочной source-bound premise и full-packet restart;
- unavailable named profile blocker без подмены;
- `panel_incomplete` при непроверенном решающем claim или неразличимых evidence
  paths;
- одно terminal rule для любого `blocker` или `*_incomplete`;
- запрет nested delegation у cross-family Premortem после наблюдаемого clean-run
  с двумя лишними голосами.

Clean-room proposal одного `lane-contracts.md` не принят, потому что методы
линз уже принадлежат definitions ролей; новый файл создал бы второго owner-а и
нагрузку без нового решения.

Не возвращены старые каталоги полей, scoring, majority rules, generic critic
taxonomy, отдельные FAQ/examples, микростадии ради `≤20` и обязательный
reference на каждый handback. Они либо выводятся из commander's intent, либо
создают церемониальную поверхность, либо не принадлежат этой функции.

После owner-критерия простоты сняты runtime-цитаты как дубли цели и roster,
поле `Кругов пройдено`, повтор terminal routing из каждой ветки, форматное
дробление одного tool call и отдельный `named.md`. Named exact launch теперь
живёт в одной строке runtime branch; это убирает файл и чтение без потери
режима.

После completed panel `19def…` сняты ещё только выводимые дубли:

- общий контекст сведён к модели `neutral object · independent path · native
  role · non-voting controller`;
- точная `next/alternative/unchanged` schema оставлена только у synthesis;
- повтор unavailable-profile stop снят из `panel.md`, потому что локальная цель,
  output и global terminal rule уже задают тот же выбор;
- запрет передавать ещё не существующие native reports снят из Premortem:
  критичный порядок уже запускает его первым;
- общий authority reminder снят из correction: цель same-stream correction не
  даёт полномочий расширять scope, а живые authority rules остаются выше skill.

Не сняты no-delegation Premortem, bounded waves и retained correction: текущий
completed panel снова наблюдаемо использовал каждый из этих seams.

Первая checker-пара потребовала вернуть дословные FE-7 цитаты в runtime. Это
не принято: exact roster и cross-family direction уже владеют поведением, а
цитаты не меняют ни use, ни route, ни terminal result. Их возврат противоречил
бы позднему owner-критерию `:33` и текущей границе «не добавлять процедуру без
counterfactual harm».

Приняты checker-находки, меняющие разбор: `Fresh Eyes`/`cross-family` в
reference triggers, scope `проверочный` у correction, named-safe Premortem
goal и материальная различимость native reports при допустимом одинаковом
verdict. Повтор correction двух режимов заменён одним общим шагом.

## Product Frame

Снят прежний буквальный тезис «совпадение — сбой запуска». Его заменяет
проверяемая граница: одинаковый итог допустим только при разных evidence paths;
одинаковые метод, источник и следствие остаются провалом.

Снят Claude-only тезис `Cross-model — 1codex`. Текущая граница симметрична по
функции и различается по runtime: Claude → Codex, Codex → Claude.

Добавлены полноценный `unchanged`, честный `incomplete`, явная текущая роль
FE-7 и граница named mode. Это не новая функция: runtime package и прошлые
trials уже исполняют эти смыслы.
