# Пакет

Вход: якорь решения и выбранный `mode`. Выход: замороженный пакет или пакеты.

1. Приложи якорь решения и наблюдаемое состояние из источника.
2. Приложи адреса исходных доказательств, существенные пробелы и границы.
3. Не добавляй интерпретацию главного агента: обоснование, диагноз, предполагаемую причину или желаемый вердикт.
4. Для `panel` перечисли `Main уже читал`, дай каждой из четырёх линз другую главную зону исходных материалов и передай `Кругов пройдено` только числом.
5. Для `named` зафиксируй только явно выбранный пользователем доступный `profile` и объект доказательства его родного результата.
6. Не пересказывай метод роли.
7. Заморозь все пакеты до первого отчёта; взаимозаменяемые зоны панели разведи заново.
