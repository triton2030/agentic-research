# Packet

Вход: decision anchor и выбранный mode. Выход: frozen packet или packets.

1. Приложи decision anchor и observable state из source.
2. Приложи raw evidence addresses, material gaps и boundaries.
3. Не добавляй интерпретацию main: rationale, diagnosis, suspected cause или desired verdict.
4. Для panel перечисли `Main уже читал`, дай каждой линзе другую главную raw-source zone и передай `Кругов пройдено` только числом.
5. Для named mode зафиксируй только явно выбранный пользователем доступный profile и evidence object его native product.
6. Не пересказывай role method.
7. Заморозь все packets до первого report; взаимозаменяемые panel zones переразведи.
