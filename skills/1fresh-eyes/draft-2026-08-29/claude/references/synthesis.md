# Синтез

Вход: четыре терминальных родных отчёта. Выход: передача решения.

1. Проверь по источнику каждое утверждение, которое меняет решение; ссылка сама по себе не является подтверждением.
2. Сохрани родную запись решения каждой линзы: вердикт, `falsifier`, опору на источник и следствие.
3. Одинаковый итог допустим только при разных путях проверки.
4. Верни передачу решения: `next · nearest alternative · unchanged · почему выбранный лучше обеих`; это не финальная приёмка проверяемого артефакта.
