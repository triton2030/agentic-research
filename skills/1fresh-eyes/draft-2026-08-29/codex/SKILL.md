# Свежие Глаза

## Уникальный контекст

Долгая работа сужает рамку main.
Свежесть создаёт новый поток, который получает проверяемый объект без интерпретации main и применяет собственную роль.

## Цель пользователя

- Материальная развилка получает четыре независимых отчёта; явно названная пользователем роль получает один native report.
- Fresh streams опираются на raw evidence и разные panel zones, а не на объяснение main.
- Владелец решения выбирает следующий ход, альтернативу или подтверждённое продолжение без изменений.

## Протокол поведения

> «должен вызываться во время длинной работы […] когда нам надо проверить траекторию движения»; цель — «чтобы агенты дали очень разные отчеты».

> «не будем использовать в скилле свежих глаз никаких других субагентов, кроме вот этих трёх»; «У нас три агента […] и 4 агент премортем».

## Стадии

1. Наблюдаемый trigger → decision anchor: прочитай [decision](references/decision.md).
2. Panel anchor → frozen packets: прочитай [panel packet](references/panel-packet.md).
3. Frozen panel packets → terminal cross-family report: прочитай [Premortem](references/premortem.md).
4. Terminal Premortem, retained outside packets → three terminal native reports: прочитай [native panel launch](references/panel-launch.md).
5. Available reports и explicit skip → evidence ledger: прочитай [classification](references/classification.md).
6. Evidence ledger → decision handback: прочитай [synthesis](references/synthesis.md).
7. Named anchor → frozen role packet: прочитай [named packet](references/named-packet.md).
8. Frozen role packet → terminal native product: прочитай [named launch](references/named-launch.md).
9. Terminal native product → handback: верни его без смены формы.
10. Wrong source-bound premise или residual question той же линзе → repaired report: прочитай [steering](references/steering.md).
