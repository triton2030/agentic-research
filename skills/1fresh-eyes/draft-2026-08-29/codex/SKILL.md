# Свежие Глаза

## Контекст

Длинная работа сужает рамку main. Новый поток становится свежим только когда
получает объект решения без объяснения main и проверяет его своей ролью.

## Цель пользователя

- На материальной развилке панель даёт четыре независимых взгляда; явно названная пользователем роль возвращает свой native product без панели.
- Fresh stream получает проверяемые факты и другие главные источники, но не rationale, diagnosis или желаемый verdict main.
- Панель выбирает следующий ход, альтернативу или продолжение без изменений; подтверждённый текущий маршрут полноценен.

## Протокол поведения

> «должен вызываться во время длинной работы […] когда нам надо проверить
> траекторию движения»; цель — «чтобы агенты дали очень разные отчеты».

> «не будем использовать в скилле свежих глаз никаких других субагентов,
> кроме вот этих трёх»; «У нас три агента […] и 4 агент премортем».

1. Покажи вопрос на столе.
2. Покажи, какое решение изменит ответ.
3. Назови конечный результат из GOAL/Product Frames; при их неполноте выведи его из имеющегося и профессиональных практик.
4. Материальная траекторная развилка → panel mode; явно названный пользователем critic, `auditor` или `md-scout` → named mode.
5. Panel mode → прочитай [native panel launch](references/panel-launch.md), затем [cross-family Premortem](references/premortem.md); named mode → [named launch](references/named-launch.md).
6. Неверный факт или остаточный вопрос той же линзе → [steering](references/steering.md); corrected stream не становится новым голосом.
7. Panel mode всегда проходит [synthesis](references/synthesis.md); named mode возвращает native product без смены его формы.

## Стоп

- Без вопроса и decision consequence панель не запускается.
- Недоступную роль или runtime не имитируй; временную нехватку слотов пережди или разложи на bounded waves.
- Панель не правит проверяемый артефакт и не объявляет final acceptance.
- Критика не самоцель: source-supported продолжение текущего маршрута завершает работу.
