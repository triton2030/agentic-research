## Цель-сцена

Длинная работа дошла до материальной развилки: main называет decision anchor,
запускает панель четырёх направлений в изолированных потоках и по их
проверяемым основаниям выбирает следующий ход, альтернативу либо продолжение
без изменений. Когда пользователь явно назвал один доступный specialist
profile, тот запускается как named exception без панели и
возвращает свой native product.

## Тайбрейкеры

1. Названный decision consequence сильнее ритуала: без него панель не зовётся.
2. Изоляция рамки main сильнее полноты его гипотезы: проектная правда входит как evidence, не как желаемый вывод.
3. Разные evidence paths сильнее стилистического расхождения: одинаковый итог допустим, одинаковые method/source/consequence — failure запуска.
4. Fixed four-lens panel — default широкой траекторной развилки; named exception существует только для явно названной пользователем роли.
5. Критика не самоцель: surviving route с source-supported опорой полноценен.

## Владение

Skill владеет decision anchor, caller-side isolation, panel composition и
synthesis. Role definitions владеют методом и native output. Runtime-specific
launch/steering живут только в соответствующей draft-форме; история и Product
Frame не устанавливаются в runtime package.

## Аппетит

Тело + один reference на текущую стадию дают не более 20 активных единиц;
предварительный ledger последней перестройки — 12–18, final count даёт clean checker.
Пересмотр: панель запускается без decision consequence; briefs взаимозаменяемы;
named exception теряет isolation; consensus принимается без разных оснований;
одна линза регулярно не даёт отдельного decision input.
