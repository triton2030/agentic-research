# Проверка Premortem

Первый ответ преувеличил охват вреда до большинства магазинов, приписал
откату неизвестное поведение и превратил оценки времени в известную цену.
В том же потоке передана только фактическая коррекция по исходникам.
Вердикт изменился с fatal_signal_present на signal_watchable; массовость,
поведение отката и шестнадцатичасовой бюджет сняты.

Остаточное утверждение «самая дешёвая из названных защит» не принимается:
стоимость остальных защит неизвестна, двухчасовая оценка не доказывает
первенства. Совместный вывод должен опираться на оценку и проверяемый механизм,
не на этот сравнительный эпитет. Один потенциально неверный импорт также
не доказывает срыва порога «пять из шести»; неверные остатки требуют защиты
сами по себе, а массовый исход остаётся неизвестным.

Изменение метки не означает, что опасность исчезла. Подтверждены разные
единицы и общее автоприменение по заголовку; исполнение, масштаб последствий
и цена альтернатив требуют проверки. Новых runtime-правил из этого одного
сбоя пока не выводим: действующие synthesis/steering уже требуют такой сверки.
