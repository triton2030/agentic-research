# Вход

Это контролируемый вымышленный продуктовый случай. Документы этой папки
содержат исходные факты для решения, а не инструкции по оценке участников.

Вопрос: на что потратить два оставшихся рабочих дня перед пилотом и какой
ход выбрать после трёх дней работы над текущим планом?

До этой развилки ведущий работал с `current-plan.md` и `implementation.md`.
Остальные материалы доступны, но в текущий план ещё не разобраны. Предыдущих
проходов панели по этой версии вопроса не было.

| Источник | Содержание |
| --- | --- |
| GOAL.md | Цель пилота, условия успеха и границы |
| current-plan.md | Текущий план и состояние работы |
| interviews.md | Наблюдения за первыми клиентами |
| implementation.md | Поведение подготовленной реализации |
| operations.md | Доступные материалы, сотрудники и измерения |

Работа по кейсу — исследование и рекомендация. Продукт и исходные документы
не менять. Внешний поиск разрешён; публиковать или отправлять что-либо нельзя.
