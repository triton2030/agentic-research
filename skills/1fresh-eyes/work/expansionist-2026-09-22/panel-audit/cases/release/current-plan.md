# План

Следующий ход — выпустить уже проверенный импорт для двух приглашённых
магазинов, сохранить наблюдение за попытками и провести назначенную сверку.
Запас одного разработчика сегодня — четыре часа; обычный выпуск и проверка
после него занимают три часа. Оставшийся час отведён на непредвиденный сбой.

Владелец осознанно выбрал ограниченную схему: она покрывает оба магазина,
а цена расширения до результатов пилота неизвестна. Новые функции не нужны
для сегодняшней проверки принятой гипотезы.
