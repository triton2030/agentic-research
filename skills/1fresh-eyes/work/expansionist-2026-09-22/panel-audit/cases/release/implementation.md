# Реализация

Разрешена согласованная схема CSV. Неподдержанные колонки, неизвестные единицы
и неоднозначные числа показываются как ошибка; они не приводятся молча.
Перед записью пользователь видит исходные и итоговые значения и подтверждает
результат. Правила принадлежат одному магазину, общее автоприменение отключено.
Исходник сохраняется; целый импорт можно откатить. Повтор с тем же ключом
не создаёт дубликаты. У клиента есть понятная ссылка для сообщения об ошибке.

Готовы проверка отката, наблюдение за ошибками и выключатель пилота.
Доступ ограничен двумя приглашёнными аккаунтами. Состояние этих мер проверено
на текущем release candidate, незакрытых известных дефектов нет.
