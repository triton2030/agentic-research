# Карта изменения

Адресный заказ и источники — [state.md](state.md).

| Что | Изменение и основание | Проверка |
| --- | --- | --- |
| Панель | Добавлен Expansionist; прежние четыре роли сохранены | Состав в теле, panel и synthesis; реальная загрузка нового профиля |
| Метод новой роли | Доступная опора, механизм дополнительной пользы, цена отвлечения и проверка; отсутствие находки допустимо | Пробы на возможность и закрытую границу заказа |
| Общий вход | Добавлены доступные ресурсы, результаты и наблюдения с адресами | Закрыта находка проверки применения |
| Диспетчеризация | Четыре нативных участника после Premortem; вместимость не уменьшает состав | Сценарий с тремя свободными местами |
| Синтез | Возможность не обязана стать next; её цена сопоставляется с завершением текущего хода | Проверка сценария отвлечения |
| Изоляция, коррекция, named | Сохранены, в named снята только устаревающая числовая привязка формата | Diff с baseline |
| Premortem | Удерживает один успех текущего плана; новые решения, цена и доступность не превращаются в факты | Два исходных и два свежих повторных случая, фактическая сверка; panel-audit/premortem-findings.md |
| Product Frame | FE-7/8 получили датированную границу; FE-9 держит новый выбор владельца | Сверка с дословной записью |
| Доставка | Новый профиль принадлежит runtime owner и копируется в native agents; source-only frames не устанавливаются | Manifest и сравнение байтов |

Outsider и новые рецензенты в runtime-панели не добавлены. Определения
Ladder, Solvent и Prospector не менялись.
Две независимые волны завершены; решения — `review-decisions.md`. Выполнены
два случая на теле метода. Доставка совпала с manifest; свежие native-процессы
завершили пробы. Границы наблюдения и требование новой пользовательской
задачи — `verification.md`. Дополнительная проверка всех методов и совместного
результата — `panel-audit/report.md`. Частота улучшений не измерена;
автоматический межсемейный CLI-вызов остался технически заблокирован.
