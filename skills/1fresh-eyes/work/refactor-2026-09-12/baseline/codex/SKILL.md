# Свежие Глаза

## Уникальный контекст

Долгая работа сужает рамку главного агента: даже просьба о проверке может незаметно передать свежему потоку его объяснение. Свежесть создают новый поток, нейтральный пакет с опорой на источники и разные главные зоны поиска; роль владеет своим методом и формой ответа. Ценность панели — в расхождениях, а решение остаётся у главного агента.

## Цель пользователя

- Материальная развилка получает четыре независимых отчёта; явно названная роль — один родной результат без панели.
- Каждая линза получает общий якорь решения без обоснования и желаемого вердикта главного агента, затем ищет свой источник и `falsifier`.
- Владелец получает проверенные `next` / `alternative` / `unchanged`; контроллер сохраняет родные выводы и не голосует. Критика может испортить хорошую работу, поэтому подтверждённый источниками `unchanged` полноценен.

## Протокол поведения

> «должен вызываться во время длинной работы […] когда нам надо проверить траекторию движения»; цель — «чтобы агенты дали очень разные отчеты».

> «не будем использовать в скилле свежих глаз никаких других субагентов, кроме вот этих трёх»; «У нас три агента […] и 4 агент премортем».

## Ход

1. Собери якорь решения: вопрос на столе, что изменит ответ и конечный результат из GOAL/Product Frames; при пробеле выведи профессиональный результат из доступных доказательств.
2. Из якоря решения до первого отчёта собери замороженные [пакеты](references/packet.md).
3. Для `mode: named`: если `profile: premortem`, передай пакет в [Premortem](references/premortem.md), иначе — [именованному специалисту](references/named.md); ошибочную посылку исправь через [коррекцию](references/steering.md), затем верни родной результат или точный `blocker` и останови проход Fresh Eyes.
4. Иначе сначала получи [Premortem](references/premortem.md) другой модельной семьи, затем три отчёта [нативной панели](references/panel.md); любой `blocker` останавливает проход как `panel_incomplete`.
5. Ошибочную посылку исправь через [коррекцию](references/steering.md) и замени исходный отчёт.
6. Четыре устойчивых отчёта передай в [синтез](references/synthesis.md).
