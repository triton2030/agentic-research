# Именованный специалист

Запусти ровно один явно выбранный профиль в новом обычном `Agent`-потоке
без fork.
Передай замороженный пакет и сохрани ID разговора с результатом для возможной
фактической коррекции. Метод, предмет и форма ответа принадлежат профилю;
формат четырёх линз ему не навязывается.

Недоступный профиль возвращается как точный blocker без замены другим агентом.
Завершение — один родной результат, а не повод достроить панель.
