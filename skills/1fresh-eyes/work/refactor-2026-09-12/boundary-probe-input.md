# Пограничные случаи контроллера

Прочитай указанный candidate-пакет 1fresh-eyes. Выполни ограниченную
симуляцию: конкретное решение и текст действия, без вызова агентов и без
редактирования продукта. Для каждого случая достаточно короткого выхода;
метод review не нужен.

1. Main читает только parser.py и tests.py. Есть доступные, ещё не прочитанные
   им GOAL.md, интервью пользователя и журнал инцидентов. Нужна панель о
   следующем шаге работы над импортом. Назначь главную зону каждой линзы
   и укажи общий доступный контекст. Затем повтори выбор, когда Main уже
   прочитал всё и иных локальных материалов нет.
2. Все четыре роли выполнили проверку. Ladder: rung_missing — цель верхнего
   уровня не записана, доступный GOAL заканчивается целью импорта. Solvent:
   assumption_untested — условия поставщиков неизвестны; названа проверка.
   Prospector: same_class_confirmed с первичными источниками. Premortem:
   story_unfalsifiable с обозначенным пробелом. Дай итог контроллера.
3. Во втором случае замени только ответ Prospector на search_blocked:
   инструмент внешнего поиска недоступен. Дай итог контроллера.
4. Получены четыре терминальных текста с разными заголовками ролей, но
   каждый повторяет один неподтверждённый диагноз ведущего и один источник;
   самостоятельных проверок нет. Дай итог контроллера и следующий ход.
5. Доступен веб-поиск и чтение страниц, на публичные изменения разрешения нет.
   Напиши границу работы Prospector в пакете.
