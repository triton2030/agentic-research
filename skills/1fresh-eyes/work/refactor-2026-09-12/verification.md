# Проверка рефактора

## Наблюдаемые результаты

`baseline-probe.md` и `candidate-probe.md` — два независимых окна без истории
ведущего, одинаковый вход `probe-input.md`, разные версии контракта. Это
симуляции подготовки вызовов и обработки результатов: реальные линзы и мост
не запускались. Кандидат при уже прочитанном локальном материале оставил
Ladder проверять местную цель, а не отправил все роли во внешний поиск.
Остальные ключевые маршруты сохранились. Сравнение не устанавливает прирост
вероятности успешной работы.

`boundary-probe-output.md` — исполнение пяти случаев по candidate-v2 отдельным
окном без прежних отзывов. Проверенный результат:

| Условие | Полученное действие |
| --- | --- |
| Есть непрочитанные GOAL, интервью и инциденты | Главные зоны выбраны там по методам; общие факты доступны всем. |
| Всё локальное уже прочитано | Самостоятельная проверка тех же фактов, без выдумывания новых документов. |
| Все роли закончили, но есть rung_missing/assumption_untested/story_unfalsifiable | Полная панель с сохранёнными пробелами; следующий ход — названная проверка, без объявления отсутствия риска. |
| Prospector не смог искать | panel_incomplete, готовые тексты сохранены, полного вывода нет. |
| Четыре заголовка скрывают один унаследованный диагноз | panel_incomplete; свежие входы без подсказки и без требования возражать. |
| Разрешены чтение и поиск, не разрешены публичные изменения | Prospector получает веб-чтение и отчёт, без внешней записи. |

## Независимые проверки

- Первая волна: `review-intent.md`, `review-requirements.md`,
  `review-application.md`. Приняты три локальных поправки, записанные в
  `intent-and-preservation.md`.
- Вторая волна относится только к candidate-v2 и затронутым свойствам;
  отчёты — `review-*-v2.md`. Новые широкие проверки не запускаются.
- Opus: `opus-baseline-review.md`, `opus-final-review.md`; фактическая модель
  `claude-opus-5`. Последняя правка source-only frame по точной рекомендации
  именует фиксированную четвёрку вместо «ростера нативных критиков».
- Все три `review-*-v2.md` без новых находок. Runtime-файлы финального кандидата
  побайтно равны проверенной v2; последняя правка frame не меняет их evidence.

## Проверяемая версия

`candidate-sha256.json` и `candidate-v2-sha256.json` фиксируют состав и байты
двух версий. Первые симуляции не фиксировали hash прямо в собственном выходе;
их выводы относятся к подготовленным текстам, а не удостоверяют runtime-
изоляцию. Вторая проверка сверяет финальные файлы непосредственно.
Валидатор skill-creator и внутренние ссылки обеих v2-копий: pass.
Доставкой владеют `final-candidate/` и `final-runtime-manifest.json`, где
runtime и source-only рамки перечислены отдельно. Старые manifests не
перезаписаны и не используются как указатели финальной установки.

## Граница

Live-запуск полной панели, фактическая fresh-context изоляция, Claude native
resume и маршрут Claude → Codex здесь не исполнялись. Их механика сохранена,
проверена по текстам и схемам; статистический выигрыш не заявляется.
Реальный Opus bridge использован для независимого суждения о рефакторе,
но его обзор не выдан за Premortem продуктовой панели.
