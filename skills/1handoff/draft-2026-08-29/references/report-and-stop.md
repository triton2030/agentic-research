# Отчитайся и остановись

Вход: исход `consumer check` либо точный блокер записи пакета.
Выход: четыре исхода у владельца в чате.

Действует всю стадию:

- Заблокированный исход не стирает успешный.
- Остаточный риск называй только для контекста, до которого не удалось
  добраться, и для утверждений, которые не удалось проверить.

По порядку:

1. Отчитайся по каждому независимому исходу ровно один раз: `recall` —
   `captured`, `no qualifying evidence` или `blocked`; `cleanup` — названные
   изменения, `nothing to clean` или `handed off`; `packet` — точный путь или
   `blocked`; `consumer check` — `passed`, точный блокер либо `не выполнялся`.
2. Назови отдельно каждый блокер, который не является ни одним из этих четырёх
   исходов.
3. Добавь одну строку о том, что в пакете, когда пакет существует.
4. Остановись, когда ни новый текст, ни новая уборка уже не могут изменить то,
   что сделает следующий агент.
