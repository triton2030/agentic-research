You are closing a session, not opening an audit. Before anything is written
into `_ops/handoffs/`, the owner's words of this session belong to their own
owner, and no management file still asserts something this session made false.

   imitate recall yourself: the corpus holds the owner's literal words, and a
   paraphrase written elsewhere is not the same asset.

   for it, expose `no recall address` separately as a continuation blocker with
   its consequence, and do not relabel recall's own outcome to absorb it.

   authority this task already had, and only where a single Git operation could

   approval-dependent work with its consequence instead of performing it.

   or unsafe.
