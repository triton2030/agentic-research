# Независимая проверка v4 · раунд 1

## Literal checker

Приняты все девять находок: русский instructional prose; честный active-set
count; определение переносимой поверхности; runtime-owned metadata без лишнего
project-root условия; authority gate снятия; условная квитанция; новые trigger
checks; сохранённая реалистичная проба; source-basis до commander's intent.

## Trajectory checker

- Принято: точное утверждение состояния отсутствия перед снятием.
- Принято: после конфликтной правки требуется новый полный цикл и новое точное
  утверждение.
- Принято: metadata разрешается по runtime ownership вне переносимой
  поверхности, а не только по root-инструкциям целевого проекта.

## Коррекция

Candidate переписан русским instructional prose, определяет переносимую
поверхность, связывает любые изменённые bytes с новым approval, проводит снятие
через точное утверждение и разделяет evidence ветвей. Source basis и фактическая
v4-проба сохранены отдельно. Новые trigger checks и повторная реалистичная проба
выполняются на исправленной версии во втором раунде.
