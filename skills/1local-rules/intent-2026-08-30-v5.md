# Commander's intent v5 · простая runtime-форма

Статус: вход нового clean-room исполнителя.

Official owner, projections и live packages до exact approval не изменяются.

## FAST

Higher-order function: project-local skill даёт одному проекту одинаковое
поведение в Claude и Codex, не становясь глобальным правилом и не ослабляя
старшие инструкции.

Basic function: обычное создание и проверка остаются у `1skill-creation`;
локальная дельта сообщает один проект, имя `2*`, две runtime-проекции и
наблюдаемое состояние `одинаково присутствует | везде отсутствует`.

Не функция: повторять authoring/check/approval flow, задавать универсальную
repo-топологию, перечислять portable manifest, предписывать rollback,
drift-recovery, квитанции или отдельные стадии ради контроля процесса.

## Уникальный контекст

Компетентный агент уже умеет создавать обычный skill и обязан следовать
применимым global/root/project instructions.

Без `1local-rules` агент не знает только локальное соглашение владельца:
package принадлежит одному проекту, начинается с `2`, работает одновременно в
Claude и Codex и не считается завершённым в частичном состоянии.

Поэтому runtime-скилл передаёт эту дельту через цель и границы решений, а не
встраивает внутрь себя бюрократию собственного refactor-а.

## Цели

- Обычный lifecycle и exact approval остаются у `1skill-creation` и применимых
  старших инструкций.
- Project-local package относится ровно к одному проекту, называется `2*` и
  использует только объявленный проектом route для Claude и Codex.
- Принимаются только совместимые со старшими инструкциями terminal states:
  общая поверхность совпадает у owner и обеих projections либо package
  отсутствует во всех трёх местах.

## Границы простоты

Каждая runtime-инструкция остаётся только с названным counterfactual harm при
удалении.

References и стадии отсутствуют, пока clean probe не докажет независимый
режим, который нельзя безопасно вывести из этого intent.

Механическое дробление перегруженного процесса не считается сокращением.

## Наблюдаемая приёмка

Use-case распознаёт ordinary skill, который нужен одному проекту как `2*`
одновременно для Claude и Codex.

Global skill и Claude-only local skill не активируют этот runtime-маршрут.

В реалистичном update/retire case агент использует объявленный проектом route,
не изобретает owner, не ослабляет старшие инструкции и не принимает partial
state.

Одновременно активный runtime-набор остаётся не больше 20 самостоятельных
единиц без reference-sharding.

Применение принципов: P-002 оставляет агенту автономность, P-003 удерживает

параллельную правду; из-за этого выбран один self-contained runtime contract,
а не новые references или второй owner.
