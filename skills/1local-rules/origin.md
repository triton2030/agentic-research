# Исходная функция

До рефактора функцию держал
`skills/claude/1local-rules/SKILL.md`; исходная tracked-версия доступна в git
по commit `56681e2161169a09056ade28864906465ed7d6c5`.

Скил нужен в момент, когда одно критичное правило одного проекта должно
всплыть не в начале сессии, а при конкретном наблюдаемом действии. Его продукт
— локальный rule-skill `2*`, который меняет действие агента и синхронизирован
между Claude и Codex из одного владельца.
