# Карта сохранности и простоты v5

## Сохранено из функции

| Смысл | Где удержан |
| --- | --- |
| Обычный skill creation | Ownership `$1skill-creation` в Уникальном контексте |
| Один проект | Отдельная строка локальной дельты |
| Префикс `2` | Отдельная строка локальной дельты |
| Claude и Codex | Один общий package в обеих средах |
| Global/root compatibility | Отдельная старшая граница |
| Project-owned topology | Owner, projections и sync только из project sources |
| Create/update terminal state | Один package у owner и в обеих projections |
| Retire terminal state | Отсутствие во всех трёх поверхностях |

## Поглощено commander's intent

| Прежняя процедура | Почему отдельная runtime-инструкция не нужна |
| --- | --- |
| Полный authoring/check/approval flow | Уже принадлежит `$1skill-creation` |
| Повторный conflict-check protocol | Граница «не противоречит старшим инструкциям» меняет решение без локальной копии процесса |
| Отдельный install workflow | Проект сам объявляет owner и sync route |
| Portable manifest | Объявленный project route определяет shared surface |
| Runtime metadata exception | Проектный route определяет допустимую platform delta |
| Адресная квитанция | Terminal state сформулирован как наблюдаемое доказательство |

## Снято

| Средство v4 | Counterfactual после удаления |
| --- | --- |
| References и стадии | Независимого режима не наблюдается; один lifecycle-момент использует всю локальную дельту |
| Собственный exact approval flow | Удаление не меняет authority: creator и старшие инструкции уже владеют approval |
| Rollback | Нет наблюдённого failure mechanism; terminal invariant не позволяет принять partial state |
| Drift-recovery | Drift остаётся обычным update case через project route |
| Отдельные receipts для веток | Present/absent terminal states дают прямую проверку без формата отчёта |
| Каталог edge cases | Новый owner-критерий запрещает процесс без конкретного вреда |

## Оправдание оставленных body-единиц

| Единица | Дефолт | Механизм | Изменяемое решение | Вред без строки | Цена строгости |
| --- | --- | --- | --- | --- | --- |

| Один проект | Переиспользовать шире | Skill content выглядит переносимым | Ограничить package одним проектом | Project-only anchors протекут наружу | Нельзя автоматически сделать package глобальным |
| Префикс `2` | Выбрать обычное имя | Имя кажется косметикой | Сохранить local routing convention | Потеряется распознавание локального package | Фиксированный namespace |
| Claude и Codex | Установить текущий runtime | Текущая среда кажется достаточной | Требовать dual-runtime package | Вторая среда останется stale | Single-runtime package сюда не входит |
| Creator lifecycle | Создать локальный workflow | Skill вызван для lifecycle | Делегировать обычную часть creator-у | Дублирование review/approval | Локальная надстройка зависит от creator contract |
| Ранняя передача дельты | Проверить локальность после draft | Обычный candidate уже выглядит готовым | Передать scope до authoring | Candidate сформирован под неверный scope | Более ранний blocker |

| Project-declared route | Вывести topology из файлов | Ближайшая projection похожа на owner | Использовать только объявленный route | Появится второй owner | Проект обязан объявить route |
