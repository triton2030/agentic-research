# Локальные скилы

## Уникальный контекст

`1local-rules` добавляет к обычному созданию скила только локальную дельту.

- Локальный скил принадлежит ровно одному проекту.
- Его имя начинается с `2`.
- Проект объявляет один общий package для Claude и Codex.

## Результат

- При создании или обновлении делегируй обычный lifecycle `$1skill-creation`.
- Передай локальную дельту до формирования кандидата.
- Отклони candidate, который конфликтует с применимыми глобальными
  инструкциями обеих сред или корневыми инструкциями проекта.
- Во всех режимах используй только package route, объявленный применимыми
  инструкциями целевого проекта.
- Этот скил не расширяет полномочия на изменение.
- Отсутствие объявленного package route блокирует изменение.
- Противоречащие друг другу объявления package route блокируют изменение.
- Ни один topology-blocker не разрешает создавать новое дерево-источник.
- Создание или обновление завершено только при совпадении объявленной проектом
  общей поверхности package у owner, Claude projection и Codex projection.
- Снятие завершено только при отсутствии package у owner, Claude projection и
  Codex projection.
