# Agentic Research

`agentic-research` — база знаний и правил для проектирования скилов, агентных
инструкций, system prompts и соседних ИИ-control surfaces под `GPT-5.5` и
`Claude Opus 4.7`.

Проект не является runtime-кодом агентов и не хранит каталог project artifacts.
Его задача — чтобы новая ИИ-сессия или внешний разработчик быстро понял:

- какие локальные знания читать перед правкой;
- где лежит стратегия проекта;
- какие критерии приёмки применяются к типу работы;
- какие старые паттерны больше не являются рабочим baseline.

## Как Читать

1. `AGENTS.md` — основной маршрут для Codex: структура, приоритеты, куда класть
   новые правила и какие скиллы вызывать.
2. `CLAUDE.md` — компактный слой для Claude Code с теми же границами.
3. `_ops/PROJECT-ROADMAP.md` — верхняя стратегия: цель, подход, стадии и
   анти-цели. Это не task tracker и не место для критериев приёмки.
4. `_ops/criteria/*.md` — постоянные критерии приёмки по сфере будущей работы.
   Критерии выбираются по задаче и готовности для агента, а не по пути файла:
   один и тот же файл может требовать criteria для текста, дизайна, repo-shape
   или instruction-layer.
   Папочные инструкции могут перечислять несколько таких файлов, если в папке
   есть разные типы работы.
5. `knowledge/` — input-layer: wisdom, guides, practical guides, examples и
   research, которые агент читает перед authoring.

## Почему Так

`PROJECT-ROADMAP.md` отвечает на вопрос “куда идём и почему”. `_ops/criteria/`
отвечает на вопрос “как понять, что работа принята”. `knowledge/` отвечает на
вопрос “на каких знаниях строим решение”.

Старые постоянные файлы `INTERVIEW.md` и `LEARNINGS.md` удалены как отдельные
owner surfaces. Их устойчивый смысл перенесён в root-инструкции, README и
criteria-файлы. Разовые исторические эпизоды не переносятся.

## Правило Критериев

Критерий появляется только из явного пользовательского сигнала или принятого
источника проекта, на устойчивый паттерн, а не на разовый эпизод.

Точный шаблон и протокол записи criteria держит живой `1user-truth`, чтобы
цели, красные линии и правила качества не расползались по разным инструкциям.
